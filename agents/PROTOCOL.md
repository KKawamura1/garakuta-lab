# エージェント代理プレイ：手順と事前登録

## 目的

人間の初見は1設計につき生涯1回しか使えない。この希少資源を節約するため、AIエージェントに同じルールを同じ情報条件でプレイさせ、**候補設計の順位付けに使える代理指標**が成立するかを調べる。

目標は感情語の再現ではない。狙うのは**認識状態の軌跡**、すなわち「何を予想し、何に困り、何で評価が変わったか」の系列である。感情の強度は自己申告させず、行動とログから機械計算する。

## 情報条件

エージェントが見るもの（人間のUIと同じ範囲）:

- 現在のHP・修復材・戦闘番号
- **次の敵だけ**の名前・HP・攻撃・装甲・特徴文
- 駆動列5枠と予備部品、それぞれの効果説明文
- 直前の戦闘の全巡回ログ、部品別の働き、余った資源
- 報酬候補3個

見せないもの:

- 将来の敵の数値、乱数シードの内部状態
- 敵の`rage`・`heat`係数の数値（特徴文でのみ示唆される）
- 部品の内部実装、勝てる配置の探索結果

## 禁止事項（総当たりの防止）

学習ログ#14が示したとおり、全配置を列挙できる主体は「隠れた正解を当てるパズル」の不快さを体験しない。したがってエージェントには次を禁じる。

1. `core/` `agents/` 以下のソースを読むこと
2. 戦闘結果を試算するスクリプトを書くこと
3. セッションファイルを直接編集すること
4. 同じ意思決定点をやり直すこと

エージェントは `agents/session.mjs` のCLI出力だけを見て、1回ずつ決める。

## 手順

```bash
node agents/session.mjs rules
node agents/session.mjs start  --session=<path> --seed=<n> --player=<id>
node agents/session.mjs act    --session=<path> --json='{"type":"place","partId":"p3","slot":2}'
node agents/session.mjs act    --session=<path> --json='{"type":"battle","prediction":"ギリギリ","worry":"装甲","worryText":"..."}'
node agents/session.mjs finish --session=<path> --json='{"replay":3,"bestMoment":"...","pivot":"あった","runStory":"..."}'
```

戦闘の直前には必ず勝敗予測と現在の最大の不安を、報酬取得時には必ず理由と認識更新の種別をコミットさせる。**結果を見た後で「驚いたか」を聞かない。** 驚きは予測と結果の差として機械計算する。

## 対照

同じコアを、認識トレースを持たない2つの機械方針でも走らせる。

- `naive`：予備部品を先頭から5枠へ入れ、以後動かさず、報酬は常に候補1を取る
- `local`：現在の敵だけを見て、入替と隣接交換を3回まで山登りする（GATE v2の局所探索プレイヤー相当）

`local` は全敵の内部数値を参照する。人間相当の情報条件ではなく、機械的最適化の下限・上限を示すための対照である。

## 事前登録された予測

エージェントを走らせる前に記録する。結果を見てから基準を動かさない。

- **P1 勝敗と面白さの分離**：認識指標（`problemChainRate`・`reinterpretationRate`・`deadTime`の少なさ）が、勝ったランを一律に高く評価しないこと。人間ログでは勝利は再プレイ度に対して −0.75 だった。勝ちを高く評価する指標は、面白さではなく強さを測っている。
- **P2 死に時間の検出**：無傷のまま圧勝予測が続いて終わるランに `dead_time` 警告が立つこと。ARC 0.1の装甲2枚ランで人間が「勝ち確定してからが長い」と記録した区間に対応する。
- **P3 単一ゲートの検出**：ARC 0.1の人間3ランでは感情の大半が装甲へ集中した。エージェント走行でも `single_gate` または `single_worry` の警告が過半のランで立ち、出力集中の首位が防御系部品に偏ること。偏らなければ、この指標は人間の観測を再現していない。
- **P4 代理としての下限**：エージェントの `problemChainRate` と `reinterpretationRate` が `naive` を明確に上回ること。`local` を大きく下回る場合、認識トレースの質が機械的最適化以下であり、代理として使えない。

いずれも合成得点にはしない。P1が破れた場合、指標の再設計からやり直す。

## 現時点の限界

人間の実ランに対する完全な遡及テスト（同じ意思決定点で同じ情報を与え、予測と不安を照合する）には、D1のイベントログのエクスポートが要る。リポジトリ内には集計済みの `analysis/emotional-arc-observations.json`（22ラン分の要約）しかないため、今回検証できるのは構造側の半分だけである。エクスポートが手に入り次第、同じCLIで人間の行動列を再生し、予測の一致率を測る。

## 第3回の事前登録：既知条件のエージェントは、退屈を検出できるか（P6）

第1回・第2回で、エージェントの再プレイ度は8ラン中6件が有効で 3,3,3,3,4,4、標準偏差0.47だった。
一方、作者は同じ盤面（ARC seed 14）に1を付け、「いつものパターンに持ち込めた回」「勝ち確定してつまらない」
と記録した。**エージェントは、人間が最低評価を付けた盤面を3と評価した。** 順位付けの道具としては、この時点で失格である。

原因の仮説は「エージェントが支配戦略を知らないから」である。作者は装甲支配を知っていて、
それを綺麗に実行できたために退屈した。初見のエージェントは同じ盤面で苦戦し、面白がった。

そこで `node agents/session.mjs brief` で全部品・全敵・全数値を先に見せ、戦略を立ててから遊ばせる条件を作る。
検証は **ARC seed 14**、つまり作者が1を付けた既知の盤面で行う。

- **P6-a 支配線への到達**：brief条件のエージェントが、防御部品（即席装甲機）を最終構成に入れて勝つ。
  初見条件では4体中1体しか入れなかった。3体中2体以上が入れれば到達とみなす。
- **P6-b 退屈の検出**：brief条件の再プレイ度が、同じ盤面の初見条件（3, 3）より低い。
  中央値が2以下なら検出とみなす。3以上のままなら、brief では熟練の退屈を再現できていない。
- **P6-c 決着点の前倒し**：申告する決着点が、初見条件（第6戦・第5戦）より早い。作者の申告は第3戦だった。

いずれも合成得点にしない。**P6-b が破れた場合、「全情報を先に見せる」では熟練条件を作れないと判断し、
記憶の持ち越し（同じ設計を複数ラン遊ばせる）へ切り替える。**

brief条件でも禁止事項は変わらない。ソースは読ませず、戦闘の試算スクリプトも書かせず、全配置の列挙もさせない。
渡すのは、ゲームが本来プレイヤーへ提示しうる情報だけである。

## 第4回の事前登録：PHASE 0.1 の人間テスト（P7）

PHASE 0.1 は機械評価で ARC 0.1 を上回った。ただし**難易度の最適点は、判定に使う指標を見ながら選んだ**。
これは学習ログ#19でCYCLE 0.2を平坦化させたのと同じ手順であり、オーバーフィットの疑いは晴れていない。
そこで人間が遊ぶ前に、指標が主張する内容を外れうる形で書き出す。

機械評価が言っていること（局所探索60シード）：

| | ARC 0.1 | PHASE 0.1 | 指標の主張 |
|---|---:|---:|---|
| 無傷勝利率 | 0.525 | 0.411 | PHASEの方が圧力がある |
| 首位部品の最頻シェア | 0.417 | 0.317 | PHASEの方が収束しない |
| 採用率5%未満の部品 | 1 | 0 | PHASEに死に部品はない |
| 勝ち筋ゼロ率 | 24.0% | **3.5%** | PHASEは理不尽な盤面が少ない |
| 死に時間 | 0.083 | 0.683 | **PHASEの方が悪い** |
| 問題の連鎖 | 0.511 | 0.335 | **PHASEの方が悪い** |

### 予測（改善side）

- **P7-a 圧力**：作者のPHASEランの無傷勝利率が 0.5 未満。ARC seed14 は 0.833 だった。
- **P7-b 警告数**：作者のPHASEランの警告が3件未満。ARC seed14 は4件だった。

### 予測（悪化side。ここを外したら指標が体験を追えていない）

- **P7-d 死に時間と問題の連鎖**：作者のPHASEランで、死に時間が1以上、または問題の連鎖が0.4以下になる。
  指標はPHASEがこの2点でARCより悪いと言っている。**もし作者が「問題が次々に立ち上がって最後まで飽きなかった」と
  報告したら、この2指標は体験を測れていない**ことになり、評価器の側を作り直す。

### 予測（機構が知覚できているか。最も重要）

- **P7-c 位相が判断になっているか**：作者が、部品の集合を変えずに枠を移す操作（作動巡回を変える操作）を
  2回以上行い、かつ自由記述か不安の申告で、タイミング・位相・巡回のいずれかに触れる。

  **これが外れた場合が、オーバーフィットの本命の形である。** 収束や多様性の指標が改善しても、
  その改善がプレイヤーに知覚できない内部構造の話でしかないなら、指標は面白さと無関係な量を測っている。

### 予測（ビジーさ。作者本人の事前仮説）

作者はプレイ前に「位相は基本的にルールを複雑にする方向なので、ややビジーなゲームになる」と述べた。
これを予測として記録する。

- **P7-e 認知コスト**：作者が、自由記述・不安の申告・報告のいずれかで、
  ルールの重さ・把握しづらさ・煩雑さに相当する不満を述べる。

認知コストの計測値は次のとおり。保持概念と敵修飾子はPHASEの方が多く、部品説明の字数は少ない。

| | ARC 0.1 | PHASE 0.1 |
|---|---:|---:|
| 保持概念数 | 6 | 8 |
| 規則行数 | 8 | 8 |
| 敵修飾子の種類 | 3 | 4 |
| 部品説明の平均字数 | 32 | 25 |
| 配置が決めるもの | 順序のみ | **位相（剰余で作動巡回が変わる）** |

数の上では大差ないが、最後の行が質的な差である。**P7-eが当たった場合、
「収束の指標は改善したが認知コストで相殺された」という、指標が捉えられない形の悪化が起きたことになる。**
その場合、位相という機構そのものを捨て、同じ「文脈で効果が変わる」をより軽い形で実現する方法を探す。

### 反証条件

作者が再プレイ度1を付け、かつ「いつものパターン」「勝ち確定してつまらない」に相当する記述をした場合、
**PHASE 0.1 の機械評価上の勝ちはオーバーフィットだったと判定する。** その場合は指標の設計へ戻り、
収束・多様性の指標が人間の体験と結びついていない理由を先に調べる。

再プレイ度そのものは主要な判定材料にしない（#24で、代理プレイヤーからは取れないと分かっている）。
作者本人の回答としては記録するが、判定はP7-a〜dで行う。

## P7-e の判定と、決定ルールの誤り（2026-08-19）

作者がPHASE 0.1を2ラン遊び、「ビジーですが、わりと面白かったです。ビジーですが。」と報告した。

**P7-e（ビジーさ）は当たり。** 認知コストの重さは予測どおり体験に現れた。

しかしP7-eに紐づけた決定ルール——「当たった場合は位相機構そのものを捨てる」——は**誤りだった**。
このルールは「ビジー＝悪い」という等号を暗黙に置いていたが、報告は「ビジーだが面白い」であり、等号は成り立たない。
ARC 0.1で作者が出した「勝ち確定してつまらない」とは明確に異なる。

**手続き上の教訓:** 予測の事前登録と、決定の事前登録は別物である。
予測（「作者はビジーだと言うだろう」）は検証可能な主張だが、
決定（「そうなったら捨てる」）には検証していない前提（ビジーさは面白さを打ち消す）が埋め込まれていた。
**決定ルールを書くときは、そこに含まれる前提も明示する。** 前提が外れたら、決定ルールは無効であって、
結果の解釈を変える理由にはならない。

修正後の扱い：**ビジーさは捨てる理由ではなく、削るべきコスト。** 面白さの信号が来ている以上、
機構を捨てるのではなく、認知コストがどこに集中しているかを特定して削る。
どこが重いかは作者のトレース（操作数、報酬ごとの操作、位相を変える操作の回数）から測る。

## P8: 飽きは1ラン内の指標では測れない（2026-08-20 事前登録）

作者がPHASE 0.1を計4ラン遊び、「**飽きてきました**」と報告した。
ラン内の指標は逆に良くなり続けていた（停滞率0、位相移動4〜5、反転率100%、無傷率も低下）。
再プレイ度は 4 → 3 → 3 → 3。自由記述は2ラン続けて摩擦に「**途中の敵が弱い**」、
物語に「**いつも通り勝った回**」。感情マーカーには「この敵弱すぎでは？毎回ノーコストで勝てる」。

ここから、飽きの正体は**ラン内の平坦さではなく、ランをまたいだ反復**だという仮説を立てる。
現行の `describeRun` は1ランの中しか見ないので、この仮説が正しければ**指標は原理的に盲目**である。

計測は `analysis/durability.mjs`（localSearchPolicy / 200シード）で行う。**数字を見る前に登録する。**

- **P8-a 関門化**：提示採用率が80%以上の部品が1つ以上ある。
  （人間の記録では崩落砲が5/5＝100%で、3ランで山場・決着として名指しされている）
- **P8-b 空の序盤**：1〜2戦目を無傷で勝つ率が70%以上。
- **P8-c 収束**：最終構成のJaccard平均が0.40以上。
- **P8-d 盲目**：a〜cが成立していても、現行の警告（`dead_time`/`no_pressure`/`idle_build`/
  `single_gate`/`single_worry`/`no_problem_chain`/`no_pivot`/`no_reinterpretation`/`no_tension`）の
  1ランあたり平均発火数が1件未満にとどまる。

### 決定ルールと、そこに埋め込んだ前提（P7-eの誤りを繰り返さないため明示する）

前提1：作者の「飽きた」は、この4ランの体験に対する報告であり、代理では取れない一次情報である。
前提2：「途中の敵が弱い」は摩擦欄に2ラン連続で自発的に書かれた不満であり、直すべきコストである。
この2つは検証済み（作者の直接の申告）なので、以下の決定ルールに未検証の等号は入っていない。

- **P8-a が当たったら**：崩落砲を単独の勝ち筋にしている構造を壊す。捨てるのではなく、
  「引けたら勝ち」を「引けたら別の問題が始まる」に変える。
- **P8-b が当たったら**：序盤の敵を、無傷で勝てない形に変える。難しくするのではなく、
  **何かを支払わせる**（HPでなくてもよい）。
- **P8-c が当たったら**：収束の測定を `durability.mjs` として常設し、以後の新ゲームは
  ラン内指標とラン間指標の両方を通さないと合格としない。
- **P8-d が当たったら**：`describeRun` の警告だけで設計判断をしていた運用を誤りと認め、
  評価器を「1ラン内」と「ラン間」の2面構成に改める。

### 反証条件

a〜cのいずれも成立しない場合、飽きの原因はここに挙げた反復ではない。
その場合は本数（4ラン）そのもの、あるいは1ランの長さ（6戦・12巡）を疑う方へ切り替える。

## P9: 正解の組み合わせは何通りあるか（2026-08-20 事前登録）

作者が飽きた理由を明示的に述べた。要点は3つで、いずれも一次情報である。

1. ゲーム自体はARCと同程度に面白い。位相で配置が悩ましいこと、同じ部品でも敵によって
   入れ替えが起きることは面白さとして働いた。バランス調整の積み重ねがそれを面白さにしている。
2. **部品を入れ替えるたびに戦闘結果を暗算するのがストレスだった。** 位相表に敵の回復や命中下限が
   載っていないので自分で計算する必要がある。**「ただの足し算で脳トレでしかないのでつまらない」。**
3. 位相表を見ながら組み合わせを試している時間は楽しい。よって
   **「正確な結果予測がすぐ出てくるが、正解の組み合わせはもっと少ない」** 方向なら、
   UIの工夫でもっと面白くなるのではないか。

これは「圧力を測れ」という第5回の結論と同じ場所を、体験の側から指している。
中盤の無傷率が78/98/95%だということは、**正解の組み合わせが多すぎる**ということである。

### 前提（決定ルールに埋め込むものを明示する。P7-eの誤りを繰り返さないため）

- 前提1：上記2と3は作者の直接の申告であり、推論ではない。
- 前提2：**PHASE 0.1 の戦闘は完全に決定的**である（11部品のいずれも `rng` を使わない。ARCの
  違法砲身とは異なる）。かつ敵の全数値は `enemyView` で画面に出ている。したがって
  **正確な結果を表示しても情報は増えない。暗算が消えるだけである。**

### 予測（`analysis/arrangement-space.mjs`。数字を見る前に登録する）

所持部品から5枠へ並べる**相異なる型の並び**を全列挙し、勝てる並びの割合を測る。

- **P9-a 中盤は正解だらけ**：3〜5戦目で、勝てる並びの割合が50%以上。
- **P9-b 最終戦は狭い**：6戦目で、勝てる並びの割合が20%未満。
- **P9-c 全体**：作者の4ラン計24戦の中央値が40%以上。
- **P9-d 無傷の正解も多い**：3〜5戦目で、無傷で勝てる並びの割合が20%以上。

### 決定ルール

- **P9-a か P9-c が当たったら**：配置空間を締める。目標帯も先に登録する——
  **勝てる並びの割合を全戦闘で 2%〜20% に収める**（0%は詰み、20%超は「何でも勝てる」）。
- **当否によらず実行する**：UIが現在の並びの**正確な結果**（勝敗・撃破巡回・残HP）を即座に出す。
  前提2により、これは情報の追加ではなく暗算の除去である。
- **副作用として記録する**：正確な予測が出るなら、`surprise` と `no_tension` は原理的に退化する
  （予測は常に当たる）。**圧力の指標を「結果が読めないこと」から「正解が少ないこと」へ移す。**
  移行後は `no_tension` を合否条件から外し、勝てる並びの割合を代わりに使う。

### 反証条件

P9-a と P9-c がどちらも外れた場合、中盤の無傷率の高さは配置空間の広さではなく、
敵の絶対値の低さから来ていることになる。その場合は配置空間ではなく敵の数値を触る。

## P10: 「並びはきつめに、部品選択はゆるめに」（2026-08-20 事前登録）

作者が理想の形を述べた。**これは指標ではなく仮説なので、分解して登録する。**

> 並びはきつめに、部品選択はゆるめに。どの部品を選択しても勝ちの目があるが、
> 部品の効果は大きく違っていて、勝敗には並び順が大きく影響する、が理想のゲームだと自分は感じました。
> なぜそう感じるのかはもっと仮説検証や分解が必要だと思いますが。

### 測れる形（新ルールセットの生成条件）

所持部品の集合を S、S を5枠へ並べたものを一つの「並び」とする。

- **T1 選択はゆるい**：到達しうるどの S についても、**勝てる並びが1つ以上存在する**割合が 98% 以上。
  （＝引き運で詰まない。既存の「勝ち筋ゼロ率」を報酬経路ではなく配置の側で見る）
- **T2 並びはきつい**：勝てる並びの割合の中央値が **5〜15%**。全戦闘で 30% を超えない。

  （＝勝てる並びの割合が 0% でも 100% でもない）。
- **T4 部品の効果が大きく違う**：部品ごとの寄与ベクトル（攻撃/遮蔽/回復/連携）の

- **T5 外した代償が効く**：勝てない並びを選んだ時の平均失点が、勝利時の回復量の **3倍以上**。

### なぜそう感じるのかの分解（作者の問いへの、検証可能な候補）

- **H1 帰属**：選択がゆるいと、負けの原因が引きではなく自分の判断になる。
  → 予測：摩擦欄と感情マーカーから「引き」「運」「来ない」に相当する記述が消える。
- **H2 密度**：並びがきついと、毎戦に実際に解く作業が生まれ、時間が判断で埋まる。
  → 予測：`idleBattleRate` 0、`phaseMoves` が全戦で発生、無傷率8割超の戦闘が2連続しない。
- **H3 意味**：部品の効果差が大きいほど、並べ替えの結果が大きく変わり、探索が単調でない。
  → 予測：手応え質問で「これしかない」「妥協した」が過半、「もっと良いのがありそう」は少数。
- **H4 再挑戦**：「持ち物は足りているが使い方が悪い」状態は、再挑戦の動機を自分の内側に作る。
  → 予測：再プレイ度が4以上、かつ `settledAt` が第5戦以降へ後ろ倒しになる。

**H1〜H4は今回の1ランでは判定しない。** 記録して、次のゲームでも同じ質問を出し続ける。

### 設計上の新しい自由（第6回の結果から導かれる）

画面が実機の答えを即座に出す以上、**規則の帰結が暗算しづらいことは、もはやコストではない。**

### 決定ルール

- T1〜T5 を機械評価で通すまで、作者には出さない。**生成条件を満たさない版は人間テストに送らない。**
- T2 を満たすために敵の数値を探索するが、**T1 を犠牲にして T2 を達成してはならない**（詰みを作らない）。

## P11: 罰を増やさず、志を上げる（2026-08-21 事前登録）

作者の指摘：

> ガチャガチャやって勝ててしまうのはたしかにつまらないのですが、**よく考えなかったことを咎められて
> 時間を無駄にするのはもっとつまらないです。積み上げのないゲームで決断を大きく咎めるのは楽しみを奪う**
> と思います。近年のゲームは、「1ランは短く、失敗すると最初からになるが、何かしら永続する値が溜まる」か
> 「1ランが何十時間も続き、最初からになることはない、失敗してもオートセーブがあってごく近いところから
> 再開できる」のどちらかに収束していると私は思っています。

**この指摘は、こちらが出した案1（試行に費用）と案2（決定を1戦で完結させない）を否定している。**
そして実データがそれを裏づける：**RELAY の人間5ランはすべて勝ちで、このゲームは一度も咎めていない。**
案1・2は存在しない問題を解こうとしていた。

### 測定：質の勾配はすでに存在する

| | ガチャガチャ（無作為20回・最初の勝ちで停止） | 考えた場合（全通りの最良） |
|---|---:|---:|
| 平均の残HP | 12.1 | 28.5 |
| 無傷で勝てた割合 | **10%** | **88%** |

全1,148,767通りの並びの内訳と、20回ガチャガチャで到達する確率：

| 等級 | 割合 | 20回で到達 |
|---|---:|---:|
| 無傷（失点0） | 1.8% | **31%** |
| 上々（1〜5） | 0.8% | 14% |
| 及第（6〜14） | 2.2% | 36% |
| 辛勝（15以上） | 10.3% | 89% |
| 敗北 | 84.9% | — |

**勝つだけなら20回で96%到達するが、無傷は31%にとどまる。**
つまり**志を上げれば、罰を一切増やさずにガチャガチャを無力化できる。**

### 変更（1点）

戦闘に**等級**をつけ、敵ごとの**自己最高記録を永続**させる。
外しても罰は無い（勝ちは勝ち、ランは続く）。作者の言う形（A）の最小形である。

同時に、**探索そのものを記録する**（設計変更ではなく計測）。
これまで観測できたのは各戦闘の**最終的な並びだけ**で、そこへ至る試行は一度も見ていなかった。
画面が結果を出すたびに、試した並びと結果を記録する。

### 予測（数字を見る前に登録する）

- **P11-a 探索は実在する**：1戦あたりの試行回数の中央値が5回以上。
- **P11-b 停止規則が変わる**：**勝てる並びを見つけた後もさらに試した戦闘が過半数**。
  （等級が無ければ最初の勝ちで止まるはずで、実際「ガチャガチャやってたらなんか勝てる」と報告された）
- **P11-c 質が上がる**：1ランの平均失点が、直近5ランの平均（約4.7）より小さくなる。
- **P11-d 罰は増えない**：負けが増えない（5ラン全勝の水準を保つ）。
- **P11-e 減衰**：再プレイ度が直近の2を上回る。**これは弱い予測**である。
  等級は減衰の本命対策ではない（減衰の本命はラン間の変異）。

### 決定ルールと前提

前提：作者の「咎めるのはもっとつまらない」「積み上げのないゲームで決断を大きく咎めるのは楽しみを奪う」は
直接の申告であり、推論ではない。**よって罰を増やす案は今後採らない。**

- **P11-b が外れたら**：等級では動機にならない。質を可視化しても遊びは変わらないことになるので、
  ガチャガチャ問題は「志」ではなく別の軸で解く。
- **P11-b が当たり P11-e が外れたら**：ガチャガチャは解けたが減衰は残る。
  そこで初めて**ラン間の変異**（毎ラン規則が少し変わり、覚えた型が通じなくなる）へ進む。
- **P11-a の実測**は、以後の探索曲線の地平を人間に合わせるために使う（#27・#32の続き）。

## P12: 問題を生む機械（2026-08-21 事前登録）

作者の訂正が出発点である。

> ゲームとしての面白さはまだ残っていると思います。（略）**もう一回やっても、もうハイスコアが
> 二度と得られない（最大でも1位タイにしかならない）という張り合いのなさが継続しない最大の理由**で、
> **残っている面白さと継続したい度合いは分けて考えてもいい**のかもしれません。

**#49 は誤りを含んでいた。** 再プレイ度の低下を「発見が尽きた」と読んだが、
作者は「面白さはまだ残っている、更新できる記録が無いだけ」と述べている。
**測っていた1つの数字が2つの量を混ぜていた。** 終了時の質問を分けた（面白さ／継続／食い違いの理由）。

### 作るもの

**1つの良い問題ではなく、問題を生む機械。**

- 中核は継承する（5枠・部品ごとの作動周期・枠で決まる位相・決定的・12巡・正確な予告）。
  作者の評価が高かった部分であり、「読むのは機械、探すのは人」の前提でもある。
- **毎ラン、法則を2つ引く。** 法則は1行で書ける規則で、機関の動き方を変える。
  継電（同系統が続くと倍率）／反継電（違う系統なら倍）／反射（余った遮蔽が返る）／
  共鳴（3つ以上作動すると全部増える）／静粛（休んだ枠は次に倍）／逆順（枠5から作動）など。
- **法則の組ごとに最適な「かたち」が変わる。** 覚えた型（RELAYの周期2,1,2）は前提から崩れる。
- **記録は法則の組ごとに持つ。** 新しい組には常に未達成の記録がある。**天井が退がり続ける。**
- **生成条件（P10のT1〜T3）を、組ごとに事前検証する。** 通らない組は出さない。
  評価器が設計時の道具ではなく、**ゲームの部品になる。**

### 予測（数字を見る前に登録する）

- **P12-a 型が転移しない**：法則の組ごとに最良の並びの「かたち」（系統構成と周期の並び）を出したとき、
  最頻の系統構成が全体の **40%未満**（RELAY 0.1 の実測は60%）。
- **P12-b 天井が遠い**：#48の規則を最初から適用し、**探索者換算（無作為の7倍・10試行）で
  最上位等級の1戦あたり到達率が50%未満。**
- **P12-c 初見の面白さ**：新設の「面白いか」が **4以上**（RELAY 初回は再プレイ度5）。
- **P12-d 継続**：新設の「もう一度遊びたいか」が **4以上**、かつ食い違いの理由欄に
  「記録が更新できない」に相当する記述が出ない。

### 決定ルールと前提

前提：作者の「面白さと継続は別」「更新できる記録が無いのが継続しない理由」は直接の申告である。
罰を増やさない方針（#44）は維持する。

- **P12-a が外れたら**：法則を変えても最適な型が変わっていない。
  法則の設計が浅いということなので、法則の粒度をやり直す。
- **P12-c が当たり P12-d が外れたら**：面白さは作れるが継続は作れない、が確定する。
  そのとき初めて、継続を**ゲーム外の仕組み**（記録の見せ方、目標の配り方）で解く方へ移る。
- **P12-b は出す前に必ず確認する。** 第10回はこれを怠って天井を1ランで失った。
