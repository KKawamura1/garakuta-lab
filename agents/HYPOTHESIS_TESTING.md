# P は仮説であって、守るべきルールではない

**2026-08-22、作者の指摘を受けて書き直した設計。**

> いまやっていることは、面白いゲームを作ることではなく、面白いゲームを作るための仮説検証をすることです。
> そのために、いまのルールが正しいかもきちんと仮説検証してください。Pは仮説であって、守るべきルールではありません。
> Pが成り立つゲームが面白いか（Precisionを上げるテスト）だけでなく、
> Pが成り立たないゲームがつまらないか（Recallを上げるテスト）も必要でしょう。

## 私が何を間違えていたか

天井（P12-b）が満たせないと分かったとき、私がやったのは
**(a) ゲームを作り直す (b) 閾値を上げてよいか訊く** の二つだった。どちらも「Pは守るもの」という前提に立っている。

正しい反応は **「参照点 RELAY 0.1（作者評価5・企画の記録）が天井を落とした。それは天井仮説への反証である」** だった。
**仮説が反証されたのに、仮説を守ってゲームの側を曲げていた。**

そして、いまのところ**どのPも「必要である」とは一度も示せていない。**
Pを満たすゲームしか作っていないので、当然そうなる。

## 0. 仮説には2種類ある（2026-08-22、作者の指摘）

> あくまで仮説ですし、「面白くする仮説」（当てはまらなくても面白い場合があって当たり前）であって
> 「つまらなさを避ける仮説」（当てはまらない場合常につまらないと考えられる）ではないので、
> 他の仮説と横並びにする必要はないです。

**これは仮説そのものより、仮説の扱い方についての指摘である。**
私はこれまで全部を同じ棚に並べ、同じ関門にかけていた。**種類が違えば、検証の設計も違う。**

| | **必要条件の仮説**（つまらなさを避ける） | **増強の仮説**（面白くする） |
|---|---|---|
| 主張 | これが無いと**常に**つまらない | これがあると**ときどき**面白くなる |
| 例 | T1 詰みを作らない／T2 並びがきつい／T3 並び順が効く | 連勝を褒めて戦闘を飛ばす／等級／自己最高の永続 |
| 反証のしかた | **破った版がそれでも面白ければ反証**（Recallテスト） | 単発の空振りでは反証**できない**。条件付きで効くのが前提 |
| 生成条件に入れるか | **入れる**（満たさない版は出さない） | **入れない**。満たさなくても出してよい |
| 測り方 | 対にして、その条件だけを破る | 有ると無いを比べる。ただし**空振りが出ても捨てない** |

**混ぜた結果、何が起きていたか。** 天井（P12-b）を必要条件の棚に置いたので、
通らないと版を出せなくなり、半日それに向けて調律していた。**あれは増強の仮説だった可能性が高い**
（RELAY 0.1 は天井を落としながら評価5を取っている）。棚を間違えると、
**通す必要のないものを通そうとして、通す必要のあるものを削ってしまう**（偏食がそれだった）。

### 増強の仮説の扱い

- 生成条件（`analysis/tune-laws.mjs` の関門）には**入れない。**
- 出すときは**要素へ分解して、1つずつ**足す。まとめて足すと、どれが効いたか分からない。
- **空振りを記録する。** 効かなかった場面があること自体は、仮説を否定しない。
  否定されるのは「**どの場面でも効かない**」と分かったときだけ。

## 0.5 検討中の増強仮説：連勝を褒めて、戦闘を飛ばす

**作者の提案（2026-08-22）。まだ仮説ですらなく、着想の段階。**

> 「同じ構成でそのまま次も勝てる」は、いまはつまらないの代名詞なのですが、
> うまくやると面白くなるかもしれません。むしろそれを褒めるようにして、
> 自動で次の戦闘をスキップし、演出で「N strike!」みたいに出たら爽快かもと思いました。
> ゲーム的に明示的な報酬を与えるのではなく、単に戦闘をスキップするだけにして、
> 時間の節約という報酬を与えるといいかもしれません。そうすれば、
> 「次の試合まで頑張って予測する」という認知負荷を強制することなく、
> とはいえ汎用的に勝てる戦略をできるだけ考えようと思えるはずです。

**なぜ筋が良さそうか。** これまで「同じ構成で勝ててしまう」を**欠陥として潰そう**としてきた
（1巡上限、型の転移）。この案は**同じ現象を報酬に読み替える。** しかも報酬が
「時間が浮く」なので、**遊ぶ側の負担を増やさずに、汎用性を狙う動機だけを作る。**
第12回の摩擦報告（「後半3体は見ないで勝てるし」「相変わらずOTKしかない」）は、
**作業を強制されたことへの不満**であって、勝ててしまうこと自体への不満ではなかった、とも読める。

### 要素へ分解する（まとめて足さない）

| 要素 | 単独で何を主張するか | 単独で試せるか |
|---|---|---|
| **a. 飛ばす** | 勝ちが確定した戦闘を自動で飛ばすと、退屈が減る | 試せる。演出も表示も無しで、ただ飛ばす |
| **b. 数える** | 連勝が数として見えると、汎用的な構成を狙う動機になる | 試せる。飛ばさずに数だけ出す |
| **c. 褒める** | 演出（「N strike!」）が爽快さを足す | a か b の上に足す形でしか試せない |
| **d. 報酬を置かない** | 時間の節約以外の報酬を与えないことが、動機を歪めない | a の変種として試せる（飛ばす＋強化 対 飛ばすだけ） |

**先に測っておくべきこと（作者の時間を使わない）**：いまの版で、
「前の戦闘と同じ並びのまま、次も勝てる」局面が実際に何割あるか。
**そこが1割なら演出の出番がほぼ無く、8割なら run の大半が飛ぶ。** 設計はその数字で変わる。

### 判定について

**これは増強の仮説なので、空振りしても捨てない。**
「飛ばしても退屈が減らなかった」1件では否定されない。
否定されるのは、**飛ばした場面で一貫して「作業感が減った」と報告されない**と分かったとき。

## 0.7 何組で判定するか（2026-08-22、遊ぶ前に登録）

作者の問い：「確率的現象の検証なので、1セットじゃ足りませんよね？」**足りない。**

強制選択なので、差が無い（どちらでもよい）とき各組は五分五分になる。全部同じ側になる確率は：

| 組数 | 全部同じ側になる確率（差が無いとき・片側） |
|---|---|
| 1組 | 50% |
| 2組 | 25% |
| **3組** | **12.5%** |
| 4組 | 6.3% |
| 5組 | 3.1% |

**3組で全会一致なら12.5%。**慣習的な有意水準は割らないが、示唆としては十分強い。
5組そろえば3.1%まで落ちる。

### ただし、票よりも自由記述が効く

第1回の T3 で、票（2組とも A）は同じでも、**理由を読んだら対が無効だと分かった**
（「ルールが均衡なのに達成する手段がない」＝操作した変数と無関係）。
**操作した変数を名指しした理由が付いた1組は、名指しの無い3組より重い。**
票は方向を、記述は**それが操作のせいか**を教える。両方見る。

### 判定規則（先に決める）

- **3組が全会一致 かつ 理由が操作した変数を名指ししている** → その条件を支持とする
- **3組が全会一致 だが 理由が別のものを指している** → **対が無効。**作り直す（第1回がこれ）
- **2対1** → 判定しない。組を足す
- **「どちらとも言えない」が過半** → その条件は面白さを動かしていない。生成条件から外す方向へ

**「差が出なかった」も結果である。** 出るまで対を作り替えるのは事前登録の趣旨に反する。

### どの対を3組やるか

**T2 を勧める。**理由は3つ。

1. **反証寄りの記録が既にある**（PHASE 0.1 は帯の外で再プレイ4,3,3,3、GATE v2 を通した CYCLE 0.2 は1,1）
2. **いまの調律が全部この条件に向かって走っている。**倒れるなら早い方がいい
3. **T3 より目隠しが効く。** T3 は位相を外すと位相表が見た目から変わるので気づかれる
   （実際に作者は「位相が乗らない、だけ？」と当てている）。
   T2 は両側とも見た目が同じで、敵のHPしか違わない

## 1. いま持っている証拠

| 条件 | 満たした版 → 結果（Precision） | 破った版 → 結果（Recall） | いま言えること |
|---|---|---|---|
| **T1 詰みを作らない** | RELAY 0.1（再5→1）、LAWS（再4,3,3,2） | ARC 0.1（勝ち筋ゼロ24%）→ 再1 | 弱い支持。ただしARCは他も違う |
| **T2 勝てる並びが5〜15%** | RELAY 0.1（再5が最高記録） | **PHASE 0.1（59〜100%）→ 再4,3,3,3** | **反証寄り。**破った版が、通した版（CYCLE 0.2＝再1,1）より高い |
| **T3 並び順が効く** | RELAY / LAWS 全部 | **無し** | **未検証。**破った版を一度も作っていない |
| **T5 外した代償** | RELAY 0.1 | 無し | **未検証** |
| **天井（P12-b）** | **無し**（通した版が一つも無い） | RELAY 0.1（71%）→ 再5、LAWS（26〜44%）→ 再4,3,3,2 | **反証寄り。**天井が近い版が最高評価を出している |
| **GATE v2 全体** | CYCLE 0.2 → **再1,1**「何しても勝てそう」 | — | **反証。**通した版が最低評価 |

**読み方：** 通した版が最低点（CYCLE 0.2）、破った版が高得点（PHASE 0.1）という組が既にある。
**関門は、少なくとも現状の形では、面白さを予測できていない。**

### ただし、この表は結論には使えない

**過去の比較は一つも ceteris paribus でない。** PHASE と RELAY は T2 以外に、法則の有無・UIの予告・敵の数値がすべて違う。
どの差が効いたのかを分離できない。**だから上の表は「仮説」であって「証拠」ではない。**

もう一つ：**絶対評価は遊んだ回数とともに単調に下がる**（RELAY: 5→4→3→3→2→1）。
版をまたいだ絶対値の比較は、順序効果と交絡している。**今までの比較は全部これを踏んでいる。**

## 2. これからの形：対にして出す

### 設計

1. **1ランを3戦に短縮する**（いまは6戦）。所要時間が半分になり、同じ時間で**2ラン＝1対**が回る。
2. 対の2本は、**登録した条件のうち1つだけが違う。** 他は機械で揃える。
3. **順序はランダム。どちらがどちらかは伏せる。**
4. 終わったら**強制選択**：「どちらが面白かったか」「どちらをもう一回やりたいか」＋理由。
   **絶対評価（1〜5）は主要指標に使わない。** 単調減衰と交絡するため。
   対にすれば順序効果は相殺でき、**同じ日の同じ気分の中での比較**になる。

### なぜ強制選択か

絶対評価は「今日は3」としか言えないが、対比較は「AよりB」と言える。
**減衰していく量でも、同時に比べれば差は見える。**

### 破る側も、ちゃんと遊べるものにする

Recallテストの版は「条件を破っただけ」で、**壊れたゲームではない。**
壊れたものがつまらないのは当たり前で、それでは仮説の検証にならない。
破る条件以外はすべて通す。

## 4. 最初の3対（優先順）

### 対1：T3「並び順が効く」

**これが企画の出発点そのもの**（「並びはきつめに、部品選択はゆるめに」）なのに、**一度も破って試していない。**

- **A（T3を満たす）**：順序に依存する法則（継電＝連なり、先陣＝その巡回の1番目）
- **B（T3を破る）**：順序に依存しない法則（共鳴＝作動数、均衡＝系統が揃っているか）

**法則の組み替えだけで操作できる**ので、他は完全に揃う。最もきれいな対。

- 仮説が正しいなら：**Aが選ばれる**
- 反証されるなら：**差が出ない**か、Bが選ばれる。そのときは「並び順が効くこと」は面白さの条件ではない

### 対2：T2「勝てる並びが5〜15%」

- **A**：勝てる並び 7%（帯の中）
- **B**：勝てる並び 35%（帯の外・緩い）
- 敵HPだけで操作できる。**PHASE 0.1 の記録は反証寄りなので、ここは本気で怪しい。**

### 対3：天井（P12-b）

- **A**：無傷の到達率が遠い
- **B**：近い
- **継続の条件なので、1対では判定できない可能性が高い**（継続は複数ランに現れる量）。
  面白さの条件（対1・対2）を先に潰してから。

## 5. 何が起きたら仮説を捨てるか（先に書く）

- **対1で差が出ない** → T3 を「面白さの必要条件」から外す。生成条件から削る
- **対2でBが選ばれる** → T2 の帯を捨てる。「正解が少ないこと」は面白さの条件ではなかったことになる
- **対3で差が出ない** → 天井を捨てる。**今日一日を止めていた条件が消える**
- **どの対でも差が出ない** → 面白さは私が測っている軸の上に無い。軸を探すところからやり直す

**差が出なかったことも結果である。** 出るまで対を作り替えるのは、事前登録の趣旨に反する。
