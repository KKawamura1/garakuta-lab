# 灯守 / TOMORI 0.1

NIGHT-EATERで見えなかった「育てたものが、場面で返ってくる」構造を、3日間の独立した縦切りで試す。

## 遊び方

1. 小さな灯りに名前をつける。
2. 一日ひとつ、耳をすます／手のひらを貸す／窓を開ける、のどれかを選ぶ。
3. 選択直後の反応と、子の中に残った記憶を見る。
4. 三日目に、育った性質が朝の出来事へ返ってくる。
5. 結末で、まだ見ていない育ち方を確認する。

どれが正解かを当てるゲームではない。選んだ接し方が、その子の声・ぬくもり・まなざしとして姿と物語に残る。

## 起動

静的ファイルとして配信する。リポジトリのルートから、例えば次で確認できる。

~~~bash
python3 -m http.server 4173
~~~

その後、`http://localhost:4173/tomori/` を開く。

通常はseedを表示せずランダムに遊ぶ。`?seed=12` のように指定すると、出会いの提示だけ再現できる。
ゲームの因果（選択、記憶、結末）はseedなしでも追えるようにしている。

## ログ

`/api/runs` へ `gameVersion: tomori-0.1` で送る。途中状態は `localStorage` に保存し、リロード後に続きから再開できる。送信失敗時は端末内キューへ入り、結果画面の再送ボタンから再試行できる。

主なイベントは次のとおり。

- `run_started`
- `scene_seen`
- `action_chosen`
- `reaction_seen`
- `emotion_marked`
- `run_ended`
- `survey_submitted`

## 設計と判定

仮説、変更点、成功／失敗信号、人間テストの問いは [analysis/TOMORI_0_1.md](../analysis/TOMORI_0_1.md) に記録する。実装は既存の `/play/` と `/night-eater/` を置き換えない。
