# おかしな機関 / ODD ENGINE 0.1

「小さな仮説検証を一つずつ積む」のではなく、作者が中身を知った後も遊びたいと思える体験へ、設計者が本気で賭けるための独立作です。

## 遊び方

1. 4つの部品を機関の通り道へ並べる。
2. 各区画で2つのガラクタから1つを選び、どこへ入れるか決める。分解して部品くずにしてもよい。
3. 3つの命令（急ぐ／整える／耳を澄ます）から1つを送る。
4. 部品が左から反応する。直前の出力を写す部品や、熱を別の働きへ変える部品がある。
5. 区画の問いに答えられれば進む。火種か機関が壊れる前に、7区画を越えれば勝ち。

同じ部品でも、命令と並びで役割が変わります。最初から完成図を探すのではなく、実行ログを見て「この部品はこう使える」と考え直すゲームです。

## ログ

感情マーカー、任意メモ、選んだ部品、入れ替え、命令、部品ごとの反応、終了アンケートをD1へ `gameVersion=odd-0.1-machine` として保存します。

seedはURLの `?seed=12` のように固定できます。seedなしで開いた場合はランダムseedがURLへ入り、リロードしても同じランを再開します。
