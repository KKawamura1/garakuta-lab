# ガラクタ列車 — SCRAPLINE

`/scrapline/` に追加した、10〜12分の縦切りプロトタイプです。既存の `/play/`、`/haul/`、`/kindling/` などは置き換えません。

## 遊び方

1. 後部ホッパーから砲台まで、最大5台の加工車を左から右へ並べる。
2. 「プレビュー」で一つの鉄塊がどう変わるか確認する。
3. 発車すると、敵の反撃までが自動で進み、加工の因果がログとして再生される。
4. 区画を突破したら、残骸から一台だけ拾う。満車なら車両をタップして交換先を選ぶ。
5. 7区画を抜けた後、面白さ・再プレイ意欲・詰まりを30秒で記録する。

画面上の `seed` は再現用です。通常起動では毎回新しい seed を生成し、`?seed=12` のように指定した時だけ同じ区画・残骸候補を再現できます。`scrapline-0.1` と build stamp は画面とログに残ります。

## 核になる仕掛け

車両は「カードの強さ」ではなく、同じ鉄塊へ順番に作用する機械です。`帯電車 → 溶解車` と `溶解車 → 帯電車` は同じ二台でも結果が違います。`磁石車 → 逆走車` では、着弾後の戻り道がもう一度答えを変えます。新しい一台を拾うたび、手持ち全体の意味が変わることを短いショーで返すのが狙いです。

## 開発・検査

```sh
node analysis/scrapline-smoke.mjs
node --check scrapline/app.js
node --check scrapline/engine.mjs
```

エンジンは副作用のない決定的シミュレーションとして切り出し、UI は `localStorage` に現在の run を保存します。アンケート送信は既存の `/api/runs` と `agent-view/sync.js` を使い、`head: scrapline` と `gameVersion: scrapline-0.1` を付けます。
