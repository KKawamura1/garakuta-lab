# ガラクタ列車 — SCRAPLINE

`/scrapline/` に追加した、7区画・最大5両の短編構築オートバトルです。既存の
`/play/`、`/haul/`、`/kindling/` などは置き換えません。

## 遊び方

1. 次の敵の動きを見て、後部ホッパーから先頭砲まで加工車をドラッグで並べる。
2. プレビューで、一つの鉄塊が車両ごとにどう変わるかを見る。
3. 発車すると、敵影、弾のID・形・速度、車両の発動、着弾、敵弾、帰還を同じ
   イベント列から約10〜13秒の短いショーとして再生する。
4. 区画を突破したら残骸から一台だけ拾う。満車なら、タップした車両と交換する
   か、今回は見送る。
5. 7区画目のボスを倒したら、最終車列、最も派手な一射、改造履歴、次の問いを
   振り返る。

通常起動では seed を画面に出さず、毎回新しい列車を生成します。`?seed=12` の
ような診断起動だけ、同じ敵順・残骸候補を再現します。現行版は
`scrapline-0.7` / `scrapline-build-20260828-r8` です。

## 敵が出す問い

- **鉄くずスズメ** — 密集隊形が遅い単発弾を止める。切断、溶融、帰還で崩す。
- **廃工場の盾** — 軽い弾を複数回弾く。圧縮、溶融、帰還の累積で抜く。
- **赤錆キャノン** — 四両以上の遅い列を照準途中で迎撃する。短い列、加速、
  溶融で先に届かせる。
- **拾い屋の列** — 非致死の弾から回復し、後尾車両を奪う。早期撃破、回収、
  帰還、尾部装甲で守る。
- **炉心を喰う王** — 群れの護衛と、正面の非溶融弾を受け流す装甲炉心の二段階。
  帰還列または溶融列で答える。

## 面白さの核

車両は個別の攻撃力ではなく、同じ鉄塊へ順番に作用する共通動詞です。切断→帯電、
帯電→切断、帯電→溶解、磁石→溶解、ループ→逆走で、弾の数・重さ・火花・速度・
状態・帰還が物理的に変わります。車両を増やすほど強いとは限らず、長い列は速攻
砲台に狙われます。

通常車両8種とレア車両3種は、専用の合成レシピではなく、この文法の組み合わせで
意味を変えます。たとえば、磁石→溶解は戻る印のついた弾を炸裂弾にし、溶解→磁石
は溶融弾を帰路へ残します。逆走車やループ車を加えると、同じ車両が発射前とは
別の順番で働きます。

## 開発・検査

```sh
node analysis/scrapline-smoke.mjs
node analysis/scrapline-balance-smoke.mjs
node analysis/scrapline-seed-regression.mjs
node --check scrapline/engine.mjs
node --input-type=module --check < scrapline/app.js
```

エンジンは副作用のない決定的シミュレーションとして切り出し、UIは現在のrunと
送信待ちキューを `localStorage` に保存します。アンケートと戦闘イベントは既存の
`/api/runs` 契約へ `head: scrapline`、`gameVersion: scrapline-0.7` で送ります。
Service Workerとmanifestも `/scrapline/` 専用です。

全順序検査では、1〜5両の64,471列を5つの問いへ通し、各敵に複数の解法があり、
全敵を支配する万能列がないことを確認します。0〜255 seedの完全ランも回帰検査に
含めています。

## 公開前の確認

アニメーション・音・振動は、因果が読める視覚表示を主にし、対応端末ではWebAudioと
Vibration APIを補助に使います。公開URLを案内する前には、リリース規約に従い、
iPhone Safari 390×844、公開環境のD1保存・export、初見プレイヤーの10〜15分評価を
別途確認します。
