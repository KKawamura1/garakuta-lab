# ガラクタ列車 — SCRAPLINE

`/scrapline/` に追加した、10〜12分の縦切りプロトタイプです。既存の `/play/`、`/haul/`、`/kindling/` などは置き換えません。

## 遊び方

1. 後部ホッパーから砲台まで、最大5台の加工車を左から右へ並べる。
2. 「プレビュー」で一つの鉄塊がどう変わるか確認する。
3. 発車すると、敵の反撃までが自動で進み、同じイベント列が約10秒の因果ショーとして再生される。
4. 区画を突破したら、残骸から一台だけ拾う。満車なら車両をタップして交換先を選ぶ。
5. 7区画を抜けた後、面白さ・再プレイ意欲・詰まりを30秒で記録する。

通常起動では seed を画面に出さず毎回新しい列車を生成します。`?seed=12` のように指定した診断起動だけ seed を表示し、同じ区画・残骸候補を再現できます。`scrapline-0.2` と build stamp は画面とログに残ります。

## 核になる仕掛け

車両は「カードの強さ」ではなく、同じ鉄塊へ順番に作用する機械です。`帯電車 → 溶解車` と `溶解車 → 帯電車`、`加速車 → 切断車` と `切断車 → 加速車` は速度・火花・弾数が変わります。`磁石車 → 溶解車` では戻り弾に炸裂印が付き、`磁石車 → 逆走車` では着弾後の戻り道がもう一度答えを変えます。新しい一台を拾うたび、手持ち全体の意味が変わることを短いショーで返すのが狙いです。

## 開発・検査

```sh
node analysis/scrapline-smoke.mjs
node --input-type=module --check < scrapline/app.js
node --input-type=module --check < scrapline/engine.mjs
```

エンジンは副作用のない決定的シミュレーションとして切り出し、UI は `localStorage` に現在の run を保存します。アンケート送信は既存の `/api/runs` と `agent-view/sync.js` を使い、`head: scrapline` と `gameVersion: scrapline-0.2` を付けます。
