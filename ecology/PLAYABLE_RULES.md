# EXP-18 プレイ可能スライスのルール

この版は、PR48で実装されたR5決定的戦闘エンジンを、組合せゲームとして触るための最小ルールです。ここで評価するのは面白さではなく、仲間・部材・自動戦闘の因果がUIから読めるかです。

## 1. 遠征の開始

1. 仲間4人から3人を選ぶ。
2. 選んだ仲間は初期行動1つと初期リアクティブ1つを持つ。
3. 初期部材5個がseedから決まり、そのうち2〜3個を選んで仲間へ取り付ける。
4. 部材の取り付け先は毎回選べる。部材は行動、リアクティブ、装備のいずれか。

仲間ごとの枠は、行動2、リアクティブ2、装備1です。行動は上から順に試され、条件を満たさない行動は飛ばされます。追加した行動・リアクティブは空き枠の先頭に入ります。行動の↑↓で優先順を変えられます。

装備は1枠です。新しい装備を付けると、同じ仲間の装備を交換します。

## 2. 部材のルール

| 種類 | 部材 | 発動の因果 |
| --- | --- | --- |
| 行動 | 溜め突き | 準備1回 → 9ダメージ |
| 行動 | 号令 | 行動権1 → 最速の前衛 |
| 行動 | 位置替え | 後衛の移動 → 前衛と場所交換 |
| 行動 | 応急手当 | HP半分以下 → 8回復 |
| 行動 | 準備狩り | 準備中の敵 → 5ダメージ |
| 反応 | 反撃 | 被弾 → RP1で攻撃者へ2ダメージ |
| 反応 | 身代わり | 敵の標的選択 → RP1で自分へ引き受け |
| 反応 | 余剰治療 | 余った回復 → 別の負傷者へ回復 |
| 反応 | 急かす | 味方の準備開始 → RP1で1段階短縮 |
| 反応 | 踏み固め | 移動 → ラウンド防壁2 |
| 反応 | 連携治療 | 応急手当の余剰 → RP1で回復 |
| 反応 | 受け流し | 被弾 → RP1でラウンド防壁2 |
| 装備 | 踏み込みの靴 | ラウンド最初の発動 → 行動権1 |
| 装備 | 継ぎはぎの盾 | 戦闘開始 → 戦闘中防壁2 |
| 装備 | 棘の刃 | 余剰ダメージ → 耐久1で1ダメージ |
| 装備 | 野営道具 | 余ったRP → 耐久1を修理 |
| 装備 | 勢いの留め具 | 移動 → 次の攻撃/回復を強化 |

初期行動・初期リアクティブにも同じR5定義を使っています。たとえば、ミナの「手当て」と「余剰治療」を別の仲間へ移すと、発動条件だけを持った部材が実際の回復行動とつながります。

## 3. 自動戦闘

戦闘中の操作はありません。各ラウンドで、行動権のある仲間が行動優先順を上から確認し、使える行動を1つ実行します。リアクティブは、被弾・標的選択・準備開始・移動など、対応するイベントの直後または割り込みで発動します。

戦闘はseed以外の乱数を使わず、同じ仲間・部材・敵なら同じ結果になります。戦闘後は、発動した行動・反応・装備摩耗・資源の受け渡しをイベント順で表示します。

## 4. 区画と報酬

| 区画 | 敵 | 戦闘後 |
| --- | --- | --- |
| 1 | 灰殻兵1体 | 3部材から1個を選び、仲間へ装着 |
| 2 | 灰殻兵＋灰殻の見張り | 3部材から1個を選び、仲間へ装着 |
| 3 | 灰殻の盾兵1体 | 遠征完了 |

報酬は見送れます。勝てなかった場合は構成画面へ戻り、seedを変えずに優先順を確認して再試行できます。現在のスライスでは、初期構成を取り付けた後の大規模な持ち物整理までは扱いません。

## 5. 既知の範囲

- 部材の候補はseed付きで変わりますが、同じrunでは固定です。
- 現在の数値と定義は、R5のfixture contentを仮の実データとして利用しています。表示名と組合せUIの方向を確認した後、production contentへ差し替えます。
- 物語、キャンペーン、12/12/18規模の本番コンテンツ、長期メタ進行はこのスライスの対象外です。
