# 灰の遠征 — 現行プレイ規則

更新日: 2026-09-03（UTC）

この文書は、現在の ecology/ が実装しているプレイヤー向けの規則です。R8 / R9 の設計資料に未実装の将来案を混ぜません。

## 0. タイトルと保存

1. **New Game** は新しい Profile を作り、Campaign Stage 0 をシキとナズナの2人・オープニング会話から開始します。既存のオートセーブを置き換えますが、手動セーブ枠は残ります。
2. **Continue** は最新のオートセーブから再開します。タイトルの **Load Game** ではオートセーブまたは3つの手動セーブ枠を選べます。
3. 手動セーブは Camp の安全な地点で作成できます。既存枠への保存は上書き確認を出します。
4. 保存は R10 専用形式です。旧形式・旧キーのセーブは互換対象外で、読み込まず新規状態から開始します。

## 1. 遠征を始める

1. Campaign Stage を選ぶ。Stage 0 が既定です。Stage 1〜3 は前段の Campaign をクリアすると開きます。
2. **初回のその Stage では、同行する仲間が決まっています。** Stage 0 は2人で、Stage を進むごとに1人加わり、Stage 3 で5人になります。一度クリアした Stage を遊び直すときは、揃っている仲間から5人を自由に選べます。
3. 隊列は2×3。前列3・後列2、または前列2・後列3です。人数が少ないぶんだけ空き枠が増えます。
4. 各仲間に行動3、反応3、常設2までを設定し、装備を2枠まで割り当てます。
5. 次の戦闘の敵、狙い、法則、変異、脅威の概要を確認して出発します。

戦闘中の細かな入力はありません。操作は、戦闘前の構成、戦闘後の報酬・野営・撤退です。

## 1.1 戦闘予測

キャンプの画面上部には、**次の一戦を最後まで走らせた結果**が常に出ています。
各メンバーの予測HPと減少量、勝敗、要したラウンド数です。技能・装備・隊列を
触るたびにその場で組み直されます。

- 予測は無料で、遠征の状態を一切変えません。
- **予測と本番は同じ経路で同じ engine を通ります。**構成を変えずに再生すれば、
  予測と完全に同じ結果になります。
- 出ないのは一箇所だけです。Stage 0 初回の勝てない一戦（灰の門）では、
  巻き戻すまで予測を出しません。まだ巻き戻す力を持っていないからです。

## 1.2 技能は取り直せない、装備は付け外し自由

予測が完全なので、組み替えの自由度が二つに分けてあります。

- **技能** … 一度解禁した技能点は戻らず、一度枠へ装着した技能は外せません。
  撤退するか12戦を突破して遠征が終わるまで固定です。「いま強くするか、
  先の戦いのために枠と点を残すか」を、そのつど決める場所です。
  （行動の優先順の並べ替えだけはいつでもできます。）
- **装備** … いつでも何度でも付け外しできます。「この敵に特に効く一品へ
  毎戦組み替えるか、どの敵にも通る一品を固定して安定させるか」を選ぶ場所です。

## 2. Campaign Stage

| Stage | 表示名 | 人数 | 加入 | 新規 pack | 有効 pack |
|---|---|---:|---|---|---|
| 0 | 灰の入口 | 2 | — | pack_edge（入口） | E |
| 1 | かばう手 | 3 | スミ | pack_wall（入口） | E＋W |
| 2 | 間合いと順番 | 4 | レイ | pack_tempo（入口） | E＋W＋T |
| 3 | 傷を抱えて進む | 5 | ナズナ | pack_care（入口） | E＋W＋T＋C |

pack は累積します。**前に覚えた技能は消えません。** 新しい pack はその Stage では
入口（7〜10技能）だけが出て、次の Stage から全体が出ます。

Stage 0 を初めて遊ぶときだけ、最初に勝てない一戦（灰の門）があります。**この一戦の
あいだは戦闘予測を出しません。**負けると時間が巻き戻り、そこで初めて予測が出ます。
以降は予測を見ながら配置を変えて挑み直せます。**この一戦は遠征に数えません**
（活動資金も持ち越しHPも動きません）。

会話は立ち絵つきで一行ずつ流れます。画面のどこを叩いても進み、文字送りの途中なら
一度目の操作で全文が出ます。AUTO（自動送り）、履歴（読み返し）、スキップがあり、
**会話はいつでも飛ばせます。**一度クリアした Stage では最初から出ません。

各 Stage は3幕12戦です。4、8、12戦目が act boss です。敵の数と threat budget は
遠征の人数に合わせて減ります。Stage 0〜3 の敵族と boss law は共通の暫定定義で、
stage-specific law はまだ実装していません。

通常戦・精鋭戦の終了時 HP は次の戦闘へ持ち越します。4・8戦目の boss 後は全回復します。
12戦目は遠征の終点です。補給は再挑戦、報酬の引き直し、野営治療の三用途で消費する
有限資源です。（次の一戦が完全に読めるようになったので、**偵察は廃止しました。**）

4、8、12戦目の直前には、その Stage をまだクリアしていないあいだ、短い幕間の会話が
入ります。加入の会話と同じくスキップできます。

## 2.1 遠征のあいだ — 根城と図鑑

精算のあとは**根城**へ帰ります。灰の縁から外れた廃屋で、進行に応じて家にあるものが
増えます。ここに隊の**名簿**（人物の来歴・関係）があり、遠征を重ねるほど読める欄が
増えます。日常の場面は条件を満たすと一つずつ出て、一度見たものは読み返せます。
根城はギルド画面のタブからも開けます。**どれも戦闘には影響しません。**

**図鑑**はギルド画面のタブにあります。会った灰殻だけが載り、倒した数に応じて
書ける欄が増えます。遠征を捨てても消えません。

## 3. 戦闘

- 同じ入力と seed は同じ結果とイベント列を返します。
- 行動は priority と condition に従い、条件を満たさない行動は飛ばされます。
- 行動がすべて飛ばされた場合は basic strike が使われます。
- 支援行動の後には、条件があれば半威力の追撃が入ります。
- 反応は受け取ったイベントと limit に従い、guard、block、barrier、回復、反撃などを発火させます。
- replay は盤面の動き、浮く値、イベントログを同じ順で表示します。
- 戦闘開始前の preview は、実際に開始する battle input と一致する情報を出します。
- 画面上部の戦闘予測は、その battle input を実際に engine へ通した結果です
  （別経路の試算ではありません）。

## 4. 装備

装備は2枠です。**遠征中いつでも自由に付け外しできます**（技能と違って固定されません）。
固定装備と、遠征中に拾う**手続き生成装備**の二種類があります。

- 生成装備の rule は、拾う前から全部読めます。情報を隠して売る仕組みはありません。
- 生成は決定的です。同じ遠征の同じ戦闘・同じ引き直し回数なら、同じ品が出ます。
- 等級は 並 / 上 / 希 / 遺物 の4段。等級が上がると完結 rule の数と予算が増えますが、
  確定した上位互換にはならず、複数の文脈か大きな代償を持ちます。
- 遠征が終わると持ち物は手放しますが、見つけた生成装備は **Blueprint（設計図）** として
  残ります。勝利2件、安全撤退2件、敗北1件まで、等級の高い順に残ります。
- Blueprint 自体に所持上限はありません。次の遠征へ持ち込める枠だけが 1〜5 です
  （ギルドで買えます）。持ち込んだ品は、その遠征の affix family の外でもそのまま動きます。
- 目利き（5段）は等級の引きを良くします。読める情報は変わりません。

## 5. 進行と保存

Profile は遠征をまたぐ活動資金、人物状態、解禁状態、Blueprint archive、物語の既読印を持ちます。
Run は現在の Stage、人数、roster、隊列、loadout、HP、補給、報酬候補、そして
その遠征で拾った生成装備の定義そのものを持ちます。Battle は一戦の seed、event、replay 状態を持ちます。

報酬、キャンプ、撤退、敗北後の扱いは、有限資源と次の選択が見えるように設計されています。
装備耐久は現状、戦闘ごとにリセットされます。野営治療の対象は現状自動選択です。
