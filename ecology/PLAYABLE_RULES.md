# EXP-18 Full prototype — ルール

この版は、PR48のR5決定的戦闘エンジンを、企画書R3/R4の「仲間・技能・装備・隊列を組み替える自動戦闘ゲーム」として一周できるようにした試作です。

## 1. プレイヤーの仕事

1. 8人の仲間から5人を選ぶ。
2. 5人を2行×3列の枠へ配置する（前3後2、または前2後3）。
3. 各仲間のスキルツリーから、行動3つ・リアクティブ3つ・常設2つまでを解禁・装着する。
4. 共有インベントリの装備を、各仲間の2枠へ割り当てる。
5. 敵の狙いを確認して出発する。
6. 自動戦闘のリプレイで、誰が誰を狙い、どの条件が発火したかを確認する。
7. 勝利後に報酬を1つ選び、HPと装備耐久をリセットして次の戦闘へ進む。

戦闘中に細かな操作はありません。プレイヤーが操作するのは、戦闘前の構成と、戦闘後の再設計です。

## 2. 仲間と隊列

仲間は固有のHP・速度・初期技能・役割を持ちます。技能と装備は付け替えられますが、仲間そのものは編成の主語として残ります。

位置のルールは次の通りです。

- 前列左・前列中央・前列右・後列左・後列中央・後列右の6枠。
- 位置替え技能は、後列の仲間と前列の仲間を交換する。
- 敵の通常攻撃は、敵の技能定義に従って前列または後列を選ぶ。
- 敵ごとの狙いは、マップと戦闘前画面で表示する。
- 編成画面では、仲間または位置枠をタップして交換対象を選ぶ。同じ仲間を再タップすると選択を解除し、選択後に別の位置枠をタップすると二人の位置を交換する。交換後は選択を解除する。

## 3. スキルツリー

技能の種類は全員が同じ43ノードのツリーから選びますが、解禁状態と技能点は仲間ごとに別です。

- 行動21個: 斬撃、手当て、防壁形成、号令、溜め突き、位置替え、大溜め、応急手当、準備狩り、息を整える、隙を刻む、狙いを澄ます、刻み斬り、貫き突き、薙ぎ払い、突き通し、受け崩し、後衛狩り、止めの一突き、傷口を開く、衝撃に備える。
- リアクティブ14個: 反撃、身代わり、余剰治療、拾い直し、踏み固め、急かす、受け流し、連携治療、行動権の循環、痛みの反響、防壁の花、準備の螺旋、受け返しの集中、防壁の縫い直し。
- 常設8個: 地力、膂力、集中力、受け、速さ、出足、備え、初手の構え。
- 前提ノードと技能点が必要なノードがある。
- 各仲間は開始時に技能点を2持つ。
- 技能点を使って解禁したノードは、その仲間だけが利用できる。
- 勝利報酬の「技能点+2」を選んだ仲間1人の、今回の遠征内の技能点が2増える。プロフィールには持ち越さない。
- 行動は上から順番に条件を確認し、最初に使えるものを実行する。
- リアクティブは被弾、準備開始、移動、回復の余剰など、対応するイベントの直後に発火する。
- 各仲間の行動枠は3、リアクティブ枠は3、常設枠は2。各枠は0個にもでき、行動が空なら通常攻撃、リアクティブと常設が空なら追加効果なしになる。行動の順序は↑↓で変更する。

## 4. 装備

装備は共有インベントリにある実物で、各仲間に2個まで装着できます。同じ装備を複数人へ同時には付けられません。

装備は、攻撃力の単純な上昇ではなく、次のようなイベントへ接続します。

- 戦闘開始 → 防壁
- ラウンド最初の発動 → 行動権
- 移動 → 集中
- 余剰ダメージ → 追加攻撃
- 余ったRP → 修理
- 受け構えが消費される → ラウンド防壁
- 被弾 → 集中
- 回復後 → RP
- 撃破後 → AP

装備には戦闘内だけで有効な耐久値があります。戦闘中に摩耗し、0になるとその装備の効果は以後発動しません。ただし破損扱いにはならず、装備そのものは失いません。戦闘終了後、次の戦闘では最大値に戻ります。

## 5. 遠征（現行: Phase B）

現行の遠征は3幕12戦です。4・8・12戦目が各幕のボスで、通常戦・精鋭戦を
挟みながら、脅威予算と難易度 rank で敵の重さが変わります。現行の配置は
`ecology/content/expedition.mjs` が持ち、戦闘入力は
`ecology/playable-battles.mjs` の `makeExpeditionBattle` が組み立てます。

- 1戦目: 灰の入口
- 2戦目: 狩りの路地
- 3戦目: 崩れた盾列
- 4戦目: 盾将の門（第1幕ボス）
- 5戦目: 灰の圧力
- 6戦目: 二つの狙い
- 7戦目: 反響の坑道
- 8戦目: 反響体の巣（第2幕ボス）
- 9戦目: 盾の回廊
- 10戦目: 灰の重列
- 11戦目: 核の前庭
- 12戦目: 灰の核心（第3幕ボス）

勝利すると、装備2候補に「技能点+2」「補給+1」を加えた報酬候補から
1つを選びます。

- 装備: 共有インベントリへ追加。
- 技能点+2: 遠征中の仲間1人を選び、その人の今回の技能点だけが2増える。
- 補給+1: 遠征中の再挑戦・引き直し・次の幕の偵察に使える補給が1増える。

### 旧 Phase A（decision-space 移行までの互換入力）

旧7区画の配置は `ecology/content/encounters.mjs` に残っています。
`ecology/playable-battles.mjs` の `makeBattle` と、旧リプレイ・契約の
検査がこれを参照します。現行のPhase B遠征はこの配列を使いません。

- 旧区画1: 灰の入口
- 旧区画2: 狩りの路地
- 旧区画3: 崩れた盾列
- 旧区画4: 反響の坑道
- 旧区画5: 灰の圧力
- 旧区画6: 二つの狙い
- 旧区画7: 灰の核心

旧テスト・旧7件の契約・beat smoke は削除済みです。旧配置と `makeBattle()` は、
別担当が decision-space を Phase B へ移行するまでの互換入力として残しています。移行完了後に旧配置と adapter の削除可否を再判断します。

この旧系列を現行の遠征の合格条件として扱いません。現行12戦の決着と到達は `phase-b.test.mjs` と `analysis/ecology-expedition-smoke.mjs` が検査します。

戦闘中のHPと装備耐久は、その戦闘の中だけ有効です。勝敗が決まると、全仲間のHPと所有装備の耐久は最大値へ戻ります。敗北時も同じ状態から構成を変えて再挑戦できます。

## 5.5 戦闘の尺度と人物 parameter

戦闘量は三桁で読めます。未強化の最大HPは160〜260、通常の一撃は10〜100程度です。

各人物は **腕力（might）・術力（focus）・受け（guard）** を持ちます。
武器技能は腕力、技術・治療・防壁は術力で伸びます。全員が両方を持つので、
支援役にも攻撃の伸び代があり、前衛にも支援の伸び代があります。

| 人物 | HP | 腕力 | 術力 | 受け | 速度 |
|---|---:|---:|---:|---:|---:|
| ユウリ | 260 | 32 | 24 | 10 | 4 |
| ミナ | 180 | 18 | 44 | 3 | 6 |
| レオン | 200 | 46 | 18 | 4 | 8 |
| スイ | 160 | 36 | 26 | 2 | 10 |
| カイ | 220 | 32 | 32 | 6 | 5 |
| ナギ | 260 | 26 | 24 | 12 | 3 |
| アオ | 160 | 16 | 50 | 2 | 5 |
| トワ | 170 | 24 | 40 | 3 | 7 |

同じ技能でも使い手で量が変わります。斬撃はレオンで46、アオで16。
応急手当はアオ（集中力50）で60、レオン（集中力18）で22です。

## 5.6 隊列

各陣営は **2行×3列の6枠**を持ち、5人編成では必ず一枠が空きます。
有効な形は **前3後2 か 前2後3 だけ**です。

- 前3は単体攻撃を分散できますが、前列を薙ぐ攻撃が3人に当たります。
- 前2は後列に3人置けますが、前列一人あたりの被弾が増えます。
- 通常攻撃と、`reach` を指定しない通常技能は、生存する前列がいる間は後列へ届きません。前列が全滅して初めて後列へ届きます。
- 前衛・後衛の位置だけでは届き方は変わりません。後列を直接狙える技能は、技能定義の effect に `reach: "ranged"` を持たせます。
- `column` のような特殊パターンは、前列の対象を起点に同じ列の後列へ広がります。後列だけを直接狙う遠隔技能とは区別します。

## 5.7 防御は3つある

同じ「硬さ」でも、問われるものが違います。

| 防御 | 効き方 | 弱い相手 |
|---|---|---|
| **防壁（◈）** | 総ダメージ量を受け止める | 総量の大きい攻撃 |
| **受け構え（▣）** | 一撃を丸ごと止め、1回消費する | 多段（1回ずつ剥がされる） |
| **受け（盾）** | 一撃ごとに固定で引く。最低1割は必ず通る | 単発大威力（引かれる割合が小さい） |

一撃の解決順は **受け構え → 受け → 防壁 → HP** で固定です。

## 5.8 攻撃の型

| 技能 | 効き方 |
|---|---|
| 斬撃 | 腕力120%の単発。技能枠を使わない通常攻撃は100% |
| 刻み斬り | 50%×3。合計150%だが**受けを3回引かれる** |
| 貫き突き | 115%。**受けを6割無視** |
| 薙ぎ払い | 前列の敵が2体以上いるとき、80%を同じ行へ。対象がいなければスキップ |
| 突き通し | 110%を同じ列の前後へ |
| 受け崩し | 115%。**受け構えと受けを完全に無視** |
| 後衛狩り | 後列の生存者だけへ120%。対象がいなければスキップ |
| 止めの一突き | HP半分以下の敵へ140%。対象がいなければスキップ |
| 傷口を開く | 未露出の対象へ110%の攻撃後、「隙」を付ける。対象がいなければスキップ |
| 衝撃に備える | 受け構えを得てから通常の追撃 |
| 溜め突き | 準備1回のあと550%の一撃。開始と準備で行動権を計2つ使う |
| 大溜め | 準備3回のあと1000%の一撃。開始と準備で行動権を計4つ使う |
| 手当て | 集中力の120%を、いちばん傷ついた味方へ回復 |
| 防壁形成 | 自分に集中力の200%のラウンド防壁 |
| 応急手当 | HP半分以下の味方を集中力の120%回復。対象がいなければスキップ |
| 準備狩り | 準備中の敵へ300%。対象がいなければスキップ |
| 隙を刻む | 未露出の敵へ隙を付ける。対象がいなければスキップ |
| 狙いを澄ます | 集中を付けてから追い打ち。集中中はスキップ |

**支援だけを並べても戦闘は止まりません。** どの仲間も技能枠を使わない通常攻撃を
常備し、支援技能を解決したあとに威力50%の追撃を一度だけ行います。
技能を持たない仲間も通常攻撃をします。追撃から追撃は生まれません。

攻撃技能は、成立した条件の中で通常攻撃より明確に強くなるようにしています。
後列・瀕死・未露出・前列2体以上などの条件が成立しない場合は技能自体を不発にし、
行動権を無駄にせず次の技能を試します。全技能が不成立なら通常攻撃へ戻り、
技能を一つも装着していない場合もまったく同じ通常攻撃になります。

技能枠は **行動3・反応3・常設2** です。いずれも0個まで外せます。常設には基礎訓練7種（地力・膂力・集中力・
受け・速さ・出足・備え）が前提なしであり、Wave 1 には守り系の「初手の構え」も
加わります。基礎訓練は詰み防止であって、完成形の主役ではありません。

### 準備の進み方

**準備は行動権で進めます。1行動権につき1段。** 溜め突きは開始1＋進行1で計2行動権、
大溜めは開始1＋進行3で計4行動権かかります。行動権が余っていれば同じラウンドのうちに
進められるので、**行動権の多い仲間や行動追加の装備は「溜めを短くする」形で効きます。**
行動権が尽きたラウンドは準備が進みません。

急かす（リアクティブ）は準備の**開始**に反応して1段進めます。反応権を1点使います。

## 6. 自動戦闘

戦闘はR5エンジンで決定的に解決されます。同じseed、同じ隊列、同じ技能、同じ装備、同じ敵なら同じ結果になります。

リプレイは、名前とHPの箱を人数分並べた盤面で見せます。敵を上、味方を下に置き、それぞれ前列・後列に分けます。行動した側の箱が相手側へ踏み込み、受けた側の箱が揺れ、その箱の上にダメージ値（赤）・回復値（緑）・防壁値（青）が浮かびます。箱の中の札は、その仲間がいま使っている技能または準備中の技能です。中央には、いま解決しているイベントの一行を出します。

箱には、名前・HP・防壁・状態異常のほかに、そのラウンドに残っている**行動権（金の菱形）**と**反応権（青い丸）**を粒で出します。行動権を使い切った仲間は箱が沈み、そのラウンドの主行動を終えたことが分かります。

再生が進む単位は**イベント1件ではなく「拍」**です。R5エンジンは1つの行動から十数件のイベントを出しますが、行動権の支払い、解決の締め、提案値のような事務は盤面に出さず、デバッグログにだけ残します。止めるか流すかは次の規則で決めます。

| 種別 | 見分け方 | 扱い |
|---|---|---|
| 主行動 | ルール由来でない（`ruleId` が無い） | **必ず止める。** 宣言と着弾で2拍 |
| サブ行動・自分に向いたもの | `ruleId` があり、対象が自分 | **止めない。** 攻撃と同じ拍に重ねて出す |
| サブ行動・他人に向いたもの | `ruleId` があり、対象が他人 | **止める。** 誰が誰を庇ったのかが要るため単独で見せる |
| 非行動（状態付与・装備摩耗） | — | **止めない。** 同じ拍に並べて出す |
| 事務（行動権・解決の締め・提案値） | — | 盤面に出さない。ログにだけ残る |

同じ拍に複数出たときは、中央の一行が「＋」で並びます。この畳み方で、拍の数はイベント数のおよそ2割になります（旧 Phase A の7区画 beat smoke は削除済み。現行 Phase B の12戦の決着と到達は `analysis/ecology-expedition-smoke.mjs` が検査します）。

一時停止、一手進める、一手戻す、速さ（ゆっくり／標準／速い）を選べます。最後まで見たあとは、同じ戦闘を最初から流し直せます。

イベントの文字一覧は**デバッグログ**として、盤面の下の折りたたみに置きます。既定では閉じており、アニメーションで分かりにくいところを文字で確かめたいときだけ開きます。デバッグログと戦闘後の一覧では、少なくとも次を表示します。

- 行動者と行動技能
- 選ばれた標的
- 準備の開始・進行・完了
- ダメージ、回復、防壁、行動権
- リアクティブの発火理由
- 位置替え
- 装備の摩耗・枯渇・修理
- 戦闘不能と勝敗

敵を全滅させた場合、現在処理中の行動チェーンに必要な撃破リアクションだけを完了したあと、直ちに戦闘を終了します。新しい仲間・敵の行動や次ラウンドは開始しません。リプレイ中の味方・敵の状態は、各イベント時点のスナップショットを表示します。

## 7. 試作の評価範囲

この版で評価できるのは、次の構造が一つのゲーム画面としてつながっているかです。

- 「好きな4人を選ぶ」
- 「誰をどこに置くか考える」
- 「技能の将来像をスキルツリーで見る」
- 「技能と装備を実際の枠へ入れる」
- 「敵の狙いを見て構成を変える」
- 「自動戦闘で予想と結果を比較する」
- 「報酬で既存構成の意味が変わる」

数値バランス、キャラクターの愛着、長期的な面白さは、この版を人間が複数回遊んだ後に判断します。
