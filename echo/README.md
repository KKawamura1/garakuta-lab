# 残響工房 / ECHO 0.1

GRAFTとは別の、短時間の再プレイ動機の試作です。6区画を抜けるあいだに「刈り取る／整える／賭ける」を選びます。走行後、次の走行には前回の手順が残り、同じ手なら熱を少し下げ、違う手なら部品を増やします。

## 検証したいこと

得点や新しいランダム配置ではなく、前回の自分の具体的な手順を見せることで「この1手を書き換えたい」という即時の再プレイ理由が生まれるかを見ます。seedはURLの `?seed=12` で固定できます。

## プレイとログ

公開時の入口は `/echo/` です。結果画面のアンケートと途中の感情マーカーを含め、GRAFTと同じD1送信経路へ `gameVersion=echo-0.1-ghost` で保存します。送信失敗時も走行はlocalStorageに残ります。
