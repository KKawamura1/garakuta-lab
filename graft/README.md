# GRAFT 0.1

既存の5枠・法則機関から独立した、接ぎ木による行動変化の小型試作です。

## 起動

リポジトリのルートで、静的サーバーを起動します。

```sh
python3 -m http.server 4173
```

ブラウザで `http://localhost:4173/graft/` を開いてください。iPhoneでは同じネットワーク上の端末からアクセスできます。

## 遊び方

- 敵の次の攻撃を見て、充電・打撃・遮蔽のどれかを選ぶ。
- 戦闘後、2つの性質から1つを選び、まだ素の行動へ接ぎ木する。
- 反動は大きく動く代わりに同じ行動を次巡休止、余波は効果を次巡へ送り、継ぎ火は次の別行動を強化する。
- 4戦を通して、最後に面白さ・再遊技意欲・印象に残った瞬間を記録する。

操作はブラウザの `localStorage` に保存されます。「新しいラン」で現在のランを破棄して、別のseedから始められます。
