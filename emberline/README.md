# 火走り / EMBERLINE 0.1

TOMORI 0.1の反証を受けて作る、独立した構築ゲームの縦切りです。

## 目的

拾った廃材で4穴の走行機関を組み、火種を5区画の先にある灯台へ運びます。廃材は3つから1つを選び、穴へ置きます。部品は左から順に発動するため、同じ部品でも順番や前の出力によって働き方が変わります。

## 操作

1. 今回の区画の問いを読む。
2. 3つの廃材から1つを拾うか、見送る。
3. 廃材を空き穴へ置くか、既存部品と交換する。
4. 矢印で部品の順番を変え、「この並びで走る」を押す。
5. 自動走行のログで、どの部品が何を起こしたか確認する。

5区画を越え、船体が残っていれば成功です。seedは通常ランダムですが、保存ログには残ります。

## 記録

選択、提示された廃材、装着先、並べ替え、各部品の発動、区画結果、感情マーカー、終了アンケートを `game_version=emberline-0.1` としてD1へ保存します。感情マーカーを押してからメモを書いても、直近のマーカーへメモを紐づけます。

## 検査

純粋なルール検査は `analysis/emberline-gate.mjs` と `analysis/emberline-smoke.mjs` で行います。自動ゲートは面白さの合否ではなく、選択・配置・順序・相互作用・結果説明が存在するかを確認します。
