# Sol / Terra 分業と仮説検証

更新日: 2026-08-31（UTC）

この文書は、灰の遠征を戦略判断、実装、作者評価に分けて進めるための運用です。役割名は変更せず、現行の EXP-18 Campaign に合わせます。

## 役割

| 担当 | 主な仕事 |
|---|---|
| Sol | 現在地の診断、問い、仮説、受入条件、継続・修正・停止の判断 |
| Terra | 実装、検査、公開先確認、事実の整理 |
| 作者 | iPhone で遊ぶ、自発的な再訪、因果が分かったかの報告 |

Sol と Terra は、作者のプレイを機械検査やエージェント評価で代用しません。

## 実験・変更の最小票

- 問い: 何を知りたいか
- 仮説: なぜこの変更で改善すると考えるか
- 変更: 今回だけ変えるもの
- 維持: 比較のため残すもの
- 成功信号: 作者の発言、行動、再訪
- 失敗信号: 因果不明、試したい変更が浮かばない、再訪なし
- 中止条件: バグ、未確認、所要時間超過、設計境界の逸脱

Terra は実装前に、目的と成功基準が恒真・恒偽になっていないか、変更範囲が広すぎないか、既知の反例を分けられるかを確認します。

## 現在の関門

1. 現行 Campaign Stage 0〜3 の実装と自動検査を揃える。
2. 公開先で UI、リプレイ、save、D1 送信を確認する。
3. 作者が 1〜2 遠征を遊ぶ。
4. 作者の結果をもとに、content 調整、表示修正、Phase C のどれを選ぶか判断する。

「もっと面白くする」を完了条件にせず、何を観測して次の判断をするかを先に固定します。
