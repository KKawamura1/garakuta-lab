# docs — 気になったときに読む資料

**必ず読むのは AGENTS.md だけです。**ここは「今後も覚えておきたいが、毎回読む必要は
ない」資料を置く場所です。次の実装でだけ気をつける残論点は GitHub Issues にあります。

| 資料 | 読むとき |
|---|---|
| `GAME.md` | いま何が実装されているか、遊びの規則を確認したいとき |
| `ARCHITECTURE.md` | どのファイルを触るか、状態・決定性・イベント列・content 契約を確認したいとき |
| `DESIGN.md` | 「なぜそうなっているのか」。pack 設計、anti-stall、完全開示、経済 |
| `OPERATIONS.md` | 検査の走らせ方、build 印、公開、作者へ渡す条件、D1 の取り出し |
| `HISTORY.md` | いまの形に至った経緯。過去の判断を蒸し返す前に |
| `RULE_ECOLOGY.md` | 個別ゲームによらない一般設計メモ（EXP-18 以前からの蓄積） |

## 更新のしかた

- 実装が変わったら `GAME.md` / `ARCHITECTURE.md` を直す（版ごとの差分は書かない。
  **常に現在形で書く**）。
- 判断が変わったら `DESIGN.md` を直し、なぜ変えたかを `HISTORY.md` へ一行足す。
- 進捗報告・作業ログ・実験記録のファイルを新しく作らない。
