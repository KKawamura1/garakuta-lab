# One Battle Ahead — 現行のゲーム仕様

いま `ecology/` が実装しているものだけを書きます。将来案は混ぜません。
未実装・未調律の項目は GitHub Issues にあります。

## 0. 形

8人ではなく**本編5人**の隊から、Stage ごとに決まった人数で 2×3 の隊列を組み、
3幕12戦の遠征へ出る自動戦闘ゲームです。戦闘中の入力はありません。操作は
**戦闘前の構成**と、**戦闘後の報酬・野営・撤退**です。
## 1. タイトルと保存

- **New Game** は新しい Profile を作り、Campaign Stage 0 をゴウとツグミの2人・
  オープニング会話から始めます。
- **Continue** は最新のオートセーブから再開します。
- **Load Game** では保存済みのゲームを選んで再開します。
- タイトル画面はゲーム説明を載せず、**つづきから／はじめから／ロードゲーム**だけを表示します。遠征の仕立てはロード後のギルドから行います。


## 2. Campaign Stage

| Stage | 表示名 | 人数 | 加入 | 新しい pack | 有効 pack | 問い |
|---|---|---:|---|---|---|---|
| 0 | 灰の入口 | 2 | ゴウ＋ツグミ | 構えと手当て `pack_care`（入口） | 構 | 武器と技の違いは、立つ場所の違い |
| 1 | 抜ける刃 | 3 | ナギ | 刃と撃破 `pack_edge`（入口） | 構＋刃 | 誰が前に立つと、誰が振り抜けるか |
| 2 | 動く隊列 | 4 | ヒバナ | 防壁と隊列 `pack_wall`（入口） | 構＋刃＋壁 | 隊列を動かして、何を得るか |
| 3 | 間合いと順番 | 5 | ゲンゾウ | 行動権と準備 `pack_tempo`（入口） | 構＋刃＋壁＋権 | 誰がいつ動くと得か |

**問題は Stage 0 で既に出ています。**主火力のツグミが隊で一番柔らかく（HP110）、
ゴウは腕力が最大なのに受けが1で細かい攻撃が全部通ります。ツグミの初期反応「応急手当」は、被弾してHP半分以下になった自分以外の味方だけを、その被弾量の50%だけ回復します。自己防衛用の「応急処置」は自分にだけ効くため、前衛ゴウ／後衛ツグミで初めて二つの役割がつながります。Stage 1 でナギが前に立ち、
Stage 2 でヒバナが隊列を動かし、Stage 3 でゲンゾウが順番を触ります。
加入する人物はその pack の所有者ではありません（分かりやすい入口を持つ人であって、
pack を独占しません）。

- Stage 1〜3 は前段のクリアで順に開きます。活動資金では買えず、飛ばせません。
- **pack は累積します。前に覚えた技能は消えません。**新しい pack はその Stage では
  入口（core、7〜10技能）だけが出て、次の Stage から全体（full）が出ます。
- 各 Stage は3幕12戦。4・8・12戦目が act boss です。敵の数と threat budget は
  遠征の人数に合わせて減ります。

### 2.1 灰の門（Stage 0 初回だけ）

Stage 0 を初めて遊ぶときだけ、**本当に負ける配置**で始まる一戦があります。片方が
倒れた拍で表示を打ち切り、時間が巻き戻って同じ盤面を戦い直します（engine は最後まで
走らせて本当の敗北を出しています）。

- **この一戦のあいだは戦闘予測を出しません。**まだ巻き戻す力を持っていないので、
  読めても直せないからです。巻き戻したあとに初めて出ます。
- **本当に負ける最初の一回だけは遠征に数えません。**活動資金も持ち越し HP も動きません。
  巻き戻したあとに勝った一戦は、そのまま Stage 0 の本編第1戦として commit されます。
  装備・補給の報酬候補と、編成全員への技能点 +1 が出て、次戦へは全回復ではなく
  そのときの HP を持ち越します。
- 巻き戻し後は、最初に負けた配置（ツグミもゴウも前列）を引き継ぎます。何も変えずに再戦しても勝てず、隊列を一手変えた結果が予測に反映されます。
- **この一戦（負ける一回・巻き戻したあとの一回のいずれも）のあいだは、タイトルへ戻る・
  安全に撤退することができません。**隊列を直しきる前に離脱すると、「一手直せば勝てる」
  導入が成立しないためです。
- 巻き戻し直後、ゴウはツグミに敗北・死亡・杭の使用を伝えません。ツグミは戦闘1後に、同じ盤面とゴウの言葉から違和感を拾います。
- 4通りの配置で、武器と技の違いと、後列から前衛を支える応急手当の因果が出ます（結果は `story.test.mjs` が固定）。この一戦だけは通常戦の敵定義を流用しつつ、敵HPを60%、前衛の攻撃力（`might` / `focus`）を115%、後列の marksman を73%に調整し、正解配置なら4ラウンドでゴウ185/300・ツグミ60/110を残して勝ちます。

## 3. 戦闘予測（このゲームの中心）

キャンプの画面上部には、**次の一戦を最後まで走らせた結果**が常に出ています。各
メンバーの予測 HP と減少量、勝敗、要したラウンド数です。技能・装備・隊列を触るたびに
その場で組み直されます。

- **予測と本番は同じ経路（`previewNextBattle` → `simulateNextBattle` →
  `makeExpeditionBattle` → `simulateBattle`）を通ります。**構成を変えずに再生すれば、
  予測と完全に同じ結果になります。preview 専用の試算は持ちません。
- 出ないのは灰の門の一戦だけです。

## 4. 技能は取得を忘れない、装着は自由

予測が完全なので、組み替えの自由度を二つに分けてあります。

- **技能** … 一度取得した技能は忘れられず、使った技能点も戻りません。取得済みの技能は
  行動・反応・常設を問わず、数の上限なく装着できます。装着した行動と反応は上から順に
  並べ替えられ、同じ条件のリアクティブはその順番で作動します。不要な技能は「誰を伸ばす？」
  の技能欄から一時的にオフにできます。オフは外したのと同じように戦闘・予測へ反映されますが、
  取得状態や前提は失いません。
- **装備** … いつでも何度でも付け外しできます。「この敵に特に効く一品へ毎戦組み替えるか、
  どの敵にも通る一品を固定して安定させるか」の選択をここに置きます。

### 技能ツリーの読み方

技能ツリーは **行動（AP を払う）・反応（RP を払う）・常設（資源を払わない）** の三つに
分かれ、画面上のタブで切り替えます。ツリーの中では、

- **左にある節が前提**で、右へ行くほど深くなります（節に出る `x=` がその深さです）。
- 節の左に引かれた線が派生の向きで、**線は交差しません**。
- 節を押すと、そこまでの前提ルートと、そこから伸びる派生先だけが強調されます。
  開いた説明の「前提」「派生先」は押せるので、横スクロールせずにルートを辿れます。
- 前提は必ず同じ種別（行動 / 反応 / 常設）の中に置かれるので、種別をまたいで
  前提を辿ることはありません。
- 節の上には、種別・消費（AP / RP）・対象または発動条件・深さ・現在レベル／最大レベル・
  分岐の数が出ます。未解禁の節も出したままで、状態（前提待ち / 点数不足 / 解禁可能）と
  必要な技能点を読めます。

深さ（`x`）の意味は決まっています。

| x | そこにあるもの |
|---:|---|
| 1 | 入口。前提を持たない基本技能 |
| 2 | 基本の使いやすさ・効率の強化 |
| 3 | **1回目の大きな役割分岐** |
| 4 | 分岐方向の強化 |
| 5 | **2回目の大きな役割分岐** |
| 6〜9 | コンボや専門性の強化 |
| 10 | 最終ビルドの到達点 |

行動ツリーと反応ツリーは、どちらも x=10 の到達点を複数持ち、**最終 Stage までに実際に
取り切れる道が一本は通っています**（届かない到達点は設計図であって、遊べる形ではありません）。

### 技能レベル

同じ効果の上位互換を別の技能として増やす代わりに、**一つの技能を段階的に強くします。**

- 解禁した技能は **Lv 1** で手に入り、そこから技能点 1点ごとに 1段上がります（最大 Lv 10）。
- 1段につき、威力・治療量・防壁が **12%** 上がります。Lv 10 で 2.08 倍です。
- **AP / RP・段数・回数・耐久は変わりません。**「1段上げたら手数が増える」は作りません。
- 威力や治療量のような連続する量を持たない技能（位置替え、号令、隙を刻む など）は
  **レベルを持ちません。**画面に「レベルなし」と書き、点を払わせません。
- レベルも解禁と同じで、払い戻しはありません。深く伸ばす（新しい役割を得る）か、
  いま持っている技能を厚くするかを、**同じ通貨の同じ値段**で選びます。

### 遠征開始時と戦闘勝利時

新しい遠征の1戦目は、遠征内技能点0、固定初期装備0から始まります。出発前に明示的に選んだ Blueprint の持込品だけは、持込品として最初から所持します。
通常戦に勝利すると、報酬候補を選ぶ前に、その遠征の現在の編成全員へ技能点を1点ずつ自動で加えます。技能点を誰か一人へ配る報酬候補はありません。プロローグ「灰の門」は、本当に負ける最初の一回だけ遠征外（技能点・活動資金の勝利報酬なし）です。巻き戻したあとに勝った一戦は本編第1戦そのものなので、他の通常戦と同じく技能点・活動資金・報酬候補が発生します。

## 5. 人物と数値

ゴウ（強打・主人公）／ツグミ（医術）／ナギ（庇護）／ヒバナ（遊撃）／ゲンゾウ（指揮）の
5人だけです。**engine の id は旧5人のまま**（warden／mender／lancer／guardian／tactician）で、
id の語義と役割は一致しません。id は技能・pack・contract の対応を保つ鍵であって役割名では
ないので、公開済み ID の引っ越しを避けてあえて据え置いています。

**5人が別々の軸を1本ずつ持ちます。**似た二人を作らないための制約です。

| 人物 | id | 軸 | 代償 |
|---|---|---|---|
| ゴウ | `warden` | HP 最大 ＋ 腕力 最大 | 受け1・技術6。細かい攻撃が全部通り、技を一つも持てない |
| ツグミ | `mender` | 技術 最大（主火力かつ治療） | HP110・受け2。前へ出すと本当に落ちる |
| ナギ | `lancer` | 受け 最大 | 腕力16。武器では削れない |
| ヒバナ | `guardian` | 行動権2（一巡に二度動く） | 一撃は隊で最弱。HP120・受け3 |
| ゲンゾウ | `tactician` | 反応点4（何度も割り込む） | 攻守とも中庸。自分からは動かない |

**数値は未検証です。**`analysis/ecology-trial.mjs` での通し調整が要ります。

- 基礎 parameter は maxHp、might、focus、guard、AP、RP。
- **攻めの軸は2本。**`might` は武器攻撃、`focus`（技術）は技攻撃と防壁を伸ばします。
- **武器と技の違いは隊列で表します。**腕力で伸びる攻撃を後列から出すと 40% まで
  落ち、技術で伸びる攻撃は落ちません（`effects.mjs` の `afterRearFalloff`、
  `REAR_WEAPON_BPS`）。敵にも同じように掛かります。
- 技能の装着数に上限はありません。行動・反応は上から順に判定され、装備だけは2枠です。
- 回復は `focus` 連動ではなく、受けたダメージ比（`event_value_scaled`）です。
  anti-stall 設計のためで、意図的にそうしています。

## 6. 戦闘

- **行動は陣営ごとのフェーズで進みます。** round 開始時に AP を回復し、まず味方が
  隊列順（前列左→中央→右、後列左→中央→右）に一人一行動、その後に敵が同じ順で
  一人一行動します。どちらかに実行可能な行動が残る限り、味方→敵を繰り返します。
  AP2 の actor も一回行動したら次の自軍フェーズまで待ちます。全員に行動可能な
  AP がなくなったら round end です。同じ側で同じ位置にいる actor だけは instance ID
  を最終タイブレークに使います。対象選択で隊列を使う技能は `position_asc` /
  `position_desc` を明示します。
- 同じ入力と seed は同じ結果とイベント列を返します。
- 行動は priority と condition に従い、条件を満たさない行動は飛ばされます。
  すべて飛ばされた場合は basic strike。純支援 active の解決後は威力50%の追撃。
- 反応は受け取ったイベントと limit に従い、guard・block・barrier・回復・反撃を発火します。応急手当は被弾に連動し、RP1・chain1で、自分以外の味方を対象にします。
- guard は一 hit ごとの固定軽減、block は hit 単位の無効回数、barrier は総量吸収です。
- **状態は5つ**です。どれもラウンドの終わりに消えます（集中だけは使うまで残ります）。
  - **隙** … 受けるダメージが増える。付けるのも払うのも技能でできます。
  - **集中** … 次の damage / heal / barrier が一度だけ増える。
  - **怯み** … その相手が**出す**ダメージが1段につき8減る。
  - **守勢** … その味方が**受ける**ダメージが1段につき8減る。**barrier（総量）でも
    block（回数）でもない三つ目の守り**で、細かい多段に強く、大技には薄いです。
  - **裂傷** … ラウンド終わりに一度だけ、1段につき12を**受け無視**で刻みます。
- replay は盤面の動き、浮く値、イベントログを同じ順で表示します。
- **通常戦はキャンプの「この敵に挑む」から、戦闘前確認の画面を挟まずそのまま
  自動戦闘の再生に進みます。**敵・狙い・隊列・完全予測はキャンプの戦闘タブに
  既に揃っているため、同じ内容を再掲する中間画面は無くしました。act boss 前の
  会話がある戦闘は、会話のあとに続けて自動戦闘へ進みます（会話そのものは残ります）。
  戦闘前確認の画面は、灰の門を巻き戻したあとの再戦（隊列の直し方を教える一戦）と、
  戦闘エンジンが安全弁で停止したあとの構成見直しにだけ残っています。
- **リプレイが最後の拍まで進むと、追加の「結果を見る」操作なしで結果画面へ進みます。**
  一時停止・一手送り・戻す・速度変更・「結果を見る」で先に進む操作は変わりません。

## 7. 遠征の進行

- 通常戦・精鋭戦の終了時 HP は次の戦闘へ持ち越し、4・8戦目の boss 後に全回復します。
  12戦目は遠征の終点です。
- retry では開始時 HP へ戻し、補給を一度だけ消費します。
- 補給は**再挑戦・報酬の引き直し・野営治療の三用途**で消費する有限資源です
  （偵察は R14 で廃止しました）。
- 通常戦後は「現 HP で進む／補給治療／報酬 reroll／安全撤退」を同じ画面へ出します。
- **通常戦の勝利は、結果画面がそのまま報酬3択の選択を兼ねます。**「報酬を見る」という
  中間画面・中間クリックはありません。最終戦（12戦目）の勝利だけは、報酬ではなく
  既存の精算画面へ進みます。
- Stage 0 の本編第1戦（＝巻き戻したあとの「灰の門」に初めて勝った戦闘）で報酬を受け取ると、補給タブが開き、「集中治療」を1回使う案内が表示されます。
- 安全撤退は敗北と区別します（Blueprint の残る件数が違う）。敗北でも確定済みの
  活動資金は持ち帰ります。
- 4・8・12戦目の直前には、その Stage をまだクリアしていないあいだ、短い幕の断片が入ります。

## 8. 装備・Blueprint

装備は2枠。通常の報酬で提示される装備は、すべて遠征ごとに手続きで組み上がります。

- 装備の rule は拾う前から全部読めます。情報を隠して売る仕組みはありません。
- 組み立ては決定的です。同じ seed / drop / 等級 / affix family からは同じ品が出ます。
- 等級は **コモン / レア / エピック / レジェンダリー / ミシック / オーパーツ**の6段。
  内部 ID は既存セーブとの互換のため維持し、表示には格番号（1〜6）も併記します。
  drop weight は順に 55% / 28% / 12% / 4% / 0.8% / 0.2% で、オーパーツは数百個に1個の想定です。
- item rarity は効果数・組み合わせ予算・耐久・発動上限を広げ、各 payoff effect には
  別の effect rarity が付きます。最高等級の item でも、低い格の効果が混ざりますが、
  少なくとも一つは item と同じ effect rarity です。
- 報酬・装備・Blueprint の表示では、装備全体を「装備レアリティ」、個別効果を
  「基礎効果」「追加効果1」…として分離し、それぞれに格番号と名称を表示します。
  複数の個別効果はレアリティの高い順に並べ、同格なら元の効果順を保ちます。
  条件・代償・数値・発動回数・耐久も拾う前から開示します。レジェンダリー以上は、
  報酬カードにも高位ドロップの強調表示を出します。
- 完結しない rule（発火不能・無料無限循環・打ち消し合う代償）は生成しません。
  50 attempt で作れなければ既定品へ黙って落ちず、診断を表示します。
- 遠征終了時、等級の高い順に **Blueprint（設計図）** が残ります（勝利2・安全撤退2・敗北1）。
- Blueprint archive に所持上限はありません。次の遠征へ持ち込める枠だけが 1〜5 です。
  持ち込んだ品は、その遠征の affix family の外でもそのまま動きます。
- 目利き（5段）は等級の引きを良くします。読める情報は変わりません。

## 9. 会話・根城・図鑑

- 会話本文（台詞と地の文）と場面の配役・立ち位置は `ecology/content/dialogue.mjs` に集約し、
  舞台・解禁条件・表示順は `story.mjs` / `homestead.mjs` に分けています。会話を変更するときは dialogue.mjs だけを編集します。
- キャラクター設定の本文（名前・人物像・来歴・関係）は `ecology/content/character-lore.mjs` に集約し、
  名簿の開示順だけを `dossiers.mjs`、能力値と編成上の役割を `characters.mjs` / `roster.mjs` に分けています。
- 地域と根城の備品の設定本文は `ecology/content/world-lore.mjs` に集約しています。
  敵の噂・図鑑は既存の `encounters.mjs` を正本とし、`world-lore.mjs` の `WORLD_LORE` からまとめて参照できます。
  戦闘・進行・解禁条件は、それぞれの定義ファイルに残しています。
- 会話は立ち絵つきの一行送り。画面のどこを叩いても進み、文字送りの途中なら一度目の
  操作で全文が出ます。AUTO・履歴・スキップがあり、**いつでも飛ばせます。**一度
  クリアした Stage では最初から出ません。立ち位置は五枠で、**加入済みの仲間は
  加入の場面から消えません。**
- 立ち絵は画像ファイルではなく、SVG を組み立てる純関数です。表情は同じ骨格の
  parameter 差として持ちます。
- 精算のあとは**根城**へ帰ります。家にあるものが9件、日常の場面が6本。抽選せず、
  条件を満たした順に一つずつ出ます。**戦闘には影響しません。**
- 根城に隊の**名簿**（来歴・根城での姿・関係）があります。ギルド画面のタブから開けます。
- ギルドに**図鑑**があります。会った灰殻だけが載り、狙い →（1体倒す）噂 →（5体倒す）
  図鑑の節、の三層で開きます。`profile.bestiary` は遠征を捨てても消えません。
- 敵カードに拾い屋の噂が一行、設計図に拾った場所が一行、精算・報酬・野営・敗北にも
  世界の側の一行が付きます。
