# 両案を壊す：そのゲームなら本当に続けて遊ぶか

更新: 2026-09-29。状態: **両案とも採用しないまま、次に捨てる条件を定める。** [45](./45-two-extremes-and-the-fun-contract.md)→[46](./46-five-hand-card-game.md)→[47](./47-ash-march-action-game.md)の順に読む。ここでの「危険」は実測結果でなく、ルールから導いた反例。

## カード型への第一の反論：先取りはただの割り算では

第一試作は初期18点、鍛打後22点、余火を使えると30点。耐久16の敵と11の次敵なら、余火込み30が27を越えるから二枚抜き、と暗算できる。次敵の耐久が15なら必要31なので失敗。**五人の「人物」を眺めるより、毎回二つの数字を足すほうが早い。** これは非常に強い棄却理由である。先取りを押す時刻さえ、良い構成なら「二枚とも倒せる時に必ず押す」へ収束しうる。

さらに、出発時の育成三枠が固定なら、同じ五枚を十二回並べる。勝った場合ほど操作が少なく、短いアニメーションも二周目にはスキップする。『Balatro』はプレイヤーが手札を選び、捨て、どの手役を作るか自分で決める。[公式FAQ](https://www.playbalatro.com/faq)が述べる手役・Joker・ブラインドを移しても、**手札の操作を引いた自動版に同じ面白さが残るという根拠はない**。カードの見た目だけを借りた数字の自動戦闘になる恐れがある。

ただし、毎戦五枚を選び直させれば即座に六回以上の「考える停止」を招く。**自動再生とカードの手札操作は、この試作では本物の衝突**。小手先のUIで解かない。第一試作で三周以内に「先取り以外も自分の選択で手役を作りたい」という声が出たら、連続十二戦を諦めるか、カード路線を捨てるか、明示的に選ぶ。

敵についても重大な損失がある。耐久26・反撃1と耐久8・反撃5の差はあるが、実際に考えることは手役の閾値と損失だけ。敵の名前を隠しても選択が変わらないなら、五人の遠征ではなく算数のスコアアタックになる。ボスに「盾札禁止」のような固有妨害を増やすと、さきに否定した持ち物検査へ戻る。

## アクション型への第一の反論：自分の構築ではなく指が勝つのでは

十二波を片指で動き続けるなら、プレイヤーの経験・端末性能・操作の得手不得手が勝敗を大きく決める。寝る前にヒバナとナギの組合せを考える楽しさは残せても、**その考えが報われるゲームだとは限らない**。射手の弾が偶然ナギに当たり、そこから火種で全滅しても、プレイヤーは「自分が設計した」と感じるより「運がよかった」と感じるかもしれない。

逆に強い育成が発火するなら、指を動かさなくても敵が消える可能性がある。その場合アクションは最初の数十秒の雑用になる。これはアクション方向にしても「毎回のUI操作が作業」という以前の批判を別の形で踏む。

技能の追加にも天井がある。[Noita公式](https://www.noitagame.com/)は自作の魔法が物理世界へ働くことを前面に出すが、こちらの縦長スマホ画面で五人分の弾・敵・HP・未来の波を同時に見ると、原因の追跡はもっと厳しい。十技能の段階で赤い火種、ナギの反射、ゴウの波を区別できないなら、190技能を持ち込む理由はない。「大量のコンボパーツをユーザーに委ねる」は、**プレイヤーが理解することを放棄する免罪符にならない**。瞬間の視覚的快感と寝る前の理解を両立できるかが賭け。

この案の弱点は十二波の長さでもある。25秒×12なら敵を早く倒さなくても約5分、序盤の弱い数波が毎周義務になる。強い構成は早く殲滅して短縮できるが、最初の一分を退屈にしたままなら続かない。速度を上げると指の操作がさらに忙しくなる。移動負担を嫌うユーザーに「慣れれば簡単」と説得してはいけない。

## 反例を先に書き、試験時に数える

| 悪い観察 | 何が壊れるか | 観察方法／棄却の目安（仮の閾値） |
|---|---|---|
| カード: 先取りの全選択を暗算で一意に決められる | 人間の賭けでなく閾値処理 | 紙札三周で、先取りの理由を全て「合計耐久以下だから」で説明したら設計を変更 |
| カード: 同じ五枚を三周連続で流し、途中で一度も見たくならない | 十二回の自動スコア映像 | 周回ごとにどの札を見ていたかを観察。二周目から最初の一枚だけ見て放置したら危険 |
| カード: 人物名ではなく「鉄を出す札」「回復札」と呼ばれる | 五人を残す約束が外見だけ | 試遊後に「誰の行動で救われたか」を聞き、名前と出来事が結びつかないなら危険 |
| アクション: 技能予約を変えても上手い操作者の勝率・突破速度がほぼ同じ | 寝る前の思考が不要 | 同じ人が初期技能のみ・連鎖予約・守り予約を各三周、敵の出現種を揃えて比較。差が操作誤差に埋もれたら危険 |
| アクション: 強い予約で指を離しても十二波を越える | 操作が付け足し | 画面中央から移動しない試験で同じ構成を三周。勝てたら敵の接触・弾・回復を再設計 |
| アクション: 爆発の理由を「よく分からない」で済ませる | 構築への所有感が消える | 六波目の連鎖直後に操作を止め、五人の誰が最初の撃破を作ったか言ってもらう。答えられなければ表示と技能接続を減らす |
| 両方: 五人のA/Bで最適解が固定され、三周後の予約が同じ | 研究する楽しさが止まる | 敵の順を変えて三周。固定予約だけが正解なら技能の価値と敵の圧力を作り直す。敵専用の封じ技は追加しない |

三周や人数は統計学的結論を出す閾値ではなく、**退屈がすでに見えるなら大規模制作へ進まないための早期停止条件**。面白さの証明には数人の試遊、異なる操作技能、再訪時の自発的な再プレイが必要。

## 今日の判断

**カード型は一画面・短い思考という条件には合うが、いまのままでは「自動で点数が出る装置」から一歩も出ていない。採用保留より厳しく、実質的に棄却寄り。** 先取りが人間の選択になる余地を発見できなければ捨てる。

**アクション型は現時点で突き抜ける可能性が高い。** 「最初の撃破を仕込む→ナギの一発が通る→五人の効果が画面上で波及する」という時間と空間の変化は、今までのHP帳簿にない。しかし五人の人格が武器アイコンになり、片指の移動が寝る前の構築を食う危険も強い。推薦は製品化の決定ではなく、**まず十技能・二波・三分の操作可能試作を一本作る**こと。移動と連鎖の両方が好きだと言う試遊者がいなければ、百技能を考える前に撤退する。

## 次の二つの小試作の完成条件

1. **カード**: 五枚と次敵二枚の紙札を十秒で読める。五人の予約を変えると「先取りしたい／したくない」の理由が変わる。同じ敵順の二周目でも、少なくとも一度は結果を見るために手を止める。耐久以外の新しい敵状態を加えずに試す。
2. **アクション**: 単色の図形と手触りでよい。五人の色、弾と敵の接触、盾から火種への連鎖、十技能のうちH-A/N-A/G-A/T-Aを実装。敵は小敵・射手の二種、波は二つだけ。三分遊んだ人が「どこを動かしたからこの連鎖が始まった」と自分の言葉で言えるか。完成した戦闘エンジンや十二波の制作を先にしない。

**この文書自体の反論漏れ**: 実際の敵AI・ヒットストップ・音・指の疲れ・人物の絵と声がないため、アクションの快感と負担を文章から推定している。紙札でのカード案も、提示した二数だけでは本来のカードゲームの偶然性・ドラフトの魅力を再現しない。両案の比較はまだ机上であり、「アクションのほうが面白い」という実測ではない。
