# 五拍の余りを持ち越す案を撤回する

更新: 2026-09-28。状態: **失敗した改訂案**。[30](./30-five-beat-clock.md)の五拍時計自体は紙上の試作候補のまま。[31](./31-five-beat-adversarial-audit.md)へ付記するための記録。

## 見つけた穴

30では「行動して敵を倒したなら、技の費やす0/1/2拍を足す前に波が消え、時計が0へ戻る」。そのため**仕留めた重い二拍技は時間上の代価を払わない**。ゴウの7ダメージが単体首領にも群れの最後にも強く、[玩具](../../analysis/skill-reboot-five-beat-toy.py)ではゴウAの1,920中1,897構成が勝ち、Bの1,474を大きく上回った。この差の全てをこの穴へ帰することはできないが、設計が重打ちの仕留めを優遇するのは確か。

これは必ずしもバグではない。「倒し切れば敵に手番を与えない」がご褒美なら、重い最後の一手が無料になることは気持ちよさの一部。ただし技能二択が成立するには、この優遇を含めて調整しなければならない。

## 書いた手直し

倒す行動の拍も使ったものと数える。敵を倒した瞬間の残り時間を、次の波に**最大3拍まで持ち越す**。たとえば前の波を時計2/5から1拍技で倒せば残り2、次の波は7拍が満ちるまで反撃しない。大槌の2拍で同じ敵を倒せば残り1、新波は6拍。敵が反撃したら次の時計は通常の5拍に戻る。これで速いヒバナと連破のゴウに、強打のゴウとは違う「次の波への余裕」という強みが生まれるはずだった。

[変更した独立玩具](../../analysis/skill-reboot-time-carry-rejected-toy.py)では、元の十二波・全3,840構成の**3,710が勝利**。最大余裕を1拍に抑えても**3,587勝**。前者はゲンゾウBが1,920/1,920勝、後者はゴウAとゲンゾウBがそれぞれ1,920/1,920勝になった。元の3,371勝から、差が**小さく**なった。持越しは速い成功を次波の猶予へ変え、その成功がさらに次波で安全な撃破を生む。勝ち続ける快感は増すかもしれないが、今回の五人と敵列では選択の差を溶かす。

## 捨てる理由と残す問い

- 3拍持越し版も1拍版も、**このまま主案へ入れない**。強い構成で十波以上を連破する絵は魅力的だが、何を選んでも成功するなら予約と人物の意味がなくなる。
- 残り拍を**戦績・演出の評価**へ変える案もあるが、報酬に結びつければ最速一択、結びつけなければ数字の飾りになる。今は制度を増やさない。
- 30のリセット規則には仕留め技の優遇が残る。ここは「意図したキルのご褒美」として明示し、ゴウBとゲンゾウA/Bを作り直す対象にする。数値だけで1,897対1,474を均等にしたとしても、別の敵列で再逆転する恐れがある。

次に進む条件は新しい資源の追加ではない。現行の五拍ルールで、①小型の連破、②首領を仕留める重打ち、③反撃を盾で受けて回復する戦いが**同じ十二波でそれぞれ意味の違う気持ちよさ**になること。玩具では達成していない。人間が30の一秒を実際に遊んで「もう一回組み直したい」と言うか、それに到達できなければ時間の構造ごと捨てる。
