# 候補B：灰火の行軍 — 正確な予測を捨て、五人の連鎖を身体で通す

更新: 2026-09-29。状態: **アクションへの転換案、未採用**。前の「五人が自動で順番に殴る」ルールは残さない。**移動をプレイヤーが担う**ため、寝る前の構築と出発後の操作という二種類の面白さを持つ。その代償を隠さない。

## 一画面で何をしているのか

縦長の一つの平原で、プレイヤーは中央の灰火を片指の仮想スティックで動かす。指を離せば停止。五人は灰火から少し離れた定位置を自動で保ち、それぞれの武器を自動で使う。敵は四辺から出て灰火へ向かい、接触か飛び道具で灰火を傷つける。プレイヤーは移動して接触を避け、ナギの盾が飛び道具を受けられる位置へ敵を誘い、仲間の射線を敵の群れへ通す。

五人を個別に歩かせない。隊の進路を自動AIに任せない。**画面から指を離すと五人はその場で止まり、敵が近づいてくる。** 十秒以上の放置は危険な場合が多い。この案では戦闘の観賞だけで十二戦勝つ約束を捨てる。

| 契約 | 第一試作の規則 |
|---|---|
| 画面 | 片手縦持ち。灰火が中央、ナギは上、ゴウは左前、ヒバナは右前、ゲンゾウは右後ろ、ツグミは左後ろ。画面内の立ち位置は灰火の移動方向で自動回転しない。ナギを弾の側に向けたいなら、隊そのものを寄せる |
| 人物 | 各人HP2。敵弾や接触を受けると1失い、0ならその波の間は倒れて自動攻撃を止める。次の波の開始時にHP1で戻る。ツグミの治療は波の途中でも一人を起こせる |
| 灰火 | HP12。敵の接触・通過した敵弾で1減る。HP0で敗北。五人全員が倒れても、灰火HPが残る限り操作で避けられる。十二波を越えれば勝ち |
| 敵 | 四辺から灰火へ移動。小敵は接触、大敵は接触しつつ遠距離弾、射手は離れて弾を撃つ。防具・専用解除属性・敵の弱点アイコンは第一試作にない。弾と接触が人物へ当たるか灰火へ当たるかは画面上の当たり判定で決まる |
| 波 | 全十二波、各波は最大25秒で次波を追加。敵をすべて倒せば約1秒で次へ進む。十二波の最後の敵を倒すと勝利。早く殲滅すると連続して進むので、強い構成ほど行軍が加速する。時間が来て未撃破なら敵が残ったまま次波が重なる |
| 先見 | 現在の波の残り5秒、または殲滅直後の短い間、次波が現れる辺と「群れ／射手／大敵」の構成を薄い残像で示す。敵の正確な座標、全戦闘の結末、五人の被弾は計算・表示しない |
| 操作 | 移動一つ。攻撃・技能・回復・ターゲット・必殺技のボタンはない。指を離すと停止、再び触れると動く。予約技能は第2・4・6・8・10波の開始前に自動で加わり、画面を止めない |

ここでの先見は「わずか先の到来方向を知る」意味であり、既存作の正確な一戦シミュレーションを廃止する。敵のランダムな細かな出現位置、弾、プレイヤーの移動により、出発前の勝敗をオラクルで照会できない。代わりに、寝る前に立てた技能の仮説が実際の空間で当たるかを試す。

## 最初に五人が必ずすること

| 人物 | 初期行動 | 姿・役割 |
|---|---|---|
| ヒバナ | 1.2秒ごとに射程内の近い敵へ火矢1 | 小敵に最初の撃破を作る。火は赤い線で追える |
| ゴウ | 1.8秒ごとに自分の近くの敵へ槌2、少し押し返す | 近い群れを開き、灰火の逃げ道を作る |
| ゲンゾウ | 2秒ごとに遠い敵へ貫通弩2。直線上の最大二体に当たる | 奥の射手と整列した群れへ圧力をかける |
| ツグミ | 5秒ごとに傷ついた味方一人を実HP1治す。全員無傷なら灰火の欠損を1治す | 生存の反復を支える。攻撃はしない |
| ナギ | 自分へ向かう敵弾か、自分から灰火へ続く直線を通る敵弾を2秒に一発まで盾で止める。弾がなければ近い敵を2.5秒ごとに1押す | 弾を目で受け止め、後の反射の起点になる |

自動行動の優先対象は上の一文で完結する。プレイヤーが五人分のターゲット規則を設定する画面はない。ナギが上にいる理由は弾を盾へ通すための位置作りであり、「弾を盾で止める」が絵として成立する。射手の弾が背後から飛べば盾を通らず、移動で隊の上をその射線へ運ぶか、弾を避ける。

## 予約する十の追加技能

取得済みは基本そのまま働く。全員、二候補から一つを出発時に予約でき、五人分が順に第2・4・6・8・10波で追加される。解禁順はヒバナ→ナギ→ゴウ→ゲンゾウ→ツグミに固定する。初回は各人Aが入った推奨予約を提示し、慣れた人がBを選ぶ。効果は**基礎行動に足す**。RP共有・優先順位・装備枠を持たない。

| 人物 | A | B |
|---|---|---|
| ヒバナ | **火種**: 敵を一体倒すたび、その死体から近くの別の敵へ威力1の火の小弾2つを放つ。小弾も敵を倒せる | **延焼路**: 火矢を受けた敵が2秒だけ燃え、その敵に重なった別の敵へ毎秒1の火を渡す |
| ナギ | **返し盾**: 敵弾を盾で受けたら撃ち手へ威力2の反射弾を一発返す | **重盾**: 盾の再使用を2秒→1秒へ短縮し、盾で守った味方のHPを実際に1回復する。回復は一波一回 |
| ゴウ | **震脚**: 味方が敵を累計3体倒すたび、ゴウの周囲に威力2の衝撃波。累計は波が変わっても続く | **裂き槌**: ゴウの押し返しで敵が別の敵へ当たると、両方に1を与える |
| ゲンゾウ | **模写弩**: 味方の基礎射撃が通算4発出るたび、最後の基礎弾を威力半分で一度だけ写す | **縫い弩**: 貫通弩が二体へ当たったら、次の基礎弩は三体を通る。三体目まで届いたら効果を消す |
| ツグミ | **戦地回収**: 敵の討伐累計6体ごとに灰火の実欠損を1回復する | **起こし薬**: 味方が倒れたとき一波一回だけHP1ですぐ起こす。次の通常治療は5秒後から数える |

「累計」を持つのはゴウの三体、ゲンゾウの四発、ツグミの六体だけで、画面では各人の円環一つとして表す。その他は目の前の弾・敵・味方の結果に反応する。十技能の新しい状態語はヒバナBの「燃える」のみ。初期の百種類超を作るなら、この十個で一周目の実感を得てから、**軌道・衝突・群れ・距離・守り・討伐数の別の接続**を加える。

### 単なる「強そうな技能一覧」にしないための生成規則

新しい技能は「見える入力→画面上の別の出力」を必ず持つ。入力は攻撃の命中、実際の討伐、敵弾の防御、二敵の衝突、味方の実欠損、基礎弾の発射。出力は弾、衝撃波、押し返し、燃焼、実回復、次の基礎行動の変化。異なる人物の技能は同じ**実討伐**と**敵の位置**を共有する。敵専用の鍵や「次の特定ボスだけを封じる効果」は作らない。

実際の敵一体から発生する討伐イベントは一回だけ。討伐でできた小弾が別の敵を倒せば、その新しい敵の討伐イベントは一回発生し、火種も続く。敵が有限なので討伐起点の連鎖も有限。**模写弩が数えるのは五人の基礎射撃だけ**で、模写弾や火種弾を再模写しない。この例外は画面上で基礎弾を太線、追加弾を細線として区別し、「基礎弾四発」の文言を技能に出す。無限増殖を防ぐ隠し上限より、入力の種類を見せる。

## 六波目で起きる可能性がある十二秒

事前予約でヒバナA、ナギA、ゴウAを取得済み。敵は小敵の群れとHP2の射手。プレイヤーが灰火を少し上へ寄せて、射手の弾をナギの盾へ通す。ナギが止め、反射弾2が撃ち手の射手を倒す。**味方による実討伐**なのでヒバナの火種が小弾2つを出し、その一つが残りHP1の小敵を倒す。火種がまた二弾を出す。三体目の実討伐でゴウの震脚が近くの群れへ広がり、さらに二体を倒す。ここで一度に空いた道をプレイヤーが抜ける。後にツグミAが解禁済みなら六体目の討伐で灰火の欠損を1治す。

この十二秒は**敵を十分に詰めておかないと起きない**。群れに囲まれる圧力が、最初の一撃を通した瞬間に画面掃除へ反転する。ゲンゾウが貫通弩で先に複数を弱らせると、ナギの反射で連続討伐が起きやすい。五人がただ別々に敵を狙っているだけなら失敗。実演では、四人それぞれの色を付けた軌跡が一つの連鎖へ混ざる必要がある。

## 参照と、その限界

[Vampire Survivors](https://store.steampowered.com/app/1794680/Vampire_Survivors/)の自動攻撃と成長、[Hades](https://www.supergiantgames.com/blog/hades-dive-into-the-blood-price-update/)の異なる強化の組合せ、[Noita](https://www.noitagame.com/)の作った仕組みが実空間で予想外に働く点、[Risk of Rain 2の開発更新](https://store.steampowered.com/news/posts/?appids=632360&enddate=1597157628&feed=steam_community_announcements)の共通効果が武器の価値を波及させる点を参考にした。これらは**仕組みからの推論**であり、『灰』が同じ快感を持つことの証明ではない。

最大の反論は明白。上手い手操作だけで勝てるなら、寝る前に考える育成の重みが消える。逆に強い予約を持てば動かず勝てるなら、アクションの追加は邪魔になる。五人全員を同時に動かしても各人が「銃座」に見えるなら、守りたいキャラクター性も失う。[48](./48-two-extremes-adversarial-review.md)でこの案を中心に壊す。
