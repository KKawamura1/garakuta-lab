# 追加候補：五人が順番に触れて初めて強くなる「継ぎ印」

更新: 2026-09-29。状態: **[50](./50-action-prototype-first-contact.md)の批判から生まれた紙上案。試作には未実装。** 技能を十個増やす前に、五人である意味が一つの共通ルールから生まれるか調べる。[47](./47-ash-march-action-game.md)の火種・震脚を丸ごと置き換える可能性もあり、単純な追加パッシブとして扱わない。

## 一つだけ公開する印

敵が味方の攻撃を受けて生き残ったら、**最後に当てた味方の色の輪**を2秒だけ持つ。次に**別の味方**がその敵に当てると輪がはじけ、今当てた味方の「受け技」を一つ発動する。同じ人が続けて当てたら輪の2秒を更新するだけ。受け技の攻撃も別の敵に当たって生き残れば、その受け技を出した人物の輪を残す。

順序は、弾の衝突→基礎ダメージ→直前の輪と撃ち手を比較→異なる人なら輪を消して受け技→生き残った敵に今の撃ち手の輪を付ける。**倒した敵には輪が残らない**が、異なる人の一撃で倒したときも受け技は発動する。受け技が別の敵を倒せば通常の討伐として処理する。ひとりの弾が一体へ複数回当たっても、それだけでは継ぎ印にならない。

画面には敵の周りに色の輪を一つ、発火時は**前の人物色→今の人物色**の短い線を一本出す。敵の上に状態語を何個も積まない。五人×順序の二人組だけでも20通りの連携方向があるが、**20通りが面白いこととは別**。見るべきは自分が狙ったつながりを実際に作れるか。

## 五人の受け技の初期値

| 二人目 | 受け技（異なる味方の輪を破ったとき一回） | 五人としての意味 |
|---|---|---|
| ゴウ | 命中した敵を中心に、近くの敵へ威力1の衝撃波 | 誰かが削った集団へ自分の槌を届かせる |
| ヒバナ | その敵の近くの別敵二体へ威力1の火の小弾 | 一体への集中を次の群れへ分ける |
| ゲンゾウ | 当てた弾の向こうの別敵へ威力1の矢を一本伸ばす | 先頭で作った印を奥の敵へ運ぶ |
| ツグミ | 傷ついた味方を実HP1治す。傷がなければ灰火の欠損を実際に1治す。両方無傷なら効果0 | 先の打撃を生存へつなぐ。ツグミは従来の治療に加え、3秒に一発だけ威力1の薬矢を撃つ |
| ナギ | その敵を押し返し、味方の前へ一発分の防弾を張る | 自分が後から触れた敵の圧力を減らす。基礎盾で反射した弾もナギの打撃と数える |

ここで「仲間が揃っていれば常時+20%」は一つもない。先の一撃があること、別人が同じ敵へ届くこと、結果が画面の別の場所へ移ることが条件。スマホ上でそれが見えなければ設計全体を捨てる。

## 三つの具体例と一つの空振り

1. ゴウの槌2がHP4の敵をHP2にして、金色の輪を残す。ヒバナの火矢1が当たり、金→赤の線、ヒバナの小弾が横のHP1の敵を倒す。最初の敵はHP1で生き、赤い輪になる。少し後にゲンゾウの貫通弩2がその敵を倒すと、赤→青の線と奥への矢が出る。**三人の順番が見える**。
2. ナギの盾からの反射弾が射手をHP3→1にする。射手には紫の輪。ゴウが距離を詰めて槌で倒すと、紫→金の線と衝撃波が出る。盾の成功が逃げ道を作る。固定隊形を動かし、ゴウを射手の側へ運んだことがプレイヤーの介入。
3. ツグミの薬矢は3秒ごとに1点しかないが、ゴウの槌2でHP5→3になった敵を薬矢でHP2にすると、金→緑の線と実治療が出る。治療のために別の回復ボタンを押す必要はない。
4. **空振り:** ヒバナの火矢がHP1の小敵を一撃で倒す。輪が付かず、誰も継げない。一撃必殺で敵を掃除する構成には「継ぎ印」が不要になる可能性がある。継ぎ印のために敵を不自然に硬くすると、あの退屈なHP帳簿へ戻る。ここを数値で無理に救わない。

## 技能を増やすときの契約

各人物は最初の受け技を持つ。育成はその**入力、出力、届く相手**のうち一箇所を変える。例えばヒバナの小弾を「二体へ」から「印がある敵を優先する」へ、ゴウの波を「敵の周囲」から「ゴウと敵の間」へ、ゲンゾウの矢を「一体先」から「印を付けた味方の反対側」へ、ツグミの回復を「人」から「灰火」、ナギの防弾を「一発」から「連続二発」へ変える。初回は各人A/B一組だけ作る。同じ入力を増やすだけの+10%を十枚作らない。

しかし高頻度の共通発動には弱点がある。上位技能がひとつ増えるたび、二人組が勝手に成立して画面へ線が多発し、**終盤に何も読めなくなる可能性が高い**。だから、第一試作の敵6体にゴウとヒバナの二人だけを載せ、一体の輪が誰の色へ変わったかを紙でも画面でも当てられるか確認する。五人へ増やした途端に追えなければ、将来の190技能を口実に続けない。

## いちばん強い反論：操作で二人をつなげるのか

五人が自動で狙う以上、継ぎ印が起きても「たまたまゴウの次にヒバナが当たった」だけかもしれない。移動で隊の位置を変えた結果、誰が先に当て、次が誰になるかを**プレイヤーが大まかに予測し、誘導できるか**が核。固定隊形では無理なら、指を動かす意味も五人を区別する意味も弱い。そこで直ちに編成UIやターゲット規則を増やすのではなく、この案自体を棄却する。

「先駆け」で新しい敵を増やすと、ゴウが一体につけた輪をヒバナが消費する前に別の敵へ狙いが移る可能性もある。敵密度が増えれば必ずコンボが増すわけではない。**敵を早く呼んだことで継ぎ印が切れた**という失敗が目で分かるなら、先見の加速は考える価値を持つ。わからなければ、単に画面が騒がしくなるだけ。

暫定: 火種の全体討伐条件は「一人が五つの武器を持っても同じ」という批判に弱い。継ぎ印は五人を必要とするが、低HP雑魚の一撃掃除と相性が悪く、移動で狙いを作れる保証がない。**置換を決める前に二人・六体で短い操作試験をする。**
