# 「店だけ」案をもう一度壊す — 停止頻度、単独最強、予約の既視感

更新: 2026-09-29。状態: **[57](./57-shop-only-action-candidate.md)を書いた直後の反論。後に[四波を実装](./ash-shop-only.html)し、[59に結果を記録](./59-shop-only-first-contact-and-continuity.md)。採用未決。** 好意的な紙上連鎖を作っただけでは、同じ案をまた売り込んだことになる。特にヒバナの商品はそのままでは危うい。

## 危険1：ヒバナだけで全部燃える

[57](./57-shop-only-action-candidate.md)の「余火」は、燃える敵が死ぬたび70px以内の別敵へ威力1の火弾を出し、その火弾が当たった敵も燃やす。HP1の小兵が全員70px以内に固まっていれば、**ヒバナの最初の一撃一発で全員倒せる**。ゴウの押し込みもゲンゾウの準備もいらない。五人の美しい因果の例を書いたつもりが、一番ありふれた敵配置ではヒバナ一人の自己増殖技能が残りを食ってしまう。

半径を70→35へ狭めるだけでは、店で常に余火を買う問題は残り、射程境界が読みにくくなる。「一波一回」や「二連鎖まで」の隠れた制限を足すと、期待した大爆発そのものを消す。余火を購入一つで完結させる構造を疑うべき。例えば**ヒバナは火を付けるだけ、別の人が燃える敵へ当てて初めて火が広がる**なら五人の関係は強くなるが、今度は自動AIの攻撃順がたまたま揃うのを待つゲームになりうる。[51の継ぎ印](./51-relay-mark-candidate.md)を店売りにしただけなら前進ではない。**両版を小さく比較して、一方だけを宣言で救わない。**

## 危険2：「買える時に買う」以外がない

同じ商品を後で買っても値段・枠・内容が変わらず、その商品の効果が常に非負なら、早く買った方が働く時間が長い。購入時に一発撃たせる演出を加えると、購入を好きな瞬間に狙うメニュー操作になり、ドラッグを減らした手軽さを別の忙しさに置換する。現実の戦闘では対象AIや敵移動のため非単調な例外はありうるが、「取得すると時に弱くなる」を時機選択の核にするのは罠に近い。

真の機会費用は**今の安い商品を買うと、同じ灰片と一補給枠で次の高い商品を買えなくなる**ことに置く。ただしこれも将来の棚が全部既知なら出発時に計算でき、完全に未知なら寝る前の計画が祈りになる。『灰』の一波先という設定で次の敵を見ることと、商品の抽選をどこまで隠すかは別に検証する。

## 危険3：買い物だけでは操作の著作が買い物以前へ戻る

自動予約を使って強い構成が十二波を止まらず突破すれば、それは[最初の構想](./45-two-extremes-and-the-fun-contract.md)に近い望ましい爽快感。一方、現在の行軍試作の無移動勝利を引き継ぐだけなら、店も技能も敵も飾り。ユーザーが考えた購入と画面上の三段以上の連鎖との間に、視覚的に追える因果が要る。

商品を三補給・各三択としたのは入力回数を抑えるためだが、買った効果が発火する前に次の補給が来れば、何を買ってよかったか学べない。波を短くすれば爽快だが学習を削る。長くすれば観賞が退屈になる。この矛盾は速度調整だけで消せない。**最初は四波の30〜45秒を実際に見て、初購入の後の5秒で何が変わったか言えるか**を調べる。

## 比較する三条件。いい結果だけ拾わない

同じ四波・同じ初期五人・同じ乱数系列を用意する。プレイヤーには試す前に「どの二人の因果を見たいか」を一文で言ってもらう。勝率だけでなく、止めた回数、店を見た理由、見たい連鎖が起きたか、起きなかった理由を記録する。数値は平衡化の材料であり、面白さの代理にはしない。

| 比較 | 聞きたいこと | 強い反証 |
|---|---|---|
| 無購入・完全放置 | 基礎の五人だけでも敵に圧力があるか | HP満タンで全波完封。または購入がないと第2波で必ず即死 |
| 余火だけを購入／衝突槌だけを購入／縫い弩だけを購入 | 一枚の商品が映像と生存へ何を足したか | 余火一つで密集も散開も最速処理し、他を買う理由がない |
| 余火＋衝突槌／衝突槌＋縫い弩／余火＋返し盾 | 別人二人を買うと**単独商品の足し算以外**の現象が見えるか | 連鎖は増えるが、誰が何をしてそうなったか画面で言えない。または単独の余火と同じ絵 |

この比較は購入価格が異なる。余火5と安価2+2の効果を勝敗で単純に比較しない。単独商品を購入しない分の灰片を保持したままでも戦闘する。「多く買った方が勝った」は相互作用の証拠ではない。生き残りと火力に加え、最初の購入以後に**どんな映像が新たに発生したか**を対照する。

## 暫定の位置づけ

移動を消した瞬間、『灰』はBrotatoやSNKRXの簡単な亜種ではなく、**映像のあるショップ型オートバトラー**になる。これは面白くなりうる。だが成功している近縁作は、配置・操縦・敵を置く・毎回の買い物など、どこかに判断を集めている。[56](./56-control-budget-research.md)。『灰』はその判断を少ない購入へ極端に集約する賭け。現時点で最も誠実な評価は**元の移動案より入力としては好みでも、ゲームとして強くなった証拠はまだゼロ**。
