# 武器ツリー・カタログ案 — 10武器 × 19節（全面改稿）

更新日: 2026-09-22
状態: **PR #288で10武器190節をplayer registryへ接続し、初期ロードアウト・敵技能分離・pack分離・取得予約の基盤を検査済み。最終係数・プレイ感・UI表示は未検証。**
前提: `10-weapon-tree-reboot.md`

## 0. 読み方

全武器を同じ19位置で書く。

- `R`: 通常は1SPを払って入る代表アクション。ただし人物ごとの代表武器2本では、初期技能として無料で持つ。
- `A → AA`: その武器で最も単純な王道。無条件中心で、読んだ通りに強くなる。
- `A → AB`: 王道から分かれる、範囲・回数・攻防配分の扱いやすい応用。
- `B → BA`: 条件と他武器への連携。
- `B → BB`: 資源・状態・対象範囲を組み合わせた、深いが一文で説明できる完成形。特別な勝利条件を使う場合も、判定は一つに絞る。
- `A3 / B3 / AA3 / AB3 / BA3 / BB3`: 親の主軸を置き換えるアクティブ形態。

| 種類 | 解決規則 |
|---|---|
| アクティブ | 選択中のメインアクション一つだけ。APごとに同じ主軸を再評価する |
| リアクティブ | 指定eventで優先列を上から検査し、その人物で最初に成立した一つだけ発動してreturnする |
| ターゲット | 対象問い合わせ時に優先列を上から検査し、最初に有効候補を返した一つだけ使う |
| パッシブ | 条件を満たすものをすべて適用する。反応窓を消費せず、早期returnしない |

各リアクティブには`発動後に残すRP`を設定できる。現在RPから費用を引いた値が留保未満になる技能は飛ばして
次を検査する。頻出RP1を取りつつ、後で起きるRP2の蘇生や完全防御を予約できる。

ターゲットは複数取得でき、優先列の上から最初に候補を返せた規則を使う。どれも成立しなければ
単体攻撃は最も近い有効な敵を狙う。非攻撃アクションは各Rに既定対象を書く。
各アクティブ本文の「最も近い」「最も遠い」「HP割合最低」は、固定対象と明記しない限りfallbackであり、
成立したターゲットがあればそちらを先に使う。

攻撃の既定射程は近接である。近接は前列から使うと最終ダメージ125%、後列から使うと40%になり、敵前列が
生存する間は敵後列を候補にできない。長射程・遠隔は使用位置の減衰なしで敵後列も候補にできるが、敵前列越しの
後列攻撃は遮蔽で75%。支援は味方への距離減衰を受けない。係数は量だけを決め、例外は各武器の「射程」に明記する。

アクティブ形態以外は出身武器を発動条件にしない。攻撃、基礎hit数、射程、準備、回復、防壁、移動などの
行動特性が一致すれば、別武器の主軸でも発動する。hit由来の状態・固定値・受け無視は原則1行動1回、割合補正は
一行動の合計へ一度だけ適用し、多段へhit数倍しない。

割合、回数、状態段数は比較用の仮値である。ただし確率は使わない。「しやすい」は、優先、固定値、回数、
閾値、確定付与のいずれかへ書き換えている。


### 0.1 PR #288で固定した実装境界

このカタログの190節は、PR #288でプレイヤー武器技能registryへ接続した。実装で追加・確定した境界は次のとおり。

- 10武器すべてを19節のcontentとして保持し、manifestは遠征中に利用できる武器だけを選ぶ。技能レベルmapや旧共通packツリーは使わない。
- 各人物の初期ロードアウトは代表武器2本のR＋A1。Rはactive候補2つ、A1はpassive2つで、初期reactive／targetは空。activeはその中から一つだけ選ぶ。
- 敵のactive／reactive／passiveはプレイヤーの表から分離した敵専用registryに置き、敵actorが参照する定義だけを残す。敵技能をこの190節へ足さない。
- 装備packと武器技能packは別registry・別manifest欄にする。UIの一体表示は見せ方のaliasであり、解禁対象と装備抽選の正本は分ける。
- 取得予約は一人一目標。前提を飛ばさず、SPが揃えば前提から順に解禁する。旧saveの移行、旧技能レベルの復元、解禁の払い戻しは行わない。
- PR #288の既存語彙（対象、状態、移動、準備、AP、RP、防壁、回復）を優先する。タイル履歴、任意の行動順キュー、時間制限の延長、特殊な防壁種別は今回のツリーでは採用しない。
- 深い節は親の基礎効果を下げず、対象数・係数・追加効果のいずれかを増やす。条件付きの追加価値は、条件外でも親の代替として機能させる。

したがって、以下の表の「R」は通常取得時には武器への入口（1SP）だが、上記の代表武器2本では初期技能として無料で持つ。

この境界は `analysis/ecology-weapon-loadout-smoke.mjs` で、初期4技能、敵registryの使用集合、装備／技能packの種別分離を検査する。

### 0.2 実装契約・表示用効果文・フレーバー

各節には三種類の文章を持たせる。

- **実装契約:** event名、固定順、fallback、資源の生成禁止など、予測と実戦を一致させるための完全な規則。
- **表示用効果文:** プレイヤーが取得判断に必要な対象、条件、量、期間、費用、上限だけを書く。event名、内部ID、
  固定マス順、別節を自動適用する説明は書かない。
- **フレーバー:** 効果を言い換えず、その武器や人物の手触りを短い文章で伝える。

フレーバーの格もツリーの深さに合わせる。ルートと浅い節は動作や手触りを短く言い切り、中層のA3・B3は
戦い方や人物の声が見える一文にする。四枝の終端AA3・AB3・BA3・BB3は、前半で光景や覚悟を描き、後半を
決め台詞にする二行構成とする。表では文の境目へ`<br>`を置き、実UIでも同じ位置を優先改行として扱う。

アクティブの置換元、種別、枝、射程、RP費用、ラウンド／戦闘回数は共通UIのタグでも表示する。とくに
「○○を置換」は効果本文へ重ねない。表では比較できるよう費用と回数も表示文へ残すが、実UIではタグとの重複を
避けてよい。

### 0.3 状態と仮数値の共通基準

腕力・技術50前後を基準にすると、受け1は100%攻撃へ約2%、200%攻撃へ約1%しか影響しない。条件付きの
一節が成立しても結果がほぼ変わらない値は置かない。今回の初期目安は、受けの浅い増減6〜10、単体防壁15〜30、
一行動の割合補正15〜30%とする。受けは**hitごとの固定軽減**なので、多段への価値は単発より高い。

| 状態 | 表示上の共通効果 |
|---|---|
| 怯みN | 次の主軸が与えるダメージ・回復・防壁-N×15%。解決後に全消費。上限3 |
| 隙N | 次に受ける攻撃ダメージ+N×15%。被攻撃後に全消費。上限3 |
| 集中N | 次の主軸が与えるダメージ・回復・防壁+N×15%。解決後に全消費。上限3 |
| 裂傷N | ラウンド終了時に固定ダメージN×5を受け、その後1減る。上限6 |
| 観測N | Nラウンドの間、全味方の攻撃で軟優先される。ラウンド終了時に1減る |
| 移動不能N | 移動または位置交換を一回無効にして1減る |

- **受け:** 1hitごとの固定ダメージ軽減。防壁は合計量、受け構えは完全に無効化する残り回数を表す。
- **隣接:** 2×3の6枠で上下左右に接している位置。斜めは含めず、複数候補は既定の位置順で一体だけ選ぶ。
- **正の状態:** 集中・守勢・観測・号旗の鼓舞など、戦闘中に付与される味方側の強化。防壁、受け構え、HP回復、AP/RP、連携、破片などの資源カウンタは含めない。


### 0.4 応急手当型の副接続

この改稿では、各武器に副接続を置くが、リアクティブの数や発動eventを揃えない。副接続は、主軸の倍率を上げるだけでなく、被弾・対象指定・準備開始・移動・撃破などの出来事を、武器らしい別の出口へ変える節である。

- 取得中の武器や選択中の主軸を条件にしない。別武器の主軸でも、行動特性とeventが一致すれば発動できる。
- 同じ武器内でも、A→AA／A→AB／B→BA／B→BBの役割を一文で説明できるようにする。リアクティブが多いこと自体を価値にしない。
- 発動条件、RP費用、チェイン／ラウンド／戦闘上限、空きマス、対象生存などを明記する。不成立時にRPだけを失わせない。
- 同じ`damage_taken`を読む場合も出口を変える。戦槌は怯み付き反撃、射出器は援護照準、医療具は単体／全体回復、大盾は被害分散、双刃は裂傷付き反撃とする。

| 武器 | 副接続の中心 | 読む出来事 | 主軸と異なる出口 |
|---|---|---|---|
| 戦槌 | 打ち返し | 味方への被弾 | 攻撃者への反撃＋怯み |
| 格闘具 | 流し身 | 自分への攻撃 | 被害軽減＋一時退避（ラウンド終了時に復帰） |
| 射出器 | 援護弾 | 味方への被弾 | 攻撃者への援護射撃＋観測 |
| 医療具 | 応急手当／連携治療 | 味方の危険域への被弾 | 単体回復／高コスト全体回復 |
| 大盾 | 痛みの肩代わり | 味方への単体ダメージ | 被害の一部を自分へ移す |
| 長槍 | 迎え槍 | 味方への被弾 | 反撃＋移動不能 |
| 鉤縄 | 引き戻し | 前列の味方への対象指定 | 退避＋被害軽減 |
| 双刃 | 返り刃 | 味方への被弾 | 反撃＋裂傷 |
| 号旗 | 遺志の号令 | 味方の撃破 | 全員への集中＋AP |
| 重弩 | 迎撃照準 | 敵の準備開始 | 先制射撃＋怯み |

この表は最低数のノルマではない。医療具のA→AAのように複数の反応を必要とするルートもあれば、重弩のB→BAのように一つの反応を軸にした方が完成するルートもある。

## 11. 十武器を横断する構成の種

「同一人物」は一つの主軸と他武器のターゲット／パッシブ／リアクティブを組み合わせる。

### 12.1 ルート要約 — 取得理由を一文で言えるか

| 医療具 | 被弾後の単体／全体回復、全体防壁、戦闘後回復 | 攻撃しない一拍、回復反応のRP、即死・防壁貫通 | A→AAは複数被弾、A→ABは集中攻撃、B→BAは防壁、B→BBは残存防壁を戻す |
| 大盾 | 毎回の防壁・誘引、被弾ごとの守勢・鏡 | 集中被弾、攻撃機会の放棄、RP | 分配・回復・反転を深い節へまとめ、鏡切れ後も防壁と誘引は残す |
| 長槍 | 各ラウンドの未行動敵、被弾への迎え槍、準備遅延 | 距離条件、条件後の威力、RP | 未行動・準備中・移動後を優先し、条件外でも通常の長射程攻撃を行う |
| 鉤縄 | 異なる敵の釣り出し、味方退避、移動eventの連鎖 | 交換先、前後列の乱れ、RP | BAは壁役を後ろへ回して後衛を前へ、BBは一度だけ全体反転し元へ戻さない |
| 双刃 | 毎起動の多段、敵へのhit分配、味方hitへの差込 | 前後列の空き、多段防御、敵一体時のAB弱体化 | ABは攻撃開始時の生存敵へ固定配分し、BBは味方の非攻撃行動を予約刃へ変える |
| 号旗 | 毎回のAP移譲、前借り、旗印の蓄積 | 次ラウンドAP、HP、短期戦の薄さ | BAは借りを返すかHPで払って繰り返し、BBは3ラウンド級の生存を勝利条件へ変える |
| 重弩 | 準備中の弱射撃、次弾、極限装填 | 準備時間、準備中の被弾、不発 | BAは待つほど大きく、BBは蓄えを現在の一発だけへ使う。行動キューは変えない |

「主軸を置き換える終端が親より弱い」状態を作らない。対象範囲を狭める場合は係数または追加効果を増やし、
親の基礎価値を失わせない。

### 12.4 実装後に数値試験する残課題

- 医療具のA→AA（単体＋全体回復）、A→AB（条件緩和）、B→BA（全体防壁＋再生）、B→BB（残存防壁回復＋戦闘後回復）を、単体大攻撃・全体多段・防壁貫通・雑魚連戦・ボス戦で比較し、四ルートが互いの下位互換にならないか。
- 医療具BB1が防壁を残さない場面でもRPを無駄にせず、BB2の戦闘後回復が連戦とボス戦の両方で取得理由になるか。
- 鉤縄BA3の前後列交換が、5人／6人編成、前衛1人、後衛1人、交換先不在で同じ固定規則に従うか。鉤縄BB3は全員を移動させた後に元へ戻らず、移動反応が無限連鎖しないか。
- 双刃AB3の5hitが2体以上で十分な合計値を持ち、敵1体時の40%×5が王道枝の下位互換として感じられないか。敵が攻撃開始時に1体だけなら分配・別対象ボーナスが発動しないことを表示と一致させる。
- 重弩BA1の準備中40%追撃、BA2の準備+1／ダメージ+50%、BA3の準備2が、被弾リスクと最終一撃の増加を釣り合わせるか。BB3は次弾0でも強く、次弾を使うと明確に上がるか。
- 号旗BAを3ラウンド以上繰り返した時、AP借金・最大HP消費・返済猶予が毎回意味を持ち、1ラウンド目だけの使い捨てにならないか。号旗BBの旗印3と勝旗が、時間延長なしで長期戦の目的になるか。
