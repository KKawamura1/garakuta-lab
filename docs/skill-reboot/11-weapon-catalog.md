# 武器ツリー・カタログ案 — 10武器 × 19節（全面改稿）

更新日: 2026-09-23
状態: **PR #288で10武器190節をplayer registryへ接続し、初期ロードアウト・敵技能分離・pack分離・取得予約の基盤を検査済み。最終係数・プレイ感・UI表示は未検証。**
前提: `10-weapon-tree-reboot.md`

## 0. 読み方

全武器を同じ19位置で書く。

- `R`: 通常は1SPを払って入る代表アクション。ただし人物ごとの代表武器2本では、初期技能として無料で持つ。
- `A → AA`: その武器で最も単純な王道。無条件中心で、読んだ通りに強くなる。
- `A → AB`: 王道から分かれる、範囲・回数・攻防配分の扱いやすい応用。
- `B → BA`: 条件と他武器への連携。
- `B → BB`: 資源・状態・対象範囲を組み合わせた、深いが一文で説明できる完成形。特別な勝利条件を使う場合も、判定は一つに絞る。
- `A3 / B3 / AA3 / AB3 / BA3 / BB3`: 親の主軸を置き換えるアクティブ形態。

| 種類 | 解決規則 |
|---|---|
| アクティブ | 選択中のメインアクション一つだけ。APごとに同じ主軸を再評価する |
| リアクティブ | 指定eventで優先列を上から検査し、その人物で最初に成立した一つだけ発動してreturnする |
| ターゲット | 対象問い合わせ時に優先列を上から検査し、最初に有効候補を返した一つだけ使う |
| パッシブ | 条件を満たすものをすべて適用する。反応窓を消費せず、早期returnしない |

各リアクティブには`発動後に残すRP`を設定できる。現在RPから費用を引いた値が留保未満になる技能は飛ばして
次を検査する。頻出RP1を取りつつ、後で起きるRP2の蘇生や完全防御を予約できる。

ターゲットは複数取得でき、優先列の上から最初に有効候補を返した規則を使う。有効候補とは、主軸の射程・陣営・生存条件を満たす対象である。候補を返せなければ次の規則を調べ、最後は主軸の既定対象へ進む。攻撃の既定は最も近い敵、単体支援の既定は各主軸に記す。対象を固定する効果、反撃・追撃の「攻撃者／同じ敵」、誘引による対象変更はターゲットを読まない。
敵一列とは前列または後列の横3マスを指す。範囲攻撃では、まずターゲット規則で基準となる敵1体を選び、その敵がいる列を攻撃する。縦列とは同じ横位置の前後2マスを指す。単体攻撃に範囲を追加する効果は、先に基準対象を選んでから副対象を決める。敵が倒れた後の追撃や残りhitは、明記しない限り別の敵へ自動で移らない。
同率の優先は距離、固定マス順で解決する。優先したい状態の敵がいない規則は候補を返さず、近い敵を無条件に返すターゲットとして扱わない。

攻撃の既定射程は近接である。近接は前列から使っても補正なし、後列から使うと最終ダメージ40%になり、敵前列が
生存する間は敵後列を候補にできない。長射程・遠隔は使用位置による減衰も敵前列による遮蔽もなく、敵後列も候補に
できる。支援は味方への距離減衰を受けない。近接の強さは前列補正ではなく、各アクティブの係数で調整する。
2×3盤面の距離は上下左右の最短経路で数え、斜め移動は距離1に含めない。位置や射程を変える効果は対象候補を作る前に解決し、選択済みのターゲットを後から別位置へ移す効果は、その技能に明記する。

アクティブ形態以外は出身武器を発動条件にしない。攻撃、基礎hit数、射程、準備、回復、防壁、移動などの
行動特性が一致すれば、別武器の主軸でも発動する。hit由来の状態・固定値は明記がなければ1行動1回。受け無視は攻撃開始時に各対象へ合算し、その攻撃の各hitで同じ値だけ対象の受けを減らす。割合補正は
一行動の与ダメージへ一度だけ適用し、多段へhit数倍しない。

射程（近接・長射程・遠隔）と対象数（単体・複数）は別の軸で決める。射程はその攻撃に定義された近接・長射程・遠隔で決まり、人物の代表武器や腕力・技術の種類では決まらない。「単体攻撃」は元の攻撃の基礎対象が1体という意味で、2hit以上でも単体のまま。振り幅・貫通で副対象を足しても、元の攻撃の単体条件は変わらない。一方、横薙ぎが数えるのは実際にダメージ判定を行う異なる敵の数であり、多段hitを人数には数えない。
「基礎量N%」は元の攻撃が参照する能力値のN%を1回の追加ダメージとする。「元の攻撃の基礎ダメージのN%」は、主対象へ向けた全基礎hitの合計を割合補正・受け・防壁より前に計算し、そのN%を副対象へ1回与える。追加ダメージは元の攻撃の一部で、独立した攻撃やhitにはならない。
横薙ぎはダメージ前に確定した計画上の異なる敵の人数で判定し、主対象の第1hitと副対象を含む攻撃全体へ+15%を一度だけ適用する。振り幅のRPを払えない場合や有効な隣接敵がいない場合は、その副対象を計画へ入れない。確定後の不命中、受け構え、途中撃破で人数や倍率を戻さない。反撃ダメージは攻撃アクションではなく、近接の後列40%減衰や敵前列の遮蔽、単体攻撃条件、横薙ぎの対象外とする。

### 0.0 一行動の解決順（全190節共通）

1. **基礎hit数・形状:** 選択中の主軸（準備攻撃なら準備完了時）から、基礎hit数・基礎対象数・射程・参照能力値を決める。追加hitや追加対象はここでは数えない。準備開始時には対象を予約しない。
2. **自己位置:** 駆け込み・歩法など、対象選択より前に明記された移動を先に解決する。同じ人物の同じ反応窓は優先列で一つだけ。移動後の位置で近接の候補と後列40%を決める。移動eventの付与もここで解決する。
3. **基礎対象:** 移動後の射程で、観測、ターゲット優先列、主軸固有の既定順を使って基準対象・基準マスを一度選ぶ。範囲主軸はこの基準位置を使う。選択済み対象への誘引・対象指定時の盾や退避・壁抜きの先行移動を次の窓で処理する。元対象と書換え後の対象は別に記録し、対象問い合わせへ戻らない。
4. **攻撃前:** 誘引、盾を差す、痛みの肩代わり、引き戻し、背を押す、迎え返し、振り幅など、被害がまだ起きていない窓を固定順・RP優先列で一度処理する。先行反撃で攻撃者が倒れたら本攻撃を中止する。攻撃前のRPや仕込みは成立時に消費し、命中しなくても返さない。防壁や強化がここで付いた場合は、以後の計算に含める。
5. **hit数→対象の確定:** 元主軸の基礎hit数を条件にする技能を先に判定し、手数・二段突きなどの追加hitと上限を確定する。書換え後の主対象と基準マスから横列・縦列・隣接・貫通・炸裂筒などの副対象を一度展開し、刃渡し等の各hit割当を固定する。同じ敵へ複数の追加ダメージ片があっても人数は敵IDで重複排除する。途中撃破でhitを再配分しない。
6. **効果量の確定:** 確定した計画対象人数、位置、対象状態、開始時の強化段数・消費した資源を読み、基礎量・全体倍率・hit限定倍率・対象限定倍率を一度だけ算出する。無手・千客万来・極限装填は消費前の段数を数えて消費し、**消費した強化の通常倍率はこの攻撃へ加えない**。逆鍛造・一点集中射のような「攻撃後に消費」は、計画時に段数を固定し、攻撃後まで通常倍率を保持する。攻撃予定対象が外れたり倒れたりしても倍率を再算出しない。
7. **hitと攻撃後:** 割り当てた順に命中を判定し、各hitの受け構え→受け/軽減→防壁→実HP損失を処理する。命中時の追加固定ダメージは、そのhitのダメージ確定前に一度加えてよい。防壁破壊・被弾・状態付与・追撃は、条件を満たした時点から**未処理のhitまたは次の行動**へ作用し、解決済みのhitや計画人数を変えない。主軸の後続移動、追加ダメージ、標の付与・消費、帰り足は攻撃後に行う。攻撃後の移動では、同じ攻撃の射程・対象・倍率を再判定しない。

攻撃前の「対象を選んだ」と、hit中の「命中した」「防壁を減らした」「HPダメージを与えた」は別のeventである。対象数による補正は予定対象で判定し、命中人数を条件とする爆圧などは全hitの結果が出てから判定する。後から起きた効果を元の第1hitへ戻す規則は置かない。派生ダメージ片は元攻撃の一部だが、追撃攻撃は独立の計画を一度だけ作る。どちらも同じ発生源の追加対象・追撃を再発動しない。

攻撃hit内の計算順は、基礎量→確定済みの攻撃・hit・対象倍率→射程と被害の倍率→受け構えによる無効化→受け（受け無視を反映）→防壁→HPとする。受け構えに止められたhitは「命中したがHPダメージ0」と区別する。整数の丸めは各hitのHP・防壁へ配分する直前に一度だけ行い、予測表示と実戦に同じ関数を使う。強化・弱体の段数変化は過去の計算へ戻さない。

ラウンド開始は返済猶予→借り返済→再生による防壁、ラウンド終了は裂傷ダメージ→血へ還す→防壁期限切れ・持続状態の半減→持久旗→旗の守りの順とする。持久旗・旗の守りがラウンド終了時に付ける状態は次のラウンド終了時まで半減しない。死亡判定は各実HP損失の直後、戦後治療は勝敗確定後に行う。

`反撃ダメージ`は攻撃アクションではなく、通常の防御・防壁計算を受ける。攻撃開始／命中hit専用の効果は発生させない。
`追撃攻撃`は独立した1hit攻撃として通常の命中効果を受けるが、発生元の同じ技能はその追撃から再発動しない。
被弾を条件にするリアクティブ回復は、各回復対象が同じチェイン中に実際にHPダメージで失った量を上限とする。防壁で止まった量と過剰ダメージは数えない。戦闘後など、被弾を条件にしない回復には適用しない。
準備中のキャラクターが敵の攻撃を受けると、その攻撃アクションの合計最終ダメージ+50%。多段でも攻撃一回に一度だけ適用し、準備は中断せず、準備値も減らさない。この共通ルールはPR #287の提案で、PR #288には未実装。実装後に数値を検証する。

割合、回数、状態段数は比較用の仮値である。ただし確率は使わない。「しやすい」は、優先、固定値、回数、
閾値、確定付与のいずれかへ書き換えている。


### 0.1 PR #288で固定した実装境界

このカタログの190節は、PR #288でプレイヤー武器技能registryへ接続した。実装で追加・確定した境界は次のとおり。

- 10武器すべてを19節のcontentとして保持し、manifestは遠征中に利用できる武器だけを選ぶ。技能レベルmapや旧共通packツリーは使わない。
- 各人物の初期ロードアウトは代表武器2本のR＋A1。Rはactive候補2つ。A1は種類を固定せず、医療具の応急手当なら初期reactiveへ入る。activeは候補から一つだけ選ぶ。PR #288の初期ロードアウト実装はA1をpassiveと仮定しているため、この変更は次の実装同期で反映する。
- 敵のactive／reactive／passiveはプレイヤーの表から分離した敵専用registryに置き、敵actorが参照する定義だけを残す。敵技能をこの190節へ足さない。
- 装備packと武器技能packは別registry・別manifest欄にする。UIの一体表示は見せ方のaliasであり、解禁対象と装備抽選の正本は分ける。
- 取得予約は一人一目標。前提を飛ばさず、SPが揃えば前提から順に解禁する。旧saveの移行、旧技能レベルの復元、解禁の払い戻しは行わない。
- PR #288の既存語彙（対象、状態、移動、準備、AP、RP、防壁、回復）を優先する。タイル履歴、任意の行動順キュー、時間制限の延長、特殊な防壁種別は今回のツリーでは採用しない。
- 深い節は親の基礎効果を下げず、対象数・係数・追加効果のいずれかを増やす。条件付きの追加価値は、条件外でも親の代替として機能させる。

したがって、以下の表の「R」は通常取得時には武器への入口（1SP）だが、上記の代表武器2本では初期技能として無料で持つ。

この境界は `analysis/ecology-weapon-loadout-smoke.mjs` で、初期4技能、敵registryの使用集合、装備／技能packの種別分離を検査する。

### 0.2 実装契約・表示用効果文・フレーバー

各節には三種類の文章を持たせる。

- **実装契約:** event名、固定順、fallback、資源の生成禁止など、予測と実戦を一致させるための完全な規則。
- **表示用効果文:** プレイヤーが取得判断に必要な対象、条件、量、期間、費用、上限だけを書く。event名、内部ID、
  固定マス順、別節を自動適用する説明は書かない。
- **フレーバー:** 効果を言い換えず、その武器や人物の手触りを短い文章で伝える。

フレーバーの格もツリーの深さに合わせる。ルートと浅い節は動作や手触りを短く言い切り、中層のA3・B3は
戦い方や人物の声が見える一文にする。四枝の終端AA3・AB3・BA3・BB3は、前半で光景や覚悟を描き、後半を
決め台詞にする二行構成とする。表では文の境目へ`<br>`を置き、実UIでも同じ位置を優先改行として扱う。

表示用効果文は、該当する場合、費用→発動条件→対象→効果→上限・期間の順に書く。アクティブの置換元、種別、枝、射程、RP費用、ラウンド／戦闘回数は共通UIのタグでも表示する。とくに
「○○を置換」は効果本文へ重ねない。表では比較できるよう費用と回数も表示文へ残すが、実UIではタグとの重複を
避けてよい。

### 0.3 状態の共通基準 — 18種類、持続状態は半減

状態は画面に短い名前と段数（例: `守勢×4`）を表示する。AP・RP・HP・防壁だけは段数ではなく、それぞれの数値で扱う。
高揚・守勢・堅牢・破甲・裂傷・再生・露呈・移動不能の8種類は段数上限を設けず、ラウンド終了時に段数を半減する。その他の状態は共通上限6段、連携だけは上限300段とする。
常時働くパッシブの補正や行動中だけの条件付き補正は、付与された状態ではない。
有利な状態を強化、不利な状態を弱体と呼ぶ。準備だけは中立の状態とする。
観測・露呈は敵に付く弱体として数える。受け構え・誘引・連携・仕込み・借りも1つにつき1段である。

| 状態 | 1段の効果 | 持続 | 区分 |
|---|---|---|---|
| 集中 | 次の主軸のダメージ・回復・防壁+30% | 主軸1回で全消費 | 強化 |
| 怯み | 次の主軸のダメージ・回復・防壁-15% | 主軸1回で全消費 | 弱体 |
| 高揚 | 主軸のダメージ・回復・防壁+20% | 終了時に切り捨て半減 | 強化 |
| 隙 | 次に受ける攻撃のダメージ+30% | 攻撃1回で全消費 | 弱体 |
| 守勢 | 被ダメージ-4%（合計軽減は最大80%） | 終了時に切り捨て半減 | 強化 |
| 堅牢 | 各hitの受け+2 | 終了時に切り捨て半減 | 強化 |
| 破甲 | 各hitの受け-1 | 終了時に切り捨て半減 | 弱体 |
| 裂傷 | ラウンド終了時に固定5ダメージ | 終了時に切り捨て半減 | 弱体 |
| 再生 | 各ラウンド開始時に防壁5（1ラウンド）を得る | 終了時に切り捨て半減 | 強化 |
| 移動不能 | 次の移動・位置交換を1回止めて1減る | 使用または終了時に切り捨て半減 | 弱体 |
| 誘引 | 有効な敵単体攻撃を自分へ1回変更して1減る | 使用まで | 強化 |
| 受け構え | 攻撃の1hitを1回防いで1減る | 使用まで | 強化 |
| 観測 | 味方の次の攻撃主軸をその敵へ優先して向け、解決後に1減る | 攻撃主軸1回ずつ | 敵への弱体 |
| 露呈 | 受けるダメージ+10% | 終了時に切り捨て半減 | 敵への弱体 |
| 連携 | 結びついた敵への攻撃ダメージ+0.5% | 対象変更・撃破で0 | 強化 |
| 仕込み | 差し刃・千客万来・次弾装填・速射準備・極限装填で共通して使う1段 | 消費まで | 強化 |
| 借り | 次ラウンド開始時のAP-1 | 返済まで | 弱体 |
| 準備 | 主軸の解決前に必要な準備を1回示す | 解決まで | 中立 |

持続する8状態は付与時に段数を加え、ラウンド終了時に各状態の合計段数を`floor(段数/2)`へ更新する。1段なら0になり消える。段ごとの付与時刻・期限・付与者は持たない。その他の状態は6段まで加算し、超過付与は無効。連携だけは300段まで加算する。
攻撃・主軸の開始時に段数を確定し、集中・怯み・隙は複数hitを含む一回の攻撃・主軸全体へ適用してから全消費する。
効果量を減らす補正でも主軸のダメージ・回復・防壁を0未満にはしない。怯み6段は-90%となり、完全停止しない。
持続状態の1段はそのラウンド中に効き、次のラウンドへ残るかは終了時の半減で決まる。裂傷は半減前の段数で終了時に固定5/段のダメージを与える。再生は前ラウンド終了後に残った段数で次の開始時に防壁5/段（1ラウンド）を与える。医療具から再生を直接付与する時は一度に2段以上とし、通常の単独付与で次ラウンドの発動を保証する。見取り・重ね構えの1段コピーは例外。再生には付与者や技術値を保持しない。
ラウンド終了時は裂傷などの終了時効果→血へ還す→防壁失効・持続状態の半減→持久旗→旗の守りの順。半減後に付いた守勢は次の終了時まで半減しない。1ラウンド当たりN段を同じ対象へ付け続ける場合、行動中の段数はおおむね2N（初期0・切り捨てなら通常2N-1）で安定する。
集中・怯み・高揚など同じ計算値への割合補正は段数分を加算してから行動全体に一度だけ適用する。隙と露呈の被ダメージ補正も段数分を合算し、同じダメージに一度だけ適用する。

観測中の敵が有効な攻撃対象なら、味方の攻撃主軸のターゲット技能より先にその敵を選ぶ。
観測は味方全体で敵一体だけ。同じ敵への再付与は段を足し、別の敵へ付けると古い観測をすべて消す。
一回の攻撃主軸を解決した後に観測を1段消費する。多段・範囲でも1段、追撃・反撃・非攻撃主軸では消費しない。
観測対象が攻撃不能なら段を消費せず、通常のターゲット規則へ進む。
集中に対する高揚と同様、隙の一回限りの被ダメージ増加に対して露呈は持続する被ダメージ増加である。観測にも付与者を保持しない。露呈は敵ごとに合計段数だけを持ち、付与者を記録しない。別の敵への付与で消えず、対象選択も上書きしない。
連携は初めて攻撃した敵へ結びつき、攻撃開始時の段数で与ダメージを計算する。連携を複製した時は対象の結び付きも複製する。
仕込みには単独の倍率はなく、取得済み技能が消費する。
借りの返済ではAPを0未満にせず、借りを全段消費する。

「強化を1つ解除」は1段解除、「強化をすべて解除」は対象に付いた全種類の強化を全段解除する。
1段解除する時は対象の状態の合計段数から1を引く。解除した強化1段につき発動する効果は、段数で数え、付与元の件数で数えない。
ラウンド終了時の半減や主軸による消費は解除に数えない。
見取り・重ね構えは強化の種類を問わず1段だけ追加する。再生1段だけでは次のラウンド開始前に消えるため、単独コピーは例外的に防壁を生まない。複製から同じ反応は再発動しない。
無手も連携・仕込み・再生・誘引・受け構えを含めて強化を消費するが、消費は最大6段までとする。
段数が多い種類から消費し、同数なら上表の順で決める。同じ種類の段に個別の期限や付与者の区別はない。
段数を指定せず弱体をすべて解除する場合は、借り・観測・露呈・移動不能を含む該当する弱体を全段除く。
AP・RP・HP・防壁は状態解除や段数操作の対象外。防壁は明示された防壁除去・破壊だけで減らす。
受けは0未満にもなり、負の受けは各hitのダメージを増やす。

基準として腕力・技術50なら、集中1は100%攻撃を約15増やす。怯み1は敵の一行動全体を-15%にする。
誘引で3ラウンドに15〜30hitを受ける盾役なら、堅牢1は合計30〜60、守勢1は合計被ダメージの4%を防ぐ。
6段なら高揚+120%、守勢-24%、堅牢+12、再生は次の開始時に半減後の3段から防壁15となる。守勢による被ダメージ軽減は最大80%とし、段数が増えても無敵にはしない。高揚・露呈・裂傷・再生・堅牢・破甲の大量付与時の数値は戦闘標本で検証する。

- **受け:** 1hitごとの固定ダメージ軽減。防壁は合計量、受け構えは完全に無効化する残り段数を表す。
- **隣接:** 2×3の6枠で上下左右に接している位置。斜めは含めず、複数候補は既定の位置順で一体だけ選ぶ。
- **準備中:** 敵から攻撃を受けると、その攻撃アクションの合計最終ダメージ+50%。準備は中断せず段数も変えない。

### 0.3a 強化1段の価値と付与量

見取り・重ね構えが無条件に1段加えるため、単独の高揚1は主軸+20%、守勢1は被ダメージ-4%（最大80%）、堅牢1は各hitの受け+2とする。集中1は次の主軸+30%、誘引1は単体攻撃1回の対象変更、受け構え1は1hit無効化、仕込み1は後続技能の資源としてそれぞれ異なる発動窓を持つ。異なる被害・行動回数で価値は変わるので、同額の数値と見なさない。

付与量を機械的にすべて半分にすると、終了前に付いた1段は次ラウンドへ残らない。戦利の破片の堅牢2と連動縄の高揚2は、それぞれ次の攻撃・攻撃後の移動から次行動への接続を守るため維持する。号旗の総進撃は高揚1、前借り命令は高揚2、城壁の返礼は守勢2へ調整する。持久旗は守勢3とし、半減後に付与される守勢が3→4→5へ進むよう、旗の守りと勝旗の条件を4／5段とする。再生は次の開始時に働くため技能からの単独付与は最低2段とし、1段コピーの効力は例外扱いで数値試験する。

### 0.4 応急手当型の副接続

この改稿では、各武器に副接続を置くが、リアクティブの数や発動eventを揃えない。副接続は、主軸の倍率を上げるだけでなく、被弾・対象指定・準備開始・移動・撃破などの出来事を、武器らしい別の出口へ変える節である。

- 取得中の武器や選択中の主軸を条件にしない。別武器の主軸でも、行動特性とeventが一致すれば発動できる。
- 同じ武器内でも、A→AA／A→AB／B→BA／B→BBの役割を一文で説明できるようにする。リアクティブが多いこと自体を価値にしない。
- 発動条件、RP費用、チェイン／ラウンド／戦闘上限、空きマス、対象生存などを明記する。不成立時にRPだけを失わせない。
- 同じ`damage_taken`を読む場合も出口を変える。戦槌は怯み付き反撃、射出器は援護照準、医療具は単体／全体回復、大盾は被害分散、双刃は裂傷付き反撃とする。

| 武器 | 副接続の中心 | 読む出来事 | 主軸と異なる出口 |
|---|---|---|---|
| 戦槌 | 打ち返し | 味方への被弾 | 攻撃者への反撃＋怯み |
| 格闘具 | 流し身 | 自分への攻撃 | 被害軽減＋一時退避（ラウンド終了時に復帰） |
| 射出器 | 援護弾 | 味方への被弾 | 攻撃者への援護射撃 |
| 医療具 | 応急手当／連携治療 | 味方の危険域への被弾 | 単体回復／高コスト全体回復 |
| 大盾 | 痛みの肩代わり | 味方への単体ダメージ | 被害の一部を自分へ移す |
| 長槍 | 迎え槍 | 味方への被弾 | 反撃＋移動不能 |
| 鉤縄 | 引き戻し | 前列の味方への対象指定 | 退避＋被害軽減 |
| 双刃 | 返り刃 | 味方への被弾 | 反撃＋裂傷 |
| 号旗 | 遺志の号令 | 味方の撃破 | 全員への集中＋AP |
| 重弩 | 迎撃照準 | 敵の準備開始 | 先制射撃＋怯み |

この表は最低数のノルマではない。医療具のA→AAのように複数の反応を必要とするルートもあれば、重弩のB→BAのように一つの反応を軸にした方が完成するルートもある。
### 0.5 射程・対象数の組合せ例

以下は「振り幅」「横薙ぎ」を取得した人物が、ほかのダメージ補正なしで行動した場合。近接は前列から、攻撃前に振り幅へRP1を払い、第1hitと残りのhitが命中し、対象が生存していると仮定する。係数は受け・防壁・丸めの前に、各攻撃が参照する能力値に対する割合で表す。

| 行動 | 届く相手と基礎係数 | 横薙ぎを含む結果 |
|---|---|---|
| 打ち返し | 攻撃者へ腕力70%の反撃ダメージ | 攻撃者に70%。攻撃アクションではないため振り幅・横薙ぎは発動しない |
| 二連斬り（主対象の左右に敵がいる） | 主対象に腕力55%を2hit。振り幅で左右の敵へ各腕力35%を1回 | 主対象へ腕力63.25%を2hit（合計126.5%）。左右の敵へ各腕力40.25%を1回。振り幅のRP1は一度だけ |
| 貫き突き | 主対象に腕力110% | 主対象に110%。長射程なので振り幅は発動せず、横薙ぎも発動しない |
| 貫き突き＋貫通（同じ縦列に別の有効な敵がいる） | 主対象に腕力110%。貫通で同じ縦列の別の敵へ110%×40%=腕力44%を1回 | 主対象に腕力126.5%。同じ縦列の別の敵へ腕力50.6%。長射程なので振り幅は発動しない |

二連斬りは2hitでも元の主軸は単体攻撃。左右の片側だけに敵がいれば、その一体だけへ40.25%。攻撃前にRP不足または隣接する有効敵がいなければ振り幅は発動せず、主対象へ55%を2hitして横薙ぎも発動しない。振り幅を使った後に第1hitが外れてもRPは戻らず、計画済みの横薙ぎ判定は変わらない。使用者が後列に残って近接攻撃する時は、表示した係数の40%へ減衰する。貫き突きは近接ではなく長射程で、前後どちらの使用位置でも減衰せず、敵前列の後ろも狙える。貫通の副対象がいなければ110%の単体攻撃となる。

## 4. 医療具（ツグミの副武器）— 傷を戻すか、次の一撃を受け止める

PR #288反映後の標準activeは防壁である。初期A1は全回復を強化するパッシブ、A2は被弾後の単体回復で、A→AAは同一行動で複数人が被弾した時の全体回復、A→ABは発動条件を緩めて負の状態も解除する。B→BAは全体防壁と次ラウンドの追加防壁、B→BBは残存防壁の利用と戦闘後回復へ進む。医療具だけは、受けたダメージを戻すリアクティブ回復を主役にしてよい。

BBに特殊な防壁種別は導入しない。ラウンド末に残存防壁を回復へ回し、戦闘終了時にHPを戻すだけである。回復の成否は通常のHP回復規則に従い、表示文には内部のanti-stall条件を書かない。

射程: **支援**。味方への距離減衰なし。

「同一人物」は一つの主軸と他武器のターゲット／パッシブ／リアクティブを組み合わせる。
「分担」は複数人物が別々の主軸を持つ。主軸を二つ同時装着しない。

| 構成 | 担当 | 接続 | 何が起きるか |
|---|---|---|---|
| 構え狙撃 | 同一人物 | 長槍＋射出器ターゲット | 準備中の敵を長槍で遅らせ、射出器で観測した一体へ味方の狙いを集める |
| 響く乱舞 | 同一人物 | 双刃主軸＋戦槌A | 双刃の多段hitへ戦槌の怯み反応を差し込み、RPを使って敵の反撃を弱める |
| 追い大槌 | 同一人物 | 戦槌主軸＋格闘具A | 基礎1hitの近接重打へ格闘具の追撃を足し、単発条件を保ったまま手数を増やす |
| 穿孔乱舞 | 同一人物 | 双刃主軸＋射出器A | 多段攻撃の一行動へ受け無視を一度だけ適用し、hit数だけ有利にならないようにする |
| バフを写す拳 | 分担 | 号旗／大盾＋格闘具BB | 号旗の集中、大盾の守勢など段数のある強化を写し、重ね構えで増やして無手の一撃へ変える |
| 被弾の返し | 同一人物 | 戦槌「打ち返し」＋医療具「応急手当」 | 同じ被弾から、槌は攻撃者を怯ませ、医療具は瀕死の味方を回復する。主軸の切替は不要 |
| 盾槍の分担 | 同一人物 | 大盾「痛みの肩代わり」＋長槍「迎え槍」 | 味方への一撃を分散し、その攻撃者へ反撃と怯みを返す。RPを防御へ使うか反撃へ使うかが競合する |
| 残壁の治療 | 分担 | 医療具BB＋大盾 | 大盾や野戦防壁が残した防壁を医療具BB1でラウンド末に回復へ回し、次戦闘はBB2で整える |

| 前借り装填 | 分担 | 号旗BA＋重弩BA／BB | 号旗でAPを前借りして準備を始める。次ラウンドのAP低下とHP負担を、極限装填の一発と交換する |

| 隙と防壁 | 分担 | 大盾BB＋医療具BA | 大盾が誘引で攻撃者へ隙を返し、医療具が全体防壁を置く。大技にはRP2を残す |

### 12.1 ルート要約 — 取得理由を一文で言えるか

各ルートは、得られる能力・面白さ・強み・弱みを一文で説明できることを目標にする。B→BBも特別扱いの
ルール改変ではなく、既存のイベント・状態・資源を深く組み合わせた完成形として設計する。

| 武器 | R | A→AA | A→AB | B→BA | B→BB |
|---|---|---|---|---|---|
| 戦槌 | 近い敵を重く叩く。単体には強いが近接限定。 | 1hit目と怯みを伸ばす正統派。多段にも一部が乗る。 | 隣接・複数対象へ広げる。集団に強いが、RPと位置取りを使う。 | 防壁・受け構え・堅牢を壊し、破甲を付ける。強化敵向け。 | 敵の強化を堅牢へ変え、守りの段数を次の大打撃へ回す。敵依存だが決まると大きい。 |
| 格闘具 | 単発の正拳で追撃の入口を作る。RPを使う。 | 多段・追い拳を伸ばし、百裂へつなぐ単体火力。 | 被弾を受け流し、攻撃hitごとの防壁で殴り合う。 | 低HPの敵を狙い、移動でも連携を積んで飛び込み膝へつなぐ。 | 味方の正の状態を写し、増やして自分の一撃へ変える。味方とRPに依存する。 |
| 射出器 | 遠距離から対象を選んで撃つ。後衛から安定する。 | 第1hit強化と受け無視で硬い敵を抜く。単体向け。 | RP追撃と被弾への援護射撃で手数を増やす。 | 観測した敵を味方が狙い、無償追撃と自分の与ダメージを伸ばす。 | RPで露呈を重ね、味方の攻撃と一点集中射へつなぐ。 |
| 医療具 | 味方に防壁を張る。安定するが直接回復しない。 | 単体の被弾後回復と、同じ敵の一行動で複数人が被弾した時の全体回復。 | 応急手当の条件を緩め、回復時に負の状態も解除する。 | 発生元を問わない全体防壁と、次ラウンドの追加防壁。 | 残存防壁をラウンド末にHPへ回し、戦闘後にも回復する。連戦向け。 |
| 大盾 | 自分に防壁と誘引を張る。攻撃を集める。 | 防壁・誘引・HPを伸ばし、攻撃を引き受け続ける。 | 防壁と守勢を味方へ広げる。 | 止めたダメージを味方へ回し、攻撃を受けるほど隊を支える。 | 誘引で隙を付け、RP2を大技に使う。 |
| 長槍 | 距離を取り、直線上の敵を突く。距離条件で火力と受け無視を得る。 | 単体火力・受け無視・列貫通を伸ばす。 | 多段と移動不能で列を止める。 | 準備中や未行動の敵を動けなくし、攻撃を受けた味方から反撃する。 | 準備中の敵へ怯みを返し、行動順を書き換えず次の一手を断つ。 |
| 鉤縄 | 敵を引き、自分を動かす。位置を変えて戦う。 | 引く距離と、引けない時の追加火力を伸ばす。 | 味方を後列へ救出し、防壁を渡す。 | 敵を前列へ釣り出し、隙・受け構え・防壁を崩す。 | 移動した味方へ守勢を与え、敵を大きく引いて隙2を付ける。 |
| 双刃 | 近距離で2hit。後列から前進して火力を出す。 | 追撃・多段・後退で単体を削る。 | hitを敵へ均等配分して雑魚を処理する。敵が一体なら単体火力になる。 | 裂傷を重ね、列へ広げる。 | 味方の非攻撃行動から仕込みを最大6まで蓄え、味方のhitへ追撃する。 |
| 号旗 | APの少ない味方へ行動を渡す。 | APと次の主軸強化を安定供給する。 | 複数人へAPと攻撃強化を同時に渡す。 | 高揚を重ね、次ラウンドのAPを前借り分だけ返す。 | 全員生存で守勢を7段以上まで積み、段数に応じた全体防壁・集中へ変える。 |
| 重弩 | 準備して大きな一発を撃つ。準備中が弱点。 | 単体高火力と受け無視。ボス向けだが遅い。 | 溜め攻撃を列攻撃・怯みへ変える。集団向け。 | 準備中に被弾しても反撃し、準備時間と火力を交換する。 | 仕込みを蓄えて現在の一発へ束ねる。双刃とも共有できる。 |

この表で一文にできない節は、数値不足ではなくルートの出口不足として再設計する。

### 12.4 実装後に数値試験する残課題

- 医療具の被弾後回復は、対象ごとに同じチェインで実際に失ったHPを上限とし、A1／AA1の増加後にも上限を超えないか。連携治療は同一敵の一行動で複数人がHPダメージを受けた時だけ働くか。戦後治療は上限の対象外か。
- 医療具の再生4／8は終了時に半減し、次の開始時に残った段数×5の防壁を付与するか。付与者の技術値や期限を持たず、野戦防壁は全員へ再生4、終療防壁は一列へ再生8を付与するか。血へ還すは残存防壁がなければRPを消費せず、残量をHPへ変換するか。
- 射出器の優先順が回復→防壁となり、観測が有効対象なら味方の攻撃主軸で先に働き、主軸後に1段だけ減るか。露呈の共有段数・終了時半減・全段消費とRP追撃の順序が表示どおりか。準備中の敵への攻撃+50%は攻撃アクションの合計に一度だけ適用されるか。
- 準備中の味方／敵が受ける攻撃アクションの合計最終ダメージが+50%となり、多段でhitごとに重複せず、準備と準備値を保つか。攻撃アクションでない反撃ダメージに誤適用されないか。
- 大盾の誘引・防壁・守勢が同じ攻撃で二重計上されず、盾を差すは対象を変えず攻撃直前に防壁を与えるか。裏返すは受けを引く前の全hit基礎量で一度判定し、防御後の結果で再判定しないか。
- 長槍は距離2以上の条件、主対象と同じ縦列の副対象、移動不能、準備値の減少、怯みを既定の位置順で処理するか。行動順の並べ替えを使わず、準備中の敵へ向ける価値があるか。
- 鉤縄の強制移動は前列・後列と空きマスの条件を守り、移動できなくても攻撃価値を失わないか。救出索、壁崩し、釣り出し、大捕縛の対象・隙・受け構え・防壁への効果をログから説明できるか。
- 双刃のhit配分は攻撃開始時の生存敵へ固定され、敵一体でも火力が落ちすぎないか。駆け込み・引き足の移動を各一度にし、差し刃は対象が倒れている時にRP・仕込みを消費しないか。仕込み0の千客万来も攻撃価値を保つか。
- 号旗のAP最少対象が固定規則で決まり、前借り命令のAP3を次ラウンドに返済し、RP1で免除できるか。高揚2と借り3が重複付与されず、最大HPを消費しないか。守勢4／5の全体防壁・集中に短期戦と長期戦の両方で取得理由があるか。
- 重弩の準備中反撃、準備+1／与ダメージ+50%、準備2の終端が、準備中の被弾リスクと一発の威力を釣り合わせるか。仕込み0の極限装填も成立し、双刃から得た仕込みも消費できるか。
- 戦槌は1hit目・怯み・受け構え・防壁・堅牢の相互作用、格闘具は追い拳・多段・受け無視・連携上限300と無手の消費上限6を、1hit／2hit／4hit／6hitと複数ラウンドで比較する。近接の後列40%減衰を保った上で、近接係数が遠隔と釣り合うか。
- すべての武器で深い終端が条件不成立時にも親の攻撃・防壁・支援の価値を保つか。同じ技能点投資で単発・多段・範囲・反応型の期待値が偏らないか。
- リアクティブ優先列とRP留保が、3・6・10ラウンドの固定標本で人物別のRP消費率と未使用率にどう表れるか。戦闘予測とログが発動・不発の理由を説明するか。
- 振り幅のRP不足・第1hit不命中・隣接敵不在では横薙ぎの人数を増やさず、発動した時だけ主対象の第1hitを含む全ダメージへ+15%を一度適用するか。貫通は多段主軸でも全基礎hitの合計40%を副対象へ一度だけ与えるか。

### 12.5 持続状態の半減監査（設計仮値）

| 状態 | 付与経路と半減後の確認 |
|---|---|
| 高揚 | 1段につき主軸+20%。連動縄は攻撃後の移動でも次行動へ1段残すため2段を維持する。号旗の進め・総進撃は1段で同ラウンドの行動支援、前借り命令2段は次ラウンドにも1段残る。 |
| 守勢 | 盾の列・引き受け役・返し縄の1段はそのラウンドだけ。城壁の返礼2は次に1段残る。持久旗は半減後に3段を付け、毎ラウンド成立すると次ラウンドの行動時に3→4→5段。旗の守りと勝旗の4／5段条件は2／3回目の成立で届く。被ダメージ軽減は最大80%。 |
| 堅牢 | 戦利の破片は解除1段あたり堅牢2へ変更し、終了時に1段残して逆鍛造につなぐ。高段数の解除・複製後も攻撃時の逆鍛造は全段を消費する。 |
| 破甲 | 砕けた鎧は一度に2段付け、終了時に1段残る。毎ラウンド2段付与なら、次の攻撃時は通常3段で安定する。 |
| 裂傷 | 裂き傷・返り刃・血路は単発2段へ変更し、付与ラウンドに2段分、次ラウンドに1段分の固定ダメージを出す。傷刻み／千客万来の2hitは各hit1段で同じ合計2段となる。血を追う・傷口拡大の対象判定は攻撃時の合計段数を使う。 |
| 再生 | 重ね包帯・終療防壁は8段、野戦防壁は4段。見取り・重ね構えの複製は他の強化と同じ1段。再生1段だけなら次の開始時の防壁を生まない。単発4段は終了時に2→1となり、次の開始時以降に防壁10・5（計15）を得る。単発8段は4→2→1となり、防壁20・10・5（計35）を得る。付与ラウンドの開始時へ遡及しない。 |
| 移動不能 | 縫い留め・迎え槍・足を止める・関所・遅延標は各2段付与し、終了時に1段残る。移動を止めた時は1段消費し、その後の終了時には残りを半減する。 |
| 露呈 | 弱点標は2段付与し、敵ごとに共有して終了時に半減。一点集中射の全段消費は攻撃後なので、当該攻撃には消費前の倍率を乗せる。 |

終了時の付与は半減処理後に行う。解除・複製・無手は合計段数を読み、段ごとの期限・付与者を記録しない。比較用の値は仮値であり、再生4は旧ルールの再生1（3回×防壁5）と合計15で一致し、再生8は旧ルールの再生2（3回×防壁10）の合計30に近い35となる。複製の再生1は単独では次の開始時に消えて防壁を生まない。既存の再生との合算時に段数の偶奇で価値が変わるため、取得価値を数値検証する。上限なしの高揚・露呈・裂傷・堅牢・破甲・再生・移動不能の集中付与と、守勢の80%軽減上限は戦闘標本で検証する。
