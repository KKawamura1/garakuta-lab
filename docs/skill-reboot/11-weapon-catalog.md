# 武器ツリー・カタログ案 — 10武器 × 19節（全面改稿）

更新日: 2026-09-19
状態: **発想を広げる初稿。係数・SP・実装可能性・既存IDへの対応は未検証。**
前提: `10-weapon-tree-reboot.md`

## 0. 読み方

全武器を同じ19位置で書く。

- `R`: 1SPを払って入る代表アクション。
- `A → AA`: その武器で最も単純な王道。無条件中心で、読んだ通りに強くなる。
- `A → AB`: 王道から分かれる、範囲・回数・攻防配分の扱いやすい応用。
- `B → BA`: 条件と他武器への連携。
- `B → BB`: その武器で最もトリッキーな規則破り。
- `A3 / B3 / AA3 / AB3 / BA3 / BB3`: 親の主軸を置き換えるアクティブ形態。

| 種類 | 解決規則 |
|---|---|
| アクティブ | 選択中のメインアクション一つだけ。APごとに同じ主軸を再評価する |
| パッシブ | 条件を満たすものをすべて適用する。反応窓を消費せず、早期returnしない |
| リアクティブ | 指定eventで優先列を上から検査し、その人物で最初に成立した一つだけ発動してreturnする |

`[照準]`は対象問い合わせへ登録するパッシブである。複数取得でき、照準列の上から最初に候補を返せた
規則を使う。どれも成立しなければ単体攻撃は最も近い敵を狙う。非攻撃アクションは各Rに既定対象を書く。

係数は量だけを決める。腕力だから後列で減衰する、技術だから敵後列へ届く、という全体規則はない。
位置制限や対象範囲が書かれていなければ、どの位置からでも同じ量で使える。

割合、回数、状態段数は比較用の仮値である。ただし確率は使わない。「しやすい」は、優先、固定値、回数、
閾値、確定付与のいずれかへ書き換えている。

## 12. 棚卸し時の問い

- 各武器のA→AAは、Bの説明を読まなくても強さが分かるか。
- 署名武器5種のA→AAは、その人物の立ち絵と役割を最短で再現しているか。
- BBは本当にその武器で最も変則的か。A側へ履歴保存や資源変換が紛れていないか。
- 全パッシブは同時適用してよいか。同時に一つだけであるべきならリアクティブへ移したか。
- 全リアクティブは、下の候補を止める価値があるか。単なる常時+量を反応列へ入れていないか。
- 照準が不成立のとき、次の照準または最短距離へ確実にfallbackするか。
- 「しやすい」「ときどき」「高確率」といった乱数を前提にする語が残っていないか。
- 能力係数だけを見て、対象範囲や後列減衰を暗黙に推測させていないか。
- 支援主軸へ理由のない追加攻撃を付けていないか。時間切れとの交換が成立しているか。
- 現engineに無いという理由だけで、直接回復、能力変更、時間操作、蘇生を弱くしていないか。
