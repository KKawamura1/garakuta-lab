# 武器ツリー・カタログ案 — 10武器 × 19節（全面改稿）

更新日: 2026-09-20
状態: **全190節の機能棚卸し済み。係数・SP・実装可能性・既存IDへの対応は未検証。**
前提: `10-weapon-tree-reboot.md`

## 0. 読み方

全武器を同じ19位置で書く。

- `R`: 1SPを払って入る代表アクション。
- `A → AA`: その武器で最も単純な王道。無条件中心で、読んだ通りに強くなる。
- `A → AB`: 王道から分かれる、範囲・回数・攻防配分の扱いやすい応用。
- `B → BA`: 条件と他武器への連携。
- `B → BB`: その武器で最もトリッキーな規則破り。
- `A3 / B3 / AA3 / AB3 / BA3 / BB3`: 親の主軸を置き換えるアクティブ形態。

| 種類 | 解決規則 |
|---|---|
| アクティブ | 選択中のメインアクション一つだけ。APごとに同じ主軸を再評価する |
| リアクティブ | 指定eventで優先列を上から検査し、その人物で最初に成立した一つだけ発動してreturnする |
| ターゲット | 対象問い合わせ時に優先列を上から検査し、最初に有効候補を返した一つだけ使う |
| パッシブ | 条件を満たすものをすべて適用する。反応窓を消費せず、早期returnしない |

ターゲットは複数取得でき、優先列の上から最初に候補を返せた規則を使う。どれも成立しなければ
単体攻撃は最も近い有効な敵を狙う。非攻撃アクションは各Rに既定対象を書く。
各アクティブ本文の「最も近い」「最も遠い」「HP割合最低」は、固定対象と明記しない限りfallbackであり、
成立したターゲットがあればそちらを先に使う。

攻撃の既定射程は近接である。近接は後列から使うと最終ダメージ40%（60%減衰）になり、敵前列が
生存する間は敵後列を候補にできない。長射程・遠隔は後列減衰なしで敵後列も候補にでき、支援は
味方への距離減衰を受けない。係数は量だけを決め、例外は各武器の「射程」に明記する。

割合、回数、状態段数は比較用の仮値である。ただし確率は使わない。「しやすい」は、優先、固定値、回数、
閾値、確定付与のいずれかへ書き換えている。

| BA2 | リアクティブ | 起爆 | `actor_entered_marked_tile`時、RP1で着弾印を消し、そのactorへ腕力120%。敵味方を区別しない。 |
| BA3 | アクティブ | 時限矢 | 予約射を置換。ターゲットがいるマスへ着弾印3を置く。敵味方を問わずactorが行動するたび1減り、0になった時、そのマスと同じ列へ腕力300%。 |
| BB1 | パッシブ | 次弾装填 | 通常の準備を経た重弩が解決するたび次弾1を得る。準備中に被弾すると0へ戻る。上限3。保持中は次弾1につき重弩アクティブのダメージ+10%。`未来撃ち`と`三時射`の追加解決は次弾を生まない。 |
| BB2 | リアクティブ | 未来撃ち | `heavy_bolt_resolved`時、ラウンド1回、RP2と次弾1で次ラウンドの重弩解決を今すぐ一度行い、次ラウンドは不発にする。 |
| BB3 | アクティブ | 三時射 | 予約射を置換。現在の一発に加え、次弾を最大2消費して同じ対象へ同時解決する。消費した次弾1につき以後の重弩解決を一回不発にする。次弾0なら通常の予約射として解決する。 |

## 11. 十武器を横断する構成の種

「同一人物」は一つの主軸と他武器のターゲット／パッシブ／リアクティブを組み合わせる。
「分担」は複数人物が別々の主軸を持つ。主軸を二つ同時装着しない。

| 構成 | 担当 | 接続 | 何が起きるか |
|---|---|---|---|
| 構え狙撃 | 同一人物 | 長槍＋射出器ターゲット | `構えを刺す`と`準備を抜く`を並べ、未行動か準備中かを敵編成ごとに優先する |
| 拳の模倣 | 分担 | 格闘具＋射出器／長槍 | 味方の遠隔・長射程の型を記録し、格闘役が自分の腕力で再現する |
| 鏡の危険域 | 同一人物 | 大盾＋医療具「危険域」 | HP25%以下まで受ける危険と引き換えに、鏡の回復量を倍にする |
| 時限の引き縄 | 分担 | 重弩＋鉤縄 | 重弩が置いた着弾印へ鉤縄役が敵を戻し、時間差の列爆発を成立させる |
| 裂傷の地割り | 分担 | 双刃＋戦槌 | 双刃役が一列の裂傷を増やし、戦槌役が同じ列を怯ませて後続火力へ渡す |
| 防護線治療 | 分担 | 大盾＋医療具 | 全体防壁と全体回復を別APで維持し、攻撃へ使える残り時間と交換する |
| 借金手術 | 分担 | 号旗＋医療具 | 前借りで一気に動く代わりに次ラウンドを弱め、倒れた時だけ時間外手術へ移る |
| 差し刃観測 | 分担 | 号旗／医療具＋双刃＋射出器 | 非攻撃主軸で予約刃を作り、観測対象への味方hitへ差し込む |
| 安全な六花 | 同一人物 | 双刃A→AA | 後列から前進して6hitを通し、主軸解決後に後列へ帰る。空き前列と深い投資が必要 |
| 駆け込み号令 | 分担 | 号旗「揃い足」＋近接役 | 毎回、後列の近接役を前へ出して攻撃させ、解決後に後列へ戻す |
| 空いた懐 | 同一人物 | 格闘具BA | 倒せば後退、次の主軸で再び前進する。倒せない時は前列に残るため火力判断が防御へ直結する |
| 盾の交代 | 同一人物 | 大盾＋格闘具「拳甲」 | `盾を差す`位置交換で庇い、後列から前列へ出た時の追加防壁で集中被弾を受ける |
| 前へ引き出す | 分担 | 鉤縄＋戦槌／双刃 | 敵後列を前列へ引き出し、届かなかった近接主軸を集中させる |
| 時間を買う三時射 | 同一人物 | 重弩BB | 被弾せず次弾を貯めた時だけ未来の弾を前借りし、後の不発をボスの短期決戦と交換する |

## 12. 棚卸し結果

| 問い | 判定 | 修正・残した判断 |
|---|---|---|
| A→AAはBを読まなくても強さが分かるか | 可 | 威力、hit、回復、防壁、AP、準備射撃の素直な伸長に限定した。双刃の`駆け込み`だけは近接の共通弱点を解く一手としてA側へ置く |
| 署名武器A→AAは人物を最短で再現するか | 可 | ゴウ=重打、ツグミ=射出器、ナギ=大盾、ヒバナ=鉤縄、ゲンゾウ=号旗を維持。医療はツグミの副武器として明示的に残す |
| BBが最も変則的か | 可、要試作 | 型の模倣、蘇生代償、陣形総入替、他者hitへの差込、時間固定、未来射撃をBBへ集約した。重弩BAの曖昧な`3event`はactor行動3回へ限定した |
| パッシブを全部重ねてよいか | 修正済み | 単純なevent加算だった`砕け音`、`合図弾`、`走れの合図`、`血飛沫`をパッシブへ移し、RPと早期returnを外した |
| リアクティブは下を止める価値があるか | 可 | 生存、庇護、割込、位置交換、印消費、AP借金、時間延長、未来攻撃など、RP・回数・在庫か安全を使う選択だけを残した |
| 対象規則は確実にfallbackするか | 修正済み | `ターゲット`を独立種別にした。候補0なら次へ進み、最後はアクティブ固有の軟優先、近接なら射程内の最短距離へ落ちる |
| 乱数を前提にする語が残っていないか | 可 | 優先順位、固定マス順、回数、閾値だけで記述した |
| 射程や後列減衰を暗黙にしていないか | 修正済み | 近接を共通既定にし、全10武器へ近接・長射程・遠隔・支援を明記した |
| 支援へ理由のない攻撃を付けていないか | 可 | 医療具と号旗は攻撃しない。大盾の`盾撃`だけは防御量を落とす明示的な攻防hybridとして残した |
| 現engineに無い効果を弱くしていないか | 可 | 直接回復、能力変更、蘇生、AP前借り、残り時間変更、位置交換を候補として維持した |
| 初期配置で移動節を代替できないか | 修正済み | 初期配置は移動eventを出さない。双刃は毎回の往復、格闘具は撃破後退→次回前進、号旗は対象ごとの一時出撃、鉤縄は戦況に応じた敵・負傷者移動にした |
| 2ラウンド目以降も働くか | 修正済み | 小さい戦闘開始時効果を廃止し、移動、防壁、照合、対象追跡を各ラウンド再起動できる形へ変更した。戦闘1回は蘇生、時間延長、総攻勢だけに限定した |
| 強い利益に見える代償があるか | 修正済み | 前列滞在、RP、空きマス、攻撃しない一拍、自傷、次ラウンドAP借金、準備、将来の不発、残り時間を対応させた |
| 代償を解く手段があるか | 修正済み | 双刃`引き足`、格闘具`空いた懐`、医療具BA、号旗`返済猶予`などを用意。ただし解決節にも深い投資、RP、撃破条件などを残した |
| 代償の解決が無条件の完全上位になっていないか | 修正済み | 帰還には空きマスと2節、後退には撃破、返済免除にはRP2を要求する。医療具BAは自傷を消す代わりに輸血より係数を下げ、重弩は被弾耐性を得ても対象死亡による不発を残す |
| 資源を作る節は消費先がなくても役立つか | 修正済み | 破片=防御、型=格闘強化、射順表=軟優先、予備血=自動回復、鏡=軽減、二点固定=防壁/隙、予約刃・時砂・次弾=対応武器の強化として、深い消費節なしの出口を持たせた |
| 条件外に主軸が停止しないか | 修正済み | `指定射`、`無手`、`網場`、`千客万来`、`急かす`、`時間外手術`、`最後の号令`、`三時射`に親主軸または基礎攻撃へのfallbackを明記した |
| 発生源と消費主軸を同時に使えるか | 修正済み | 双刃の予約刃を「自分の非攻撃主軸」から「味方の非攻撃主軸」へ変更。主軸切替なしで`差し刃`と`千客万来`を使える |
| AP・RP・追加解決が自己増殖しないか | 修正済み | 号旗同士のAP受け渡しを禁止し、重弩の追加解決は次弾を生成せず、`未来撃ち`をラウンド1回にした |

追加で、自動戦闘なのに手動選択を要求していた空きマス・列指定を固定規則へ置換し、廃止済みの速度を
号旗から除いた。格闘具の消えて育たない連携、双刃の同時利用できない予約刃、条件外に停止する主軸、
上限のなかった射出器の照合も修正した。

節数はアクティブ70、リアクティブ17、ターゲット9、パッシブ94の合計190。十武器すべて19節を維持する。

### 12.1 武器ごとの実戦ループ

| 武器 | 2ラウンド目以降の価値 | 主な代償 | 代償の扱い |
|---|---|---|---|
| 戦槌 | 毎回の怯み、列攻撃、強化除去 | 近接、遅い単発、敵強化への依存 | ターゲットで壊す相手を選び、破片を次打へ変える |
| 格闘具 | 同一対象の連携、撃破ごとの前後移動 | 対象変更で連携消失、倒せないと前列残留 | 目を離さない、拳甲、空いた懐。安全は撃破できた時だけ得る |
| 射出器 | 条件ターゲット、観測、毎ラウンドの射順 | 素の係数は近接王道より低い、順を外すと照合消失 | 遠隔射程と防御無視、照合はラウンド上限3で再挑戦できる |
| 医療具 | 毎回の直接回復、再生、余剰資源 | 攻撃しない一拍、輸血の自傷 | BAで自傷を消す代わりに回復量を落とす。蘇生は時間・最大HPを払う |
| 大盾 | 毎回の防壁・誘引、被弾ごとの守勢・鏡 | 集中被弾、攻撃機会の放棄、RP | 分配・回復・反転があるが、深い投資かRPを要求する |
| 長槍 | 各ラウンドの未行動敵、敵移動、行動順へ介入 | 条件後は威力低下、RP、割込後の本来手番消失 | ターゲットと移動不能で条件を作り直す |
| 鉤縄 | 毎回異なる敵・負傷者を動かし、印を更新 | 空きマス依存、攻撃を捨てる救助、敵味方両方への起爆 | 壁打ちの失敗補償と各主軸のfallbackを持つ |
| 双刃 | 毎起動の前進→攻撃→後退、裂傷蓄積、味方hitへの差込 | 前後列の空き、AA2未取得時の前列残留、多段防御 | 引き足は安全と引き換えに2節の取得を要求し、往復それぞれで敵の移動反応も受ける |
| 号旗 | 毎回のAP移譲・一時出撃・準備短縮 | 自分の攻撃一拍、AP借金、残り時間 | 帰陣、返済猶予、条件付き総攻勢。条件外は親主軸へ戻る |
| 重弩 | 準備と発射の反復、印、次弾の蓄積 | 準備中の被弾、対象死亡、未来の不発 | 装填維持、鉤縄連携、次弾在庫と未来撃ちの有効化で前借り量を制御する |

### 12.2 実装前に数値試験する残課題

- A→AAの無条件パッシブを全取得した時、終端アクティブの実効値が他枝を消さないか。
- ターゲットを借りる1SPが、後列の重要敵を狙える遠隔武器だけに偏らないか。
- `駆け込み`単体の前列残留が十分な代償で、`引き足`取得後の安全な往復が火力節一つ分に見合うか。
- `揃い足`の一時出撃が、号旗自身の攻撃一拍を捨てる価値に見合うか。
- 反応優先列がRPを使い切る順番を、戦闘予測とログから説明できるか。
- `総入れ替え`や`時穿ち`が、予測と本番で同じevent順を返し、無限連鎖を作らないか。
- 3、6、10ラウンドの固定標本で、戦闘1回以外の各取得節が二度以上結果へ寄与するか。
