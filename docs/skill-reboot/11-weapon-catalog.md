# 武器ツリー・カタログ案 — 10武器 × 19節（全面改稿）

更新日: 2026-09-20
状態: **発想を広げる初稿。係数・SP・実装可能性・既存IDへの対応は未検証。**
前提: `10-weapon-tree-reboot.md`

## 0. 読み方

全武器を同じ19位置で書く。

- `R`: 1SPを払って入る代表アクション。
- `A → AA`: その武器で最も単純な王道。無条件中心で、読んだ通りに強くなる。
- `A → AB`: 王道から分かれる、範囲・回数・攻防配分の扱いやすい応用。
- `B → BA`: 条件と他武器への連携。
- `B → BB`: その武器で最もトリッキーな規則破り。
- `A3 / B3 / AA3 / AB3 / BA3 / BB3`: 親の主軸を置き換えるアクティブ形態。

| 種類 | 解決規則 |
|---|---|
| アクティブ | 選択中のメインアクション一つだけ。APごとに同じ主軸を再評価する |
| リアクティブ | 指定eventで優先列を上から検査し、その人物で最初に成立した一つだけ発動してreturnする |
| ターゲット | 対象問い合わせ時に優先列を上から検査し、最初に有効候補を返した一つだけ使う |
| パッシブ | 条件を満たすものをすべて適用する。反応窓を消費せず、早期returnしない |

ターゲットは複数取得でき、優先列の上から最初に候補を返せた規則を使う。どれも成立しなければ
単体攻撃は最も近い有効な敵を狙う。非攻撃アクションは各Rに既定対象を書く。

攻撃の既定射程は近接である。近接は後列から使うと最終ダメージ40%（60%減衰）になり、敵前列が
生存する間は敵後列を候補にできない。長射程・遠隔は後列減衰なしで敵後列も候補にでき、支援は
味方への距離減衰を受けない。係数は量だけを決め、例外は各武器の「射程」に明記する。

割合、回数、状態段数は比較用の仮値である。ただし確率は使わない。「しやすい」は、優先、固定値、回数、
閾値、確定付与のいずれかへ書き換えている。

| 署名武器A→AAは人物を最短で再現するか | 可 | ゴウ=重打、ツグミ=射出器、ナギ=大盾、ヒバナ=鉤縄、ゲンゾウ=号旗を維持。医療はツグミの副武器として明示的に残す |
| BBが最も変則的か | 可、要試作 | 型の模倣、蘇生代償、陣形総入替、他者hitへの差込、時間固定、未来射撃をBBへ集約した。重弩BAの曖昧な`3event`はactor行動3回へ限定した |
| パッシブを全部重ねてよいか | 修正済み | 単純なevent加算だった`砕け音`、`合図弾`、`走れの合図`、`血飛沫`をパッシブへ移し、RPと早期returnを外した |
| リアクティブは下を止める価値があるか | 可 | 生存、庇護、割込、位置交換、印消費、AP借金、時間延長、未来攻撃など、RP・回数・在庫か安全を使う選択だけを残した |
| 対象規則は確実にfallbackするか | 修正済み | `ターゲット`を独立種別にした。候補0なら次へ進み、最後はアクティブ固有の軟優先、近接なら射程内の最短距離へ落ちる |
| 乱数を前提にする語が残っていないか | 可 | 優先順位、固定マス順、回数、閾値だけで記述した |
| 射程や後列減衰を暗黙にしていないか | 修正済み | 近接を共通既定にし、全10武器へ近接・長射程・遠隔・支援を明記した |
| 支援へ理由のない攻撃を付けていないか | 可 | 医療具と号旗は攻撃しない。大盾の`盾撃`だけは防御量を落とす明示的な攻防hybridとして残した |
| 現engineに無い効果を弱くしていないか | 可 | 直接回復、能力変更、蘇生、AP前借り、残り時間変更、位置交換を候補として維持した |

追加で、自動戦闘なのに手動選択を要求していた空きマス・列指定を固定規則へ置換し、廃止済みの速度を
号旗から除いた。移動は`駆け込み`による近接減衰解消、敵後列の引き出し、勢い、防壁、印、反応へ接続し、
単に最短距離の対象を散らすだけの効果にはしない。

### 12.1 実装前に数値試験する残課題

- A→AAの無条件パッシブを全取得した時、終端アクティブの実効値が他枝を消さないか。
- ターゲットを借りる1SPが、後列の重要敵を狙える遠隔武器だけに偏らないか。
- `駆け込み`と`揃い足`が、空き前列を一つ残す編成に十分な価値を作るか。
- 反応優先列がRPを使い切る順番を、戦闘予測とログから説明できるか。
- `総入れ替え`や`時穿ち`が、予測と本番で同じevent順を返し、無限連鎖を作らないか。
