# 武器ツリー・カタログ案 — 10武器 × 19節

更新日: 2026-09-19
状態: **発想を広げるための初稿。係数・SP・実装可能性・既存IDへの対応は未検証。**
前提: `10-weapon-tree-reboot.md`

## 0. 読み方

全武器を同じ19位置で書く。

- `R`: 1SPを払って入る代表アクション。
- `A1 → A2 → A3` / `B1 → B2 → B3`: 二つの中間経路。`A3`と`B3`は主軸形態。
- `AA` / `AB`: A3から分かれる二つの終端経路。
- `BA` / `BB`: B3から分かれる二つの終端経路。
- 各終端の3番目は主軸形態。親の主軸を置き換えるが、兄弟終端とはsidegradeである。

表の種類はプレイヤー向けの見せ方である。

| 種類 | 意味 |
|---|---|
| 主軸 | 選択中のメインアクション。同時に一つだけ |
| 特性 | 取得すると原則オン。条件・費用・limitを満たすと働く |
| 照準 | 対象優先を変える排他特性。同時に一つだけ |
| 姿勢 | 自分の位置・受け方・振る舞いを変える排他特性。同時に一つだけ |

`[横断]`は、別武器をメインにしても働く想定を示す。明記がない特性も、固有アクションIDではなく
共有eventを読む場合は横断候補である。RP、回数、割合、状態段数はすべて仮置きで、面白い接続を
説明するためだけに書く。

既存語彙は、集中・隙・怯み・守勢・裂傷・防壁・受け構え・AP・RP・準備を優先する。
新しい語彙を使う場合も、最終実装で既存語彙へ畳めるかを後で検討する。

## 1. 戦槌 — 守りを壊し、受けた重さを返す

導入人物: ゴウ
代表アクション: **槌打ち** — 腕力依存・近接・単体。後列では減衰する。
中心event: `damage_blocked`、`barrier_broken`、`status_applied:staggered`、`damage_taken`。
Aは敵の守りを崩す即応線、Bは自分が受けた圧力を次の一撃へ溜める線。

| 位置 | 種類 | 名称 | 効果・接続案 |
|---|---|---|---|
| R | 主軸 | 槌打ち | 最前の敵一体へ腕力依存の重い一撃。受けが高い相手にも最低限の実ダメージを保証する。 |
| A1 | 特性 | ひびを読む | [横断] 防壁または受け構えを持つ敵への最初のhitを強める。量ではなく「守りがあること」を読む。 |
| A2 | 特性 | 砕け目 | [横断] 自分が敵の防壁を壊すか受け構えを消費させたとき、ラウンド1回、その敵へ怯みを1段付ける。 |
| A3 | 主軸 | 崩城打ち | 槌打ちを置換。受けの一部を無視し、防壁・受け構えへ当てた場合は怯みも付ける。 |
| AA1 | 特性 | 固いほど響く | [横断] 敵の受けで減らされた量に応じて、その攻撃の最後に受け無視の追加量を返す。chain1回。 |
| AA2 | 特性 | 砕片拾い | [横断] 敵の防壁が壊れたとき、自分へ集中を1段。誰が壊してもよいがラウンド1回。 |
| AA3 | 主軸 | 震天崩し | 崩城打ちを置換。単体大打撃。対象の怯みをすべて消費し、段数に応じて受けと防壁を深く貫く。 |
| AB1 | 特性 | 余震 | [横断] 怯みのある敵へ単体攻撃を当てたとき、同じ行の他の敵へ小さい衝撃を配る。 |
| AB2 | 特性 | 崩落連鎖 | [横断] 怯みのある敵を倒したとき、隣接する敵へ怯みを1段ずつ渡す。戦闘中の上限を持つ。 |
| AB3 | 主軸 | 地割り | 崩城打ちを置換。対象の行全体を叩き、守りを持つ相手だけへ追加量と怯みを与える。単体量は震天崩しに劣る。 |
| B1 | 姿勢 | 腰を落とす | 前列で移動していない間、最初に受けるhitを軽くする。移動したラウンドは無効。 |
| B2 | 特性 | 受けた重み | [横断] 自分の防壁・受け構え・守勢で減らした量を、そのラウンドの次の攻撃へ一部だけ載せる。 |
| B3 | 主軸 | 返し槌 | 槌打ちを置換。直前の敵行動以降に自分が軽減した量に応じて強くなり、使うと蓄積を空にする。 |
| BA1 | 特性 | 金床の呼吸 | [横断] 狙われたあと実HPダメージを受けなかった場合、RPなしで受け構えを1つ得る。ラウンド1回。 |
| BA2 | 特性 | 打ち返す備え | [横断] 自分が狙われた瞬間、RP1で次の主軸の最初のhitを強める。実際に受けなければ消える。 |
| BA3 | 主軸 | 金床返し | 返し槌を置換。蓄積した軽減量を単体打撃と自分への防壁へ分ける。攻防を同時に返すが、地割りの面処理はない。 |
| BB1 | 特性 | 据え足 | [横断] そのラウンドに一度も移動していなければ、攻撃の最初のhitと受けを小さく強める。 |
| BB2 | 特性 | 重圧の底 | [横断] HP半分以下で攻撃を受けたとき、戦闘1回だけ集中と守勢を同時に得る。 |
| BB3 | 主軸 | 不動砕き | 返し槌を置換。準備1回の後、蓄積した軽減量を全て使う単体大打撃。準備中に動かされると蓄積の一部を失う。 |

### 想定する横断

- 大盾が作った`damage_blocked`を、戦槌の「受けた重み」が別の主軸へ載せる。
- 長銃が後列の防壁役を狙い、戦槌の「砕片拾い」が誰の破壊でも集中へ変える。
- 鉤鎖で怯んだ敵を一列へ寄せ、地割りで面処理する。

## 2. 大剣 — 傷と撃破を、一度の大振りへ変える

導入人物: ゴウ
代表アクション: **斬り下ろし** — 腕力依存・近接・単体。安定した高威力と後列減衰を持つ。
中心event: `lose_hp`、`hp_percent`、`actor_defeated`、`excess_damage`、`target_changed`。
Aは自分の傷を力にする線、Bは手負いの敵と撃破後の余勢を使う線。

| 位置 | 種類 | 名称 | 効果・接続案 |
|---|---|---|---|
| R | 主軸 | 斬り下ろし | 最前の敵一体へ腕力依存の大振り。追加条件を持たず、単体継続火力の基準になる。 |
| A1 | 特性 | 手負いの刃 | [横断] 自分のHPが半分以下の間、攻撃の最初のhitを強める。回復すれば止まる。 |
| A2 | 特性 | 傷を力に | [横断] 費用としてHPを失ったとき、集中を1段得る。敵からの通常被弾は対象外。chain1回。 |
| A3 | 主軸 | 捨て身斬り | 斬り下ろしを置換。威力を大きく上げる代わりに、自分へ隙を1段付ける。 |
| AA1 | 姿勢 | 背水 | HP半分以下では前列を維持し、後列へ自動退避しない。守勢を得る効果は薄くなるが攻撃が強まる。 |
| AA2 | 特性 | 灰の血路 | [横断] 自分に隙が付いたとき、RP1で守勢を1段得る。隙そのものは消さず、危険を無効化しない。 |
| AA3 | 主軸 | 灰断ち | 捨て身斬りを置換。自分の隙を全消費して単体へ大打撃。消費した隙が多いほど強いが、攻撃後にHPを失う。 |
| AB1 | 特性 | 痛みの配当 | [横断] 自分が費用で失ったHPの一部を、そのラウンドの次の攻撃へ追加量として載せる。 |
| AB2 | 特性 | 血煙 | [横断] HP半分以下で敵を倒したとき、同じ行の敵へ隙を1段ずつ付ける。ラウンド1回。 |
| AB3 | 主軸 | 血煙薙ぎ | 捨て身斬りを置換。自分のHPを払い、敵一行を薙ぐ。HPが高いほど支払える量が大きく、低HPでは安全側に縮む。 |
| B1 | 照準 | 手負い狙い | HP割合が最も低い、届く敵を優先する。倒し切れない同率では前列・位置順。 |
| B2 | 特性 | 余勢 | [横断] 過剰ダメージを出したとき、その一部を集中として次の攻撃へ持ち越す。ラウンドを越えない。 |
| B3 | 主軸 | 断頭 | 斬り下ろしを置換。HPが一定以下の敵へ大きく伸び、条件外では斬り下ろし相当の量を保つ。 |
| BA1 | 特性 | 一歩も止まらず | [横断] 自分が敵を倒したとき、戦闘1回だけAPを1得る。APを得たeventから再発火しない。 |
| BA2 | 特性 | こぼれ刃 | [横断] 敵を倒した攻撃の過剰ダメージを、届く別の敵へ小さく渡す。追加攻撃ではなく同じactionの余波。 |
| BA3 | 主軸 | 追葬 | 断頭を置換。倒した場合だけ、残った過剰ダメージを次の敵へ一度渡す。単体bossには断頭と同等で止まる。 |
| BB1 | 照準 | 大物狙い | 最大HPが最も高い、届く敵を優先する。瀕死の小敵より長く残る敵へ圧力を集める。 |
| BB2 | 特性 | 刻みを嫌う | [横断] 同じ敵を二回以上連続で狙ったとき、二回目以降の単発攻撃を強める。対象を替えると消える。 |
| BB3 | 主軸 | 巨獣断ち | 断頭を置換。対象の最大HPが高いほど追加量を得る。処刑域の倍率は失い、長期単体戦へ寄せる。 |

### 想定する横断

- 医杖でHPを安全圏へ戻すか、背水を維持するかが同じ構成内の判断になる。
- 双刃が小敵を削り、大剣の手負い狙い・追葬で撃破連鎖を始める。
- 重弩の過剰ダメージも「余勢」「こぼれ刃」が読める。

## 3. 長銃 — 狙いを選び、同じ一発の意味を変える

導入人物: ツグミ
代表アクション: **精密射撃** — 技術依存・遠隔・単体。後列減衰を受けず、前列がいても後列を候補にできる。
中心event: `target_selected`、`target_changed`、`damage_taken`、`preparation_started`、同一対象履歴。
Aは照準と弱点処理、Bは射数・対象の切り替えを扱う。

| 位置 | 種類 | 名称 | 効果・接続案 |
|---|---|---|---|
| R | 主軸 | 精密射撃 | 届く敵一体へ技術依存の遠隔攻撃。既定ではHPが低い敵を狙うが、照準特性で上書きできる。 |
| A1 | 照準 | 手負い照準 | HP割合が最も低い敵を優先する。既定の絶対HP順と異なり、大型の手負いも候補になる。 |
| A2 | 特性 | 観測射 | [横断] 自分が選んだ対象へまだ隙が無ければ、攻撃後に隙を1段付ける。ラウンド1回。 |
| A3 | 主軸 | 弱点射撃 | 精密射撃を置換。状態を一つ以上持つ敵へ追加量。状態を消費せず、他の「食う」技能へ残す。 |
| AA1 | 特性 | 仕留め勘 | [横断] HP25%以下の敵への最初のhitを強める。対象を倒せなければ自分へ隙を1段付ける。 |
| AA2 | 特性 | 無駄弾なし | [横断] 攻撃で過剰ダメージが出たとき、次に異なる敵を狙うまで集中を1段保持する。 |
| AA3 | 主軸 | 止めの一発 | 弱点射撃を置換。最もHP割合の低い敵を優先し、対象の隙を全消費して処刑量へ変える。 |
| AB1 | 照準 | 術者照準 | 治療・防壁・AP/RP移譲を行う敵を優先する。対象タグまたは技能性質から判定する想定。 |
| AB2 | 特性 | 妨害弾 | [横断] 敵が準備を始めたとき、RP1でその敵へ怯みを1段。ラウンド1回。 |
| AB3 | 主軸 | 沈黙射 | 弱点射撃を置換。準備中または支援技能を持つ敵を優先し、命中すると準備を遅らせるかRPを削る。 |
| B1 | 特性 | 据えた照準 | [横断] 直前の自分の攻撃と同じ敵を狙うと、最初のhitが強まる。対象が動いてもinstanceで追う。 |
| B2 | 特性 | 狙い替え | [横断] 直前と異なる敵を狙ったとき、攻撃後に自分へ集中を1段。ラウンド1回。 |
| B3 | 主軸 | 二点射 | 精密射撃を置換。同じ対象へ二hit。受けに弱いが、hitを読む双刃・状態特性と接続する。 |
| BA1 | 特性 | 三発目の癖 | [横断] 同じchainの三hit目が通ったとき、対象へ裂傷を1段。ラウンド1回。 |
| BA2 | 特性 | 初弾優先 | [横断] ラウンド中の自分の最初の攻撃だけ、集中を消費せずに量へ反映する。二回目以降は通常どおり。 |
| BA3 | 主軸 | 連装射 | 二点射を置換。同じ対象へ三hit。裂傷・隙との接続は増えるが、固定受けの厚い敵には最も弱い。 |
| BB1 | 照準 | 列を読む | 生存敵が最も多い行を優先し、その行の中では既定の対象順を使う。 |
| BB2 | 特性 | 射線共有 | [横断] 自分が後列の敵へ当てたとき、前列の最もHPが低い敵へ隙を1段。ラウンド1回。 |
| BB3 | 主軸 | 掃射 | 二点射を置換。敵一行へhitを分配する。単体への総量は連装射より低く、受け構えを広く剥がす。 |

### 想定する横断

- 「術者照準」は戦槌・大剣など、対象選択可能な他の主軸にも適用できる。
- 双刃・連装射・重弩の複数hitが「三発目の癖」を共用する。
- 号旗でAPを受け取った二回目の起動では、「据えた照準」と「狙い替え」のどちらを狙うかが変わる。

## 4. 医杖 — 傷を戻し、余った手当てを次の備えへ回す

導入人物: ツグミ
代表アクション: **応急照射** — 技術依存・味方単体。直前の攻撃の回復窓内で最も傷ついた味方を治療する。
中心event: `damage_taken`、`effective_heal`、`excess_healing`、`recovery_window_closed`、状態除去。
Aは実HP治療と救命、Bは防壁・守勢・状態処置へ広げる。純支援主軸なので、原則として解決後に弱い通常追撃を行う。

| 位置 | 種類 | 名称 | 効果・接続案 |
|---|---|---|---|
| R | 主軸 | 応急照射 | 回復窓内で最も傷ついた味方一人を技術依存で治療する。有効対象がいなければ通常攻撃へ落ちる。 |
| A1 | 照準 | 急患優先 | 直前の一撃で失ったHP割合が最も高い味方を優先する。単なる現在HP最小とは異なる。 |
| A2 | 特性 | 手当ての余白 | [横断] 自分が実効回復を与えたあと、その相手へ守勢を1段。ラウンド1回。 |
| A3 | 主軸 | 集中治療 | 応急照射を置換。HP半分以下の対象への量が増え、回復後も半分以下なら受け構えを1つ付ける。 |
| AA1 | 特性 | 危険を診る | [横断] 味方へのpending damageが残HP以上なら、RP1でその味方へ守勢を付けてから解決する。chain1回。 |
| AA2 | 特性 | 命をつなぐ | [横断] 自分以外の味方が戦闘不能になる一撃の回復窓で、戦闘1回だけHP1へ戻し、回復不能分は残す。 |
| AA3 | 主軸 | 命綱 | 集中治療を置換。瀕死者への治療後、そのラウンドの次の一撃を受け止める構えを付ける。対象が安全なら通常の集中治療。 |
| AB1 | 特性 | 余りを配る | [横断] 自分の治療に余剰が出たとき、RP1で別の負傷者へ一部を回す。同じ余剰を二度使わない。 |
| AB2 | 特性 | 手当ての列 | [横断] 同じ行に負傷者が二人以上いるとき、単体治療の一部を行内の別の味方へ分ける。 |
| AB3 | 主軸 | 野戦治療 | 集中治療を置換。選んだ味方と同じ行をまとめて治療し、最も傷ついた一人だけ量を厚くする。 |
| B1 | 特性 | 清い手 | [横断] 自分が味方を治療したとき、ラウンド1回、その相手の隙または裂傷を1段だけ除く。 |
| B2 | 特性 | 残る処置 | [横断] 回復窓を閉じる前に治療した対象へ、実効回復量の一部をラウンド防壁として残す。 |
| B3 | 主軸 | 防疫照射 | 応急照射を置換。治療に加えて悪性状態を一つ除き、除けなければ代わりに守勢を付ける。 |
| BA1 | 特性 | 余剰防壁 | [横断] 自分が出した余剰治療を、同じ対象への防壁へ変える。余剰治療eventを消費し、他の出口とは競合する。 |
| BA2 | 特性 | 壊れ際の手当て | [横断] 味方の防壁が壊れた直後、RP1でその味方を小さく治療する。回復窓が無ければ防壁へ変わる。 |
| BA3 | 主軸 | 回生障壁 | 防疫照射を置換。実効回復に加え、同量の一部を戦闘防壁として張る。状態除去は一段だけに縮む。 |
| BB1 | 特性 | 病を力へ | [横断] 味方から悪性状態を除いたとき、その味方へ集中を1段。ラウンド1回。 |
| BB2 | 特性 | 守勢の処方 | [横断] 守勢を持つ味方への治療を強め、治療後に守勢が残れば受け構えを1つ付ける。 |
| BB3 | 主軸 | 全身調整 | 防疫照射を置換。対象の悪性状態を複数除き、除いた数に応じて治療・守勢・集中へ配分する。単純な治療量は回生障壁に劣る。 |

### 想定する横断

- 大剣の背水を維持したい人物には回復を薄く、防壁・守勢だけを渡す選択が生まれる。
- 大盾が作った防壁の破壊を「壊れ際の手当て」が読み、戦槌は同じ破壊を集中へ変える。
- 双刃が裂傷を使う敵に対して、清い手で一段ずつ除くか、全身調整へ深く進むかが分かれる。

## 5. 長槍 — 列と間合いを読み、動く前の敵を射抜く

導入人物: ナギ
代表アクション: **貫き突き** — 腕力依存・近接・単体。前列からは後列も候補にできる長いreachを持つ。
中心event: `target_selected`、`actor_moved`、`preparation_started`、列関係、`target_changed`。
Aは列を貫いて敵陣を整える線、Bは迎撃と先手で敵の行動前を取る線。

| 位置 | 種類 | 名称 | 効果・接続案 |
|---|---|---|---|

| BA3 | 主軸 | 鉄壁号令 | 備え号令を置換。味方一行へRPを分配し、RP0だった者へ守勢も付ける。APへの変換はできない。 |
| BB1 | 特性 | 次を指す | [横断] 味方の行動解決後、RP1で未行動の味方一人を次の味方phaseの先頭へ置く。行動回数は増やさない。 |
| BB2 | 特性 | 拍を預ける | [横断] 先頭へ置いた味方が支援行動をした場合、その次の味方へ集中を1段。ラウンド1回。 |
| BB3 | 主軸 | 拍子替え | 備え号令を置換。味方一人へRP1を渡し、その人物を次の味方phaseの先頭へ置く。APを増やさず順番だけを変える。 |

### 想定する横断

- 重弩・戦槌の準備を進めるか、双刃へ二回目のAPを渡してhit条件を起こすかを選ぶ。
- 大盾へRPを渡すと庇護が増えるが、ゲンゾウ自身の反応点は減る。
- AP2のヒバナへさらに渡しても、三番目のアクティブは出ず、同じ主軸が変化した盤面を再評価する。

## 10. 重弩 — 準備を払い、貫通と爆発へ大きな一発を置く

導入人物: ゲンゾウ
代表アクション: **装填射** — 腕力依存・遠隔・準備1回の単体大打撃。後列からでも減衰しない重い投射武器。
中心event: `preparation_started`、`preparation_advanced`、`preparation_completed`、`excess_damage`、貫通関係。
Aは単体・防御貫通・状態消費、Bは爆発・列・遅延効果へ広げる。

| 位置 | 種類 | 名称 | 効果・接続案 |
|---|---|---|---|
| R | 主軸 | 装填射 | 準備1回の後、届く敵一体へ腕力依存の大打撃。準備開始と発射で二起動を使う。 |
| A1 | 特性 | 装填姿勢 | [横断] 自分が準備を始めたとき、守勢を1段。ラウンド1回。 |
| A2 | 特性 | 狙いが定まる | [横断] 自分の準備が完了したとき、集中を1段。誰かに進めてもらってもよい。 |
| A3 | 主軸 | 穿甲矢 | 装填射を置換。対象の受けと防壁の一部を無視する。防御が薄い敵への量は装填射と同程度。 |
| AA1 | 照準 | 大物を射る | 最大HPが最も高い敵を優先する。同率では防壁・受けが高い敵。 |
| AA2 | 特性 | 同じ穴 | [横断] 同じ敵へ準備攻撃を二回続けて当てたとき、二回目は受けをさらに無視する。戦闘1回。 |
| AA3 | 主軸 | 城穿ち | 穿甲矢を置換。単体へ極大打撃を行い、防壁を壊した余りを実HPへそのまま通す。対象変更には弱い。 |
| AB1 | 照準 | 崩れを射る | 怯みまたは隙の合計段数が最も多い敵を優先する。 |
| AB2 | 特性 | 楔を抜く | [横断] 状態を消費する攻撃を行ったとき、消費した段数に応じて集中を一部返す。chain1回。 |
| AB3 | 主軸 | 楔抜き矢 | 穿甲矢を置換。対象の怯み・隙を全消費し、段数に応じて受け無視の追加量。状態が無ければ穿甲矢相当。 |
| B1 | 特性 | 初荷 | [横断] 戦闘で最初に始める準備だけ、開始時に1段進んだ状態になる。戦闘1回。 |
| B2 | 特性 | 破片の行方 | [横断] 単発攻撃で過剰ダメージが出たとき、同じ行の別の敵へ一部を飛ばす。chain1回。 |
| B3 | 主軸 | 炸裂矢 | 装填射を置換。対象への大打撃後、同じ行へ爆発を配る。単体量は穿甲矢より低い。 |
| BA1 | 照準 | 射線を通す | 同じ列に生存敵が二体いる列を優先する。同率では後列のHPが高い列。 |

| BB1 | 特性 | 残した矢 | [横断] 準備攻撃が対象を倒せなかったとき、その敵へ「埋込矢」を一つ残す。仮の新状態。 |

### 想定する横断

- 号旗が準備を進める、長槍が敵の準備を止める、重弩自身は準備完了を集中へ変える。
- 戦槌・長銃が作った怯み／隙を楔抜き矢が食い、消費後を別の特性が読む。
- 大剣の余勢、双刃の余り刃、重弩の破片の行方が同じ過剰ダメージを異なる時間軸で使う。

## 11. 十武器を横断する構成の種

以下は完成レシピではなく、交換可能な接続の例である。人物・武器・装備のどれか一つを替えても、
同じ共有eventから別の出口へ進めることを狙う。

| 種 | 主軸候補 | 仕込み | 利得先 | 苦手・代償 |
|---|---|---|---|---|
| 砕いて撃つ | 戦槌／重弩 | 防壁破壊、怯み | 震天崩し、城穿ち、砕片拾い | 防御の薄い多数敵では準備過多 |
| 傷を刈る | 双刃／大剣 | 裂傷、低HP、過剰ダメージ | 血解き、追葬、余勢 | 高い固定受け、治療で背水が消える |
| 列を作る | 鉤鎖／長槍 | 敵移動、同列化 | 串刺し、横薙ぎ鎖、足並み | 動かせないboss、空き位置不足 |
| 守って返す | 大盾／戦槌 | 対象変更、block、防壁破壊 | 金床返し、反攻構え、受けの受け渡し | 貫通・全体攻撃、RP枯渇 |
| 二度動かす | 号旗／双刃／長銃 | AP移譲、対象履歴 | 千切り、連装射、狙い替え | 一人へ寄せすぎると他のRPが死ぬ |

## 12. 棚卸し時の問い

実装候補へ絞るときは、各節について次を答える。

1. ルートだけでも、この武器を主軸として一戦試す理由があるか。
2. A3とB3は、数字以外の性能軸が違うか。
3. 四終端のどれかが、他の三つを全状況で上回っていないか。
4. 横断特性は、別武器の主軸でも実際に一回以上鳴るか。
5. 同じeventを読む別の出口が二つ以上あるか。
6. その節を外した方が説明も構成も豊かになるなら、数合わせで残していないか。
7. 照準・姿勢の競合は、装着順ではなく一つの排他選択として説明できるか。
8. 無料反応、AP/RP移譲、準備進行、対象変更が循環していないか。
9. 取得前の一文だけで、いつ働き何を変えるか読めるか。
10. その武器の所有者以外へ渡したとき、新しい構成が一つ以上見えるか。
