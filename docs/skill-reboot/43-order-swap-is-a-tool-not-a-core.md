# 五人の順を一箇所だけ入れ替える：大きく効くが、主役にはしない

更新: 2026-09-29。状態: **戦闘前の追加設定としては保留。固定順の価値を再確認した試験。** [再現コード](../../analysis/skill-reboot-adjacent-order-audit.py)。[35の前線](./35-replenishing-frontier.md)では五人がH→G→Z→T→N（ヒバナ、ゴウ、ゲンゾウ、ツグミ、ナギ）で動く。プレイヤーがこの順を出発時に一箇所だけ隣と交換できれば、短い技能を増やさず深い戦略になるかを調べた。解禁順は別にG→H→Z→T→Nで固定。予射や敵技奪取は使わず、36の返り火と比較用のB数値だけを使う。

## 初巡だけなら理解しやすい

初期前線HP4・4・6。全員Aで、ゴウだけ初期解禁。元のH→G→Zなら、ヒバナの基礎2で先頭HP4→2、ゴウA8がそこを倒し、ゲンゾウの基礎2が次を削る。その後ゲンゾウAが解禁すれば、ゴウの大きな一撃を後から写しやすい。

G→H→Zへ交換すると、ゴウA8が先頭を倒した後、ヒバナAの三射が次へ飛ぶ。ゲンゾウAが実行する時点の直前の表示威力はヒバナの**1**なので、ゴウの8を写せない。この構成での交換は、主要な連鎖を自分で切る行為になりやすい。各人物の技能と位置が見えていれば、プレイヤーが理由を説明できる変更だ。

## 同じ技能・敵列での対照

HP1.2倍の固定十二隊で、五人のA/B32枝。元順と、一箇所だけ隣と交換した順を一回ずつ比較。表の「救済」は元順では負けるが交換で勝つ、「悪化」は元順では勝つが交換で負ける。数は枝の種類であり、プレイヤー数や面白さではない。

| 交換 | 基本敵列 救済／悪化 | 射手・広域首領 救済／悪化 | 基本で両方勝ち、交換が速い／遅い／同じ |
|---|---:|---:|---:|
| H↔G | 5／9 | 5／6 | 9／5／2 |
| G↔Z | 3／6 | 5／8 | 9／5／5 |
| Z↔T | 2／8 | 3／4 | 9／3／5 |
| T↔N | 1／1 | 0／1 | 3／1／20 |

確かに「一度入れ替えて先へ行ける」は起こる。しかしこれだけなら四択の正解探しになり得る。特に全員Aは通常隊216経路で元順216/216勝なのに、H↔Gでは0/216。これは強い戦略的違いというより、ゲンゾウの写す対象を壊した結果として予測可能だ。ゲンゾウAを持つなら、位置を保つことがほぼ定石になる。

固定経路でH↔Gが敗北から勝利へ変えた「ヒバナB・ゴウA・ゲンゾウB・ツグミA・ナギB」も、経路を216通りにすると元順118勝・交換後124勝とわずかな差。敵HPを一体ずつ**1下げる**と元順216勝・交換後162勝、**1上げる**と元順88勝・交換後38勝へ逆転する。固定経路の一勝を「自分で作った意味ある配置の発見」と扱うのは危険。どこに敵が到着して返り火が渡るかの閾値が変わっている可能性がある。

## 判断

この設定は、[Into the Breach公式](https://subsetgames.com/itb.html)のように一手ごとの予告を見て位置を直すゲームでは強い主役になれる。一方、ここで残したいのは**自分の五人の順を頭の中で予測し、予約した成長が十二隊をまたいで続く**楽しさ。毎遠征で並べ直すUIを常設すると、元の問題である「設定を直す→予測をやり直す」の検索空間を増やす。T↔Nの交換は大半の構成で同じ勝敗・所要行動になり、四箇所を全部考えさせる価値も低い。

固定順を現在の三枠候補では維持する。将来、同じ技能が主役の異なる道筋を人間が明確に語れるようになったときだけ、特別な育成で一度順を入れ替える案を再検討する。大きな数値差が出ることは、面白い選択だという証拠にならない。
