# 二本道の紙試験：同じ五人で、二人の順だけが違うと何が起きるか

更新: 2026-09-29。状態: **ルール一局面の手計算。フルゲームの勝敗・面白さは未検証。** [53](./53-authorship-before-spectacle.md)の安い試験のうち、ゴウとヒバナの受け渡しだけを先に行う。途中で都合のよい専用状態を敵へ足さない。

## 一回だけの接触に絞る

前の敵はHP4。ゴウの槌は2、ヒバナの矢は1。どちらも前の敵へ一回ずつ当たり、敵はHP1で残る。最初に当てた人物の印を、後に当てた人物が破る。[継ぎ印の共通ルール](./51-relay-mark-candidate.md)どおり、ヒバナが後なら別の敵二体へ火弾1を一発ずつ、ゴウが後なら前の敵から半径53内の**別の敵すべて**へ波1。前の敵は、いずれの受け技でも追加ダメージを受けない。二人の位置を入れ替えただけで、前の敵への基礎ダメージは常に3。

| 後続の小敵（それぞれHP1） | ゴウ→ヒバナ。ヒバナが受け手 | ヒバナ→ゴウ。ゴウが受け手 |
|---|---|---|
| 前敵から20・30・40離れた三体の密集 | 火弾は二体を倒し、一体残る | 半径53の波で三体とも倒す |
| 前敵から80・100離れた二体の散開 | 火弾が射程145内の二体を倒す | 波は届かず、二体残る |

これは**攻撃属性の無効化**ではなく、同じHP・同じ五人・同じ受け技で、敵の位置関係だけが変わる比較。左の群れなら後手ゴウ、右の散開なら後手ヒバナが生かせる。ゲンゾウを両道の合流へ置けば、残った一体を処理する別の出口がある。ナギとツグミは漏れと被害を受け止められる。だから「この敵の正解技能を装備しないと詰む」とは違う可能性がある。

## 反論を先に付ける

1. **いつも後手ヒバナでよいのでは。** 密集三体のうち一体漏れても、合流のゲンゾウが落とすなら差は実質ゼロ。逆に後手ゴウが遠方二体を撃たなくても射手が片付けるなら差はゼロ。紙上の撃破数と勝敗の差を混同しない。
2. **実時間に同じ敵を二人が一回ずつ撃つとは限らない。** 射程・攻撃周期・他の標的によって二人が別の敵を撃ち、継ぎ印自体が発火しない可能性がある。そうなったとき順番を強制するターゲットUIを増やしたら、以前のルール怪獣に戻る。
3. **プレイヤーには三体の距離20/30/40を読めない。** iPhoneで敵の密集か散開かは絵で見えても、半径53の端を暗算させる設計にはしない。ゴウの波を地面の淡い円で、ヒバナの火弾を目で追える軌跡で示す。見ても違いが分からなければ捨てる。
4. **一戦先の敵配置まで正確に分かると配置を毎回替えたくなる。** だから配置を出発時に固定し、先見は次の波が群れ寄りか散開寄りか、どちらの道へ来るかまで。先駆けのON/OFFは時間の賭けであり、後手技能の着替えではない。
5. **終盤に一撃で前敵を倒すほど強くなれば継ぎ印が消える。** 強いことがコンボを止める最悪の誘因。印は敵が生き残った場合だけでよいという[51](./51-relay-mark-candidate.md)の規則を守ったまま、コンボが不要になる強さも楽しいか検証する。継ぎ印のために硬い敵ばかり増やさない。

暫定: 「単純な入力→複数の違う出力」という技能の種は見つかった。ただし**紙上で二つの配置が違う結果を出せた**だけ。五人全員を配置する意味、十二波の爽快感、一度決めた位置が退屈にならないことを何も証明していない。次は七陣地・三波を実際に遊ぶまで、新しい技能を増やさない。
