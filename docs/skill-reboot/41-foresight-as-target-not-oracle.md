# 先見を「結果を見る」から「まだ来ない敵を撃つ」へ変える試験

更新: 2026-09-29。状態: **未採用の比較用技能。中核にはまだしない。** [人が触れる三枠試作](./frontier-prototype.html)、[再現用Python](../../analysis/skill-reboot-fire-routing-and-stolen-attacks.py)。現在の一戦先の先見機は、作動を観察するには使えても、未来が戦場に直接作用しない。結果を何度も照会して緑を探す誘因が強い。そこで先見を**ヒバナが届く場所**として試す。

## ルールと画面

敵は十二隊合計23体。今いる敵を三枠に表示し、待機列の先頭一体だけを「少し先に見える敵」として表示する。ヒバナAは今いる先頭へ1を三回。B「予射」は前線を一切撃たず、**先見に見える待機列先頭へ4**。傷は残り、死ねばその一体を待機列から除く。次の敵が新たに一体見える。待機列が空なら現前線最後尾へ4。味方は従来どおりH→G→Z→T→Nと動き、現在の敵一体を倒すと待機列先頭が現在の最後尾へ入る。現在の敵だけが一巡末に反撃する。勝利は全待機列・全前線の消滅。五人全滅で敗北。

返り火があれば予射へ一度だけ足される。既に今いる敵へ近付けるゴウの打ち抜きやゲンゾウの三射とは別の進路をヒバナが先に作る。視界は一体先なので任意の敵を狙い撃つ能力ではない。未来の敵を倒しても現在の前線が残る間は休息や技能解禁を早めない。

## 一度の実際の動き

「ヒバナB・ゴウA・ゲンゾウA・ツグミB・ナギA」をヒバナから解禁した固定経路の初動。前線は第1隊HP4・HP4、第2隊HP6、先見は第3隊HP5。

1. ヒバナの予射4は第3隊HP5→1。**現在の三体は無傷。**
2. ゴウの基礎攻撃5は第1隊の先頭HP4を倒す。手負いの第3隊HP1が現在の最後尾へ入る。
3. ゲンゾウの基礎攻撃2は、まだ前にいる第1隊のもう一体をHP4→2へ削る。ツグミがHP1を削り、ナギが防壁2を得る。古参が反撃する。
4. 次巡のヒバナは新たに見えた先の敵を予射で撃つ。返り火があればそこへ加算される。十二隊を突破できたこの一例では、まだ来ていない敵を計6体倒し、通常行動81回、敵の攻撃30回、終了時生存HP合計16。

ここは前の直感的な語りを**訂正**する。『ヒバナが先の敵を傷つけ、ゴウが今を倒し、ゲンゾウがその手負いを即座に仕留める』と期待した。しかし三枠ではゴウが一体倒しても手負いは最後尾へ入るだけで、ゲンゾウは通常先頭を撃つ。予射と次の味方の攻撃はすぐにつながらない。見えない敵を削った数字が数巡後に意味を持つ設計で、目標の短いカタルシスとは距離がある。

## 勝ちやすさだけで評価しない

基本HP1.2倍、返り火、ゴウB6・ゲンゾウB2×3で、予約順120×他四人のA/B16の1,920条件ずつ比較。三枠、ヒバナB4は前線を撃かない。

| 敵列 | ヒバナA 1×3 | ヒバナB 先の敵へ4 | Bが勝ったときの平均先行撃破 |
|---|---:|---:|---:|
| 基本 | 1,807/1,920 | 1,120/1,920 | 2.74体 |
| 射手・後列攻撃首領あり | 894/1,920 | 488/1,920 | 1.73体 |

同じ固定解禁順G→H→Z→T→N、通常隊の216経路×他四人16枝の3,456対では、基本敵列でAだけ勝つ2,208、Bだけ勝つ34、双方勝つ場合Bが速い930。複合敵列でAだけ1,525、Bだけ141、双方勝つ場合Bが速い258。**予射は高速化の誘惑より生存損失が大きい。** 前線への1と先への4にするとBの勝率は基本1,828、複合978へ上がるが、216経路対決で双方勝つ場合のB高速化が基本3,196/3,250件に偏る。前1＋先2なら基本1,683、複合887とAに近い一方、平均の先行撃破は0.37／0.17体で、画面でほとんど見えない。数字合わせで両枝を等勝率にするほど肝心の技能の顔が消える。

三枠を一枠へ狭めれば、予射を受けた敵が次の撃破ですぐ登場し、五人のリレーは見やすい。ただし元の敵攻撃力で全構成が1,920/1,920勝ち、射手・広域首領を混ぜても1,920/1,920。敵一体しか反撃しないので緊張を失う。単純に敵攻撃を2倍にすると基本敵列でA1,829、B1,757勝となるが、防壁・返り火による閾値の調整になり、敵を三体同時に相手にする強弱は戻らない。一枠化もこのままは採らない。

## 自己批判と次の関門

- 今の三枠・一体先では、先見の一体と現在の三体をiPhoneで同時に見せる必要があり、文字の四段目が増える。視認性はブラウザで直接確かめる。
- 先行撃破は「戦わずに敵を飛ばした」に近い。ヒバナが世界から一体消すのに他の四人は手助けできない。数値上は早いのに、五人のコンボに遠い。
- これを全員に配れば未来の敵を無傷で狩るのが最適になり、敵が戦闘に出ない。ヒバナだけに閉じれば今度はキャラクター間連鎖が増えない。
- 一戦先だけを見て戦略を立てるより、見えた数字を先に削る操作にプレイヤーの思考が吸い寄せられかねない。先見という設定の使い道があることと、「寝る前に考えたくなる」ことは違う。

人間が触る三枠試作ではBだけを置き換え、実際にこの先行撃破を見られるようにした。実験の焦点は**前線の危険を承知で未来を傷つけるとき、プレイヤーが理由を話せるか、あとから喜べるか**。作者が対戦録を読めることを証拠にしない。もし前衛への干渉と直後の回収を一つの事件として見せられないなら、中核へ昇格させない。
