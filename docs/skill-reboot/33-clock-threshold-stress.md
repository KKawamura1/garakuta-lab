# 五拍時計を守らないための閾値試験

更新: 2026-09-29。状態: **五拍案は保留。数値調整に進まない。** [30](./30-five-beat-clock.md)の十枚と敵HP・敵攻撃・12波をそのままにして、敵が動くまでの拍数だけを変えた。[再現用Python](../../analysis/skill-reboot-five-beat-tempo-stress.py)。120通りの五人順×32通りのA/Bを全列挙。技能は全て最初から有効、予約成長・人間の理解・iPhoneでの読みやすさは測っていない。

| 時計の取り方 | 全3,840構成の12波突破 | 備考 |
|---|---:|---|
| 全波5拍、元案 | 3,371 | 30・31と同じ基準 |
| 全波4拍 | 1,463 | ゴウ大槌あり969、なし494。ゲンゾウ開戦の矢あり1,194、写し弩269 |
| 全波3拍 | 0 | 技能の組合せ以前に敵が早すぎる |
| 小型4・首領7・縫い手5拍 | 3,836 | ほぼ選ぶ必要がない |
| 小型5・首領7・縫い手6拍 | 3,840 | 全構成成功 |
| 小型4・首領3・縫い手5拍の厳しい例 | 6 | ほぼ一つの構成だけになる |

これはゲームの適切な勝率を示さない。固定の敵列とHPを用いた粗い機械検算にすぎず、上の変化は難度の変更も含む。**それでも、少し異なる時計を敵に持たせれば一択が緩和されるはずという救済案は、現試作を頑丈にはしなかった。** 速い敵へ「0拍を選べ」が事実上の指定になり、遅い敵は選択を要しなくなる。特定の時計に数値を合わせて成功率を50%へ戻す行為だけでは、ユーザーが嫌う着替えの問題を解決できない。

比較として、全技能の拍差を無視し、五人の行動五回で敵が一度行動する場合も試した。[粗い対照Python](../../analysis/skill-reboot-fixed-round-control.py)。「波を倒しても行動時計を戻さない」なら1,797構成が勝ち、「波で時計を戻す」なら3,033構成、「新波がその巡で攻撃しない」なら2,277構成。この数字で固定五人巡を採用することはできない。元の十枚は0/1/2拍の交換条件に依存するので、拍を無視すると**別の技能セット**として不公正に比較している。固定巡に戻すなら、技能とその選択を作り直す。

## なぜ今の五拍案を棚上げするか

「早い技は一拍得する」という局所の快感は明確だった。しかし十二波の成否が敵時計の小変更に大きく反応するなら、敵に性格を付ける手段を時計の速さへ寄せられない。しかも二拍の技がその技で波を全滅させると、拍は次波で0へ消える。大ダメージで倒せるときだけ重さの負担が消えるため、既に強い攻撃がますます得をする。前に試した「余り拍を持ち越す」修正も[32](./32-time-carry-rejected.md)の通り、ほぼ全構成成功へ寄せた。

次の設計では、十二波の連破と固定の五人順を残し、**敵時計以外の一つの因果**からコンボを生む。撃破を次の波の入り口へつなぐことが候補。ただし「先頭を殴る」「大ダメージにする」だけが最適なら、ここも棄却する。

## 数え間違えないための限定

- 3,840は「順番×二択」であり、五つの技能解禁順（別の120通り）は含まない。
- 敵配置は一列、ナギを優先して殴る単純なAI。敵ごとの部位・位置・予兆は未実装。
- 「突破数の差」は面白さ、読みやすさ、多様な正解、悔しい負けの説明可能性の証拠ではない。
- 固定巡との比較は傾向を見る対照だけ。十技能を固定巡向けに再設計した候補が必要。
