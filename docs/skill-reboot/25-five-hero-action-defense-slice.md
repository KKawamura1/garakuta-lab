# 予見する護送隊: 六波の縦切りと反証

更新: 2026-09-28。状態: **未実装の紙上・最小動作試作計画**。[24の方向転換](./24-card-grammar-and-action-defense.md)を読む。現行ゲームの置換は未決定。十二波・十技能への拡張や既存のStage移植は、この試験を通ってから。

## 1. 最小のプレイ場面

画面は縦向きiPhone（まず390×844を確認）。五人全員の小隊が自動攻撃し、プレイヤーは一指で隊の進行方向を曲げる。止めて考えられる。六つの短い敵波を連続して遊び、合計三〜四分を仮の上限にする。波の間に買物画面は挟まない。敵を倒すか通過をしのいで灰火を守る。漏れた敵は灰火のHPを削るが、特定の攻撃属性がないと無敵の敵は作らない。

最初は五人の基本動作だけ。ツグミは射撃と治療、ヒバナは走って引き、ゲンゾウは敵の進路を待って撃つ。出発前に[24の各人二候補](./24-card-grammar-and-action-defense.md)から改造を選び、解禁順を予約する。試作では第2、4、5波の後に一人ずつ開き、第6波の反復敵へ三つの改造が同時に働く。残り二人の改造は長編で試す候補。いつでも一時停止して次の予約を見られるが、完了した改造を付け替える作業はない。

敵は遅くまとまる群れ、狙いをつけて弾を撃つ遠隔二体、横から速く走る小型、最後に複合の少し硬い敵を含める。第1波と第6波に同型の群れを置き、第6波では数とHPを上げる。全員に同じ開始配置・敵出現列を使う。別の属性を持つ技能を要求する敵は出さない。

## 2. 実際の因果を二系統作る

**火床の道:** 出発前にゴウの衝突押し出し、ヒバナの「味方弾が火床を通ると着弾点にも火床」、ゲンゾウの命中押し出しを予約する。基本状態でもヒバナが引いて火床を残し、ゴウは敵をその火床へ押せる。改造が進むとゲンゾウの弾が火床を横切って別の床を作り、押した敵がその床へ入る。プレイヤーは小隊を火床と敵のあいだへ導いて射線を作る。「ヒバナの技がゲンゾウ専用」ではなく、ナギが弾を返す別構成でも同じ床を作れる。

**反射と射線:** ゴウの衝突押し出し、ナギの敵弾反射、ゲンゾウの貫通を予約する。敵を押して一列にまとめ、遠隔の敵弾を小隊の盾で返し、通常弾と反射弾が列を通る。ヒバナの基本火床は助けになるが、改造Aがなくても列で越えられなければ失敗。敵弾が来ない波でもゴウとゲンゾウの基本射線が残るので、ナギの改造が完全な死に札になるかどうかを測る。

どちらも人物の固有動作から出発する。ツグミの射撃と手当てが両方見え、ヒバナの走る姿が火床の絵に埋もれず、ゲンゾウの遅い一発に判断の意味がなければ、人名だけ借りた別チームなので却下する。

両方とも技能一枚を足すだけで必ず勝つという脚本ではない。小隊の位置、敵の間隔、撃つまでの時間によって「床ができたが敵が通らない」「反射したが敵列を外れた」が起こる。失敗から次の操作または取得順へ戻れることが肝心。カード文に「ゴウとヒバナのとき」と書かなければ成立しないなら技能の組立に失敗している。

## 3. 未来視の契約

- 波の前に次の敵の出現位置と進路を短く示す。移動中は**数秒先に敵が妨害されなかった場合の位置**を薄い残像で示す。予告できるのは敵の予定行動まで。自分が弾を当て、押し、進路を変えれば残像との差が生まれる。
- 予告表示には最終勝敗、灰火の残HP、完成したコンボの発火回数を一括表示しない。プレイヤー入力が未来を変える以上、正確な最終結果として表示できない。ゲーム内では「敵の予定進路」と明記する。
- 予告を見て動き方を考えたい時と、目の前に集中したい時の両方を許す。一時停止・低速再生を設け、視線移動が邪魔なら波の前だけの表示へ縮める。反射神経の課題にして就寝前の思考を追い出さない。

## 4. 実装の小さな契約

五人の基本動作、敵三種、火床、弾、防壁、HP、押し出しだけを別の小さな実験画面に置く。RP、AP、対象優先列、190節の移行は先に行わない。位置・弾・火床の衝突を画面で見せる。敵を多く出して派手さで隠さない。

- 改造は一人物につき一つ。同じ改造で一発の弾を何度も変換しない。弾は壁・敵・寿命で消える。火床は時間で消える。反射弾をもう一度反射しない。敵や味方を新しく生成する技能は最初の十枚に入れない。
- 五人のうち誰の弾・火床・盾かを確認できる色と短い戦歴を持つ。ただし見た目に十の色や長い文字列を足さず、停止中に一つの弾を触って「ナギの反射→ヒバナの火床→着弾点の床」を追えるか試す。
- まず六波の動作と因果だけ作る。高品質な演出、長い物語、Stage保存移行、大量の技能設計をしない。縦切りで好きになれた時に初めて本編の資産移植を議論する。

## 5. 比較して「好き」の場所を見つける

| 比較 | 変えること | 確かめること |
|---|---|---|
| C0 一指と基本五人 | 五人の基本動作だけ。未来視あり | 動かすだけでも楽しいか。誰の行動か分かるか |
| C1 数値改造 | 同じ取得時点にHP・攻撃などを増やす | 単なる成長だけで喜べるか |
| C2 物体を変える改造 | C1とおおむね同じ生存難度を狙い、24の連鎖技能を開く | 火床型・反射型が新しい動きとして面白いか。予想外の接続が起きるか |
| C3 経路を描く | C2と同じ移動速度・改造で、出発前に小隊の大まかな経路を一筆で描き、自動追従させる。出発後は停止・見直しだけ | 実時間の一指操作が核か、先に経路まで仕込んで動く姿を見る方が楽しいか |

勝率の厳密な一致は無理なので、「C2の方が単に強かった」場合は好きな理由を結論にしない。数人の初見・再プレイを分け、同じ敵列でも条件順を変える。現行のターン制十二戦と直接の勝率比較はしない。**作りたい次の技能を本人が思い付くか**は、夜の構築欲の近い手掛かりになる。

## 6. 失敗を先に決める

1. **技能より操舵だけが楽しい。** C0とC2で次の改造を考える意欲が変わらず、見返すのは敵を避けた場面だけ。ゲームは普通のアクションとしては良いかもしれないが、求める構築ゲームにはなっていない。
2. **操舵は面倒。** C3の経路予約がC2より楽しく、改造の考察も続くなら、アクション操舵を削って**経路を作る自動防衛**へ絞る。どちらも退屈ならカード手札案Bへ進む。
3. **火床一択。** 反射・射線の予約順が成立せず、ヒバナの改造Aを取らないと進めない。連鎖を増やしたのではなく装備検査を作った。
4. **視認できない。** 二段の因果を停止中に指差せず、iPhone表示で「なんか燃えた」になる。見た目だけ強調して誤魔化さず、弾数・発火密度・同時装備を削る。
5. **未来視が役に立たない。** 予告を見ても動き方や予約へ反映せず、単に薄い背景が増える。予告する時間・内容または未来視を中心に据える判断を撤回する。
6. **寝る前に考えない。** 一回遊んだ後、次の取得順・二通りの構成を頭の中で試したくならず、翌回に操作の腕だけ磨く。残すべき条件を満たしていない。
7. **開通が遅い。** 三つの改造がそろう前が単調で、六波の大半を飛ばしたい。取得間隔を先に直し、それでも退屈なら連続波の長さを削る。
8. **人物が消える。** 火床を置くだけのヒバナ、治療だけのツグミ、間隔射撃するだけのゲンゾウとして記憶される。技の組合せが面白くても五人の人格を残せなければ、この配役を捨てる。
9. **小試作で作れない。** 弾・火床・押し出しを正しく動かすために既存の190節や全Stageを先に移行する必要が出る。独立した縦切りとして切り出せないなら、制作上の賭けが大きすぎる。

C1/C2の差、C2/C3の差、火を使わない構成、未来視の利用がそろって初めて長編を考える。両方の移動方式で改造が面白くない場合は「もう少しカード数を増やす」で埋めない。[24](./24-card-grammar-and-action-defense.md)のB（毎戦三枚から一枚選ぶ小さなカード手札）を独立に紙上試作し、12回の小さい判断が本当に重いか調べる。
