# 本命候補を更新: 「五拍先までに倒せ」

更新: 2026-09-28。状態: **独立した2〜4分試作の候補。未採用・本編未実装。** [一画面HTML試作](./five-beat-prototype.html)で十枚・全12波を動かせる。 [29の一巡ごとに反撃する案](./29-unbroken-expedition.md)は小試算で攻撃一辺倒になったため、その敵行動時計を捨てる。[31の数字と批判](./31-five-beat-adversarial-audit.md)も併読。現行のゲーム仕様と190技能はまだ変更しない。

## このゲームの一文

**五人の行動を一列に並べ、敵が攻撃するまでの五拍へ何手ねじ込むかを仕込む。敵を倒すと次の波が即座に入り、敵の時計は五拍から始まる。十二波を一つの連鎖で踏破する。**

「五拍」は世界共通の一つの数字。早い技は0拍、普通は1拍、重い技は2拍。技の攻撃・手当てを解決してからその拍を加算し、合計5拍になった時点で生存敵が一度ずつ動く。その技で敵が全滅したなら敵の行動は起こらず、新しい波の時計は0。五人は円状の決まった順序で行動し続ける。敵の波が変わっても**次に動く人物へ指針が戻らない**。

楽しさの単位は「ヒバナが一拍を浮かせたので、ゴウの重い一撃とゲンゾウの写しが敵の攻撃より先に間に合う」こと。二人が強くなっただけでなく、五人の順番・攻撃の威力・敵の時計が噛み合った結果を一本の軌跡で見る。敵を倒した直後に次波が入るため、勝利が一つの画面で続いていく。

## 操作と勝敗を先に固定する

出発前に五人の順番、各人A/Bの主行動、五つの解禁順を決める。一つは出発時に有効、残りは第2・4・6・8波を越えた直後に予約どおりに基礎行動を**置き換える**。技能は一人一つだけ。いつも使える別のAP技を併存させず、同時に読ませる特殊規則は最大五つ。第4・8波で希望者だけ停止して、未解禁の予約と順番を変えてよい。強い構成なら出発後は一度も画面を開かない。

| もの | 契約 |
|---|---|
| 遠征 | 十二の波が一画面で順に来る。波は最大三体。波全滅時、次の波が直ちに現れる。十二波全滅で勝利、五人全滅で敗北。次へボタン・各波の勝利精算はない |
| 五人 | それぞれHP。出発時の固定順で、一人ずつ一行動。倒れた人の席は空手番として通過し、時計は普通の1拍進む。追加ヒットは元の行動内で処理し、もう一席を作らない |
| 敵時計 | 波が入ると0/5。その波へ**次の席から**味方の行動コスト0/1/2を足す。5以上になった行動のあとに敵が生きていれば全員が左から行動し、時計から5を引く。全滅なら新波へ0/5。持ち越した余りコストは、新波へ課さない |
| 持越し | 味方のHPと防壁、五人順は波を越える。防壁は人物ごと上限3。敵HPは波ごと。第4・8波の後、倒れた味方はHP2で復帰し、他は欠損HPの半分を回復。止まらず進む |
| 敵行動 | 既定の敵はHPを削る。単体の狙いはナギ→ゴウ→ヒバナ→ゲンゾウ→ツグミの固定順。後衛の縫い手だけ、敵行動時に先頭のHPを上限まで2回復する。敵の反撃予定と残り拍は常時表示 |
| 先見機 | **次の一波の敵のHP・攻撃／治療内容と現在の時計**を見せる。敵も味方も含めた最終勝敗を仮実行して表示しない。現在の戦闘は一手送り・停止・早送りできる。未来視を結果検索へ使えない |

敵は味方の各手の間には割り込まず、五拍の満了時だけ動く。味方が先に五手を続けられるのは**全員が1拍のときだけ**。味方の順番自体はいつも同じなので、「五人がこう繋がる」という予約時の想像を保てる。二拍の強打を使えば敵が途中で動く可能性も、自分で選んだ分として時計に明示される。

初期の小画面は中央に現在の敵と「敵まで●●●○○」の五つの拍、下に五人の輪と次の手番の強調、端に次波の小さい予告だけ。状態が10個並ぶ盤面へ戻さない。HP・防壁・時計以外に共通状態は足さない。コピー元の一撃と「この波でまだ撃っていない」は技能固有の内部記録として、発火時だけ矢印で見せる。

## 十の主行動。数値は検査用

未解禁時は、ナギ「防壁1/1拍」、ヒバナ「先頭へ1/1拍」、ツグミ「先頭へ2＋傷の深い味方へHP1/1拍」、ゴウ「先頭へ3/1拍」、ゲンゾウ「先頭へ1/1拍」。人物は離脱しない。解禁したA/Bでその人の基礎行動を置き換える。未解禁なら旧行動が動くので予約中も空席にならない。犠牲を伴う置換はカードに表示し、取得したら無条件に得になると装わない。

| 人物 | A | B |
|---|---|---|
| ナギ | **駆け込む盾**: 自分へ防壁1、攻撃せず**0拍** | **返す盾**: 自分へ防壁2、1拍。次に敵の攻撃で自分の防壁が削れたら、防いだ量をその敵へ返す。敵の一回の行動段階につき一度 |
| ヒバナ | **早足**: 先頭へ1、**0拍** | **裏取り**: 最後尾へ5、2拍。一体ならその一体へ5。先頭を無視して射手を狙えるが時計を進める |
| ツグミ | **狙撃と手当て**: 先頭へ2、傷の深い味方へ実HP1回復、1拍 | **集中治療**: 先頭へ1、傷の深い味方へ実HP3回復、1拍。回復対象がいなくても行動する |
| ゴウ | **大槌**: 先頭へ7、2拍。大きな一発だが時計が進む | **なぎ倒し**: 先頭へ3、1拍。その敵を倒したら、余りのダメージに3を加えて次の敵へ一度だけ当てる。次の波にも届く。二体目からは再発動しない |
| ゲンゾウ | **写し弩**: 直前に実行された味方の一撃の表示ダメージを先頭へ一度撃つ、2拍。元の技の追加効果を写さない。コピー元がなければ1 | **開戦の矢**: 自分がこの波でまだ撃っていなければ先頭へ3、そうでなければ1。どちらも1拍 |

「実HP回復」「余り」「表示ダメージ」は共通の数値で、新しい状態アイコンではない。ゲンゾウは誰かの効果全文をコピーしない。ヒバナの速い1は他の大技を時計内へ押し込むために存在し、ゴウの大きい7はその時間を使う。ナギが時計を節約して守るか、盾を厚くして返すかには実際の敵の反撃が必要。最初の試作で十枚に役割が生まれなければ、節を増やさない。

## 五人を数字にしないための演出契約

- **ゴウ:** 前に出る強打が画面を揺らし、2拍が一度に埋まる。ナギが倒れた後は敵の固定狙いの二番目を自分が引き受ける。腕力と責任が同じ出来事になる。
- **ヒバナ:** Aは攻撃の直後に時計が動かない。Bの「裏取り」は戦闘位置を恒久的に移す技ではなく、その一撃だけ最後尾を狙って元の隊へ戻る。移動先を放置して敵を漏らす操作はない。
- **ナギ:** 最初に狙われる人物。盾で防いだ値と、返した値を同じ敵弾の往復として描く。自分が複数人の射線を魔法で覆うようには見せない。
- **ツグミ:** 狙った敵への射撃と、実際に減っていたHPの治療を一つの手番内で別々に表示する。無傷時は空の回復演出を飛ばす。
- **ゲンゾウ:** コピーしたのは直前の**数字**だけだと、元の一撃と写した一撃を一本の細い線でつなぐ。元技の連鎖まで複製したように見せない。

この人物演出は本編の台詞・立ち絵を移植したという主張ではない。[HTML試作](./five-beat-prototype.html)は名前と短いログのみで、人物の魅力までテストできない。

## 手で追える一場面

順は**ヒバナA→ナギA→ツグミA→ゴウA→ゲンゾウA**。HP12の単体敵、時計0/5。ヒバナは1ダメージで0拍。ナギは防壁1を張って0拍。ツグミは2ダメージで1拍。ゴウの7ダメージで合計10、時計は3/5。ゲンゾウがゴウの表示7を写して敵を倒す。合計5拍に到達したが敵はもういないので反撃は起きない。**ヒバナとナギが一拍ずつ節約していなければ、ゴウの行動時に5拍となり、HP2の敵がゲンゾウより先に反撃する。**

現実の十二波では、倒した瞬間に次波が入り、ゲンゾウの席の次が誰かも持ち越す。敵が弱ければ五拍に届く前に二、三波へ飛び込み、強い首領では盾と治療を使って何度も時計を越える。一つの筋が**速い雑兵処理**にも**遅いボス戦**にも通るかが設計上の賭け。

## 踏み外しやすい点

- **バトルの手触りが時計の算数になる。** 五拍の差を絵と音で理解できず、数字を暗算するだけなら失敗。技の後、敵が動くまでの残りの席をプレビューとして太く見せるが、結果の予言は出さない。
- **0拍を集める一択。** 0拍のヒバナとナギがいつも最善なら十枚の選択は偽。2拍の大槌や写し弩がボスで意味を持ち、1拍の反射盾が被弾を攻撃へ変えるかを試す。
- **五拍目に倒すのが唯一の答え。** HPを細かく調整して5未満へ納めるパズルばかりなら、アクションの爆発ではなく算数。勝てる経路を一つにしない。
- **後半の敵が耐久壁になる。** 守りを使わせるためだけにHPを盛ると、早い連破がそこで止まり、以前の一巡案より長く退屈になる。
- **五人の選択が重い。** 順番120通り・二択32通り・解禁順120通りで、全部を頭で評価できない。合理的なプレイヤーが最初から攻略表を探すなら、順番を五人の輪の隣接関係だけへ絞るか、予約順を固定する。勝敗Oracleで緑探しを復活させない。

この案に面白さを見いだす理由は「十個の技能名」そのものではなく、**攻撃時計が敵の行動だけを決め、撃破によって時計がリセットされ、味方の行動順がリセットされない**という三規則が、波をまたぐ連鎖を作ること。これが実際に楽しいかは[31](./31-five-beat-adversarial-audit.md)でまだ否定し続ける。
