# 勝敗の反転を祝いすぎない: HP境界と自動休息の反証

更新: 2026-09-29。状態: **35–37の結論を狭める監査。** [再現Python](../../analysis/skill-reboot-frontier-perturbation.py)。[37](./37-how-to-author-useful-skills.md)の「同じ敵列でゴウのA/Bを替えると勝敗が反転する」は事実だが、その一例を強いデザインの証拠として扱うのは早かった。

十枚、返り火、敵の攻撃、解禁順は37と同じ。全敵のHPを一体ずつ±1した。敵全体では二十数HPの変更になるため、全遠征としては無視できる変化ではない。

| 一体ごとのHP変更 | ヒバナB・ゲンゾウA・ツグミA・ナギA: ゴウA／B | ヒバナA・ゲンゾウB・ツグミB・ナギB: ゴウA／B |
|---|---|---|
| −1 | 突破／全滅 | 突破／全滅 |
| 0 | 突破／全滅 | 全滅／突破 |
| ＋1 | 全滅／突破 | 全滅／全滅 |

第二の「他四人を変えるとBだけが勝つ」例は、全敵HP−1で**Aだけが勝つ**へ逆転した。第一の「Aだけが勝つ」例も、HP＋1で**Bだけが勝つ**へ逆転した。つまり37の具体的な二場面を、数字が前後しても同じ答えになる堅牢な証拠とは呼べない。

同じ複合敵列で、三つの区間内の通常隊の順を変えた216経路×解禁順2通りを試すと、安全と呼んだヒバナA・ゴウA・ゲンゾウA・ツグミB・ナギAの成功数は、HP−1で422/432、基準で418/432、HP＋1で376/432。最初の固定敵列ではこの構成が120/120解禁順で勝ったが、**万能という語は不正確**。とはいえ各条件で大半を通るため、同じ構成を使い続ける問題はまだ大きい。

最後に第4・8隊の自動休息を止めた。同じ複合敵列HP1.2倍、解禁順120×A/B32で勝利は**1,706/3,840 → 253/3,840**、上の安全構成は**120/120 → 61/120**。十二隊を止まらず突破する設計は、この自動回復にかなり依存している。休息を入れるかどうかは演出上の細事ではなく、敵の標的や治療技能を評価する土台。

## 判断をどう変えるか

37の「同一敵列での反転」は、Bを選ぶ理由が**原理的に存在し得る**という低い関門に留める。技能が面白いかの本当の関門は、プレイヤーが「三射で削ったので貫通の余りが次へ届く」「今回は実際に防いだので次の矢が太くなる」を、HPを一つずつ暗算せず**画面から言える**こと。その見え方と選びたさは小試算では未検証。数値を動かして勝敗の両方向の件数をそろえる作業を続けても、企画の核を強くしない。
