# 基礎6テーマ・36技能カタログ v3

Stage 0の2人が、各人13SP以内（根Lv1を1つだけ無償選択）で、戦6までに5SP程度の核を作れる最小版。A/R/Pは表示ラベルをそのまま使い、同名のhit数違いは置かない。

## 設計契約

|項目|定義|
|---|---|
|A|アクティブ。手番に資源を払い1回行動。盤面条件がなければfallback。|
|R|リアクティブ。明示イベント直後にRP・上限を再確認して反応。R由来の同R再発火なし。|
|P|パッシブ。対象選択・計算・精算規則だけを変更。行動枠や反応候補は増やさない。|
|SP|A/R/PすべてLv1・各rank+1SP。Pのみ一律2SPにはしない。Stage0 rootから各人1技能Lv1だけ無償。|
|新状態|毒（round-end削り）、裂傷（次の直接攻撃で割れる）。隙/鈍り/構え/守勢/集中/防壁と役割を分ける。|
|無限防止|Rはchain/round/battle上限、追撃1件、同一R再読禁止。AP/RP交換は総量不変。|

### 共有状態

- **隙**: 対象の次の味方直接攻撃1回が防御1単位を無視し、その開始時に消える。
- **裂傷**: 対象が次に直接ダメージを受けた時に固定追加ダメージを1回与え、1段減る。最大3。round-endには発火しない。
- **毒**: round-endに最大HPの2%を1段ごとに受ける。最大3。医術で除去できる。
- **鈍り**: 敵の次の準備進行を1段減らす。準備がなければ次の直接攻撃を10%下げて消える。
- **構え**: 次の1hitのダメージを0にする。多段はhitごとに消費され、最大2。
- **守勢**: 次の1攻撃から固定値を軽減して1段消える。最大2。
- **集中**: 次に所有者が行うAの効果量を15%増し、A解決時に1消費。Rの反応を増やさない。
- **防壁**: 残量までダメージを受ける共有シールド。防壁0になった時だけbarrier_brokenイベント。

### 共有イベント

`target_selected`, `action_declared`, `prepare_started`, `prepare_advanced`, `prepare_completed`, `damage_proposed`, `damage_taken`, `damage_blocked`, `barrier_broken`, `guard_consumed`, `effective_heal`, `status_applied`, `actor_moved`, `actor_defeated`, `overkill`, `action_resolved`, `round_end`

## Stage0の3ビルド

各人のfree seedはroot Lv1のみ。以下の「戦6核」は各人5SPで成立し、残りを13SPまで深掘り・横断へ回せる。

### 断ちと急場

- free seed: A=break_open Lv1 / B=guard_cover Lv1
- 戦6核（各5SP）: A=`break_open Lv2`, `break_wedge Lv1`, `break_fracture Lv1`, `guard_brace Lv1` / B=`guard_brace Lv1`, `med_firstaid Lv1`, `med_remedy Lv1`, `command_delay Lv1`
- 13SPまで: A=`break_open Lv3`, `break_wedge Lv3`, `break_fracture Lv3`, `guard_brace Lv2`, `guard_cover Lv1`, `command_signal Lv1`, `move_step Lv1` / B=`guard_cover Lv3`, `guard_brace Lv3`, `med_firstaid Lv3`, `med_remedy Lv2`, `command_delay Lv2`, `move_step Lv1`
- 使い方: Aが防御を剥がし、Bが対象選択と実損回復を受け持つ。破砕根を医術根へ入れ替えてもイベントが成立する。

### 裂傷をつないで仕留める

- free seed: A=combo_link Lv1 / B=med_firstaid Lv1
- 戦6核（各5SP）: A=`combo_link Lv2`, `combo_bleed Lv1`, `combo_turn Lv1`, `break_fracture Lv1` / B=`med_firstaid Lv2`, `med_remedy Lv1`, `med_triage Lv1`, `guard_cover Lv1`
- 13SPまで: A=`combo_link Lv3`, `combo_bleed Lv3`, `combo_turn Lv3`, `break_fracture Lv3`, `command_signal Lv1`, `move_flank Lv1` / B=`med_firstaid Lv3`, `med_remedy Lv3`, `med_triage Lv3`, `guard_cover Lv2`, `command_delay Lv1`, `move_step Lv1`
- 使い方: Aの裂傷をBの回復・守勢が支え、敵が単体/準備/多段で変わっても仕留め条件が変わる。追い手はStage1で後付けできる。

### 遊撃と拍

- free seed: A=move_step Lv1 / B=command_signal Lv1
- 戦6核（各5SP）: A=`move_step Lv2`, `move_flank Lv1`, `move_screen Lv1`, `combo_link Lv1` / B=`command_signal Lv2`, `command_delay Lv1`, `command_reserve Lv1`, `med_remedy Lv1`
- 13SPまで: A=`move_step Lv3`, `move_flank Lv3`, `move_screen Lv3`, `command_signal Lv2`, `command_reserve Lv1`, `combo_link Lv1`, `break_fracture Lv1` / B=`command_signal Lv3`, `command_delay Lv3`, `command_reserve Lv3`, `guard_brace Lv2`, `med_remedy Lv1`, `med_firstaid Lv1`
- 使い方: Aが列と対象を変え、BがAPの総量を増やさず未行動者を先にする。盾敵がいない戦闘でも横槍・合図・通常攻撃が残る。

## Stage1以降の横断節

- **Stage1 `防いだ一撃を開口へ`**: `damage_blocked, barrier_broken, guard_consumed` — 護衛の受け返し/破砕の砕け目/連撃の裂傷拾いが同じイベントを読む。技能ID同士を前提にしない。
- **Stage1 `被弾前後を分ける`**: `damage_proposed, damage_taken, effective_heal` — 護衛はdamage_proposedで受け替え、医術はdamage_taken/effective_healで回復する。最後の盾と命綱は同時に同じ救命処理をしない。
- **Stage2 `移動から裂傷/隙へ`**: `actor_moved, target_selected` — 遊撃が敵を動かす、連撃/破砕が共有状態を読む。敵を盾持ちに限定しない。
- **Stage2 `準備から順番へ`**: `prepare_started, prepare_advanced, action_declared, action_resolved` — 指揮は早駆け/差し止め、破砕は楔打ち、遊撃は横槍で同じ予兆を別の出口へ送る。
- **Stage2 `毒と裂傷の使い分け`**: `status_applied, round_end, damage_taken` — 裂傷は次の直接攻撃で割れ、毒はround-endに削る。医術の解毒/応急処置は過剰回復を資源化しない。
- **Stage3 `三人目の拍`**: `action_resolved, resource_refreshed, round_end` — 拍渡しは未行動者の順番だけを変え、AP/RP/行動回数を増やさない。

## 合法性・自動優先順

- 各人はStage0 rootから1つのLv1だけを無償選択し、同じrootを後から買い直さない。
- 各buildの戦6核は1人5SP以内、最終前は1人13SP以内。Stage0の6テーマ入口から自由に入れ替え可能。
- Aの条件不成立は通常攻撃/安全支援へfallback、RはRP不足なら不発で元eventを壊さず、Pは追加行動を作らない。
- Rはイベント1件あたり所有者1回・chain/round/battle上限を持ち、R由来の攻撃は同じRを再読しない。
- 医術はcurrent HPのmissingだけを回復し、overheal・過去被弾・古傷・自傷をSP/AP/RPへ変換しない。
- 最後の盾は事前redirect＋構え消費、命綱は事後HP1＋状態除去であり、同じ致死eventに両方の救命処理を重ねない。
- 対象同率は前列/後列、位置、安定ID。乱数や特定人物/特定技能ID必須条件は使わない。

- **A**: 同一所有者内は(1)自分/味方が次の一撃で倒れる危険、(2)準備中の敵を止める、(3)仕留め条件、(4)状態を作る/割る、(5)位置・順番、(6)通常行動。数値priorityがある場合は小さい順、同率はloadout順。
- **R**: イベント時に(1)最後の盾など事前致死救済、(2)退路/かばい立ちなど被害形状、(3)命綱など事後救済、(4)解毒/応急、(5)準備妨害、(6)防御破壊/状態、(7)追撃/拍渡しの順で候補を比較する。候補はRP・limit・predicateを直前再確認し、同一eventのreaction budgetは2件、無料追撃は1件まで。
- **P**: 発火順を持たず、対象選択→計算→精算の順に規則へ適用する。PでA/R候補を増やさない。
- **globalLimits**: 一chain256 event、battle4096 eventを上限とし、同一skill/ownerはchain1回。反応が同じeventを再発火条件にしない。

## 監査メモへの対応

- 3hit→4hit→5hitを別技能にせず、`連ね`は裂傷を作る/割る一手、`追い手`は裂傷イベントへの一回追撃、`仕留め`は状態消費の終点に分離した。
- Lv3でも対象選択・状態消費・準備進行・対象数・発動範囲のいずれかが変わる。数字だけの空ランクを置かない。
- `最後の盾`は構えを消費する事前redirect、`命綱`はHP0後の事後HP1復帰＋状態除去。片方の名前を変えただけの同効果にはしない。
- 破砕の入口は防壁敵限定ではなく、非防御なら裂傷、条件不成立なら通常打撃へ戻る。
- P表示は「パッシブ」とし、Pは対象選択/計算/精算のみ。反応イベントを読む技能はRに分類した。
