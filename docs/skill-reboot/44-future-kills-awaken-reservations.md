# 先見で討伐すると、予約技能がその巡に目覚めるか

更新: 2026-09-29。状態: **次に人が触って批評する未採用候補。** [比較できるブラウザ試作](./frontier-prototype.html)、[再現コード](../../analysis/skill-reboot-fire-routing-and-stolen-attacks.py)。[41の予射](./41-foresight-as-target-not-oracle.md)は手負いを最後尾へ送るだけで、五人の即時連鎖が弱かった。予射で敵を倒した成果を、待機列の短縮だけではなく**取得予約の発火**へつなぐ。

## 一つの解禁規則を差し替える

最初の一人は出発時にA/Bが有効。残り四人のA/Bは順に予約される。従来は第2・4・6・8隊の最後の敵を倒した時に次の一人を解禁した。比較案では**討伐総数3・6・11・14体に達したその瞬間**に次の一人を解禁する。先見に見える待機中の敵をヒバナBで倒しても一体と数える。現在の前線の敵を倒す場合にも同じ一体を数える。出発時の三枠はH→G→Z→T→Nで一巡し、勝利は全敵消滅、敗北は五人全滅。第4/8隊の自動休息だけは前線の隊突破で行う。

この23体の固定敵列を**通常順に前から倒すだけなら**、3・6・11・14体はほぼ第2・4・6・8隊の突破と一致する。予射が先の敵を倒すと討伐数が先行し、前線がまだ残るうちに予約技能が使える。閾値そのものが答えを作るための特別な敵ギミックではなく、既存のSP獲得を討伐単位へ動かした比較である。ブラウザ画面ではチェックを外せば従来の隊突破式と同じ五人・同じ敵列を試せる。

## 具体的な連鎖と、期待の訂正

固定経路、ヒバナ→ゴウ→ゲンゾウ→ツグミ→ナギをその順で解禁し、枝を**B・A・B・A・B**に予約する。敵HP1.2倍、先見の予射4、返り火最大4。

1. 初巡、ヒバナBは先見の第3隊HP5を4削る。ゴウの基礎5は今の先頭を倒し、手負いHP1が前線の後ろへ入る。古参からの反撃でナギが実防御し、返り火が生まれる。
2. 次巡、ヒバナの予射4+返り火1が次に見えた第3隊の敵HP5を先に倒す。これで先見側の討伐も数え、隊突破前に討伐が進む。ゴウの**基礎行動中**に総討伐3へ達し、ゴウAが解禁する。ここは重要で、ゴウはこの巡に既に基礎行動を始めているので、解禁した大槌8は**次巡から**。ヒバナが直接ゴウの即時大槌を撃たせるわけではない。
3. 第3巡、ヒバナがさらに先の敵を倒し、ゴウの攻撃が今いる敵を倒すと総討伐6、ゲンゾウBが解禁。**ゲンゾウはまだ動いていないので、この巡から三連弩2×3になる。** 先の敵の早期討伐が現在の後続人物の動きへ届いた最初の具体例。
4. 隊突破式ならこの同じ枝は通常行動85、敵の攻撃26回で全滅する。討伐式なら**通常行動74、敵の攻撃19回、先行撃破4、五人中の生存者ありで第12隊を突破**する。ただし同じ経路・他四人の枝でヒバナAにした構成も、通常行動71、敵の攻撃15回、残HP27で勝つ。Bが最善になった証拠ではない。

## 期待できるものと、まだ大きい欠陥

- 「先の敵を倒す→予約していた仲間の技が目覚める→現在の敵へその技が飛ぶ」が**たまたま緑になった理由**でなく、プレイヤーが追える出来事になり得る。先見を一戦先の覗き穴から一つの攻撃対象にし、SP予約と接続する。毎戦のメニューは要求しない。
- 技能を取る時の楽しさが、「新しい数値」よりも「解禁を早める別の狩り方」に広がる。ただし現時点で予射できるのはヒバナだけ。他四人はより速いSP獲得の受け手であって、共同で先の敵を倒していない。
- **討伐閾値は視覚上の新しい時計。** 3/6/11/14を暗記させたら失敗。画面には討伐数と次に目覚める一人を見せ、その人物が動く直前に解禁したときだけ強調する。現行試作はログ文と数字までで、十分な演出ではない。
- 予射Bは数巡後の前線を弱くするが、現在の敵を残す。HPや被弾が深刻なとき、未来へ逃げる構成は単に自殺になる。これが意図した危険として感じられるか、硬い敵と脆い敵の特定順で持ち物検査にならないかを人間が判断する必要がある。
- SPを討伐に付けると、敵を倒すほど技能でさらに敵を倒す**正帰還**が生まれる。強い型の放置がもっと簡単になりかねない。高速化が一つのカタルシスでも、複数周回で考える理由が消えるなら棄却する。

この案は前の二つの棄却より、もともと残したかった**一戦先の視界・取得予約・十二隊一息**を同じ出来事へ接続できる。ただし固定枝A/B・固定敵列の試算であり、人間のワクワクを証明していない。次の関門は、ブラウザで解禁の瞬間を一巡送りで見て、その場で「なぜ今ゲンゾウが三連弩になったか」を説明できるか。そして同じ枝で二度目も出発したいか。
