# 新しい試作候補: 三枠の敵列を十二隊で補充する「押し寄せる前線」

更新: 2026-09-29。状態: **前の五拍案より先に遊んでみたい未採用候補。** 仕様・190技能・本編コードは変更しない。[五拍の弱さ](./33-clock-threshold-stress.md)と[撃破バトンの棄却](./34-kill-baton-rejected.md)を受けた別系統の設計。[再現できる粗い試算](../../analysis/skill-reboot-replenishing-frontier-toy.py)は人間の楽しさを測らない。

## 面白さの賭け

**ゴウが倒した敵の後ろへ新手が一体入り、その新手へゲンゾウの次の矢が飛ぶ。敵列が絶えず詰め寄り、五人の一巡が十二隊をまたいで一本につながる。** 強くなるほど同じ一巡で前へ進める。敵が残ったときは全員の行動が終わってから反撃し、ナギとツグミの役目が現れる。上手く仕込めば十二隊を途中で設定画面を開かずに突破する。

この案では「いつ次の敵を迎えるか」が技能の共通インターフェイス。余剰ダメージを万能に次波へ運ぶだけでは大槌一択になりやすい。撃破時の追加行動だけでは守り役が連鎖を止める。**敵の補充という盤面側の一規則**を共有し、複数ヒット、後ろ狙い、一撃、余りの貫通、治療、防壁をその場で別々に働かせる。

## 五人と敵と時間の契約

| 項目 | 初回試作で固定するルール |
|---|---|
| 五人 | ヒバナ→ゴウ→ゲンゾウ→ツグミ→ナギの順。五人全員の通常行動を解決してから、生き残った敵が前から行動。敵はその途中へ割り込まない。死者の席は飛ばす |
| 敵 | 十二の小隊を順に一列の待機列へ置く。画面には前から三体まで。出発時も先頭三体を出すため、最初の二体が第一隊なら三体目に第二隊の敵が見える |
| 補充 | 一体死ぬたび、生存敵は前へ詰め、待機列の先頭から一体だけ**一番後ろへ**入る。次の人物は現在の前列を狙う。補充された敵はその五人巡の終わりにまだ生きていても**その巡だけ行動しない**。次巡以降は行動する |
| ヒット | 一つの技が複数ヒットなら、一ヒットごとに現時点の先頭を選び直す。倒せば次のヒットが補充された新敵へ届く。一撃の余剰ダメージは通常捨てる。明記した「貫通」だけは余りを現在の先頭へ継続する |
| 生存 | 人物は個別HP、防壁。敵は既定の狙い順ナギ→ゴウ→ヒバナ→ゲンゾウ→ツグミ。全十二隊の敵が消えれば勝ち。五人が全滅した時点で負け。第4・8隊の最後の敵を倒すと、死者HP2で復帰、他の欠損HP半分を自動回復 |
| 育成 | 出発時に各人のA/B置換行動と、五人がそれを解禁する順番を予約する。最初の一人は即時、残りは第2・4・6・8隊までの敵を全滅させた時点で順に解禁。未解禁の人物は基礎行動を続ける。**停止は要求しない** |
| 先見 | 現在の三体と、待機列の次の一体／次の小隊の概要を示す。何人残るか、勝てるかを計算して一瞬で表示しない。今の巡は一手送り・一巡送り・高速再生で観察できる |

新しく入った敵の眠りは個別状態を積むためではなく、「五人目の撃破で突然補充された首領が無抵抗の味方へ即攻撃する」不条理を消す一つの入場規則。三枠は後ろほど薄い色で表示し、その巡に入った人物に輪郭を付ける。次巡には輪郭が消える。十種以上の状態アイコンを画面へ載せない。

## まず十枚。技能の作り方が試される

人物ごとに基礎行動が一つ、成長でA/Bのどちらか**一つへ置換**。ここでは0拍もRPも優先列もない。A/Bの文字は特定の敵への正解札を意味しない。HP・攻撃力は初期の試験数字。

| 人物 | 基礎行動 | A | B |
|---|---|---|---|
| ヒバナ | 先頭へ2 | **継ぎ矢**: 先頭へ1を三回。その都度先頭を選び直す | **奥射**: 最後尾へ4を一回 |
| ゴウ | 先頭へ5 | **大槌**: 先頭へ8を一回。超過は捨てる | **打ち抜き**: 先頭へ5を一回。倒したら余りをその時点の先頭へ続ける。余りが尽きるまで |
| ゲンゾウ | 先頭へ2 | **写し弩**: この五人巡で直前に味方が実行した一ヒットの**表示威力**を、先頭へ一回撃つ。元の追加効果は写さない。先行ヒットがなければ1 | **二連弩**: 先頭へ2を二回。各ヒットの前に先頭を選び直す |
| ツグミ | 先頭へ1、欠損最多の味方へ実HP1回復 | **手当て射**: 先頭へ2、実HP1回復 | **治療優先**: 先頭へ1、実HP3回復 |
| ナギ | 自分へ防壁2、上限3 | **堅守**: 自分へ防壁3 | **押し盾**: 自分へ防壁1、先頭へ2 |

「複数ヒット」「後ろ」「一撃」「余り」「写す」は、入場と補充に接する五つの異なる形。例としてヒバナAの三射は弱い敵を一射で倒した後に残りを次の相手へ向けられる。ゴウAは厚い首領へ高効率、ゴウBは瀕死の敵を過剰に叩いた余りを次へ送る。ゴウA直後ならゲンゾウAは8を撃てるが、ゴウBで余り2だけを最後に通したならゲンゾウAは5の**元の表示威力**を一度だけ撃つ。ナギBは守りを薄くして一巡の最後に止めを刺す。ツグミBはその分を治療して次巡を生き残らせる。五人の動作の間に小さな連鎖が見えるかが本題。

### 最初の一巡を実際に追う

第一隊の小敵はHP3×2、第二隊の小敵HP5。最初の三枠は **3・3・5**。全員AだがナギだけBとする。

1. ヒバナAの1×3が先頭のHP3を倒す。後ろから第三隊HP4の敵が補充され、盤面は **3・5・4**。
2. ゴウAの8が先頭HP3を倒す。余り5は捨てる。第三隊からもう一体HP4が入り、**5・4・4**。
3. ゲンゾウAが直前の「表示威力8」を写し、HP5を倒す。第四隊の首領HP20が後ろへ入り、**4・4・20**。
4. ツグミAが先頭HP4を2にし、傷ついた味方がいなければ治療は0。
5. ナギBが防壁1を張り、先頭HP2を倒す。第五隊HP3が入り、**4・20・3**。

残った三体はこの巡で入ったばかりなので反撃しない。次巡、ヒバナの1×3で先頭HP4を1にし、ゴウが仕留めて首領が前へ詰める。ゲンゾウの8は今度は首領へ刺さり、**首領が生き残れば巡の終わりに反撃する**。これが「遠征が加速するが、硬い敵では守りと治療へ接続する」の観察例。ヒバナBなら後ろのHP5を先に削り、別の到着順と被弾になる。どちらも敵固有の解除条件ではない。

## 少ない思考と寝る前の思考を両方に置く

出発の標準は「五人のA/Bを各一度選び、予約順は人物の並びのまま」。慣れた人だけ解禁順を並べ替える。波のたびに五人の装備を再設定しない。SPが入る瞬間は既に決めた置換が画面で起動し、戦闘は続く。開始時の選択が多いなら各人のAを標準の一枚として、最初の強化は一人分だけ選ぶ試作へ縮める。

敵の差は「この敵にはこの技」という解除札で作らない。自然な変化はHP、一列の人数、後ろの治療者、敵攻撃の強弱から生む。一体を素早く倒す構成と、残った三体の攻撃を受けて治しながら押す構成がどちらも十二隊を通れるか。**敵が違うだけでA/Bを入れ替えるのが最善なら失敗**とする。

## 粗い全列挙で分かったことと、分からないこと

元の敵HPを一律1.2倍した固定の十二隊で、全員最初から強化済みなら32通り中22通りが勝つ。予約解禁を入れ、五人の解禁順120×A/B32を走らせると**1,551/3,840**が勝つ。倍率1.0では3,537、1.1では2,412、1.3では743。全員解禁済みで補充だけ止めた対照では、倍率1.3でも32/32が勝ち、補充ありでは13/32だった。**補充の有無は勝敗へ効いている**が、説明できる面白さへ効くかは未検証。

三つの区間内の通常隊の順序だけを入れ替え、首領は第4・8・12隊に留めた216通りの経路をHP1.2倍で比較した。高速寄りの「BAAAB／解禁H→Z→G→N→T」は145/216、守り寄りの「AAABA／G→Z→N→T→H」は216/216、全Bは17/216。**同じ構成でも敵順で危険度が変わる一方、全経路を通す安全構成が既にある。** その構成を繰り返すだけなら失敗する。

これらは一つの敵列・単純AI・五人固定順・すべて単体HP・画面を見ないPythonの数え上げ。UI、人物への愛着、コンボの理由説明、予約時に選びたくなるかは一切測っていない。倍率で勝敗が変わるのは敵耐久の増減による当然の難度変化でもある。

## この案を壊すための次の検査

1. 人間に十枚と一巡目だけを見せ、次にどの敵が現れ、どの人物が狙うかを**説明前に当てられるか**。間違えたら三枠補充は読みにくい。先見を結果検索にして埋めない。
2. 同じ安全構成を三回続け、第二回以降も見る場面があるか。なければ「最速記録」だけを報酬にせず、敵編成と技能の受け渡しを作り直す。
3. ナギAの防壁、ツグミBの治療を外しても勝てるなら、ボスをただ硬くする前に攻撃の頻度・対象を自然に見直す。反対に両者必須なら持ち物検査なので失敗。
4. 解禁一回目の人物を変えたくなる理由があるか。120通りを選ばせて意思決定が増えるだけなら順番予約を廃止する。試算では第一解禁ナギが不利な経路もあり、平等な五択と装えない。
5. 一巡を順に再生しても「三隊を越えた」ことに感情が動かず、終盤は高速送り一択なら、補充という新ルールに見合う便益がない。**五拍案よりましというだけでは採用しない。**

暫定判断: この仕組みには、技能を個別に複雑化せずに一巡が次の小隊へ届く具体的な発火点がある。**まだゲームの面白さを証明していない。** 次は人間が触れる一画面試作と、敵の攻撃先を少し変えても「強い安全構成」だけへ収束しないかの検査が必要。
