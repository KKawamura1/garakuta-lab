# 二波の図形試作を触って、まず失敗を記録する

更新: 2026-09-29。状態: **設計者によるデスクトップ幅の初回観察のみ**。[試作を開く](./ash-march-two-wave.html)。人間のiPhone試遊でも面白さの判定でもない。[47](./47-ash-march-action-game.md)と[49](./49-future-as-accelerator.md)から最低限を実装した別エンジン。既存本編には入れていない。

## 実際に確かめたこと

Cloudflareのブランチ公開画面をブラウザで開き、予約技能ONで出発し、`先駆け ON`を押し、隊を一度だけ短くドラッグして動かした。5秒のカウントが進み、第1波の敵が残っている状態で第2波へ移った。灰火HP12→11、討伐8、さらに討伐9で画面の短い因果文に**「ヒバナ → ゴウの震脚」**が表示された。その後、**ほとんど追加操作なしで二波を突破し、討伐16・灰火HP12/12**で終わった。一体は灰火へ接触して消えたので討伐数は十七体より少ない。JSの構文も`node --check`で確認した。これは画面と内部イベントが一部つながった証拠であり、遊びとしての成功ではない。

## 見えた欠陥

1. **いまは文字を読まないと連鎖を把握しにくい。** 小敵の数字が減り、画面下に「ヒバナ→震脚」と出る。誰の一撃がどこに広がったか、戦場の絵だけでは読めない。討伐・盾・震脚の短い色つきリングを追加したが、デスクトップ幅の一回の観察では改善を確認していない。
2. **指を少し動かしただけで二波を勝った。** 第2波へ進んだ時点で灰火HP11、最終的には実回復でHP12/12。現行の敵数と火力では、移動の判断が必要だったとは言えない。立ち止まった対照試験と、技能OFF対照試験が要る。暫定的には、アクションの必要性に赤信号。
3. **五人の姿は小さな色丸と文字。** これでは人格を守れていない。五人の表情と声を足しても、行動の違いが視覚的に読めなければ機関銃五つに見える問題は残る。
4. **先駆けの因果はまだ不明。** 次波が早く来たことは見えるが、それで火種や盾の連鎖が強くなった瞬間までは確認していない。ここを実証できないなら、アクセルは危険を増すだけのボタン。
5. **Cloud Browserでの経過は壁時計と一致しない。** 開いていない間にアニメーションが抑制されるため、公開画面で次波までかかった待ち時間をiPhoneの5秒の操作感と同一視しない。

## 次に捨てるかどうか

色リングを足した版の画面で、ナギの盾から返り火、火種、震脚を**文字を読まずに**追えるか。同じ本人が予約技能を外す、先駆けをOFFにする、移動を止める、の各対照を試し、どの入力が結果を変えたか言えるか。二波がほぼ放置で勝てるなら、少なくともこの敵密度・移動速度ではアクションとして失敗。

さらに大きな疑いがある。ヒバナ→ゴウは「敵を倒したら誰かの自動効果が出る」というだけで、五人がそこにいる必要が薄い。**一人が五つの武器を持っても同じ現象なら、五人のキャラクターを残す条件に失敗する。** [51](./51-relay-mark-candidate.md)では、五人が別々に敵へ触れること自体をコンボの材料にする一案を試す。ただし、状態アイコン地獄の再発を強く警戒する。
