# 大胆なパックを実装へ移す境界

状態: v3検討の共通条件。技能の数値・採用一覧は基礎/拡張カタログで決める。本書は既存engineへ案を押し込むためではなく、新しい遊びが何を変更するかを明確にする。

## 何を壊し、何を保つか

| 新しい遊び | 壊してよい従来の常識 | 仕組みとして明確にすること |
|---|---|---|
| 次roundのAPを前借り | 毎round同じ行動回数 | 誰のいつの資源を借り、返済は何より先か。倒れた/戦闘終了時の扱い |
| 溜めや状態の持越し | round終了で全部消える | 対象はbattle内か次のbattleか。上限/失効時点/保存領域 |
| 毒や弱体の拡散・反転 | 状態は付けた相手で終わる | 複製か移動か、段数/残り時間/発生元を引き継ぐか |
| 味方敵の枠・罠・地形 | 位置は射程と狙われ方だけ | 空枠がない場合、押出先の優先順、既に行動した人の手番、罠の有限在庫 |
| 耐久を火力へ変換 | 装備を長持ちさせるほど得 | 消費した耐久と自然破損を区別するか。装備が壊れた後に残る能力 |
| 戦後回復・次戦準備 | 技能は戦闘内だけ | 勝利/敗北/撤退での適用条件、battle開始時の構成に結び付く一回の精算 |
| 報酬特化 | 強い戦闘技能ほど良い取得 | 戦闘能力/取得SP/装備枠等の機会費用と、何の報酬分布を変えるか |

「前借りしたけれど返済前に勝つ」は、初動に賭けるビルドの成功として許容できる。毎戦債務を持ち越して帳尻を合わせることを自動で要求しない。全敵への毒や大火力で通常戦を圧倒することも許容する。対抗する敵は隠れた無効化ではなく、初動・人数・射程・持続など公開された軸を変える。

## 発動順をプレイヤーの判断にする

反応を一律に「一イベント一人」に制限すると、仲間全員が連動する楽しさを失う。基本は個別のRPや回数、共有資源の消費、位置や対象との関係で終点を作る。発火条件と順序は、優先順位の変更で狙った効果が先に出るようにする。

同じ状態を二つの技が使うときは、片方が消費すればもう片方の燃料が減る。その競合を隠さず、予測で見せる。複製する上級技能は、その通常の競合を破る強みとして扱えるが、複製由来を再複製して無限に増やせない在庫・起点回数・世代のどれかを説明する。

## 戦後効果を一律禁止しない

「戦後、固定量を回復する」技能は、勝利時に一回適用すれば、ラウンドを稼ぐだけで回復を無限に増やす技能とは異なる。戦闘開始時に付与した有限回数や、敵の一意な撃破を根拠にする報酬も同様である。

現行anti-stallの意図は、敵を生かして待つだけで持越し資源が改善する稼ぎを防ぐこと。これを「戦闘後に役立つ技能を作れない」と読み替えない。

逆に「毎round、次戦用回復薬を1個作る」は待つことが主目的になる。採るなら、一戦の在庫を前払いする、先に勝ったほうが残数が多い、有限回数を攻撃と共用するなど、終わらせる判断が残る形にする。上限を付けるだけで必ず面白くなるとは限らない。

## 戦利品技能の成立条件

報酬技能は、必ずしも与ダメージへ変換されなくてよい。「今回は撃破力を落として良い品を持ち帰る」こと自体がビルドになる。

- 戦闘開始時の習得/有効化/装備状態を、その戦闘の報酬条件の根拠として保存する。勝利後の付け替えで過去の報酬を増やさない。
- 何が増えるかを限定する。候補数、採用品数、素材量、特定効果の出現、活動資金等を全部同時に増やす万能技能にしない。
- 敵個体の一意な撃破・勝利・固定の戦闘目標を数える。同じ敵への無害な行動や復活を繰り返して無限に増やさない。
- 稀な品を狙うなら、稀少性の変化と戦闘側の機会費用を比較する。最終戦だけ常に入れるのが唯一の正解なら、入れる時点・育成費・それ以前の累積条件を検討する。
- 報酬特化なしでもシナリオ解禁と基礎成長は進む。稼ぎ技能を必須の通行料にしない。
- 既存の引き直し用seedを敵生成や後続dropへ流用しない。技能で変える報酬は入力として明示し、同じ入力では同じ結果にする。

報酬プレビューを出すか、達成条件だけを出すかは別のUI判断。どちらでも、確定時だけ別の抽選をして予測と食い違わせない。

## パック解放と初周/再周回

初周の役割は、すべての終点を取り切ることではない。入口と小さな組合せを楽しみ、次に試す枝が見えること。後半の役割は、増えたSP・新パック・拾った装備で、同じ初期技能の働きを変えること。

そのため、カタログの検査は二段に分ける。

1. **初周の核:** そのシナリオで得られるSPだけで中盤までに成立し、残りの戦闘で使える。
2. **後の到達点:** 必要なシナリオ/永続投資/SPを明示し、その条件では実際に到達可能。最初から届かないこと自体をエラーにしない。

永続SPは全員の無条件火力を増やす側面がある。敵を自動で強くして相殺せず、解禁済み難度と新しい敵圧力で遊ぶ場を用意する。投資なしの初回クリア経路も保持する。

## 最初に試す拡張

基礎だけを何度も磨いて大胆な要素が後回しになることを避ける。最小の試遊版にも、基礎3構成に加え、時間の前借り・状態の伝播・耐久の燃焼のいずれか1パックを入れる。通常の戦い方を覆す成功例と、その仕込みが裏目に出る例を一つずつ試す。
