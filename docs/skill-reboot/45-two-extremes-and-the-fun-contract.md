# 二つの極端を先に作る：手役のゲームと、弾が増殖するゲーム

更新: 2026-09-29。状態: **比較のための未採用設計**。前の[三枠前線](./35-replenishing-frontier.md)と[一斉射の棄却](./42-one-salvo-five-makers-rejected.md)の小修正ではない。本文の数値や遊び心地は実機試遊前の仮説。`GAME.md`、190技能、実装契約は変更しない。

## まず、何を「面白い瞬間」と呼ぶか

この企画で欲しいのは、技能の発動数そのものではない。**以前は何も起きなかった箇所に、新しく得た一つの性質がつながり、一度起きたことが次の事件を呼んで、五人の誰がその転機を作ったか見えること。** 例えば、ナギが弾を防ぎ、ゲンゾウが写し、ヒバナの火が新しい敵へ移り、ツグミが拾った薬で次の波を耐える。「ナギを伸ばした自分の考えが、ヒバナまで届いた」と言えることが重要。

その前には苦しさも要る。まだ一発目の撃破に届かない、次の敵が強く見える、最初の連鎖が途切れると危ない。**同じ不足が、育成前には敗因、育成後には連鎖の起点になる**なら、強化が効いたことを感じる。意地悪な敵専用の鍵、毎戦の装備変更、予測画面の緑になるまでの総当たりは、その苦しさを作る方法として使わない。

現在の前線試作は、五人・三枠・十二隊のすべてのHP変化を扱うため、一回の出発に小さな事件が何十回もある。何をしたか追える反面、**見たいのが「連鎖が始まり、敵列が崩れた」一瞬なら、HPを一つずつ削る描写はその間を引き伸ばす**。さらに勝率を数えやすいことが、設計者を「勝つ構成が何通りあるか」へ誘導してしまった。勝率は退屈を測れない。[39](./39-preview-observation-and-next-kill-gate.md)以降の細部検討はいったん止める。

## 一度捨てるものを明記する

|  | A: 五人の手役（カード型） | B: 灰火の行軍（アクション型） |
|---|---|---|
| 一度に見える事件 | 五枚が揃って一つの大きな判定 | 実空間で初撃→撃破→弾・火・治療が増殖 |
| 残す未来 | 次の敵札と、望めば次の巡の一札 | 数秒後に来る波の方向と種類 |
| 捨てる未来 | 全十二戦の完全な勝敗予測 | 戦闘の完全なシミュレーション自体 |
| 寝る前の思考 | 五人の札をつなぐ予約と、次の敵を今引き受ける賭け | 五人の武器と予約進化の組合せ、連鎖の起点探し |
| 実プレイの入力 | 基本は見守り、危険なときだけ未来札を引く。育成三箇所は予約可能 | 片指で五人を動かして避ける。指を離すと停止、攻撃は自動 |
| 失うもの | 個別の命中・前後列・五人のHP。敵は戦闘札になる | 放置して十二戦突破する体験。勝敗の数学的な説明可能性 |
