# 候補A：五人の手役 — 戦闘を一枚の結果に圧縮する

更新: 2026-09-29。状態: **高い抽象度への転換案、未採用**。細かい前後列、AP/RP、個別HP、ターゲット優先列を捨てる。以下は第一試作用の完結したルールであり、既存本編との互換案ではない。

## プレイヤーがすること

寝る前に、五人の札の育成先を予約する。出発後、五人は毎回同じ順番で一枚ずつ札を置き、見慣れた手役を作る。十二枚の敵札を順番に破る。先見で次の敵札を見て、**今の一撃で次の敵まで倒せそうなら、次の敵札を今の勝負へ引き込める**。成功すると二戦が一撃になり、育成も早まる。失敗すると二体から反撃を受ける。安全に進みたければ何もしなくてよい。

五人の札には人格と固有の作用がある。敵は一枚の「耐久・反撃・名称・絵」で表現し、戦闘のアニメーションは五人の札が並ぶ→手役が点灯→一撃で札が割れる約二秒に圧縮する。十二戦を連続再生しても、一手役の結果は一画面で読める。

## 一巡の全ルール

1. 現在の敵札一枚を表にする。先見欄には**次の敵札一枚**だけが常に見える。以降は裏向き。現在の敵と次の敵を含め、十二枚すべて破れば勝利。
2. 任意で「先取り」を一回押すと、次の敵を現在の敵の後ろへ引く。先取りしなければ次の敵は今巡にいない。既に二枚が場にあれば押せない。先取りはその巡の手役を置く前に確定し、取り消せない。
3. ヒバナ→ゴウ→ゲンゾウ→ツグミ→ナギの五枚を**必ず一枚ずつ**自動で置く。各札の基礎点は2、合計10。各札に「火・鉄・水・盾」の印が一つある。ゲンゾウ初期札は直前の印を写す。
4. 左から隣り合う同印二枚を「対」一組として+4点。カードは対に二重参加できない。左から連続した三枚が全て異なる印なら「流れ」一組として+4点。流れ同士は札を共有できる。最終点は基礎点＋対＋流れ＋取得技能の明記した点。判定順は札を確定→対・流れを数える→点を得る→敵へ与える。
5. 点数を先頭の敵の残り耐久から引く。倒して二枚目が場にあるときだけ、余った点が二枚目に届く。二枚目を倒しても三枚目は自動入場しない。余りは消える。技能に明記した追加点は条件が成立した段階で一回だけ足す。
6. 生き残った敵札はそれぞれ表示された値で共有の灰火HPを攻撃する。ナギの毎巡の防御1、技能の防御とツグミの治療を適用する。灰火HPの初期値12、0で敗北。倒した札の反撃は起きない。敵の耐久は巡を越えて残る。
7. 敵札を累計3、6、9枚倒した瞬間、寝る前に予約した三つの育成が順に起動する。未予約ならその時だけ三択で止まる。倒す順序が早まれば育成も早い。出発時に育成三つを予約すれば**十二枚を連続再生**できる。

試作の敵には新しい状態異常も専用の解除技能もない。まず耐久と反撃だけを変える。例えば耐久8・反撃5は素早い撃破や防御に意味があり、耐久26・反撃1は手役の成長を試す。**この二数だけでは敵が単調なら、案そのものの弱点として扱う。** ボスに「火を無効化」などの持ち物検査を追加して救わない。

## 初回90秒の実例

最初の二枚は「煤鼠」耐久16・反撃2、「灰射手」耐久11・反撃3。初期の五枚は `火・鉄・写→鉄・水・盾`。基礎10、鉄の対+4、末尾の `鉄・水・盾` の流れ+4、**合計18**。

- 安全に行く: 先取りせず煤鼠を一撃で倒す。余り2は消える。煤鼠は反撃できない。次の巡に灰射手を一撃で倒す。灰火HP12のまま二戦を越える。
- 欲張る: 先取りを確定する。18のうち16で煤鼠を倒し、余り2で灰射手を11→9にする。灰射手は反撃3、ナギの防御1で灰火HP12→10。次巡に灰射手を倒す。**この時点の先取りは悪手である。** 説明できる悪手なのでよい。
- その後: 累計3枚討伐でゴウの「鍛打」が起動すると、鉄の対は+8になり合計22。さらに累計6枚でヒバナの「余火」が起動すると、先取りした二枚目がいる巡で**一枚目を破った瞬間に+8点を一度だけ追加**できる。同じ煤鼠16・灰射手11なら22+8=30で二枚を一巡で破る。最初は傷を負った賭けが、育成後は二戦を一撃で畳む定番になる。二枚目の耐久が15なら一撃では倒せず反撃がある。先見の次札を見て先取りするか考える。

ここで楽しい可能性があるのは+4の数字ではなく、「まだ危険だった先取りが、自分の二枚の札の組合せで、次の成長を前倒しする加速装置に変わった」変化。**同じ耐久閾値を暗算するだけで終わる可能性も高い。**

## 初回の札。十枚を同時に売り込まない

初期札五枚は上記の印、基礎2点。成長三箇所の候補を次に限定する。A/Bは一人につき取得時にどちらか一方へ札を置き換える。予約済みなら途中で毎回選び直さない。

| 人物 | A | B | 何が変わるか |
|---|---|---|---|
| ゴウ | **鍛打**: 最初の鉄の対を+8点（通常+4）にする | **独槌**: 自分が対に参加しなかった巡だけ、基礎点を2→8にする | 対を集めるか、違う印を並べるか |
| ヒバナ | **余火**: 一枚目の敵を破り二枚目が場にいたら、その二枚目へ+8点。一巡一回 | **燃え継ぎ**: 流れ一組につき+2点。倒した敵からの余りを上限4まで次巡へ持ち越す | 先取りして二枚抜き、または次巡へ余熱を渡す |
| ゲンゾウ | **右写し**: 直前ではなく右隣（ツグミ）の印を写す | **両写し**: 左隣と右隣の印から、対を作れる方を自動で一つ写す。同点なら左 | 札を並べ替えず手役を変える。両写しは便利だが優先規則の説明が必要 |
| ツグミ | **手当て**: 流れ一組につき実HPを1治す。一巡最大2 | **調律**: 流れが二組以上なら+6点、治療はしない | 同じ手役を生存か突破に変える |
| ナギ | **重盾**: 対が一組あれば防御3、それ以外は1 | **門盾**: 先取りした巡は防御4、それ以外は1 | 対の構築かリスクのある先取りを支える |

札全体は毎回五枚だけ。初期十択を要求せず、まず三つの予約枠でヒバナ・ゴウ・ツグミなど三人を育てる。残る二人の枝は再遠征で変えるか、長い遠征で増える余地として保留。**最初から190札を移す判断はしない。** この小ささで発見がなければ大量追加で解決しない。

## 先見と自動進行の境界

先見は次の敵札の耐久・反撃・絵を見せる。出発前に現在の五枚で「対が一組、流れが一組」といった**手役の内訳**は見られる。先取りはその巡の手役より先に確定し、判定後に巻き戻せない。育成予約の修正は出発前、または敗北・撤退後だけ。勝敗の十二戦一括コンパイルボタンは置かない。十二戦そのものが短い五枚の解決の連続となる。

乱数は第一試作に入れない。結果が決定的でも**修正して無料で再照会する窓がない**ので、予測オラクル問題は異なる形になる。ただし五枚の点数が固定されていると、先取りは単純な耐久比較へ退化する。そこが成立しなければ第二試作で公開された小さな札山から追加札を一枚引く変動を検討する。**乱数を足して暗算の単調さを隠したことにはしない。**

## 根本的な損失と試すべき問い

- 五人の誰が傷ついたかというドラマは消える。名前と表情だけ残してもキャラクター性が薄いなら、カード案は失敗。
- 敵はほとんど数字二つ。「敵を倒す」より「点数を伸ばす」が主役になる。これは[Balatro](https://www.playbalatro.com/faq)の構造からの意図的な借用だが、同じ楽しさが自動手役に宿る保証はない。
- 初期18、鍛打22、余火込み30という変化は一度知れば予測できる。プレイヤーが三周目にも「一枚先を引き込むか」を迷う理由があるか。
- 三つの育成が敵HPの算数だけで決まり、カード名を変えても同じ結果なら、手役を作った意味がない。
- 画面で札が割れる快感が二秒に収まるか。十二回同じ五枚を並べるだけならアニメーションを飛ばされる。

**最初の検証:** 紙札五枚・敵十二枚・技能A/B各一枚を使い、人間二人に初回と別順の二周をしてもらう。先取りを押した理由、その後の育成で変化した選択、五人を役名でなく名前で覚えたかを記録する。点数が合っていても、二周目の先取りが毎回同じなら棄却。
