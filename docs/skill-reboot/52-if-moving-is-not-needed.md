# 動かなくても勝つなら、動かさないゲームとして設計し直す

更新: 2026-09-29。状態: **第三の分岐を紙上で検討し、現状は保留**。二波試作で、ほぼ静止の旧連鎖はHP満タンで突破し、継ぎ印も無移動で発火した。[50](./50-action-prototype-first-contact.md)、[51](./51-relay-mark-candidate.md)。小さな試作の難易度不足に過ぎない可能性もあるが、「移動を楽しくするため敵の移動速度だけを上げる」のは無理にアクションへ寄せる行為かもしれない。

## 候補C：五人を道の曲がり角へ置く

敵が進む道を二本描き、途中で交差して灰火に着く。入口左と入口右に二箇所ずつ、合流後に三箇所、合計七つの陣地がある。出発時に五人を異なる陣地へ一人ずつ置き、二つ空ける。各人は自分の陣地から、射程内の敵を自動で攻撃する。敵は決まった道を進み、灰火へ到達すれば灰火HP12を1減らす。十二波を守れば勝ち、HP0で負け。敵は左・右・両方から来る。次の一波の入口と敵の大まかな数が見える。

**操作は出発時の五回の配置と育成予約。** 戦闘中は「先駆け」ON/OFFのみ任意で、ONにすれば五秒ごとに未撃破の敵の上へ次波を重ねる。隊をドラッグし続ける必要はない。大きい群れをあえて呼べば、撃破起点の火が隣の敵へ飛び、強い構成は十二波を短く突破する。

継ぎ印は一人目の攻撃で輪を付け、二人目が同じ敵を撃つと受け技を出す。**配置順と二本の道で接続が変わる。** 例えば左入口にゴウを置いて押し返すと、その道の次の陣地にいるヒバナが金→赤の印を破り、火が密集した後続へ散る。合流点にゲンゾウを置くと左右両方の印へ矢を伸ばせる。ツグミは合流点で傷ついた人物か灰火を治す。ナギは飛び道具が灰火へ届く射線を塞ぐ場所に置く。五人の行動順は実際の敵の経路として目で追える。

二戦ごとに五人を並べ直すことは求めない。遠征を通じて同じ陣地の機械が育つ。敗北しても直前の波から無料に戻る予測機はない。出発後の敵の個体位置と発火タイミングは見せるが、十二波の結末を計算して表示しない。最短で勝つプレイヤーは先駆けONを維持し、恐ければOFFで一波ずつ片付ける。

## これが最初から強いとも言えない

| 反論 | 痛さ |
|---|---|
| 一列の最適配置が分かれば、毎回五人を置くのは作業 | 元の「着替え」と同じ問題。保存配置のまま走れるなら配置判断そのものは一回で終わる |
| 右の敵には右に置く、左には左に置く | 敵入口の違いを持ち物検査へ変えうる。左右の人数が違うだけで今の五人が両方対応できる構成にしないといけない |
| 道を歩く敵を見ているだけ | [Bloons TD 6公式](https://ninjakiwi.com/Games/Mobile/Bloons-TD-6.html)は塔の多様なアップグレードと能力を持つが、こちらが配置も育成も出発前に済ませると、戦闘中の意志決定を大幅に削る。[Ballionaire公式](https://store.steampowered.com/app/2667120/Ballionaire/)は配置した盤から物理連鎖を作るが、新しいトリガーを各ラウンドでドラフトする。**両作から配置と連鎖だけを借り、選択の頻度を引いたときの面白さは未知** |
| 継ぎ印が自動発火するだけなら一人五武器問題の名前を変えたに過ぎない | 五人の配置順にプレイヤーの意図があり、意図した順に発火したと説明できるかが唯一の差。順を変えても勝敗と体験が同じなら五人の関係は飾り |
| 途中で陣地を入れ替えるUIを作れば解決、という誘い | それは毎波のパズル、ロードアウト作業へ戻る。次の一波にだけ効く「救済配置」が必要な設計なら候補Cを捨てる |

既存のアクション候補Bで指の操作が面白くならなかった場合に、候補Cを**二本道・五人・六体の紙配置**で一度試す価値はある。ただしCを「動かさなくてよいから快適」とだけ評価しない。戦闘中に何を期待して画面を見るのか、五人の位置を一度選んだ後に寝る前に考える新しい問いが残るのかを先に聞く。

暫定の序列は **Bの連鎖を意図して起こせるか→駄目ならCの配置を一周試す→自動手役Aは棄却寄り**。これは製品の選定ではない。いまのBが放置で勝てる事実を受けて、Cを対案として明示的に残す。
