# 未来は答えではなくアクセルにする — 「先駆け」への改訂

更新: 2026-09-29。状態: **[47](./47-ash-march-action-game.md)への一つの改訂提案**。カード型[46](./46-five-hand-card-game.md)へ無批判に移さない。面白さは未試遊。

## 直前の案のままだと、先見は壁紙に近い

アクション型で次の波の方角を少し早く知っても、多くの場面では「今の敵を倒す」しかすることがない。寝る前に未来が少し見えるという設定が、わずかな射線調整になってしまう。次の敵を現在へ呼べるなら、未来の情報は**いつ危険を招き入れるか**の判断になる。

カード型では耐久16と次11、手役18なら、今引いても二枚目へ2点が届くだけ。育成後30なら合計27を超えるから引く。この判断は合計と点数の比較でほぼ終わる。カード版の「先取り」はこのままでは薄い。一方、アクションには同時に存在する敵の**密度と位置**があり、その密度は撃破から新しい火種、盾への敵弾、三討伐目の震脚を生む。未来の波を重ねることが、危険であると同時にビルドの燃料になる。

## 「先駆け」は一度押す持続スイッチ

画面右下に親指で押せる `先駆け OFF/ON` を一つだけ置く。OFFの標準進行は、現在波が全滅すれば約1秒で次波、残れば前波の到着から25秒後に次波。ONにした最初の次波は**スイッチを押してから5秒後**、以降は最後の波の到着から5秒後に、現在波が残っていても来る。全滅させたときの1秒進行はONでも同じ。OFFへ戻すと次波以降の早出しだけ止まり、すでに到着した敵は消えない。第十二波までしか到着しない。タップを連打せず、一度ONにしてそのまま十二波へ走れる。移動中も左親指を離さず右手で押すか、一度止まって押す。初期状態はOFF。

UIは現在波 `6/12`、次波の「北から小敵8・射手2」、先駆けON時の到着までの円形5秒だけを示す。**現在のすべての敵のHPと未来の勝敗は表示しない。** 次の一波より先は見えない。敵配置の細部と弾は生成時に確定し、出発前に再実行して結果を見る機能もない。

### どういう瞬間に押したくなるか

第六波の小敵がまだ四体残り、盾の正面に射手の弾が近づいている。ヒバナの火種は撃破が続けば増えるが、今の四体が散っていて次の標的へ届きにくい。先見は次波が北から小敵を八体運ぶと告げる。ここでONにすると五秒後に敵が重なり、ナギの反射で一体倒す→火種の標的が増える→三討伐目でゴウの震脚、と育てた機械が加速する可能性がある。遅れれば、既存の四体と新しい八体に囲まれて灰火が削られる。**同じ能力で「密集すると強くなる」か「囲まれると死ぬ」かが紙一重**になる。

第七波を一秒で全滅させるほど強ければON/OFFどちらでも次波はほぼすぐ来る。無意味な早出し操作を要求しない。まだ持ちこたえつつ敵を倒し切れない中間の強さで、先駆けがもっとも危険で面白い。実装してみて、この中間域が遠征の短時間しか存在しなければ、このスイッチも棄却する。

## 背反を隠さない

1. **撃破供給の自己増殖。** 敵を多く呼ぶほど火種・震脚・回復が増え、強いビルドだけがさらに強くなる。これは一時的なカタルシスだが、以降すべて自動で消し飛べば「先見で考える」要素を消す。十二波を高速殲滅できる瞬間そのものに価値があるか、周回すると退屈かを測る。
2. **最適解の固定。** ONにするのが常に得ならスイッチは初期設定でしかない。常に損なら危険な飾り。敵の密度と盾の位置でON/OFFの価値が変わるか。反例として、同じ強い構成が常に第2波からONで安全なら変更する。
3. **スマホ負荷。** 第十二波まで5秒間隔で重ねると最大で多数の敵・弾を描く。隠れた連鎖上限で解決しない。最初の二波でフレーム時間を測り、厳しければ敵の数ではなく波の人数と効果の絵を削る。
4. **操作の複雑さ。** 移動とON/OFFの二入力が最小。右手のタップで片手プレイを壊すなら、画面右下だけでなく左親指が届く長押し領域を試す。先駆けがなくても標準の十二波は遊べる。
5. **「敵ごとの着替え」への回帰。** 北から射手が来ると分かっても、今回の育成を一時的に盾装備へ変えるUIはない。今ある五人をどこに置き、どの時点で未来を呼ぶかが変わる。もし結局「この技能がないと射手波では先駆けを使えない」なら、先駆けは任意の賭けであり、勝利条件にしてはいけない。

## 二波試作で一つだけ尋ねる

ヒバナ火種とナギ返し盾を付けた二波、片方は先駆けOFF、片方は一波目にON。**ONのとき「先に危険を呼んだから連鎖が増えた」と同一人物が言えるか。** ONの方が勝てた、倒す時間が短かった、では不十分。増えた敵が最初の反射弾・火種・次の撃破をどう変えたか、画面を指して説明できるかを見る。できなければ先見は装飾であり、先駆けも削る。

この改訂が成立すれば、「寝る前にどの連鎖の起点を育てるか考える」「一戦先を見て、自分で危険な密度を作る」「決まると五人の火が十二波を一息に焼く」という三つが一つの行為につながる。まだ**文章の仮説**である。
