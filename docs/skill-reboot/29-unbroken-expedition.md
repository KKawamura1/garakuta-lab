# 仮説「十二連破」――五人の一巡が波をまたぐ

更新: 2026-09-28。状態: **撤回した試行。未採用・未実装**。[30の五拍時計](./30-five-beat-clock.md)へ敵行動の構造を作り直した。現行の12戦・技能カタログを変更する指示ではない。[28の棄却記録](./28-discard-log-fun-first.md)から続く。数字は手で追うための仮値。

## 1. 遊びたい一秒

第3波、先頭の敵が残りHP1。ヒバナが倒し、まだゴウとゲンゾウの番がある。**第4波が同じ画面に即座に入る**。ゴウは次の敵を叩き、ゲンゾウは今入ってきた後衛を撃ち抜く。第4波の敵は次の拍まで反撃できず、第5波へ手が伸びる。「一戦ごとに勝利画面→次へ」ではなく、昨夜仕込んだ五手が敵の列を食い破るのを一続きに見る。

第8波の厚い首領はその五手に耐え、ナギの盾を割る。次の拍、盾を割ったぶんが反撃として戻り、ツグミの治療が実際に役に立つ。速攻だけが常に答えになるならこの構造は失敗である。

## 2. 一画面のルール

遠征は**一回の長い戦闘**。順番に十二の敵の波が来る。「12戦」は進捗の呼称として残してよいが、戦闘の解決を十二回リセットしない。画面中央に現在の敵一〜三体とそのHP、右端に次の波のシルエットとHP・行動、下に五人の順番・HP・防壁と使用中の改造を出す。敵がいなくなった瞬間に次の波が入る。勝利画面と報酬画面は第12波を越えた一度だけ。残りの味方行動は新しい波へそのまま当たる。

| 要素 | 最小試作の契約 |
|---|---|
| 五人 | 各人HPを持つ。一拍に行動一回。出発時に並べた五人順を毎拍繰り返す。行動不能者は飛ばす。順番は戦闘中には変えない |
| 敵 | 一波に一〜三体。左から先頭、後衛の順。全員いなくなると次の波が即座に入る。敵HP・標的・行動は画面に出す |
| 味方の基礎行動 | ゴウ: 先頭に3。ヒバナ: 先頭に1。ツグミ: 先頭に2、最も傷ついた味方へ実HP1回復。ナギ: 先頭に1、自分へ防壁1。ゲンゾウ: 先頭に1。対象がいなければ行動を消費せず、次の波が入ってから実行 |
| 目標・敗北 | 第12波の敵が全員倒れ、味方が一人以上生存すれば勝利。五人全員がHP0で敗北。逃げた敵や門HPはない |
| 敵の番 | 五人の一拍が終わった時、**その拍の開始時点にいた生存敵だけ**が左から一度行動。途中で現れた敵は次の拍まで撃たない。既定の単体攻撃はナギ、ゴウ、ヒバナ、ゲンゾウ、ツグミの順で生存者一人を狙う。ナギの防壁が先に減り、残りがHPを減らす |
| 持越し | 波を越えて味方HPと防壁を保つ。敵HPは波ごと。防壁は味方の最大HPが上限。第4・8波の突破時に、味方は欠損HPの半分（切り上げ）を回復し、倒れた味方はHP2で復帰。進行や改造解禁は止めない |
| 表示速度 | 五人の行動を初回は順に見せる。波を連破した拍だけ自動で短く強調し、同じ発火は以後まとめ表示可能。いつでも停止・一手送り・速度変更可。全12波を早送りしてもよい |

敵が途中で現れて同じ拍に反撃すると、後半の味方が敵を倒して次波を呼んだことが罰になる。そこで到着敵はその拍の敵行動に加えない。これは隠し免疫でなく、波カードに「次の拍から攻撃」と印字する。前の拍から残った敵は反撃し、防御・治療の意味が残る。

先見機は**次の一波の組成と敵行動**を照らす。味方を一波先まで仮実行して勝敗を表示しない。画面は未来の予定と現在の実戦を続けて表示する。「緑になるまで無料で直す」は発生しない。動作理解は速い本番と一手送り、そして短い固定練習三波で行う。敗北後は同じ敵列でも無償で再挑戦できるため、ここが盲目的な総当たりに戻る可能性はある。

## 3. 取得の制度を小さく壊す

出発時、各人に**二候補から一つの改造**を予約し、五人の順番と解禁順を決める。最初の一つは第1波から有効、残りは第2・4・6・8波の突破で自動解禁。メニューを開く必要はない。第4・8波の突破後だけ、望めば一時停止して**残りの予約と並び順**を編集できる。強ければ一度も触らず12波へ。最小試作では一人一つの改造しか稼働せず、後半の有効な特殊規則は最大五つ。190節をそのまま移さない。

以下の二候補は意図的に異なる出口を持つ。各人の基礎行動は残る。括弧内の回数・対象は表示する。固有名を参照する効果は作らない。

| 人 | A | B |
|---|---|---|
| ゴウ | **貫き槌**: 自分の3ダメージの余りが、次の敵へ同じ一撃として移る。敵列が尽きたら次の波の先頭まで届く。余りは敵HPを引くたび減り、尽きたら終わる | **合わせ槌**: この拍にすでに誰かからHPダメージを受けた敵を殴ると6ダメージ。余りは消える |
| ヒバナ | **駆け抜け**: 自分の攻撃で敵を倒すと、次に現れた敵へ1ダメージをもう一度だけ与える（一拍一回）。追加の一撃から再発動しない | **裏取り**: 現在の波に二体以上いれば先頭でなく最後尾へ2ダメージ。一体なら先頭へ通常の1 |
| ツグミ | **仕留め手当て**: 自分の射撃で倒すと、その場で最も傷ついた味方をHP2回復。基礎の行動後HP1回復も行う | **痛みを弾に**: 基礎の行動後HP1回復の後、その拍に自分が実際に回復したHPと同じダメージを最後尾へ一回撃つ。無傷なら追加射撃なし |
| ナギ | **厚い盾**: 行動時の自分の防壁獲得が1から2になる。先頭への1ダメージは残る | **返す盾**: 敵の番で自分の防壁が敵の攻撃を防いだ量だけ、その攻撃元へダメージを返す（一拍に一回）。防壁1と先頭への1ダメージは残る |
| ゲンゾウ | **写し弩**: 自分の通常の1ダメージの代わりに、この拍で直前に解決した味方の基礎攻撃一回と同じ表示ダメージを先頭へ撃つ。元の技能効果はコピーしない。直前に味方攻撃がなければ1 | **迎え撃ち**: この拍に新しい波が入っていたら、行動時に最後尾へ3ダメージ。入っていなければ先頭へ通常の1 |

「直前」「余り」「実際の回復」は戦闘画面に数字と矢印で見せる。写し弩が別の写し弩をコピーせず、駆け抜けが自分を再発動しないのは安全のための隠し例外ではなく、両技能の印字した一回制限。これでも初見に読めないなら技能自体を捨てる。

## 4. 一拍を手で計算する

味方順は**ナギ→ヒバナ→ツグミ→ゴウ→ゲンゾウ**。ゴウAとゲンゾウBが解禁済み。第3波には先頭A（HP5）と後衛B（HP4）、次の第4波には首領C（HP10）一体。拍の開始時にいたAとBだけが今回敵行動の資格を持つ。

ナギがAを1削りHP4、防壁1。ヒバナがAを1削りHP3。ツグミがAを2削りHP1、傷ついた仲間がいれば1治療。ゴウの3がAの残り1を倒し、余り2がBへ飛ぶのでBはHP2。ゲンゾウはこの拍に新しい波が入っていないため通常1をBへ、BはHP1。Aは倒れた。Bは拍開始時からいたので、この拍末にナギを攻撃する。

次の拍、ナギの1がBを倒す。**ゲンゾウの番ではなく、ナギの一手目で**第4波が入った。ヒバナ1、ツグミ2、ゴウ3が首領CをHP4まで削り、ゲンゾウBは「この拍に波が入った」ので3ダメージを撃ち、CはHP1。Cは到着した拍に敵行動をしない。ゴウAなしならBは最初の拍末にHP3、次の拍ナギ1→ヒバナ1→ツグミ2でやっと倒れ、第4波に当たるのはゴウ3とゲンゾウBの3だけでCはHP4。**改造一つで境界が味方三手ぶん移る**。これは倍率より、次の敵に誰が届くかの変化である。

上記のA/Bの位置と解決順はあくまで一局面。Genzou Bは次波に入った拍にしか強くなく、単体ボスが長く残ると基礎1に戻る。その場合は直前の大技を写すAと、ゴウBの一点火力が有利になる可能性がある。ナギAを取れば受けられる拍数が伸び、ナギBは守りが割れる時だけ火力を返す。**どれも勝つ**とはまだ言えない。

## 5. 技能を作るための制約

新技能は「敵に与えるHPダメージ」「敵が倒れて次波が現れる時刻」「味方の失うHP／防壁」「五人の順番」の**少なくとも一つを、実際に見える形で変える**。入口は「自分の行動」「撃破」「到着」「敵の攻撃」「実回復」の五種類をまず使い回す。技能の完成文は一行程度、同時に表示する改造は五枚まで。取得技能を全ONにして怪獣にしない。新しい状態名を増やして十枚に拡張しない。

コンボと数えるのは、Aを外すとBの発火時刻・対象・結果が変わる場合だけ。単なる二人の加算攻撃は数えない。試作で調べる四つの**候補**は、①削り→ゴウAの余り→次波の到着→ゲンゾウB、②先行の小打撃→ゴウBの倍打→ゲンゾウAの写し、③ナギAで耐える→ツグミBの実回復を射撃へ→後の波を早める、④ヒバナBの後衛削り→ツグミAの撃破回復→ナギが長く前に立つ。③はツグミの基礎HP1回復が小さすぎ、④は単に同じ敵を二人で撃っただけかもしれない。これらを成功した四系統とはまだ数えない。

## 6. この案への強い反論

1. **結局DPS競争。** 到着敵がすぐ反撃しないので、火力が正義になり、ナギと治療が無用になりうる。守りの構成と速攻の構成が、同じ十二波を異なる因果で走破できないなら敵HPを盛って修正しない。このループを棄却する。
2. **最適な順番が毎回同じ。** 小打撃を先、大技を後に置けばよいだけかもしれない。ゴウB＋ゲンゾウA、ゴウA＋ゲンゾウB、ナギ盾＋反撃の間で合理的な順番が二種類もなければ、並べ替えUIは無駄。
3. **十二波が早く終わるのは、十二戦を遊んだ感覚ではない。** 一回の派手な連破が気持ちよくても、次の出発で何を考えたいかが残らないなら短い花火で終わる。ベッドで五人の役割を考え直したいか実測する。
4. **前提が単純すぎて190技能は作れない。** その場合190へ引き延ばさない。二候補×五人と数種類の次の波だけで面白くなければ、数量不足のせいにしない。
5. **順番と解禁予約の検索。** 五人の順は120通り、改造32通り、解禁順120通りで机上は46万通り。正確な勝敗試算を無料で出せばまた緑探しになる。表示しなくても同一波の再挑戦で学習せず総当たりする人はいる。原因を説明できない再試行率を測る。
6. **キャラクターが攻撃値の違う駒になる。** ゴウの大振り、ヒバナの走り、ツグミの射撃と手当て、ナギの盾、ゲンゾウの記録は短い技能にも残す。ただし操作・会話・アニメが五人の関係を伝えられなければ、名前だけ守った失敗。
7. **現在のゲームからの距離が大きい。** 戦闘の連続化、十二の勝利精算の統合、190節の非互換、実戦の予測仕様変更が要る。現行を直接書き換えず、独立の2分試作で比較する価値しか現時点では主張しない。

**本命と断定しない。** 上記の一秒に一番引力があるので、次に紙上と小さい実装で「防御が空気では」「境界を理解できるか」を落とす。失敗したら書き換えて残す。
