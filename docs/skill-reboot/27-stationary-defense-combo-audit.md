# 三列防衛: 十技能の因果検算と棄却条件

更新: 2026-09-28。**未実装の紙上試験。** [26の盤面・勝敗・一拍の契約](./26-stationary-defense-contract.md)を前提とする。ここに書く例は「コンボが必ず面白い」証明ではない。24/25の火床・一指操舵はこの試験へ持ち込まない。

## 1. 基本動作と十枚の改造

五人の人物像は[設定の正本](../../ecology/content/character-lore.mjs)に従う。新しい状態名や技能名による専用接続を最初の試作へ加えない。既定の射撃は弾が**選ばれた敵のいる列を入口へ直進**するものとして描く。他列から狙う場合でも、その列の射線として表示する。敵の移動・HP・味方弾・防壁以外の共有物を使わない。

| 人物 | 改造なしの動作 | A（選択） | B（選択） |
|---|---|---|---|
| ゴウ | 担当列の距離1の敵を毎拍2ダメージで殴る | 生存した相手を入口側へ1マス押す | 殴った後、自分に防壁1を得る |
| ナギ | 担当列で味方に当たる**最初の敵弾一発**を毎拍防ぐ。近接は通常どおり受ける | 防いだ弾を味方弾（1ダメージ）として同じ列の射手へ返す | 遠征前に決めた隣一列の敵弾も対象にする。ただし二列を合わせて毎拍一発だけ |
| ヒバナ | 選んだ隣接二列を毎拍交互に巡回し、今いる列の距離1・2の最前敵を1ダメージで鉤打ち | 生存した相手を入口側へ1マス引き戻す | 今の列に標的がいない時だけ、もう一方の巡回列の距離1・2の敵を1ダメージで引き、自分の列の同距離が空いていれば移す |
| ゲンゾウ | 二拍ごとに全列で最も門に近い敵へ重弩の味方弾（2ダメージ）を撃つ | 自分が行動可能な間、**味方弾は同じ列の二体目も1ダメージで貫く** | 自分が行動可能な間、味方弾は最初の命中後、生き残った敵を入口側へ1マス押す |
| ツグミ | 毎拍、全列で最も門に近い敵へ味方弾2ダメージ。三拍ごとに最も傷の深い味方を2回復する | **自分の弾で敵を倒すたび**、最も傷の深い味方を1回復 | 三拍ごとの治療でHP上限から余った量を、その対象の防壁へ変える（防壁上限2） |

射撃の同距離の標的は左→中→右で決め、各行動後に選び直す。治療の欠損HPが同じならナギ→ゴウ→ヒバナ→ゲンゾウ→ツグミの順。全員が全快でもこの順に治療対象を選ぶので、ツグミBなら防壁がつく。防壁は被ダメージより先に減り、その波の終了で消える。誰の技能も他の人の固有名を効果文へ入れない。

味方の解決順は**ゴウ→ヒバナ→ツグミ→ゲンゾウ**、ナギの盾・反射はその後の敵射撃時だけ。ヒバナがゴウより先に敵を引いて近接対象を消す順序は採らないが、次拍の標的を遠ざけて損をする取得罠は残り得る。

押し戻しの行先が空なら1マス移る。敵がいるなら**動かず、押した敵と行先の敵が各1ダメージ**を受ける。衝突から二度目の押し戻しは発生しない。射撃の貫通は最初の対象が死んでも同列で入口側にいる二体目へ届き、一発につき二体まで。ゲンゾウBの押し戻しは一発の**最初の対象だけ**。ナギの反射も味方弾なのでゲンゾウA/Bの対象だが、反射弾を盾で再反射することはない。敵のHPは有限で、押すたびにダメージを与える。

これでもゲンゾウA/Bは自分の弾だけでなく全員の弾を変え、一枚が強すぎる恐れがある。行動回数・射撃密度・発火結果を見て、取得する理由が毎回AかBに固定されるなら技能を作り直す。黙って「最初の弾のみ」などの隠れた優先列は足さない。

## 2. 紙上で成立する連鎖と、成立しない条件

| 型 | 具体的な因果 | 成立しない条件・反証 |
|---|---|---|
| **衝突と貫通** | ゴウAが距離1の敵を距離2の敵へ押す→二体に衝突ダメージ→ツグミとゲンゾウAの弾が同列の二体を削る | 前の敵が殴られて即死する、距離2に敵がいない、ゲンゾウが倒れている。数値の一発差が他列の撃破へ波及しなければ演出だけ |
| **横取りと集中** | ヒバナBが手薄な列の敵をゴウのいる列へ移す→次拍にゴウの一撃が届く→射撃は空いた元の列の別敵へ向く | 移動先が埋まる、ヒバナがその拍に別の敵を殴る、移す先の方が守りが薄い。敵ごとにこれを強制すれば着替えゲー |
| **守りから射線へ** | 同じ列のナギAが敵弾を返す→返した味方弾が射手に当たる→ゲンゾウAがいれば後ろの二体目にも届く | 敵が撃たない、後ろに二体目がいない、ナギと射手の列が違う。反射だけで常に勝つなら連鎖ではなく強い一枚 |
| **撃破から持久へ** | 前拍のゲンゾウBによる弾の押し戻し・衝突で敵を弱らせる→次拍ツグミAの射撃が倒して味方を癒す→前衛がもう一拍持ちこたえる | ツグミより先に別人が倒す、回復対象が無傷、次拍までに前衛が落ちる。この型だけ勝敗が変わらなければ弱い |
| **治療から反射の維持へ** | ツグミBの超過回復がナギへ防壁を残す→同拍の一発目は盾で返す→二発目を防壁でしのぐ→次拍にもナギAの反射が可能 | 射手が一人だけなら防壁は余り、ナギBとの同時取得はできない。遠隔敵を増やしてこの型を必須化しない |

**ゲンゾウだけがコンボの接続点か**も疑う。独立の候補として、左列の距離2に敵射手、ヒバナが中列へ巡回し、中列には標的がなくナギがいる局面を置く。ヒバナBは射手を中列の距離2へ引き、同拍に射手が中列へ撃てばナギAが防いで返す。ゲンゾウの技能なしで二枚が因果でつながる。ただし、引かなければ左列の門へ当たるはずだった弾を防げる一方、射手を中列の味方へ近づけてしまう。いつも得とは限らない。この局面が自然な敵列で生じなければ「独立したコンボ」と数えない。ゴウAの衝突で弱った敵をツグミAが仕留めて前衛を治す接続もゲンゾウ不要だが、単に二人で同じ敵を殴っただけとの違いを実戦で問う。

一番上の型の一拍を数で追う。中列に距離1の敵A（HP6）、距離2の敵B（HP5）がいて、ゲンゾウがこの拍に撃つ。ヒバナは左↔中巡回の左側、右列には距離2の敵C（HP2）がいて右列の固定仲間はいない。ゴウAがAを2削って押そうとし、BにぶつかるのでAはHP3、BはHP4で距離は変わらない。ツグミの弾でAはHP1になり、**ゲンゾウAの全味方弾貫通**によってBもHP3になる。ゲンゾウの弾がAを倒してBもHP2へ削る。敵が進んで次拍にはBが中列の距離1、Cが右列の距離1へ来る。ゴウがBを倒し、ヒバナは中へ移っても標的がなく、ツグミがCを倒す。貫通がなければBはHP4のまま次拍を迎え、ゴウの2とヒバナの1を受けてもHP1で残る。既定対象は同距離なら中列が右列より先なので、ツグミはBを撃ち、Cが門へ入る。**右敵がいなければ、変わるのはせいぜい倒す時刻と前衛の被弾**である。この差を無条件に大きな「コンボ」と宣伝しない。

反射の型も射線を実際に置く。中列の距離2にHPの残る射手、距離3に別の敵、ナギは中列、ゲンゾウAが生存中。射手の敵弾が中列を来たとき、ナギが一発目だけ防ぎ、同じ列へ返す。射手が反射の1、後ろの敵が貫通の1を受ける。ツグミやゲンゾウの前半攻撃で射手が先に死ぬ場合、この連鎖は一度も起きない。敵のHPを不自然に盛って見せ場を作っていないかも検査する。

## 3. 「組合せが多い」の判定を厳しくする

上表の五行は五個の成功したビルドではない。衝突、射線、防御持久という**せいぜい三系統**が、別の発火条件で現れたものに近い。十枚の改造から数十万通りの戦略が出るとは言えず、紙上では「五人の砲台」批判をまだ退けられない。

次の技能を作る時は、まず敵HP・位置・弾・防壁という既存の物に対し、**何を入力にして何を変えるか**を書く。同じ「押して一ダメージ」の亜種を増やしても系統は増えない。入力と出力の組を増やせないなら、190節へ伸ばす形式として不適格と判断する。目先のコンボ数を増やすために秘密の状態・発動優先列・固有名依存を重ねない。

現時点の技能表は**紙上審査で合格していない**。敵弾が出なければナギAは消え、衝突しなければ押し戻しは単なる時間稼ぎで、ゲンゾウA/Bは多くの弾を一枚で変える。十枚で見せ場の型を四つ説明でき、うち二つ以上がゲンゾウの改造に依存せず、どれか一枚を外しても異なる強みが残るよう設計し直すことが先決である。この関門を通らないまま、六波を実装してバランスや演出で救わない。

小試作は六波、基本五人＋出発前に選んだ三つの改造（初期一つ、第2・4波後に一つずつ）。遅い群れ、二体の射手、左右からの小型、硬い一体を用意し、特定改造がないと倒せない敵は置かない。第1波の型を第6波で強めて戻す。比較条件は、同じ敵に対して**数値改造のみ**／上表の改造／各波に一度だけ手動命令を出せる方式。手動命令でしか戦闘が楽しくないなら、事前予約型を守るために入力を隠さない。

現行の五人オート戦闘も同じ参加者に短く遊んでもらい、勝率でなく「もう一回組み直したい」「戦闘を最後まで見たい」を比べる。三列防衛の方が意味を理解しやすくても、五人の一巡を想像する楽しさを失ったら改築の価値はない。390×844の画面で三列×四距離、最大五人、門HPと次の二拍を同時に読めなければ、場の密度だけで失格。

観察するのは、①介入なしで何波続けたか、②予約した技の前後で何が変わったか本人が予想・説明できたか、③一番好きな場面が配置と技能か、瞬間的な交代か、④数字だけの強化と好みが違うか、⑤火力・反射・持久が異なる攻略として成立するか、⑥次の遠征を寝る前に組み直したくなったか。通常波で毎回交代したい、勝因が不明、三系統のうち一つしか合理的でない、技能より手動命令だけが楽しい、のいずれかならこの形式を主案に昇格させない。

**結論は保留。** 操舵の穴を塞いだだけで面白さを得たことにはならない。三列防衛でも十枚から三系統以上を増やせない可能性は高い。その場合、さらに敵や状態を増やす前に、少数の手札を実行中に選ぶゲームへ移るか、構築を主役にする前提自体を見直す。
