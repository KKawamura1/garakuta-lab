# 捨てた案: 撃破で次の仲間へ追加行動のバトン

更新: 2026-09-29。状態: **保留ではなく棄却。** [五拍試験](./33-clock-threshold-stress.md)の後に考えた、単純な連携規則。Ballionaireの「一つが次を鳴らす」感触は魅力だが、物理球や大量の装置を五人の戦闘へ移植することを狙わない。[Ballionaire公式](https://store.steampowered.com/app/2667120/Ballionaire/)の仕組みと本案の効果は別物。

## 提案した規則

五人が固定順で通常行動し、五人の通常行動が終わるたびに生き残った敵が反撃する。敵を一体撃破したら、次の人物にその波で一度だけ追加行動が渡る。追加行動も敵を倒せばバトンが続き、途中で十二波を越えても続く。一行動で複数倒してもバトンは一本。人物の「一度だけ」は新波に入ると戻る。敵の攻撃は追加行動の間へ割り込まない。五人が次々に点灯することを期待した。

十枚の試験カードでは、ゴウの追加行動は単体6か複数へ各3、ゲンゾウは前撃の数値を写すか固定3、ヒバナは最後尾3か全体2、ツグミは射撃2＋治療2か実治療量＋1の射撃、ナギは防壁3＋射撃1か防壁1＋射撃3。通常行動は五人共通の固定値。五人のキャラクター別の追撃が波を跨いでつながるか[使い捨てPython](../../analysis/skill-reboot-kill-baton-rejected.py)で32通りを数えた。予約成長や自由な順番変更は入れていない。

| 敵HP倍率 | 追加行動なし・32通りの突破 | 追加行動あり・32通りの突破 | 成功時の最少通常行動数 |
|---:|---:|---:|---:|
| 1.0 | 32 | 32 | 109 → 58 |
| 1.1 | 0 | 28 | 64 |
| 1.2 | 0 | 30 | 74 |
| 1.3 | 0 | 25 | 76 |
| 1.4 | 0 | 18 | 84 |
| 1.5 | 0 | 0 | — |

数字が一見よいのが危ない。追加行動は明らかに勝率と速度を上げたが、上のどの倍率でも一続きの追加行動の最大は**二〜四手程度**に留まった。HP1.3倍で最速だった構成は追加行動20回を十五回前後の短い断片へ分割しただけで、五人が一気に十二波を飛び越える核心の絵は起きなかった。HPを小さくして連鎖を強制するなら、敵は何もできず治療・防壁の意味が薄くなる。HPを上げて敵を重要にすると、連鎖は止まる。

さらにバトンは「撃破した次の人へしか渡らない」。支援人物が次なら火力連鎖は止まりがちで、その人物を攻撃へ変更するのが得になる。逆に倒せる相手が続けば、守りは必要ない。**面白い連鎖の入口と支援の役割が互いを削った。** 毎波の一回制限を忘れず表示するために五枚の小さい札まで必要。これは単なる数値調整の弱さではなく、発火条件を撃破だけに置いた設計の偏り。

示した突破数は楽しさの実測ではない。32通り・一敵列・初期全技能有効・人間プレイヤーなしの範囲に限る。ゲーム内へこの案を取り込まない。次は撃破を報酬にするだけでなく、**敵の補充が五人の行動順に変化を与える**設計を考える。
