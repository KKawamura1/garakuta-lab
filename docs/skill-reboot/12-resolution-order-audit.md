# 190技能の解決順監査（PR #287）

更新日: 2026-09-23。対象: `11-weapon-catalog.md` の10武器×19節、全190節。この監査に基づく解決順・技能文面はPR #287のカタログと設計文書に反映済み。PR #288の実装と予測UIはまだ同期していない。

## 結論

計算の入口は「一度だけ作って固定する攻撃計画」とする。基礎形状・基礎hit数・使用位置・主対象・対象書換え・副対象・hitの配分・支払うRP・参照する強化段数を、ダメージを与える前に定める。**対象数による攻撃全体の倍率は、計画された異なる対象の数だけを読む。** その後の命中、受け、防壁、HP減少、撃破、移動、反応の成否を、既に確定した対象数・第1hit・倍率へ遡及させない。後から生じる効果は次のhit、次のダメージ片、次の行動、次のラウンドのいずれかに限る。

「最終的に50以上のダメージを与えたら左右にも攻撃し、その複数対象化で元の攻撃が強化される」では、最終ダメージが対象数を決め、対象数が最終ダメージを決める。例えば元の最終ダメージ45、複数化で+15%なら、対象追加なしでは45で不発、対象追加ありでは51.75で発動という相互参照になる。計算を繰り返す実装自体は可能でも、何を起点にするか決まらず、結果や表示が揺れる。**閾値を使うなら補正前の基礎値で先に判定する**か、**確定済みの実ダメージを見て別の後続ダメージを発生させる**。後続ダメージは元の攻撃を再計算しない。

## 一行動の段階

| 段階 | 確定する要素 | 後から変えてよいもの |
|---|---|---|
| 0 戦闘・ラウンド初期 | 所持技能、現在値、準備・借り・再生などの開始時処理。恒常補正を読む | この段階の数値は行動宣言時に再取得する |
| 1 宣言・準備 | 選択中の主軸、準備の必要時間・AP、基礎射程・基礎対象数・基礎hit数。準備技能は完了時に対象を選び直す | 敵の位置・状態は準備完了まで変わり得る |
| 2 対象前移動 | 駆け込み・歩法などを優先列とRPで解決し、**移動後**の位置と射程を決める | 移動eventの強化は計画固定前だけ反映する |
| 3 主対象 | 射程内候補→観測→ターゲット優先列→主軸の既定順。同率順、基準となる列・縦列を選ぶ | 後の状態変化で主対象を選び直さない |
| 4 対象反応 | 誘引による書換え・消費、盾を差す、痛みの肩代わり、引き戻し、壁抜きの先行移動など。元対象と最終受け手を別に記録する | 位置変更後の扱いを明記した技能以外、対象問い合わせへ戻らない |
| 5 攻撃開始反応 | 背を押す、迎え返しなど。反応者順・RP支払・自分の仕込み/堅牢等の使用量を確定する | 反撃で攻撃者が倒れたら本攻撃を中止し、対象の選び直しはしない |
| 5b 副対象拡張反応 | 基準対象と対象変更の確定後、計画固定前に共通窓を一度開く。振り幅・貫通・炸裂筒のうち、リアクティブ優先列で最初に条件とRPを満たす一つだけを発動し、副対象と追加ダメージを登録する | 条件不成立またはRP不足の技能は飛ばして次を検査する。同じ攻撃へ別の副対象拡張を重ねない |
| 6 計画固定 | 基礎hitへの追加、刃渡りの配分、貫通・炸裂筒などの副対象、実際に**予定された**異なる対象人数、各hitの割当を確定する | hit後にこの計画を遡及修正しない。未使用hitは死亡後も再配分しない |
| 6a hit前の防御崩し | 計画固定後、主軸がdamage前に防壁または受け構えを減らす場合、その結果の確定後に対象ごとに共通窓を一度開く | 砕けた鎧が選ばれれば破甲を付与し、続く効果量・hit計算から適用する。すでに解除された受け構えはhit後の窓で再読しない |
| 6b 効果量確定 | 最終対象人数、位置、対象状態、開始時の強化段数・消費資源から、割合補正、hit基礎量、受け無視を固定する | 後のhit結果や攻撃後の移動から倍率を再計算しない |
| 7 hit・防御・被弾 | 予定順に命中→受け構え→受け/守勢等→防壁→HPを確定。そのhitの防壁破壊・実HP損失・状態付与・追撃/反撃/回復を、対応する反応窓で処理する | 新しい破甲・防壁・怯み等は以後のhit/行動に効く。既処理hitは変えない |
| 7b 防御崩し反応 | 各hitで受け構えが減った、または防壁が減って0になった結果を確定した後に共通窓を一度開く。砕けた鎧・砕け音のうちリアクティブ優先列で最初に条件を満たす一つを解決する | 破甲や残り受け構えの除去は同hitを再処理せず、未処理hitから適用する |
| 8 攻撃後・移動後 | 生存判定、盾撃や引き打ち等の後続付与/強制移動、壁打ちの不足分、行動後の標・観測消費・堅牢消費・帰り足 | 後続の追加ダメージは別片として処理し、元の対象数・倍率を変えない |
| 9 時間境界 | ラウンド開始の借り返済・再生発動、終了時の裂傷・血へ還す・防壁失効／7持続状態の半減・持久旗→旗の守り、戦闘後治療 | 開始時は再生段数を固定・全消費してから15/段の防壁を一度付与し、その反応で新たに得た再生は次の開始時まで待つ。境界内の順は一意に決め、一度きりの効果を再判定しない |

段階6の「対象」は**有効な予定ダメージ対象**であり、命中成功・HPへの実ダメージを要しない。予定した敵へのhitが外れた、受け構えで止まった、あるいは先のhitで倒れたとしても横薙ぎの判定を取り消さない。反対に対象不在・射程外ならその候補は不成立とし、RP不足なら飛ばして優先列の次候補を検査する。候補がなければ拡張しない。攻撃の元の基礎対象数と基礎hit数は、派生後の人数/hit数と別フィールドで保持する。

反応窓は一人物につき優先列の最初に成立した一つだけを実行する。振り幅・貫通・炸裂筒は対象変更後・計画固定前の同じ副対象拡張窓を共有する。砕けた鎧・砕け音は、主軸のhit前防御除去後と各hitの防御結果後に開く防御崩し窓を共有し、対象・同一hitの状態変化ごとに一度だけ候補となる。別の時点のeventには新しい窓を開ける。パッシブは固定の段階へ加算し、イベント由来の付与は原因eventに紐づけて一度だけ処理する。追撃・反撃・防壁分配/強化複製には発生源IDを残し、同じ技能へ再入力しない。副対象への「追加ダメージ片」と独立した「追撃攻撃」は別種とする。前者は元攻撃の補正を受けるが新たな主軸を開始しない。後者は自分自身の単体攻撃計画を一度だけ作る。

## 一つのhitで使う値と順序

攻撃計画には `baseTargetCount`、`baseHitCount`、`plannedRecipients`、各hitの割当、移動前後の位置、射程、能力値、攻撃開始時の状態段数、RP支払、計画時の対象状態を保存する。「単体」「基礎hit数」は元の主軸の値、「2体以上」は計画した異なる敵の人数を見る。副対象拡張反応窓からは技能を一つだけ適用する。主軸本来の範囲と選ばれた拡張の対象が重なれば敵IDを重複排除し、追加ダメージ片はその主軸の計画へ一度登録する。派生片が新たな副対象拡張を再実行しない。

各hitは、(a)能力値×そのhitの基礎係数、(b)攻撃全体・hit限定・対象限定の割合補正を各々の決めた層で適用、(c)後列近接40%・準備中被害+50%・被害軽減等の倍率、(d)受け構えによる無効化、受け無視を差し引いた受け、(e)防壁、(f)実HP損失、の順に扱う。受け構えに止められたhitは「命中したがHPダメージ0」と区別する。防壁破壊、被弾後回復、撃破は(f)まで確定してから通知する。hitごとに防御へ配分する直前に一度だけround-half-upし、被害分割は基礎量の40/60へ割り振った後で双方の受け・防壁を計算する。割合補正は同種の段数を加算し、一行動に一度だけ適用する。予測UIも実戦と同じ計算関数を使う。**事後の状態付与をこの計算へ差し戻さない。**

副作用がある命中反応はhitごとの結果確定後に開き、追撃は明示された最大回数・RP/仕込み在庫・発生元の再帰禁止で有限にする。反応で同じ敵が死んでも、元攻撃の未処理hitを別の敵へ振り直さない。「攻撃の最後に一度」発生する処理は、予定hit列が終了してから対象ごとに一度だけ数える。

## パッシブ競合の分類監査（2026-09-23）

全55個のパッシブを読み直し、他技能が同じeventで対象・状態・発動資格を変え、優先順位で結果が変わるものを洗い出した。直接競合したのは単体攻撃の範囲拡張（振り幅・貫通・炸裂筒。前回の監査でリアクティブ化済み）と、戦槌の砕けた鎧／砕け音だった。後者を両方リアクティブにし、hit前の防壁/受け構え解除後と各hitの防御結果後に開く「防御崩し」反応窓を共有させる。同hitの結果が両方の条件を満たしても、優先列から一つだけを選ぶ。

それ以外のパッシブは、条件に使う値を該当処理段階で固定してから効果量を決めるか、別の技能の適格性・対象・同一eventの結果を変えずに加算できるため、全条件成立分を適用する。近接ダメージ+15%は近接分類を変える技能がなく、単体ダメージ+15%は攻撃対象の確定後に効果量を決めるので、どちらもパッシブのまま。広域化は横板が派生付与を作る前の基礎対象人数を読む。二拍先はAP対象確定後にRP1で追加APを付与し、借り札は借りを得た味方へ高揚1を付ける。二拍先はリアクティブとしてRP優先列を使う。

## 検証する最小ケース

1. 戦槌・長槍・重弩: 振り幅＋貫通＋炸裂筒を同時に取得し、リアクティブ優先列を並べ替える。単体近接／長射程／準備攻撃で、それぞれ最初の適格技能だけが副対象を加え、後続の拡張が重ならないこと。RP不足・条件不成立なら次の候補へ進む。横薙ぎは選ばれた拡張後の予定対象を一度だけ数える。
2. 医療・大盾: 単体防壁＋横板＋広域化＋盾の列＋重ね包帯。広域化が元の単体防壁に遡及せず、派生付与と複製が有限に止まること。
3. 大盾: 2hit、受け構え、防壁、守勢、誘引、肩代わり、裏返す。攻撃前の同一条件だけで無効化可否が決まり、hitごとの副作用で再予測しないこと。
4. 鉤縄: 強制移動が途中で塞がれた時、鉄鉤/巻き上げの元ダメージは一定、壁打ちの不足分だけ後続片になること。壁抜きで先行移動した時の高揚の作用も固定。
5. 双刃・長槍・重弩: 基礎hit判定→追加hit→刃渡し配分→途中撃破→裂傷/爆圧。未実行hitの再配分や元hitの再計算がないこと。
6. 攻撃開始反撃で攻撃者が倒れた場合、被弾後反撃で倒れた場合、観測対象が消えた場合、準備完了までに敵が移動した場合を別々に検査する。
