# 拾い火 / KINDLING 0.1

「拾ったものを、相棒の体にする。」

壊れた小さな相棒と、胸に残った最後の灯りを、夜明け前に家へ届ける短い構築ゲームです。

## 遊び方

1. 次の道を選ぶ。屋根を跳ぶか、路地を守るか。道ごとに必要な力と、失敗したときに失うものが違います。
2. 夜道で拾った二つの物から一つを選ぶ。
3. 選んだ物を、目・胸・手・脚のどこかへ組み込む。同じ物でも場所で働き方が変わります。
4. 「歩き出す」を押すと、相棒が自動で夜道を進みます。何が発動したか、画面の動きとログで確認できます。
5. 6つの場面を越え、灯りを家へ届けます。失敗しても、相棒の傷と物語が残ります。

## 設計上の主役

- 強い物を引いたかではなく、来た物をどう読んだか
- 機械的な数値ではなく、相棒の姿とふるまいの変化
- 難しさだけではなく、成長・圧倒感・演出・愛着・次の問い
- 負けても何も残らないのではなく、次の道や結末への手がかりが残る

## 記録

KINDLING 0.1は、既存の /api/runs へ次を保存します。

- seed、版、build stamp
- ルート選択、素材の提示・選択、取付先、入れ替え
- 各場面の要求、発動した行動、連鎖、結果
- 感情マーカーと任意メモ
- 最終構成、物語上の結果、終了アンケート

## 起動

公開後は次のURLです。

https://garakuta-lab.pages.dev/kindling/

seedを指定すると同じ素材と道を再現できます。

https://garakuta-lab.pages.dev/kindling/?seed=12

seedは結果を固定するためではなく、同じ問題をもう一度考えるために使います。
