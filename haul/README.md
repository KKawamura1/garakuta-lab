# 持ち帰り限界 / HAUL 0.1

ECHOの反証を受けた独立試作です。抽象的な部品数の最高記録ではなく、壊れた帰還艇を直すための部品を6区画から持ち帰ることが目的です。

各区画では「回収する」「安定させる」「深く潜る」を選びます。深く潜ると多く取れますが、危険が増え、限界を越えると船体が傷つきます。部品・危険・船体を見ながら、どこで安全を買うかを決めます。

## 検証したいこと

意味のある達成目標と、見えているリスクを押す／抑える判断が、スコア更新よりも「次はあそこで判断を変えたい」という再プレイ理由を生むかを検証します。seedはURLの `?seed=12` で固定できます。

## プレイとログ

公開時の入口は `/haul/` です。選択前後の資源、区画の脅威と回収量、崩落、感情マーカー、終了アンケートをD1へ `gameVersion=haul-0.1-goal` として保存します。
