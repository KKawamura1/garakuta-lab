# SCRAPLINE — 次担当向け最小ランブック

更新日: 2026-08-27（UTC）

## 目的と現在地

目的は、自動検査を緑にすることではなく、作者が中身を知った後も繰り返し遊びたいゲームを作ること。
現在の `scrapline-0.7` / `scrapline-build-20260827-r7` は、企画書の因果機構を壊さずに
人間へ提示できるところまで機械検証済みである。機械検査は「面白い」を証明しない。

最初に次の順で読む。

1. `AGENTS.md` — リポジトリ全体の目的と変更権限
2. `analysis/SCRAPLINE_GAME_CONCEPT.md` — 検証したい体験
3. `analysis/SCRAPLINE_IMPLEMENTATION.md` — 実装と検査の対応
4. この文書 — 実行順、判定、停止条件
5. 公開作業だけ `docs/HUMAN_TEST_RELEASE.md`

## 一コマンドの入口

作業中の短い確認:

```sh
node analysis/scrapline-agent-gate.mjs --quick
```

引き渡し前の完全確認:

```sh
node analysis/scrapline-agent-gate.mjs --full
```

最後の `SCRAPLINE_AGENT_GATE {...}` が機械可読の結果である。終了コード0だけをPASSとする。
`--quick` は局所回帰、`--full` は256 seedの到達可能性と64,471列の万能解探索まで含む。
ruleset、engine、敵・報酬、探索器を変えた場合はpush前にfullを実行する。文書、表示、保存配線だけの
変更はquickでよい。ただし公開前は変更範囲にかかわらずfullを実行する。

## 判断の順番

1. **企画上の境界を一文で言う。** 例: 「長列は全敵共通の着弾時間を払う」。
2. **観測可能な反例を一つ作る。** 正常例だけでなく、壊したら落ちる条件を決める。
3. **データ、探索、物理を分ける。** fixtureの古さ、合法手の列挙漏れ、ゲーム規則の欠陥を混同しない。
4. **最小の証人で確認する。** 一つのseed・一つの編成で因果を確認してから全探索へ進む。
5. **完全ゲートを通す。** 数字を見た後で閾値や分母を動かさない。
6. **結果と未確認を分けて残す。** 実行コマンド、終了コード、主要数値、未確認項目を書く。

### 失敗時の切り分け

| 失敗 | 最初に調べること | 禁止される近道 |
| --- | --- | --- |
| quickの固定例 | 期待値が旧rulesetのfixtureか、現在の因果機構そのものが壊れたか | 通すためだけの期待値更新 |
| seed到達可能性 | UIで可能な合法手を探索器が全列挙しているか | 特定seedへの正解報酬注入 |
| 万能固定列が1以上 | 最初の反例列と、どの敵の問いが消えたか | 列名・正確な両数・特定comboへの罰則 |
| 同seed二方針 | 二経路の採用報酬、発動機構、並べ替えが実際に異なるか | assertionを緩めて同一経路を二つに数える |
| E2E / 保存 | UI操作、ネットワーク、D1、exportのどこで欠けたか | 未確認をPASS、作者に代行依頼 |

## 変更権限

安価な実装担当だけで進めてよい作業:

- 自動検査の実行、失敗箇所の事実整理
- rulesetを変えない表示崩れ、操作不能、保存・export配線の修正
- 古いfixtureを、登録済み仕様との対応を証拠つきで修正
- 公開先390×844のE2E、リロード、D1保存、export照合
- 文書と実装マップの同期

停止して上位担当または作者へ渡す作業:

- 物理規則、敵、報酬生成、難度、数値閾値の変更
- seed到達可能性を満たすための新しい救済規則
- 万能固定列を消すための新しい相性・例外
- 人間ログから「面白い」「仮説成立」と結論する判断
- 未確認項目を残した公開、または公開可否の判断

停止時は、`期待 / 実際 / 最小再現 / 該当検査 / 変更していないもの` の5点だけを渡す。

## GitHubへ保存するときの注意

この作業環境のcheckoutはリポジトリ全体を含まない場合がある。GitHub APIでtreeを作る場合、
現在のリモート先端commitを `base_tree` にして変更ファイルだけを加える。ローカルのファイル一覧から
完全treeを再構築してはいけない。push前にリモート先端が想定parentのままか確認し、fast-forwardで更新する。
