## 1. 前提：このゲームは何か

**推測で補わないこと。**以下はすべて実装の事実である。

- **自動戦闘の遠征ゲーム。戦闘中の入力は無い**（`docs/GAME.md` §0）。
  操作は戦闘前の構成と、戦闘後の報酬・野営・撤退だけ
- 本編5人から、Stage ごとに決まった人数で **2×3 の隊列**を組み、**3幕12戦**の遠征へ出る
- **中心は戦闘予測**（`docs/GAME.md` §3）。キャンプ画面上部に、
  **次の一戦を最後まで走らせた結果**が常に出ている。各メンバーの予測 HP と減少量、勝敗、
  要したラウンド数。技能・装備・隊列を触るたびにその場で組み直される
- **予測と本番は同じ経路を通る。**構成を変えずに再生すれば予測と完全に一致する
- 技能は解禁も装着も**不可逆**。装備は**いつでも付け外し自由**（`docs/GAME.md` §4）
- **マップ探索は無い。**12戦の梯子である。4・8・12戦目が act boss（**ボスは3体**）
- 1ランはプレイヤー体感で数十分

つまり遊びの本体は戦闘の前にある。**負ける未来が先に全部見えていて、
隊列と技能と装備を組み替えて、勝てる未来に差し替える。**本戦は答え合わせに近い。

## 2. 前提：世界（設計文書の要点）

出典は `analysis/CAST_REBOOT_TWELVE_TOMORROWS.md`。

**固定因果**（§2.1）— 坑では戦闘条件が確定すると結果も確定する。潜行員は携帯型の
〈先見機〉でその固定未来を戦闘前に読み出せる。**表示されるのは確率ではない。**

```
  > 勝利 / 7巡
  > ゴウ   　128 → 43
  > ツグミ 　104 → 0
  > ヒバナ 　 96 → 17
```

**記憶剥離**（§2.2）— 坑の中で形成された**具体的なエピソード記憶**は、外へ出ると崩れる。

| 残るもの | 失うもの |
|---|---|
| 坑へ入る前までの人生 | 誰とどんな会話をしたか |
| 外で読んだ日記・映像・報告書の内容 | 第何戦で誰が倒れたか |
| 身体に残った傷や疲労 | どの瞬間に誰を好きだと思ったか |
| 人間関係についての知識 | 深部で何を恐れ、何を決めたか |

> 危険な経験を何年しても、その「経験した実感」が十分には積み上がらない。

**坑外崩壊**（§2.3）— 坑で生成された〈遺装〉は外へ持ち出すと崩れる。帰還時に**一つだけ**
定着処理でき、その一品には来歴が残る。

> 本人はその遠征を忘れている。だから装備は、**失われた冒険の物証**になる。

**5人** — ゴウ(24)・ツグミ(15)・ナギ(22)・ヒバナ(11)・ゲンゾウ(71)。喜劇の配役を持つ。
温度は暗くない。

### 尺度の誤りについて（重要）

「明日」と「昨日」は**どちらも実際の尺度より大きい**。

- 見えるのは**次の一戦、七巡ぶん**の確定結果であって、日ではない。次の一戦の先は見えない
- 消えるのは**一回の遠征のエピソード記憶**であって、過去でも一生分の記憶でもない

「明日」は PR #80 の題『十二の明日をほどく』と Scenario 1「明日の死者」から引き継いだ語で、
**機構と一度も対応していない。**設計文書側のこの二箇所も点検対象である。

## 4. 調査して分かった型

### RPG の題の型

1. **探索する場所を名詞にする** — 『世界樹の迷宮』『Darkest Dungeon』『Baldur's Gate』。
   世界樹の迷宮は「現代の自分達が『ウィザードリィ』が生まれた時と同じ視点に立ったら
   どうなるか」をコンセプトに作られたシリーズで、題は潜る場所そのもの。
   **作品名＝舞台名は RPG では正常**であり、地域名との重複は欠点にならない
2. **プレイヤーが追う物・機構を固有名詞にする** — `Elden Ring`／『諸王の聖杯』
3. **世界法則・現象を漢字で圧縮する** — 『真・女神転生』『十三機兵防衛圏』。
   十三機兵防衛圏は「13人が機兵に乗って防衛戦をやる」から、と開発者が説明している
4. **職能・人数を言う** — 『オクトパストラベラー』（8人の旅人）『風来のシレン』
5. **メイン題＋サブ題** — 『世界樹の迷宮II 諸王の聖杯』。シリーズを継ぎ足す器

### 日本語と英語の長さの違い

英語題は名詞句一つで完結する（`Into the Breach` / `Loop Hero` / `Darkest Dungeon`）。
日本語で同じことを漢字4文字でやると報告書の見出しになり、座りが悪い。
日本語RPGの主流は **「の」で繋いだ6〜10モーラ**——世界樹の迷宮(9)、風来のシレン(7)、
不思議のダンジョン(9)、灰の遠征(6)。『十三機兵防衛圏』は例外扱いでよい。

### 俳句の型（作者からの補助線）

- **一物仕立て**（一つの物を深く描く）と**取り合わせ**（離れた二物を並べる）がある。
  初心者に勧められるのは取り合わせで、理由は一物仕立てには新しい発見が要るから
- **二物衝撃** — 離れた二つを並べて相乗効果を出す
- 決定的な一行：**「取り合わせる季語は、俳句のタネに近すぎない方が素敵な句になる。
  近すぎると当たり前の一物仕立ての句のようになり、オリジナリティがなくなる」**

これが §3 の失敗の診断そのものである。「灰の辺境」（灰＝荒れた場所／辺境＝荒れた場所）も
「明日の隊列」（どちらもゲーム機構の語）も、**近すぎる取り合わせ**だった。

### 『ぼくらの太陽』の分析（作者による）

> 「太陽がとても重要で、貴重で、かつそれが味方全体で共有されている」という
> **現実との差分**が、たった6文字8モーラで表現されている。

作りは **普通名詞（太陽）＋その普通さを壊す修飾（ぼくらの）**。しかも二語の register が
最大限に遠い（天体／人称）。**そしてこの題はジャンルを一言も言っていない。**
言っているのは世界の差分だけである。したがって
**題にジャンル表示を求めるべきではない。ジャンルは絵とサブ題が言う。**

## 5. 候補にかける検査

1. **尺度が正確か。**見えるのは次の一戦。消えるのは一回の遠征。日・過去・一生に広げていないか
2. **二物の register が遠いか。**近すぎる取り合わせは当たり前になる
3. **名詞か。**文になっていないか（文はADV・ノベルの題に見える）
4. **6〜10モーラか。**「の」で繋がるか。漢字4文字の圧縮になっていないか
5. **想起されるゲームが実物と一致するか。**探索RPG・ボスラッシュ・経営ゲームに見えないか
6. **既存作と衝突しないか。**検索して一意か
7. **実装への波及。**`REGION_LORE.ash_frontier.displayName`（灰の辺境）との関係、
   公開済み ID の引っ越しが起きないか、`contract-snapshot.json` の再生成が要るか

## 6. 未決の一点 — 主題をどれに置くか

**題より先にこれを決める必要がある。**設計文書 §0 の主題「人は、記憶と記録の総和なのか」は
尺度が実装と合っていない（一生分の記憶を含意している）ことが分かったため、主題自体が未決。

| 主題 | 根拠になっている実装 |
|---|---|
| **A. 記憶と記録の総和**（現行 §0） | ほぼ無い。尺度が実装と二桁ずれている |
| **B. 経験が積み上がらない** | SP は遠征中の実戦経験で帰還時に失う（§5の表）／装備非持ち越し／成長は横方向のみ（AGENTS.md）／ゲンゾウ71歳の設定はここから導出済み（潜るのをやめた人間しか老成しない） |
| **C. 残るのは物証だけ** | 一品だけ定着処理して持ち帰る／来歴表示（「第7〜12戦：ツグミ使用」）／壁の写し（同じ物を二度拾えるとは限らないので形のほうを残す）／家が増えていく |
| **D. 覚えているのはプレイヤーだけ** | 先見機（完全情報）と記憶剥離（記憶ゼロ）が同居している理由がこれ一つで説明される。ローグライトの暗黙の約束を世界法則として明文化したもの |

**この文書を書いた時点での推奨は C を主題に置き、D を構造の説明として持つこと。**

- C は、プレイヤーが毎ラン最後に実際にやる操作（どの一品を持ち帰るか）と主題が同じものを指す
- B は世界法則としては正しいが、プレイヤーの手が動かない
- D は題にしにくく、Aftermath の書き方に効く

ただしこれは**未確定**であり、作者はまだ選んでいない。
