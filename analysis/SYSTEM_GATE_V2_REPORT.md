# ゲームシステム絶対足切り試験 v2 2026-08-17

## 問い

平均的に勝ち筋が多いシステムではなく、各ランで渡された材料から、人間が現在の敵だけを見て勝敗を動かせるシステムを選べるか。

旧評価は候補間の相対比較としては機能したが、全知勝率を約75%へ正規化したため、最善でも負けるランを25%程度許容していた。CYCLE 0.1の人間テスト2ランは、全報酬経路・全配置を探索しても第5戦を越えられず、この欠落を実証した。

## v2で追加した足切り

- 500シードそれぞれについて、全32報酬経路と全配置を探索する。
- 平均だけでなく、勝ち筋ゼロ率と勝利経路割合の下位10%を見る。
- 現在の敵だけを評価し、隣接交換・控えとの入替を3回まで行う局所探索プレイヤーを置く。
- 並びをほぼ変えない素朴プレイヤーとの差を「判断の効果量」として見る。
- 次戦成績がほぼ同じなのに片方だけ将来詰む分岐を数える。
- 報酬のどちらも現在・近似最善構成へ寄与しない死に2択を数える。
- 各部品種をラン全体から一つずつ除き、固有部品・役割の必須性を調べる。
- D1で観測した2件の失敗ランを固定回帰ケースにする。

閾値は仮置きであり、単一スコアへ合成しない。目的は面白さの判定ではなく、人間テストに値しない構造の棄却である。

## 主要結果

500通常シード、役割欠損120シードで比較した。

| 指標 | 現行 CYCLE 0.1 | 発電・蓄電の多用途化 | 多用途化＋検証済み乱数 |
|---|---:|---:|---:|
| 勝ち筋ゼロ率 | **31.2%** | 1.8% | **0%** |
| 勝利経路割合・下位10% | 0% | 46.9% | **56.3%** |
| 現在敵＋局所探索の勝率 | 52.0% | 97.6% | **100%** |
| 素朴プレイヤー勝率 | 4.2% | 53.0% | 56.2% |
| 判断の効果量 | 47.8pt | 44.6pt | **43.8pt** |
| 不可視の将来罠 | 12.0% | 8.7% | **0%** |
| 死に報酬2択 | 14.5% | 3.4% | **3.3%** |
| 最弱の役割欠損勝率 | **0%** | 91.7% | **91.7%** |
| 生成候補の採用率 | 100% | 100% | 84.6% |

現行版では盾をラン全体から除くと全知勝率0%、砲を除くと9.2%だった。敵を10%弱体化しても盾なし勝率は0%のままであり、数値調整だけでは役割待ちを解消しなかった。

発電機へ攻撃3、蓄電器へ装甲3を追加すると、特定の消費先がなくても供給部品が現在価値を持つ。勝ち筋ゼロ率は31.2%から1.8%へ減り、盾なし91.7%、砲なし93.3%まで改善した。D1で観測した2件の失敗ランも、同じ初期部品・同じ4回の報酬提示から第5戦を越えられる。

ただし多用途化だけでは、13.4%のシードに少なくとも一度、次戦ではほぼ同等に見えるのに片方だけ将来詰む分岐が残った。数値を3〜5%緩和しても消えなかったため、これは難易度ではなく不可逆な報酬選択とラン生成の問題と判断した。

そこで、ラン開始時に初期部品と全報酬列を生成し、次の条件を満たさない候補だけ引き直す案を比較した。

- 全知で勝ち筋が存在する。
- 全32報酬経路の25%以上が勝てる。
- 次戦成績がほぼ同じなのに片方だけ将来詰む分岐がない。

84.6%の生成候補がそのまま採用され、残り15.4%だけを棄却すれば全足切りを通った。素朴プレイヤー勝率56.2%に対し、局所探索プレイヤー100%で、最大耐久を増やしただけの簡単化とは異なり、並べ替え判断の差も43.8pt残った。

## 判断

現行CYCLE 0.1と数値緩和案は棄却する。固定本体案は改善したが、盾・砲欠損への耐性が不足し、部品が本体の上積みに寄りやすいため採用しない。

次の人間テスト候補は **発電機・蓄電器の多用途化＋検証済み乱数** とする。ただし、これは面白さの証明ではない。人間テストでは次を反証する。

1. 発電機は常に前、蓄電器は常に入れる、という新しい固定順位にならないか。
2. 攻撃3・装甲3の副効果が理解コストを増やさず、欠品ストレスだけを減らすか。
3. 局所的な並べ替えで改善方向を実際に発見できるか。
4. 勝率が高くても緊張が消えず、「自分がうまく作った」と感じるか。
5. 報酬で既存部品の評価が逆転し、最終構成ではなく経緯に固有性が出るか。
