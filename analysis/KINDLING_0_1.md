# KINDLING 0.1 実験票

更新日：2026-08-26

## 問い

難易度と規則の複雑さを増やさなくても、次の体験を一つの短いランで接続すれば、作者が「次は別の相棒を作って試したい」と思うか。

- 来た材料を自分の構成へ読み替える
- 構成が相棒の見た目とふるまいへ返る
- 弱い開始状態から、途中で明確に強くなる
- 失敗しても相棒と物語に変化が残る
- 結果が予兆、行動、派手な反応として返る

## 大きな変更

EMBERLINEまでの「部品の数値と戦闘結果を読む」構造をいったん外し、部品を生きた相棒の部位へ組み込む。道には具体的な問いを置き、選択の結果をCanvasアニメーションと短い物語で返す。

## 保持するもの

- ランダムに来る材料を、問題として扱う
- 材料の価値が取付先と状況で変わる
- 構築中心、短時間、seed再現
- 自動実行を構築の答え合わせにする
- プレイログ、感情マーカー、任意メモ、終了アンケート
- 人間テスト前に自動検査と公開先E2Eを行う

## 最小ルール

- 相棒には目・胸・手・脚の4つの部位がある。
- 各素材は、取付先によって別の行動になる。
- 各場面で二つの道から一つを選ぶ。道は異なる要求と報酬を持つ。
- 道を選んだあと、二つの素材から一つを選ぶ。
- 素材は空き部位か既存部位へ付け替えられる。歩き出した後は固定される。
- 道の要求を満たせば灯りが増え、失敗すれば灯りが一つ減る。
- 灯りが0になると失敗。ただし、失敗したランにも傷・記憶・結末を残す。
- 6場面を通過すると成功。

## 体験上の仮説

1. 物の名前と取付先が、単なる資源名より相棒への愛着を作る。
2. 数値の増加を姿・動き・音へ翻訳すると、構築の有能感を感じやすい。
3. 道に具体的な目的を置くと、現在の選択に重みが出る。
4. 失敗後にも相棒の反応と物語が続くと、敗北が次の問いになる。
5. 新要素の解禁と、同じ素材の別用途が、低い規則複雑さでも再プレイを作る。

これは複合仮説であり、KINDLING 0.1だけで各要因の因果を分離しない。縦切りの体験として作者が再プレイしたくなるかを先に見る。支持された場合、次に演出・物語・構築の対照版を作る。

## 成功信号

- 「この物をここに付けたから、こうなった」と具体的に言える
- 相棒の変化や発動の瞬間を、勝敗以外の出来事として語る
- 道の選択に本気で迷う
- 失敗後に、次に変える構成または見たい結末を言える
- 終了後に、同じseedの再現ではなく別の道・取付先・素材を試したい
- 終了画面の姿・履歴・物語を見返す

## 失敗信号

- 取付先ごとの最適解が常に固定される
- 二つの道が同じ数値問題に見える
- 派手な演出はあるが、自分の選択と結びつかない
- 相棒の見た目が変わっても、何をしたか意味がない
- 失敗がただの損失になり、次の問いがない
- 途中で一つの構成が完成し、残りの選択が消える
- storyや解禁を増やさないと一周目の満足が成立しない

## 公開前の受入条件

- HTML/CSS/JavaScriptの構文と主要状態遷移を自動検査する
- seed再現、全6場面の成功・失敗、素材の取付・交換、道の両分岐を検査する
- Canvasが390×844相当で画面内に収まる
- 途中リロードから復旧する
- 勝利・敗北の最終画面、最終構成、履歴、surveyを確認する
- emotion markerへ任意メモを紐づける
- 公開先で最長経路を通し、D1保存とexport照合を確認する
- versionとbuild stampを表示する

## 判定

自動検査の合格は、相互作用とログが存在することの証拠であり、面白さの合格ではない。作者の1〜2ランを待って、面白さ、再プレイ度、記憶に残った瞬間、次の具体的な計画で判定する。


## 2026-08-26 balance revision: 選択を死なせない

初回の公開前ブラウザ確認と、seed 6・12・ランダム相当の経路探索で、次の問題を発見した。

- 1場面目の初期形によって、表示されたルートの片方が「追加素材を1つ入れても必要な2軸を満たせない」場合があった。
- 2場面目以降にも、前場面を通過しても次のルートへ一手で繋がらない状態が残った。
- これは難易度の問題ではなく、プレイヤーが選択の結果を学習できない「死んだ選択」の問題である。

そこで、初期形を「つながり＋灯り」にし、提示素材を不足量まで満たせる候補へ寄せた。さらに、速度→火花→跳躍、守り→修復、あたたかさ→なおす→帰還という連鎖を6場面のデータに接続した。経路探索では seed 6・12・20260826 の各条件で6場面の成功列を確認した。

この修正は「全ルートを勝てるようにする」ものではない。選んだ道と組んだ体が次の場面の下地になること、失敗はその連鎖を外した結果として読めることを狙う。公開後は、成功率よりも次を観測する。

1. プレイヤーが素材の部位変更を自分の発見として語るか。
2. 失敗後に、同じ答えの再試行ではなく別の道・別の形を試すか。
3. 最終的な「帰った」は、物語だけでなく自分の組み方の帰結として受け取られるか。


## 2026-08-26 browser E2E finding: 触ったあとまでを一つのループと数える

公開画面で実際に「素材を選ぶ → 部位へ組み込む」まで操作したところ、組み込み後に selectedPart が空になる一方、開始ボタンの有効条件が selectedPart の存在になっており、歩き出せない不具合を発見した。自動的なルール検査では検出できなかった。

開始条件は「素材を選択中ではないこと」に修正した。以後の結合テストでは、表示・選択・組み込み・開始・結果までを一つの導線として確認する。


## 2026-08-26 browser E2E finding: seed実験は保存状態を混ぜない

seed 12の途中状態を保存したまま、別seedのURLを開いても同じ保存キーから途中状態が復元されることが分かった。これはseed比較の入力を壊す。

明示seedのURLではseedごとにlocalStorageの保存領域を分け、同じseedでは再開できるように修正した。seedを指定しない通常ランは従来の既定領域を使う。


## 2026-08-26 follow-up: 不足量を満たす素材を出す

seed 6の公開E2Eで、初期所持品と同じ鏡が候補に出ることを確認した。重複そのものはルール上使えるが、初見では「何を選べば意味があるか」を濁す。候補生成を、未装着かつ不足している値を一手で満たせる素材を優先するよう修正した。該当がない場合だけ、同じ軸の未充足素材へフォールバックする。

- 速度・守り・あたたかさの連鎖が実際の公開画面で成立し、2場面目と3場面目に「受け流し」、最終場面に「なおして、あたためる」が表示された。

- テスト中は「感想を送る」を押していないため、ユーザーの感想データをこのE2EからD1へ送信していない。

これは公開版の結合と到達可能性の証拠であり、面白さの合格ではない。次の人間テストでは、特に「部位を選んだことが相棒の行動として記憶に残ったか」「別の道や別の形を試したくなったか」を聞く。


## 2026-08-26 author test: KINDLING 0.1 仮説は不支持

D1 exportの最新20件に、作者のKINDLING 0.1の完了ランが1件含まれていた。

- run: `bb5db3fc-02fd-4031-9974-4d0af8284406`
- seed: `333789230`
- 所要時間：約19分
- 到達：6 / 6場面（4通過、2失敗。最終ルート失敗で終了）
- 面白さ：1 / 5
- 再プレイ度：1 / 5
- 感情マーカー：11件、すべて「わからない」
- 最終自由記述：「言葉が意味不明。何をしているのかわからない。ゲームとしてもどこが面白いのかわからない。自分の選択が意味を成している気がしない。」
- 次に試したいこと：「なし」

### 行動列から分かること

初回の「屋根を跳ぶ」で、素材の選択をテープと羽の間で7回変更した後、羽を脚、テープを手へ組み込んだ。次の「胸を張って守る」では釘を胸へ組み込み、「受け流し」が発動した。しかし、結果画面では「胸を張って守るを歩いているとは？」「受け流し？」と記録している。

3場面目では「橋をつなぐ」を選んだが、なおす・灯すの要求を満たす素材を組み込まず、そのまま歩いて失敗した。直前に「あ、詰んだ？」、その後に「ステージを選ぶまで何ができるかわからないので、運ゲーでは？」と記録している。これは、失敗が次の構築仮説にならず、要求値を見て詰みを判定する体験になったことを示す。

### 仮説ごとの判定

| 仮説 | 判定 | 根拠 |
|---|---|---|
| 素材名と取付先が相棒への愛着を作る | 不支持 | 所持素材・取付結果・相棒の行動がプレイヤーの中でつながらず、「自分の選択が意味を成さない」となった |
| 数値を姿・動き・音へ翻訳すると有能感が出る | 不支持 | 「受け流し」が発動しても意味が理解されず、コンボ名が追加の謎になった |
| 具体的な道の目的が選択に重みを出す | 不支持 | 「鉄の犬」「帰るべき窓」「記憶が残る／灯りが戻る」の関係が説明されず、目的と報酬のトレードオフになっていない |
| 失敗後も物語が続けば、敗北が次の問いになる | 不支持 | 失敗後に「何を変えればよいか」ではなく「詰んだ？」が残った |
| 同じ素材の別用途と新要素が再プレイを作る | 未成立 | 別用途を試したいという具体的な次の計画は生まれず、再プレイ度は1だった |

### 問題の層

今回の主因は、物語が短いことではない。抽象的な語彙・世界設定・要求値・結果演出が、プレイヤーの行動と結びつかないまま同時に提示されたことである。

- 「音を返して霧の厚みを読む」「次の一度は、すぐそばだ」「胸を張って守る」「火花で走る」は、何を操作し、何が起きるのかが自然な日本語としても行動としても読めない。
- 「帰るべき窓」が何を指し、プレイヤーと相棒がどの関係にあるのかが導入されていない。長編化すれば解決する可能性はあるが、最初の行動の意味が分からない状態では長編化による改善を仮定できない。
- ルートを選ぶまで、提示素材が要求をどう変えるかが分からない。さらに要求値が明示されるため、ルート選択後は不足値を満たす部品を置くだけになり、組み合わせの発見になっていない。
- 結果ストーリーは主にルートの成功・報酬に紐づき、素材や取付先を選んだ因果が見えない。コンボも「何と何が、なぜ、何を変えたか」が結果画面で理解できない。
- 「記憶が残る」と「灯りが戻る」は将来価値や現在価値として説明されず、意味のある選択ではなく未説明の分岐になっている。

なお、今回の最初の3件の感情マーカーに同じメモが付いているのは、マーカー押下後に入力欄をクリアしていなかったUI不具合による。これは今回修正した（PR #29）ため、3件の同一文を独立した発言数として解釈しない。ただし、残りの「わからない」マーカーと自由記述だけでも、理解・因果・再プレイの仮説は明確に不支持である。

### 判断と次の受入条件

KINDLING 0.1は「本気のゲーム」としては不採択とする。失敗作として実装・ログ・感想は残し、文章の言い換えや場面追加だけで延命しない。

次の試作では、長期ループを実装する前に、最初の1場面で次を成立させる。

1. プレイヤーが「誰と、何のために進むか」を一文で言える。
2. 「素材 → 取付先 → 相棒の具体的な行動 → 目の前の問題への作用」が一続きで見える。
3. 結果画面で、選んだ素材・部位・行動が成功／失敗の原因として表示される。
4. 組み合わせは数値の合計ではなく、二つの行動が変化して新しい行動になることが見える。
5. 失敗した直後に、プレイヤーが「次はこれを変える」と具体的に言える。
