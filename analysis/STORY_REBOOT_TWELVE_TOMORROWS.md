## 0. 目標

このゲームの強みは、戦闘そのものより**「結果を完全に先読みし、隊列・技能・装備を組み替えて勝てる未来へ寄せる」**ことにある。

物語側でも同じ主題を扱う。

- 未来は完全に読める。
- しかし過去は、灰庭から帰るたびに抜け落ちる。
- 数字は嘘をつかない。
- だが、人が何を思い、なぜ誰かを選んだかは数字だけでは残らない。

中心テーマは次の一問。

> **人は、記憶と記録の総和なのか。**

プレイヤーは戦闘では完全情報を得る一方、人物については不完全な記憶と不完全な記録を頼りに関係を積み上げる。

# 2. 舞台：〈灰庭〉

「迷宮」という語は使わない。

旧市街の地下から広がる異常領域を、人々は**〈灰庭〉**と呼ぶ。

外から見れば地下遺構だが、内部では距離・物質・記憶の保存則が崩れている。深度ごとに景観も法則も異なり、同じ経路を二度通っても同じ物が見つかるとは限らない。

人々は「迷宮へ入る」ではなく、

- 灰庭へ降りる
- 第二深度へ潜行する
- 層域を越える
- 結節を断つ

と言う。

## 2.1 起源

約40年前、国家研究施設〈明日観測所〉が未来予測研究中に事故を起こした。

施設は消滅せず、周辺を巻き込んで現実から半ば切り離された。

その跡にできたのが灰庭。

事故以降、灰庭では「まだ起きていない出来事」が、条件さえ固定されれば一意に定まる。

# 3. 灰庭の三つの法則

## 3.1 固定因果

灰庭では、戦闘条件が確定すると結果も確定する。

敵、味方、現在HP、隊列、技能、装備が同じなら、同じ戦闘は必ず同じ結果になる。

潜行員は携帯型の〈先見機〉で、その固定未来を戦闘前に読み出せる。

表示されるのは確率ではない。

> 勝利 / 7巡
> ハル 128 → 43
> コヨリ 104 → 0
> ヒバナ 96 → 17

という**確定結果**。

隊列や装備を変えれば初期条件が変わり、別の未来が表示される。

### ゲームとの対応

- Preview = 先見機による固定未来の観測
- 本戦 = 観測済みの未来を実行する
- 同構成なら完全一致 = 世界法則そのもの

---

## 3.2 記憶剥離

灰庭の中で形成された**具体的なエピソード記憶**は、境界を越えて外へ出ると崩れる。

失うのは「遠征中に何が起きたか」。

残るもの：

- 灰庭へ入る前までの人生
- 外で読んだ日記・映像・報告書の内容
- 身体に残った傷や疲労
- 人間関係についての知識
- 理屈として学び直した事実
- 理由を説明できない感情の残滓

失うもの：

- 誰とどんな会話をしたか
- 第何戦で誰が倒れたか
- どの瞬間に誰を好きだと思ったか
- 戦闘中に身につけた身体感覚
- 深部で何を恐れ、何を決めたか

このため潜行員は年齢の割に独特の幼さを持つ。

危険な経験を何年しても、その「経験した実感」が十分には積み上がらない。

妙に実務的なのに妙に無邪気、修羅場慣れしているのに感情処理だけ未熟、というアンバランスさが灰庭潜行員の特徴になる。

ただし人格が毎回初期化されるわけではない。外で日記を読み、仲間と話し、自分なりに意味づけたことは次の遠征へ持ち越される。

> 何があったかは覚えていない。
> でも、その人の隣にいると安心する。

という関係が成立する。

---

## 3.3 灰外崩壊

灰庭で生成された特殊物質〈遺装〉は、外へ持ち出すと急速に崩れる。

ただし帰還時に一つだけ、高価な〈定着処理〉を施せる。

定着した遺装だけは次の潜行へ持ち込める。

この一品には、性能だけでなく来歴を残す。

例：

> 白銀の留め針
> 第六層域「雨のない街」で発見
> 第7〜12戦：コヨリ使用
> 第12戦後、本人の希望で定着

本人はその遠征を忘れている。

だから装備は、**失われた冒険の物証**になる。

# 4. ゲームシステムの物語上の意味

| システム | 物語上の意味 |
|---|---|
| 戦闘予測 | 先見機が固定未来を読み出す |
| 隊列変更 | 未来の初期条件を変える |
| SP | 遠征中に得た実戦経験。帰還時に記憶剥離とともに失う |
| スキル解禁 | 「さっきので分かった」という、その遠征中だけの学習 |
| 装備 | 灰庭で生成された遺装 |
| 装備リセット | 灰外崩壊で失われる |
| 1つ持ち帰り | 一品だけ定着処理できる |
| 補給 | 灰庭内で使える医療・凝固・触媒資材 |
| SPを諦めて補給+1 | 戦闘後の短い安定時間を「復盤」に使うか「採取・調合」に使うかの二択 |
| 4,8戦目後の全快 | 結節を断つと安全域が生まれ、まとまった治療時間が取れる |
| 12戦 | 一層域を維持する三つの結節を順に断つ。4/8/12が結節守護体 |

## 4.1 SPか補給か

戦闘後、次の灰流が来るまでの安定時間は短い。

その時間でできることは一つ。

### 復盤する

5人で直前の戦闘を振り返り、身体が覚えているうちに動きを詰める。

→ Skill Point

### 採取・調合する

灰庭内でのみ効く薬材・凝固剤・触媒を採取して補給品を作る。

→ Supply +1

つまり、

> **強くなるために今の戦いを学ぶか、次の傷に備えるか。**

という選択。

# 5. 巻き戻しは常用能力ではない

先見と巻き戻しは別物にする。

## 先見

- 常用
- 既知技術
- 未来を見るだけ
- 現実は変えない

## 〈帰環杭〉

潜行開始時に設置する緊急安全装置。

- 灰庭内でしか作動しない
- ごく狭い範囲・短時間だけ
- 致命的事故時に直前の局所状態へ戻す
- 莫大な備蓄を消費するため通常運用では使えない
- 使用者の記憶も戻るため、便利な経験稼ぎにはならない

Scenario 0の最初の一戦だけ、先見機が故障した状態で本当に敗北する。

帰環杭が一度だけ作動。

同じ場所へ戻る。

コヨリが先見機を応急修理し、今度は「負ける未来」を戦う前に見る。

ここでゲームの中心ルールをプレイヤー自身に体験させる。

# 8. 関係性

5人を「男主人公＋女性4人のハーレム」にしない。

恋愛はハル―コヨリを中心に薄く長く進める。

他にも同程度に太い関係線を作る。

## ハル ↔ コヨリ

幼馴染。

遠慮がない。

コヨリの好意はストーリーが進むほど明白になるが、告白で消費しない。

「帰還した後も一緒にいる」こと自体が関係の中心。

## ヒバナ ↔ スミ

正反対。

ヒバナが喋り、スミが一言返す。

スミはヒバナを庇う。

ヒバナはスミを笑わせようとする。

二人には過去の共有記憶があるが、互いに覚えていない。

## ハル ↔ リツ

どちらも記録至上主義から始まる。

似ているからぶつかる。

最終的には最も理屈を交わせる相手になる。

## コヨリ ↔ リツ

知性同士。

コヨリはリツの「全部説明できる」態度が嫌い。

リツはコヨリが理屈よりハルを優先する瞬間に興味を持つ。

## コヨリ ↔ スミ

コヨリは「過去の記憶を戻したい」。

スミは「戻す必要があるのか」と疑い始める。

テーマ上の対立軸。

# 9. 12戦のドラマ構造

各Scenarioを3幕として使う。

## 1〜4戦：Want

今回の具体的な目的を置く。

4戦目ボスで最初の障害を突破し、予想外の情報を得る。

## 5〜8戦：Conflict

最初の目的だけでは解けない問題へ変わる。

仲間内でも意見が割れる。

8戦目で意味を反転させる情報を置く。

## 9〜12戦：Choice

最後は「強い敵」だけで終わらせない。

そのScenarioの中心人物が何かを選び、その選択を実行するための12戦目にする。

## 帰還後：Aftermath

本当のエンディング。

全員が遠征中の具体的記憶を失っている。

記録、装備、傷、感情の残滓から、自分たちが何を選んだかを知る。

# 13. 会話を書くときの原則

## 13.1 属性を言わせない

「私は元気な子です」「私は賢いです」を台詞で説明しない。

- ヒバナは話す速度と行動で元気さを出す
- コヨリは観察の細かさで賢さを出す
- スミは返答の短さと行動で感情を出す
- リツは説明の精度と、説明できないものへの苛立ちで知性を出す

## 13.2 好意を説明しすぎない

コヨリは「ハルが好き」と長く独白しない。

- 睡眠時間を覚えている
- 体調変化に細かい
- 遠征後も日常へ戻る前提で話す
- ハルの兄探しを邪魔しない

という行動の累積で見せる。

## 13.3 キャラは主人公のためだけに存在しない

各人物に、ハル不在でも成立する関係と目的を持たせる。

## 13.4 記憶喪失を安い感動装置にしない

毎回「忘れちゃった、悲しい」を繰り返さない。

忘れることが社会制度、仕事、恋愛、責任、医療、記録文化へどう影響するかを日常側でも描く。

## 13.5 帰還後を必ず描く

12戦目が終わりではない。

失われた遠征を、残った人間がどう受け止めるかが各Scenarioの締めになる。
