# 実験票と回答の対応表

各実験フォルダでは、`R`を要求（Request）、`A`を回答（Answer）として番号を振る。

- `R01`: 実験票。本文中の要求IDと回答ファイルを対応付ける。
- `A01`以降: 要求ごとの回答。ゲートはA〜Dを分割する。
- 旧ファイル名の詳細ログは、既存記録を保持するため残し、番号付き回答から参照する。
