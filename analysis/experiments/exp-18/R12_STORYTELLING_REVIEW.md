## 1. 結論

R11 は物語について一つの賭けをした。参照作品（ドラクエ／世界樹の迷宮）から
**「会話は増やさない。投資先は立ち絵の情報量と、読める設定」**と決めている
（R11 §1「参照作品からの帰結」）。

実装されたのは、**その半分だけ**である。

| R11 が投資すると決めたもの | 実装状態 |
|---|---|
| 立ち絵の情報量（5人 × 8表情、差し色、立ち位置、mood） | **入っている。**`portraits.mjs` / `story.mjs` / `renderStory` |
| 読める設定（世界樹のギルドカードにあたるもの） | **どこからも読めない。**R11 §2・§4・§5 の全文が設計資料の中だけにある |

つまり R11 の賭けは、いま**成立も反証もしていない**。作者が Gate で
「この人たちを好きになったか」を判定しても、判定対象の片翼が画面に出ていない。

**最優先は、賭けを測れる状態にすること。**具体的には次の3つ、この順である。

- **A. 読める設定の面を作る**（R11 §9.5）— R11 が愛着の源として選んだ側を実装する
- **B. 世界の声を、既にある画面へ載せる** — 会話を増やさずに物語を増やす唯一の道
- **C. 幕（4・8・12戦目）に短い断片を置く** — いま12戦の中が完全に無音である

立ち絵の画像化（R11 §9.2、40枚）は**この3つより後**でよい。理由は §5 に書く。

## 3. なぜ「会話を増やさない」が「物語がない」になったか

R11 の判断そのものは正しいと考える。ドラクエも世界樹も、仲間の台詞量は多くない。

ただし両作は、**会話が薄い代わりに世界の側が喋り続けている**。

- 町のNPC、宿屋、酒場の一言
- モンスター図鑑の解説文
- 道具・装備のフレーバーテキスト
- 階層／地方ごとの短い描写

灰の遠征には、**この受け皿が一つも無い。**確認したところ:

- 敵カードが持つのは `ENEMY_TARGETING`（`ecology/content/encounters.mjs:103-117`）
  だけで、「前列の生存者を、左から狙う。」のように**純粋に機械的な一文**である。
  世界の側の声はゼロ。しかも `husk` 系5種は表に無く、既定文へ落ちている
- R8 §3.2 は ProfileState に**「図鑑」**を挙げているが、未実装。
  `app.js:1896` の `codex` は装備の未入手一覧であって、図鑑ではない
- 生成装備と Blueprint は rule 文だけを持ち、**由来を持たない**。
  R8 §3.1 は「愛着の主語は人物、偶然性の主語は装備」と書いているが、
  装備側に記憶が無いので、偶然性が物語になっていない
- キャンプ（roster / skills / equipment / map）は全画面がシステム文

したがって現状を一言で言うと、R10 §4.2 の診断が**そのまま生きている**。

> キャラクターを好きにさせるオープニングというより、
> キャラクターを通して戦闘システムを覚えるオープニング

R11 は人物の中身を厚く作り直したが、**厚みの置き場を作っていない**ので、
プレイヤーから見た情報量は R10 の時点とほとんど変わっていない。

**増やすべきは会話量ではなく、会話以外の器である。**

## 4. 提案

### A. 読める設定の面（ギルドカード）— 最優先

R11 §9.5 そのもの。優先度を最上位に置く理由は §1 のとおりで、
**これが無いと R11 の賭けが測れない**からである。

- 内容は**新規に書かない。**R11 §2（灰・協会・技能の三層・根城）、
  §4（5人の来歴・灰から拾った一品・根城での姿・喋り方・ギャップ）、
  §5（関係6件）に全文がある。設計資料から**画面へ移送するだけ**である
- 新しい content ファイル1つ（`ecology/content/profiles.mjs` 相当）と画面1つ。
  **engine・schema・content 契約の変更はゼロ**で済む
- **段階開示にする。**加入していない人物のカードは出さない。
  これは §4.E-1 の漏れも同時に塞ぐ
- 検査は `story.test.mjs` へ足せる。「本編5人ぶんのカードがある」
  「未加入の人物のカードは引けない」「関係の相手が実在の仲間を指す」

R11 §9.4（根城の場面）より先にこれを置く理由: 根城は**新しい表示面と新しい会話**の
両方を要求するが、ギルドカードは**表示面だけ**で足りる。同じ「設定の厚み」を
渡すのに、安いほうから試す。

### B. 世界の声を、既にある画面へ載せる

会話ではないので、R9 §7 の「1断片2〜6行」「正解を説明しない」を侵さない。

1. **敵の一行（拾い屋の噂）。**`ENEMY_TARGETING` の隣に、狙いとは別の一行を置く。
   敵カードは**毎戦の戦闘前に必ず読まれる**ので、物語の配達先として最も安い。
   R11 §2.1 の「灰殻に説明を与えない」は守れる — **噂の形**にすればよい
   （「詰所の台帳では、これを兵と数えない」程度に留める）
2. **設計図の由来。**Blueprint は遠征をまたいで残る唯一の物である。
   「どの Stage の何戦目で、誰が拾ったか」を一行持たせるだけで、
   archive が**遠征の記録**になる。生成は決定的なので由来も決定的に付けられる
3. **精算の締め。**`renderSettlement` は結果分類（勝利／安全撤退／敗北）と
   到達戦数を既に持っている。R11 §2.2「撤退は敗北ではなく判断」を、
   ここで一行として渡せる

### C. 幕の断片（4・8・12戦目）

いま12戦のあいだが完全に無音である。act boss は**プレイヤーが既に止まる点**なので、
新しい導線を作らずに置ける。

- Stage 0〜3 × 3幕 = 12断片、1断片2行として **+24行**。
  現行46行に対して半分の増分で、幕の切れ目が全部埋まる
- 初回のみ表示（`storyBeatsForStart` と同じ既読判定に乗せる）
- ここは **§4.E-2〜4 の穴を埋める枠**として使うのが良いと考える。
  ナズナが Stage 2・3 に出ていない、スミ4行・レイ3行、関係6件のうち
  行動として出ているのが1件だけ、という偏りは、幕の断片で直せる

### D. いま間違っている表示（この PR で訂正した）

R11 の加入順の組み替え（§8.5）に、表示側の文言が追随していなかった。

### E. 直していない、作者の判断が要るもの

1. **本編に来ない3人が「後で加入する仲間」として名前で出ている。**
   `app.js:1636-1643` は Campaign 中に `<details>後で加入する仲間（6人）</details>` を出し、
   トキ・ヨリ・アカリまで名前と役割を並べる。R11 §9.7 のとおり3人には来歴が無く、
   Campaign にも出ないので、**「後で加入する」は嘘**である。同時に、
   カイ・スミ・レイの加入も先に割れる。ギルド画面（`app.js:1163`）も8人タブで、
   未加入の人物を鍛錬・枠購入できる。
   案: Campaign 中は `castCharacterIds` の外を出さない。ただし Free mode との
   兼ね合いがあるので、**作者判断**とした
2. **ナズナが Stage 2・3 の加入場面に居ない。**最初の相棒であり、R11 が
   ヒロインと位置づけた人物が、後半2つの join から配役ごと落ちている
3. **スミ4行・レイ3行。**愛着の対象として設計された人物の、本編での台詞量である
4. **関係6件（R11 §5）のうち、行動として出ているのは スミ⇄カイ の1件だけ。**
   シキ⇄レイ（レイだけがシキの「奥」の欲に気づいている）、レイ⇄ナズナ（二人とも
   別の帳面を書く）、シキ⇄ナズナ（体調記録でシキの変化に気づいている）は
   一度も画面に出ない
5. **負け続けると物語が一切進まない。**`stageEndStorySection` は
   `settlement.outcome !== "won"` で空を返す（`app.js:2847`）。
   「撤退は判断であって敗北ではない」（R11 §2.2）という世界観と、
   物語の進み方が食い違っている
6. **加入会話が、その Stage をクリアするまで毎回出る。**`app.js:1567` は
   `isCampaignStageCleared` だけを見るので、Stage 2 に3回失敗すればスミの加入は
   4回再生される（スキップはできる）。R9 §8 は「2回目以降は加入会話と導入戦を
   スキップする」を求めていた

## 5. 順番についての意見

- **A → D** が、R11 の賭けを作者評価にかけられる状態にするための最小である
- **B → C** は、Gate で「人物が立っていない」と判定された場合に効く。
  先に全部やると、何が効いたのか分からなくなる
- **立ち絵の画像化（R11 §9.2）は最後。**40枚は取り消しが利かない投資で、
  R11 自身が「人物と会話が固まったあとに着手する」と書いている。
  §4.A〜C は全部、立ち絵を SVG のまま進められる

R10 §4.3 が「全員分の設定を一度に増やすより、最初の2人を記憶に残す方が
効果を測れる」と書いているのは、いまも有効だと考える。§4.A を5人分いっぺんに
出すのが重いなら、**シキとナズナの2枚だけ**先に作るのが安全である。
