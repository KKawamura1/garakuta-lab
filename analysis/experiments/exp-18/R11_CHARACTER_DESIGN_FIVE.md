### 参照作品からの帰結

「ドラクエ／世界樹の迷宮」という回答は、**会話の増量を求めていない**ことを意味する。
両作とも仲間の台詞量は多くない（ドラクエの主人公は喋らず、世界樹のギルド員は
ほぼ喋らない）。それでも人物は立つ。

したがって本設計は次の配分を採る。

- **会話の分量は現状維持。** R9 §7 の「1断片2〜6行」「正解を説明しない」を守る。
- 投資先は**立ち絵の情報量**と**読める設定**（世界樹のギルドカードにあたるもの）。
- 各人の will は台詞で説明させない。**行動と、たまに漏れる一行**で滲ませる。

## 2. 世界 — 灰と、拾い屋の制度

### 2.1 灰

一度栄えて焼けた文明の跡。外の世界はそこから再興し、いまは蒸気機関と電信を持つ
ところまで戻っている。だが**発明する力は戻っていない**。新しい技術は、灰の中から
掘り出した図面を再現することで手に入る。

灰殻（husk）は、かつての住人の抜け殻である。それ以上の説明を作品内で与えない。
拾い屋のあいだで噂されている程度に留める。

### 2.2 拾い屋と協会

拾い屋は生業であって、抵抗運動でも救助活動でもない。だから**撤退は敗北ではなく
判断**である。危なければ戻る。戻って、また入る。

協会（詰所）は潜行等級を管理し、器材を貸し出し、拾得物を査定する。

### 2.3 技能の三層 — 「毎回取り直す」の世界観上の意味

**これが本設計の要である。** 実装を読むと、技能は二層ではなく三層に分かれている。

| 層 | 実体（コード） | 遠征をまたぐと |
|---|---|---|
| **身体** | `trainingLevels {might, focus, guard, vitality}`<br>`progression.mjs:212`（Profile側） | **残る** |
| **職能** | 各人の `starterTactics` / `starterReactives`（`roster.mjs`）<br>＋ baseline（斬撃・防壁形成・応急・foundation 7種、`packs.mjs`） | **毎回そのまま入る**<br>増えも減りもしない |
| **その遠征の手** | `runSkillPoints` / `runUnlockedSkills`<br>`progression.mjs:603-604`（Run側） | **消える** |

`playable-battles.mjs:220-221` が遠征開始時に starter をそのまま装着するため、
**人物固有の職能は最初から永久に固定されている**。毎回取り直すのは第三層だけである。

第三層には、説明を要する性質が4つある。

1. 4系統中**3つしか有効にならない**（`packs.mjs` 冒頭。毎回どれかの系統が欠ける）
2. 遠征の**最中に**技能点を払って解禁する（開始時点では持っていない）
3. `resetRunSkills` は使った点を**全額戻す**（組み替えに罰がない。`progression.mjs:672-686`）
4. Stage が進むと解禁の幅が増える（core → full。R9 §3.1）

これを次のように読む。

> **第三層は個人の技ではない。協会の詰所から借り出す器材と、それを使うための
> 隊内の取り決めである。**
>
> 「後衛狩り」は個人の特技ではなく、後列へ届く投擲具と、それを撃つ合図。
> 「準備狩り」は、敵が溜めているのを見抜く計器と、それに合わせて割り込む段取り。
>
> 借り出せる棚は**3系統分しかない**（性質1）。詰所を出る時点では全部決められない
> ので、現場で組み上げながら覚える（性質2）。組み替えても器材は減らないから、
> やり直しに罰がない（性質3）。潜行等級が上がると、借りられる棚が増える（性質4）。
>
> そして**帰ったら返す**。だから次の遠征は、また借りるところから始まる。
>
> **持ち帰れるのは設計図だけ。** 器材は協会のものだが、灰の中で拾った図面は
> 拾った者のものだ。

この読みの利点：

- Blueprint だけが Profile に残る（`progression.mjs:309`）という**実装上の非対称性が、
  そのまま制度の説明になる**。物理法則の発明を必要としない。
- 「稼ぐ → 等級が上がる → 借りられる棚が増える → 奥へ行ける」が、
  主人公の will（§3.1）とメカニクスの進捗を同じ線に乗せる。
- 灰殻に特別な説明を与えずに済む。

**採用しなかった案**：「灰の中でだけ成立する手順で、外へ出ると薄れる」。
これは物理法則の追加を要求するうえ、「薄れる」の内実を最後まで具体化できなかった。
制度による説明のほうが、蒸気と電信の文明レベルとも整合する。

### 2.4 根城

詰所へ器材を返したあと、5人は自分たちの根城へ帰る。廃屋を直した家。
拾ってきたもので少しずつ増えていく。**日常の場面と設定の厚みはここに置く。**

`CHARACTER_STATS` と `roster.mjs` の実装値をそのまま転記したものである。

| id | 名前 | 役割 | 加入 | HP | 腕力 | 集中 | 受け | 速度 | 位置 |
|---|---|---|---|---:|---:|---:|---:|---:|---|
| warden | シキ | 守護 | Stage 0 | 260 | 32 | 24 | 10 | 4 | 前 |

### 3.1 シキ — 受ける人（warden・主人公・女性・24歳前後）

**HP260 / 腕力32 / 集中24 / 受け10 / 速度4 / 前列**
starter: `bulwark` `strike` / `brace_after_hit` `cover_ally`

#### will

協会の地図は、灰の縁から数えて**四つ目**で終わっている。その先が見たい。

奥へ入るには潜行等級が要る。等級には実績と金が要る。だから稼ぐ。
**稼ぎは手段で、目的は奥。** 本人はその順序を隊のみんなに言っていない。

#### なぜ班を作ったか

一人では持ち帰れないから。そして、一人では等級が上がらないから。
**5人を編成する仕組みそのものが、主人公の願いの形をしている。**

#### 身体と佇まい

背は高くない。肩と背中が厚い。左腕に当て革を重ねて巻いている（受ける腕）。
速度4は鈍いのではなく、**動かないことを選んでいる**。

#### 灰から拾った一品

灰の中でだけ針が動く、掌に収まる計器。潜行等級の証を兼ねる。首から下げている。

#### 喋り方

一人称「わたし」。平時は短く、数字で喋る。

> 「補給は四つ。三つ使ったら戻る」

#### ギャップ

帳簿と補給を計算する現実主義者。撤退の判断が早い。
**だが「四つ目より奥」の話題が出ると、一文が長くなって止まらなくなる。**
本人は隠せていると思っている。四人とも気づいている。

#### 根城での姿

帳簿をつけ、拾ってきた物の目録を作る。
目録の最後のページにだけ、**まだ行っていない場所の名前**が書いてある。

#### 表情の出方

`firm` と `calm` が多い。`smile` は少なく、出ると効く。
奥の話題では `shock` に近い高揚が出る。

---

### 3.2 カイ — 抜ける人（lancer・男性・20歳前後）

**HP200 / 腕力46 / 集中18 / 受け4 / 速度8 / 前列**
starter: `strike` `heavy_swing` / `scavenge_ap` `counter_blow`

#### will

速く終わらせたい。長く居たくない。**灰の中で考える時間が、一番怖い。**

#### なぜ応じたか

腕力46に対して受け4。速いが保たない。どの班からも「保たない」と断られていた。
シキだけがこう言った。

> 「あなたが保たないのは、後ろで受ける人がいなかったからだ」

**この一言が、腕力46／受け4 と、シキの受け10 の関係そのものである。**
誘い文句が、そのまま隊列の設計になっている。

#### 身体と佇まい

細くて速い。傷が多い。手が荒れている。

#### 灰から拾った一品

灰から拾った刃。外の鋼では出せない薄さで、よく欠ける。研ぎ直しても元には戻らない。

#### 喋り方

一人称「俺」。短い。断定する。返事が早い。

#### ギャップ

**何でも速い。** 飯を食うのが異様に速く、詰所の書類を書くのも速く、そして間違える。
止まると考えてしまうので、止まらない。

#### 根城での姿

一番先に寝て、一番先に起きる。朝の火を起こすのはいつも彼。
誰もそれを頼んでいない。

#### 表情の出方

`firm` と `wry` が多い。`worry` は滅多に出ないが、出ると場が固まる。

---

### 3.3 スミ — 受け止める人（guardian・女性・16歳前後・小柄）

**HP260 / 腕力26 / 集中24 / 受け12 / 速度3 / 前列**
starter: `bulwark` `strike` / `cover_ally` `brace_after_hit`

#### 設計の核

**受け12（隊内最大）／速度3（隊内最遅）／HP260（シキと並んで最大）。**
これを一番小柄な人物に与える。

一番小さい子が、一番前で、一番受けて、一番遅い。そして避けない。
**ギャップを外から貼っていない。** パラメータが最初から持っていた性格である。

#### will

受けたい。**受けた側にしか分からないことがあるから。**

#### 経歴／なぜ応じたか

詰所で器材を運ぶ仕事をしていた。潜行等級を持っていなかった。
シキが保証人になった。

#### 身体と佇まい

一番小さい。だが一番厚い盾板を担ぐ。協会の備品で、体格に合っていない。
速度3は重い物のせいではなく、**単に急がないから**。

#### 灰から拾った一品 — **持っていない**

**5人で唯一、拾った物を何も持っていない。** 持ち物は全部協会の備品である。
差し色に彩度の低い灰青（`#a8b6bb`）を割り当てているのはこのため。
**一人だけ自分の色を持っていない。**

Stage を進めるうちにこれが変わる余地として、意図的に空けてある。

#### 喋り方

一人称「わたし」。短い。感情の起伏が声に出ない。敬語を使わない。

> 「そこ、危ない」

#### ギャップ

表情が薄く、痛がらない。
**だが根城では、拾ってきた物を棚に並べるのが好き。**
並べ方に本人しか分からない規則がある。誰かが動かすと、黙って直す。

#### 根城での姿

棚を作っている。棚は増えていく。

#### 表情の出方

`neutral` と `calm` が圧倒的に多い。
**だからこそ `smile` が出たときの効果が5人で最大になる。**
この一枚のために5人を設計していると言ってよい。

### 3.4 レイ — 渡す人（tactician・男性・30歳前後）

**HP170 / 腕力24 / 集中40 / 受け3 / 速度7 / 後列**
starter: `relay_order` `mark_target` / `guard_step` `triage_relay`

#### will

読んだものを、自分の目で確かめたい。

#### 経歴／なぜ応じたか

協会の記録係だった。何百という遠征記録を読み、誰がどこで何をして戻らなかったかを
全部数えた。数えているうちに、机の上では分からないことがあると気づいた。

**等級の通し方を知っている。** だからシキの「奥へ行く」に、5人で一番実務的に効く。
シキの欲に最初に気づいたのも彼で、気づいたうえで協力している。

#### 身体と佇まい

姿勢がいい。手が綺麗——現場の人間の手ではない。

#### 灰から拾った一品

灰から拾った時計。外では狂う。
別に携帯電信機を持っているが、こちらは外の技術（蒸気と電信の世界の産物）。

#### 喋り方

一人称「私」。丁寧。説明する。

> 「三、二、……いま」

#### ギャップ

**全部数える。** 歩数も、残り補給も、誰が何回被弾したかも。
**なのに方向音痴。** 地図は完璧に読めるのに、帰り道で必ず一度曲がり損ねる。
本人は認めない。

#### 根城での姿

記録をつける。協会へ出す用と、自分用の二冊。**自分用のほうが厚い。**

#### 表情の出方

`neutral` と穏やかな `smile` が多い。`shock` がほぼ出ない人なので、
出たときは本当にまずい状況である。

### 3.5 ナズナ — 止める人（mender・女性・27歳前後）

**HP180 / 腕力18 / 集中44 / 受け3 / 速度6 / 後列**
starter: `strike` `idle_shuffle` / `mend` `triage`

#### will

**灰の傷は、灰の中でしか分からない。**

#### 経歴／なぜ応じたか

外で医者をしていた。灰から帰った者を診続けて、外の医術では戻らない傷があると知った。
診るために、自分で入ることにした。

#### 身体と佇まい

手際がいい。荷物が多い（薬包、計器、記録帳）。

#### 灰から拾った一品

灰の傷を見るためのレンズ付きの眼鏡。片眼だけ。

#### 喋り方

一人称「わたし」。断定する。冷たく聞こえる。

> 「その傷、いま塞ぐ意味はない」
> 「戻せるのは、いま受けたぶんだけ」

これは実装の挙動そのものである（応急処置は同じ一撃にしか効かず、
持ち越しHPは待っても戻らない）。**冷たさが、ルールの正確さから来ている。**

#### ギャップ

治療を断ることが多いので、冷たいと思われている。
**だが根城では、全員の体調を勝手に記録している。**
誰が何時間寝たか、何を食べたか。訊かれると「観察です」と言う。

#### 根城での姿

記録帳をつける。レイの記録帳とは別物。
**二人が同じ夜に、別々の帳面を書いている。**
レイは「何が起きたか」を、ナズナは「誰がどうなっているか」を書いている。

#### 表情の出方

`calm` と `firm`。`wry` がよく似合う。

## 4. 関係

「誰が誰をどう思っているか」を、説明台詞ではなく**行動として**持たせる。

| 組 | 関係 |
|---|---|
| シキ ⇄ カイ | 最初の二人。カイは「シキが受けるから自分が抜ける」と分かっているが、口に出さない |
| スミ ⇄ カイ | スミが庇うと、カイは怒る。**速い人間と、避けない人間。**Stage 1 の join がこの衝突 |
| レイ ⇄ ナズナ | 二人とも記録をつける。目的が違う。レイは出来事を、ナズナは人を |
| シキ ⇄ レイ | レイだけがシキの「奥」の欲に気づいており、気づいたうえで等級を通している |
| スミ ⇄ シキ | シキが保証人。スミにとってシキは「入れてくれた人」 |

## 5. 立ち絵の仕様

### 5.1 差し色

`portraits.mjs` の既存 accent をそのまま流用する。**UI 側の色トークンを変えずに済む。**

| id | 名前 | accent | 意図 |
|---|---|---|---|
| warden | シキ | `#91cbd5` | 淡い水色。冷静さと、その下の熱 |
| lancer | カイ | `#e5a26b` | 琥珀。速さと消耗 |
| guardian | スミ | `#a8b6bb` | 灰青。**唯一、彩度を持たない**（§3.3） |
| tactician | レイ | `#d8d18a` | 淡い金。記録と真鍮 |
| mender | ナズナ | `#9bd69e` | 若草。薬と観察 |

### 5.2 表情の枚数

`portraits.mjs` の `EXPRESSIONS` 8種を維持する。`story.mjs` が既にこの8種で
書かれており、`story.test.mjs` が全組み合わせを検査しているため。

**5人 × 8表情 = 40枚。**

| id | 内容 | 主な用途 |
|---|---|---|
| `neutral` | 平静 | 既定 |
| `firm` | 力む・決める | 断定、決断 |
| `worry` | 困る・案じる | 迷い |
| `smile` | 笑う | 数を絞る。**スミの一枚が最重要** |
| `calm` | 目を閉じる・穏やか | 諦観、納得 |
| `shock` | 驚く | 事故、割り込み |
| `wry` | 苦笑・皮肉 | カイとナズナに多い |
| `hurt` | 痛み | 被弾、敗北 |

`ecology/content/portraits.mjs` は SVG を純関数で組み立てている。冒頭コメントが
