# EXP-18 R1 — SCRAP FRONTIER 最小コア仕様

更新日: 2026-08-29（UTC）  
状態: 事前登録。実装前。  
上位企画: [継続性の再定義と新企画案](../../EXPANDING_GAME_DIRECTION_2026-08-29.md)  
対象: 面白さの核だけ。UI、物語、ランダム報酬、長期バランスは対象外。

## 0. この実験で確かめること

一つの強い小隊を完成させた後、その小隊を弱体化・解体せずに残し、別の問いに答える第二小隊を追加し、二正面で両方が同時に必要になる構造を作れるか。

機械検査は面白さを合格させない。次の感情曲線が実装可能な規則として成立していることだけを確認する。

> 並びを予想する  
> → 予想した連鎖で群れを圧倒する  
> → 同じ小隊が装甲要塞では明確に止まる  
> → 別原理の小隊を作る  
> → 旧小隊と新小隊を二正面へ同時投入する  
> → 一小隊の並びから、部隊の割り振りへゲームが一段大きくなる

## 1. 面白さの核

核は「敵Aには属性A」という相性表ではない。

プレイヤーが扱うのは、三つの具体的な量だけである。

- 一撃の大きさ
- 一拍に倒せる対象数
- 敵の大技までに使える拍数

敵はこの三量の組み合わせで問題を出す。機体は固有レシピではなく、攻撃、追撃、余剰の引き継ぎ、充填、狙撃、防壁という共通動詞で答える。

第一小隊は「一撃の余剰を次へ渡し、一拍に多数を倒す」強さを持つ。第二小隊は「複数体を倒す力を捨て、一つの装甲を短時間で破る」または「前衛を無視して目標を狙う」強さを持つ。

どの能力も単なる攻撃力+10%ではなく、勝利への道筋を変える。

## 2. 戦闘の完全規則

### 2.1 共通

- 味方小隊は前から最大3体。初版のシナリオは2体で構成する。
- 敵も前から並ぶ。
- 戦闘は最大3拍。
- 戦闘中の乱数はゼロ。
- 各拍は次の順で処理する。
  1. 味方の拍開始効果
  2. 味方が前から順に一回ずつ行動
  3. 勝利条件判定。達成なら敵は行動せず即勝利
  4. 敵が前から順に行動
  5. 全味方破壊判定
- 3拍目終了時に勝利条件未達なら敗北。
- 通常攻撃は最前の生存敵を狙う。
- 敵の通常攻撃は最前の生存味方を狙う。
- 狙撃だけはミッション目標を直接狙う。
- 戦闘結果の事前予告は出さない。
- 敗北後は同じ敵編成・行動を確認でき、再挑戦できる。

### 2.2 ダメージ

一回の攻撃を次の順で処理する。

1. 実効威力 = max(0, 攻撃威力 - 対象の装甲)
2. 実効威力を対象の防壁から減らす。
3. 残りをHPから減らす。
4. HPが0以下なら破壊する。

装甲は攻撃ごとに適用する。したがって、威力3の攻撃を二回行うことと、威力6の攻撃を一回行うことは、装甲3に対して同じではない。

### 2.3 余剰

小隊に「貫通処理」が装備されている場合だけ、攻撃で対象を破壊した後の余剰実効威力を次の敵へ渡す。次の敵では装甲を改めて適用する。

貫通処理は一個の物理的な指令チップであり、同時に一小隊へしか装備できない。第二小隊へ移せば第一小隊から外れる。

## 3. 味方機体

| ID | HP | 行動 |
|---|---:|---|
| ram / 衝角機 | 6 | 最前敵へ威力6 |
| echo / 追響機 | 4 | この拍に直前の味方攻撃が存在すれば、その元威力の半分（切捨て）で最前敵を攻撃 |
| capacitor / 蓄電機 | 5 | 次の生存味方へ電荷2 |
| cannon / 集束砲機 | 5 | 全電荷を消費し、最前敵へ 威力2 + 電荷×4 |
| guard / 防壁機 | 5 | 最前味方へ防壁3 |
| sniper / 狙撃機 | 4 | ミッション目標へ威力3。目標がなければ最後尾敵へ威力3 |

電荷は戦闘内だけ保持し、集束砲機の攻撃時に全消費する。戦闘をまたいで持ち越さない。

## 4. 第一小隊の指令チップ

最初のチュートリアル後、三つから一つを選び、第一小隊へ装備する。いずれも群れを突破できるが、勝ち方が異なる。

| ID | 効果 | 予想させたいこと |
|---|---|---|
| overrun / 貫通処理 | 破壊後の余剰を次へ渡す | 威力6ならHP3を二体倒せる |
| double_echo / 二重追響 | 追響機が一拍に二回追撃する | 衝角1体＋追撃2体で三体倒せる |
| brace / 構え | 各拍開始時、最前味方へ防壁3 | 倒す速度は遅いが、群れの反撃を耐えて3拍使える |

一個の指令チップだけを装備する。数値上位互換ではなく、余剰、行動回数、生存時間という別の勝ち筋を与える。

## 5. 敵

| ID | HP | 装甲 | 行動 |
|---|---:|---:|---|
| drone / 小型機 | 3 | 0 | 毎拍、最前味方へ威力1 |
| bastion / 防塞機 | 10 | 3 | 毎拍、最前味方へ威力1 |
| artillery / 遠砲機 | 5 | 0 | 1〜2拍は待機。3拍目に全味方へ威力6 |

遠砲機の3拍目行動は戦闘前から表示する。隠れた時間制限にしない。

## 6. 三つのミッション

### M0: 接続試験

- 敵: 小型機2体
- 勝利: 全敵破壊
- 初期小隊: 衝角機、追響機
- 指令チップ: なし

期待結果:

- 衝角機→追響機の順なら1拍で勝つ。
- 追響機→衝角機の順なら、追響機が働かず2拍かかる。
- 「前の攻撃を追うので後ろへ置く」という一文で差を説明できる。

### M1: 群集線

- 敵: 小型機6体
- 勝利: 全敵破壊
- 小隊: 衝角機、追響機
- 制限: 3拍

期待結果:

- 指令なしでは、衝角機が2拍目の反撃で壊れ、3拍目に追響が起動せず敗北。
- 貫通処理なら2拍で勝つ。
- 二重追響なら2拍で勝つ。
- 構えなら3拍で勝つ。
- 選んだ指令が実際の戦闘イベントとして見える。

### M2: 遠砲要塞

- 敵: 防塞機、遠砲機の順
- 勝利: 遠砲機を破壊
- 制限: 3拍
- 遠砲機は3拍目の敵行動で全体威力6。

期待結果:

- 第一小隊は、どの初期指令でも遠砲機へ届かず敗北する。
- 蓄電機→集束砲機は、防塞機を2拍で破壊し、3拍目に遠砲機を破壊して勝つ。
- 防壁機→狙撃機は、防塞機を無視し、2拍目に遠砲機を破壊して勝つ。
- 「第一小隊を弱体化された」のではなく、群れ向けの強さと要塞向けの強さが異なると読める。

## 7. 二正面

M1とM2を同時に提示する。一つの小隊は一方へ投入すると、解決まで他方へ使えない。

- 第一小隊をM1へ投入する。
- 新しい第二小隊をM2へ投入する。
- 両方の勝利で前線突破。

交差検査:

- 蓄電機→集束砲機はM1に敗北する。
- 防壁機→狙撃機はM1に敗北する。
- 第一小隊はM2に敗北する。
- したがって、第一小隊を解体して第二小隊へ作り直すだけでは二正面を突破できない。

ここで初めて、プレイヤーの対象が「一小隊の順序」から「複数小隊の役割と割当」へ拡大する。

## 8. 最小キャンペーン順

1. M0を遊ぶ。
2. 第一小隊用の指令チップを三つから一つ選ぶ。
3. M1で選んだ強さが実際に働く。
4. M2と、二つの第二小隊候補を同時に見る。
5. プレイヤーは重砲経路か狙撃経路を選ぶ。
6. 選んだ第二小隊でM2を突破する。
7. M1とM2が同時に再起動し、二正面になる。
8. 第一小隊と第二小隊を割り当て、両方を突破する。
9. 次の技術ツリーと三正面の予告だけを見せて終了する。

初版ではランダム報酬を入れない。まず、この固定された感情曲線が理解でき、次の規模を見たくなるかを確認する。

## 9. 実装境界

実装する:

- 純粋関数の決定的戦闘エンジン。
- 上記6味方、3敵、3指令、3ミッション。
- 配置、指令、戦闘結果、イベントログ。
- 二正面の割当判定。
- 事前登録した構造検査。

実装しない:

- ブラウザUI。
- アニメーション、音、D1、セーブ。
- スキルツリー全体。
- ランダム報酬。
- 長期キャンペーン。
- 数値自動調整。
- 面白さの代理評価。

## 10. 機械受入条件

1. 同一入力のイベント列が完全一致する。
2. M0は正順1拍、逆順2拍。
3. M1は指令なしで敗北し、三つの指令それぞれで勝利する。
4. M2は第一小隊の三指令すべてで敗北する。
5. M2は重砲小隊と狙撃小隊のどちらでも勝利する。
6. 重砲小隊と狙撃小隊はM1に敗北する。
7. 正しい二正面割当だけが両方勝利する。
8. 全攻撃、装甲、防壁、電荷、追響、余剰、遠砲発射がイベントログで追える。

## 11. このコアが失敗する場合

構造検査が通っても、次の可能性がある。

- M1とM2の対応が明白すぎて、思考ではなく仕分けに見える。
- 第一小隊用指令の三択が、実質的に同じ勝利へ見える。
- 二正面が単に二つの既知問題を並べただけで、ゲームの拡大に感じられない。
- 3拍では予測と結果の差が小さく、見守る期待が生まれない。
- 第二小隊が「新しい戦略」ではなく、鍵穴へ鍵を挿すだけに見える。

これらは人間評価でしか判定しない。初版の構造はチュートリアルとして意図的に明快だが、面白さの支持には「次の混成敵や三正面を考えたい」という自発的な欲望が必要である。
