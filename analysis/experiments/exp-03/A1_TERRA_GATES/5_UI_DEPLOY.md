# UI・デプロイ結果

対象: EXP-03 R1_CONTROL「Gate A〜D通過後の最小UI・導線」

## 実装

- 入口: /control/?seed=7
- 版: control-0.1-play
- 3戦、HP引き継ぎ、敵の次攻撃表示、部品ログ、感情マーカー、終了アンケート、localStorage復旧を実装。
- 報酬は画面内で候補を選び、続けて外す装備を選ぶ。後付け替えはできない。
- 既存のゲーム規則セット・既存UIは変更していない。

## 公開確認

公開URL: https://garakuta-lab.pages.dev/control/?seed=7

ブラウザで次を確認した。

1. URLが公開ページへ到達し、タイトルが「操機 / CONTROL 0.1」になる。
2. seed 7 / 1戦目、敵HP19、次の攻撃4、自己HP30が表示される。
3. 第1戦の合法行動を操作できる。
4. 勝利する最後の釘打ち砲が有効になり、第1戦後の報酬画面へ遷移する。
5. リロード後も途中状態とログが復旧する。

確認中に、勝利になる終端行動をUI側で無効化していた不具合を発見し、合法な終端行動も有効化した。敵数値・チップ効果・勝敗条件・ゲート条件は変更していない。

Cloud Browserの接続回復タイムアウトにより、同一セッションでの第2〜3戦完走までの自動確認は完了できなかった。公開ページの初期画面、第1戦、勝利、報酬画面、リロード復旧までは確認済みであり、残る未確認点はブラウザ接続が回復した時点で3戦完走を通すことである。
