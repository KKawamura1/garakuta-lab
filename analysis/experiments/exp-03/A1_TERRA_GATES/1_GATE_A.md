# Gate A — 戦闘計算の正確性

対象: EXP-03 R1_CONTROL「Gate A」

## 実装

EXP-03専用の純粋な決定的計算を core/control.mjs に追加した。既存の core/run.mjs や既存画面のルールセットは変更していない。自動検査は analysis/gate-control.mjs で行った。

## 結果

**合格: 7 / 7**

| # | 検査 |
|---:|---|
| 1 | 同じ入力から同じ戦闘結果になる |
| 2 | エネルギー不足の部品は作動できない |
| 3 | 崩落砲は次のターンに再使用できない |
| 4 | 蓄電輪の攻撃+5は次の1回だけ消費される |
| 5 | 追従軸は前の異なる部品を50%で再実行し、自分自身の連鎖はできない |
| 6 | 各ログのHP・敵HPと、返却された最終状態が一致する |
| 7 | 同じ戦闘入力を再計算しても結果が一致する（リロード回復の計算契約） |

HP・敵HP・ダメージは整数で計算し、戦闘ログでも整数で保持する。Gate Aは、仕様に書かれた効果・禁止条件・状態記録の最小契約を満たした。
