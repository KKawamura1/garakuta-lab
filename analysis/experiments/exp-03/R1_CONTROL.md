# EXP-03 操機 / CONTROL 0.1

状態：**事前登録済み・未実装**  
作成日：2026-08-24  
戦略担当：GPT-5.6 Sol  
実装・検査担当：GPT-5.6 Terra / Luna

## 問い

主動詞を「5枠を並べて正確な予告を見る」から、**敵の次行動を見て、戦闘中に部品を1つ作動させる**へ変えると、考えた結果をその場で支払う面白さが生まれるか。

## 仮説

EXP-01では、ランダムな取得物が既存部品を再評価させる瞬間が効いた。EXP-02では、噛み合わせを理解する瞬間は効いたが、固定解へ向けた反復探索は二度目に作業化した。

そこで、部品を「正解配置の材料」ではなく「毎ターン選べる行動」にする。

敵の次の攻撃が見えている状態で、

- 今発電するか
- 今守るか
- 今攻撃するか
- 重い一撃のために溜めるか

を選ばせれば、完全情報でも「全部は同時にできない」取引が生まれる。ランダム報酬は、以後の選択肢と戦い方を変える。

## 変更

既存ルールセットを変更せず、独立した小型試作 `/control/` を作る。

### ラン

- 1ラン3戦
- 最大HP30、戦闘間でHPを持ち越す
- 各戦闘は最大8ターン
- 敵HPが0なら勝利、8ターン終了または自HP0なら敗北
- 敗北でラン終了

### 戦闘

- プレイヤーは部品を3個装備する
- 並べ替えと戦闘前の完全予告は無い
- 各ターン、装備中の部品から作動可能な1個を選ぶ
- 選択後、部品効果→敵攻撃の順で解決する
- 敵の「次の攻撃値」は選択前に表示する
- 遮蔽はそのターンの敵攻撃にだけ有効で、次ターンへ持ち越さない
- エネルギーは戦闘内で持ち越し、戦闘終了時に0へ戻る
- 選択後の結果は短いログで表示し、次ターンへ進む

### 部品

| 部品 | 効果 |
|---|---|
| 手回し発電機 | エネルギーを2得る |
| 釘打ち砲 | エネルギー1を使い、5ダメージ |
| 崩落砲 | エネルギー2を使い、10ダメージ。次の1ターンは作動不能 |
| 偏向板 | エネルギー1を使い、このターン遮蔽7 |
| 蓄電輪 | エネルギーを1得る。現在エネルギーが2以上なら、代わりに次の攻撃部品のダメージ+5 |
| 追従軸 | エネルギー1を使い、直前ターンに使った別部品を50%の効果で再作動する。連続して追従軸は使えない |

数値は自動ゲートに通らない場合だけ、後述の範囲内で敵側を生成・選別する。部品数値は人間結果を見る前に変更しない。

### 初期構成と報酬

- 初期構成は「手回し発電機・釘打ち砲・偏向板」
- 第1戦と第2戦の後、未装備部品からランダムに2個提示する
- 1個を選び、装備中の1個と交換する
- 拒否・リロールは無い
- 取得後に装備を自由に戻したり、過去の部品へ付け替えたりしない
- seedにより提示順を再現できる

報酬選択は「正解を当てる」ためではなく、以後の行動集合を変える一度の判断として扱う。

## 維持しないもの

- 5枠配置
- 位相表
- 戦闘結果の完全予告
- 配置の総当たり
- 法則2個
- 等級・記録・strike
- 変異チップ
- 固定問題の目標得点

## 人間テスト前の自動ゲート

面白さは判定せず、壊れた戦闘だけを落とす。

### Gate A: 計算一致

- 各部品の単体効果
- エネルギー不足時に作動できないこと
- 崩落砲の1ターン停止
- 蓄電輪の次攻撃加算が1回だけ消費されること
- 追従軸が追従軸を再発動せず、直前部品を50%で再現すること
- 表示ログ・HP・敵HP・内部状態の一致
- リロード復旧

### Gate B: 戦闘の技能幅

全行動列を列挙し、各戦闘について次を満たす。

- 少なくとも1つ勝利方策がある
- 全合法行動を一様に選ぶランダム方策の勝率が5%超80%未満
- 同じ部品を可能な限り繰り返す各単純方策のうち、全3戦を突破するものが無い
- 最適勝利方策が2種類以上の部品を実際に使う
- 最適方策と、少なくとも1つの合法な初手の間で、勝敗または終了HPに差が出る

### Gate C: 報酬の両側

各報酬提示について、どちらを選んでも次戦に少なくとも1つ勝利方策が残る。さらに、2つの選択後で最適行動列または終了HPが異なる。

片側だけが常に上位なら、そのseedを使わない。

### Gate D: 参照点とseed選定

先に次の壊れた参照点を同じゲートへかけ、棄却されることを確認する。

- 敵HP5・攻撃0の自明戦闘
- 敵HP999の不可能戦闘
- 毎ターン攻撃0で、釘打ち砲だけを押せば勝てる戦闘

その後、seed 1から昇順に探索し、A〜Cを最初に満たす1seedを選ぶ。人間結果を見てseedを選び直さない。

敵ごとに変更してよい生成値は、HP18〜36、次攻撃0〜10、最大8ターンだけ。新しい敵能力は追加しない。

## 成功信号

1ラン以内に次のうち2つ以上が出て、少なくとも1つが行動ログで確認できれば支持候補とする。

1. 敵の次攻撃を理由に、攻撃・発電・遮蔽の予定を変える
2. エネルギーまたは停止ターンを見越して、直近の最大値ではない部品を選ぶ
3. 報酬によって、その後に多用する行動または戦い方が変わる
4. 「あの攻撃に備えて溜めた」「この部品を取ったのでこう戦った」とランの経緯を説明する
5. 敗北直後に別の具体的な行動列を試したいと思う
6. 24時間以内に、依頼されず別seedを遊ぶ

## 失敗信号

- 毎ターン、同じ部品または明らかな最大値を押すだけ
- 発電→攻撃の固定手順を繰り返すだけ
- 敵予告を見ても行動が変わらない
- エネルギー管理が面白い判断ではなく帳簿作業になる
- 部品が「機械」ではなく、一般的な攻撃・防御ボタンにしか感じられない
- 報酬後も行動列が変わらない
- 「配置がなくなっただけで、前より浅い」
- 1ラン後に別の部品やseedを見たいと思わない

## 中止条件

- 1ラン10分を超える
- UI表示と実計算が一致しない
- 合法な部品があるのに選べない
- 全部品が作動不能になり進行不能
- Gate B/Cを通るseedが1〜10000に存在しない
- 操作または部品説明を読んでも理解できない

## Terra / Lunaの完了条件

1. まず戦闘計算をUIから分離して実装する
2. Gate A〜Dを実行し、結果を `A1_TERRA_GATES/` に要求別の連番ファイルで保存する
3. ゲート不通過ならUI・デプロイへ進まず、結果だけ返す
4. 通過時だけiPhone幅の最小UI、ログ、感情マーカー、終了アンケートを実装する
5. 版を `control-0.1-play` として保存する
6. 既存ルールセットを変更しない
7. ブラウザ通し確認、リロード復旧、ログ保存を確認する
8. mainへpushし、Cloudflare Pagesへデプロイする
9. 作者へはURLと「最大1ラン・10分」だけ伝え、成功条件を事前に教えない
10. 人間テスト後は `A2_TERRA_HUMAN/` に生ログ・原文・事実要約を分けて保存する

## プレイ量

ゲート通過後、作者は1ランだけ遊ぶ。すぐに2ラン目を依頼しない。24時間以内の再訪は自発行動として別に記録する。
