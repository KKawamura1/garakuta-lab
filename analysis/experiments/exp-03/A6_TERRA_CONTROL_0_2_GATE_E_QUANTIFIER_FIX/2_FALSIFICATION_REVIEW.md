# A6反証レビュー

高価な探索を始める前に、R6が要求した全Gateを次の観点で反証した。

1. seedや入力に関係なく、機械的にPASSまたはFAILしないか。
2. Gateが目的と異なるものを測っていないか。
3. 良い参照例と悪い参照例を意味的に分離できるか。
4. 量化、状態比較、tie、到達不能状態に矛盾がないか。
5. 小さな反例で評価器を壊せないか。

## 発見した問題

- Gate Eが全交換先を有用と要求していた。R6の意味は、各報酬について有用な交換先が少なくとも一つ存在すること。
- ignore-next-attackが各ターンの現在状態を保持せず、初期状態に近い状態で評価していた。
- Gate Fが参照ケースを実Gateへ入力せず、宣言的な結論だけを記録していた。
- 独立naive列挙、positive/negative fixture、Gate Eのnon-vacuity検査がなかった。
- Gate Aがイベント値の算術的一貫性まで検証していなかった。

## 修復方針

- Gate Eは使用・不使用・全体最適の全結果を比較し、使用経路が全体最適集合に含まれ、厳密に改善する交換先が各報酬に一つ以上あることを要求する。悪い交換先は証拠として残すが、良い交換先の存在を打ち消さない。
- ignore-next-attackは現在HP、敵HP、energy、loadout、disabled、bonus、previous、残りターンから毎ターン再計算する。将来攻撃だけを0にした反実仮想を使う。
- Gate Fは5つの参照シナリオを実際のB〜Eへ通す。
- A〜Eのpositive/negative fixture、Gate Eのnon-vacuity fixture、seed 1〜10の独立比較を追加する。

ゲーム値、初期装備、敵・報酬規則、8ターン、seed範囲、閾値は変更していない。
