# EXP-03 CONTROL 0.1 — 実装・修正・人間テスト統合レポート

作成日: 2026-08-24  
対象: analysis/experiments/exp-03/R1_CONTROL.md  
実装・検査・記録: Terra / Luna  
人間テスト対象: control-0.1-play, seed 7

> この公開版は、実装経緯と集計結果を記録する。個別の任意メモ原文、アンケート自由記述、run IDはリポジトリへ複製せず、取得元のActions artifactを参照する。

## 1. 目的と変更範囲

EXP-03では、5枠配置と完全予告を主動詞にしていた既存ルールセットを変更せず、独立した /control/ 試作を追加した。

新しい試作の主動詞は、敵の次攻撃を見ながら、戦闘中に装備部品を1つ作動させること。既存の core/run.mjs、既存UI、既存ルールセットは変更していない。

R1で定めた構造は次のとおり。

- 1ラン3戦、最大HP30、HPは戦闘間で持ち越し
- 各戦闘は最大8ターン
- 初期装備は generator / nail / deflector
- 戦闘中は装備中の3部品から合法な1部品を選ぶ
- 敵の次攻撃値を選択前に表示
- 第1戦・第2戦後に報酬を1つ選び、装備中の部品1つと交換
- エネルギーと停止ターンを戦闘内の判断要素にする

## 2. 実験票に対する実装・検査の順序

### 2.1 戦闘計算の分離

core/control.mjs にEXP-03専用の決定的計算を実装し、analysis/gate-control.mjs からUIと独立して検査した。

### 2.2 Gate A〜D

Gate A〜Dはすべて合格した。

- Gate A: 7/7。部品効果、エネルギー不足、崩落砲の停止、蓄電輪の一回限り加算、追従軸、ログと状態、再計算一致を確認。
- Gate B: seed 7。3戦すべてに勝利方策があり、ランダム方策の勝率は0.05超0.80未満。単一部品固定では全戦突破できず、最適方策は2種類以上の部品を使い、初手差が結果へ影響した。
- Gate C: seed 7。各報酬の両側に勝利構成が残り、報酬選択によって最適構成または行動列／終了HPが変わった。
- Gate D: 自明・不可能・釘打ち専用の3参照点をすべて却下。seedを1から昇順に走査し、最初に条件を満たしたseed 7を採用。

Gate通過前にはUI・デプロイへ進めない、というR1の条件を守った。

なお、Gate Bの探索では、R1が許可する敵値の範囲内で生成値を調整した。最終的なseed 7の敵はHP18〜26、攻撃0〜4の範囲で、Gateの閾値を変更したものではない。

## 3. 実装修正の経緯

### 3.1 ゲート通過後にUIを追加

ゲート通過後、/control/ の最小UIを追加した。

- 敵の次攻撃表示
- 部品選択と合法性表示
- 戦闘ログ
- 報酬選択と交換部品選択
- 感情マーカー
- 終了アンケート
- localStorageによる途中状態・リロード復旧
- D1へのプレイログ保存

### 3.2 勝利直前の合法行動が無効になる不具合

公開画面の通し確認中、第1戦を勝利で終える最後の行動が、UI側の判定によって無効化される不具合を発見した。

修正内容は、UIのボタン活性化判定を、単なる「次ターンへ進めるか」ではなく、計算結果の legal を基準にすること。勝利で戦闘が終端になる行動も合法なら選択できるようにした。

これはUIの合法性判定の修正であり、敵数値、部品効果、勝敗条件、ゲート条件は変更していない。

### 3.3 報酬交換の入力導線

報酬選択後に、交換対象の装備を画面内で選ぶ2段階導線へ整理した。ブラウザ標準の入力ダイアログに依存せず、候補と交換対象を画面上で確認できるようにした。

これは入力UIの修正であり、報酬候補、交換回数、後付け替え不可というルールは変更していない。

### 3.4 部品説明の追加

初期UIでは、部品名だけでは効果が把握しにくかったため、戦闘画面と報酬画面に部品効果の説明を追加した。

これは情報提示の補修であり、部品の数値・効果・選択肢は変更していない。

### 3.5 感情マーカーの任意メモ

感情マーカー押下時に、任意メモを入力できるダイアログを追加した。

- 最大160文字
- マーカー種別、ラベル、戦闘番号と一緒に保存
- D1の moments と run events の双方に記録

今回の人間ランでは、マーカー4件と任意メモ4件が保存・取得できた。

### 3.6 修正後の検査

修正後に次を再確認した。

- control/app.js の構文検査
- Gate A〜Dの再実行
- Gate結果が総合合格であること
- seed 7の公開画面到達
- 第1戦の合法行動
- 勝利直前の行動
- 報酬画面
- リロード復旧

公開確認ではCloud Browserの接続タイムアウトにより、同一セッションで第2〜3戦を自動完走するところまでは確認できなかった。この未確認点は、人間テストによって実際の3戦完走ログで補われた。

## 4. 人間テストの集計結果

GitHub Actions run 32678395057でD1 exportを実行し、control-0.1-play・seed 7の人間ラン1件を抽出した。

- 3戦到達
- 3戦全勝
- 最終HP 5
- 戦闘ターン数 6 / 8 / 6
- 報酬交換 2回
- マーカー 4件
- 任意メモ 4件
- 楽しさ 1/5
- リプレイ意欲 1/5

戦闘ごとの終了HPは、順に10 / 10 / 5だった。

報酬交換は、第1戦後に capacitor を取得して deflector と交換、第2戦後に collapse を取得して capacitor と交換した。

## 5. 観測事実

- seed 7は3戦完勝し、公開画面から最後まで進行できた。
- 人間は発電と攻撃を組み合わせ、第3戦では collapse も使用した。
- プレイ中のメモには、必要攻撃回数、ガード時の追加発電、攻撃力、HP持ち越しへの関心が記録された。
- 一方、アンケートの数値は楽しさ1/5、リプレイ意欲1/5だった。
- 自由記述では、最適解が明らかだったという評価と、報酬の価値を感じなかったという評価が記録された。
- 第2戦について、敵が攻撃してこなかったという観測があった。
- 現在のD1イベントは部品使用と戦闘終了時HPを記録するが、敵攻撃のターン別イベントやターン別HPを記録していない。そのため、この観測だけでは敵攻撃処理のバグ、攻撃値0の仕様、表示上の誤解を区別できない。

この文書は、EXP-03についての実装・修正・検査・公開・人間テストの中間報告である。

1. 既存ゲーム本体のルールセットを変更せず、独立試作を追加した。
