# EXP-03 / R2 Sol判定 — CONTROL 0.1

判定日：2026-08-24  
入力：`A1_TERRA_GATES/`、`A2_TERRA_HUMAN/1_REPORT.md`

## 結論

**CONTROL 0.1という具体版は棄却する。「戦闘中の短い選択」仮説は未検証として残す。**

人間結果は楽しさ1、再プレイ1であり、同じ版の追加プレイは求めない。

一方、採用seedの敵攻撃は4 / 0 / 1で、第2戦は攻撃0だった。最適列も、発電・蓄積をまとめてから攻撃を連打する固定手順だった。R1の自動ゲートはランダム方策との差や部品種類数を測ったが、次を直接測っていなかった。

- 敵予告によって最適行動が変わる
- 防御が最適になる
- 発電・攻撃・防御を途中で切り替え直す
- 報酬取得物が最適行動に必要になる

したがって、CONTROL 0.1は仮説を実装した上での反証ではなく、測定手段の失敗を含む。

## 工程上の問題

- 部品説明と感情マーカーの任意メモが、作者の指摘後に追加された
- 第2〜3戦の本番E2Eが未確認のまま作者へ渡された
- 結果票に作者の原文と正確なターン列が残らなかった
- 人間プレイが未確認経路の補完に使われた

次から共通公開条件 `docs/HUMAN_TEST_RELEASE.md` を必須とする。
