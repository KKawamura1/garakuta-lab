# EXP-01-R2 構造ゲート・人間テスト用seed選定依頼

状態：**EXP-01-R1の実装後に追加されたSol要求**

## 要求

ゲーム内容、敵数値、チップ効果、報酬は変更せず、仮説固有の構造ゲートを追加測定する。

到達可能な手持ちを標本化し、配置とチップ装着先を全列挙して、次を報告する。

1. 取得前後の最適配置距離
2. 最適装着先の分布
3. 採用部品の順位変化
4. 後続報酬による最適装着先変更率
5. 勝てる構成ゼロ率
6. 全配置勝利率

結果に合わせて閾値を変更せず、測定結果と実装上の解釈を先に報告する。構造ゲートは条件付き合格とし、人間テスト公開の判断は測定後に行う。

人間テスト用seedは、seedを昇順に機械走査し、次を満たす最初のseedを採用する。

- 勝てる構成ゼロ、全配置勝利の状態を除外する
- 実際に取得する第1チップについて、取得前後の最適配置距離が3枠以上
- 第1戦後の3報酬のうち少なくとも1つで、旧最適装着先が新最適集合から完全に消える
