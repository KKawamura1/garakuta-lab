## なぜ

### 1. 不満と称賛が、同じ現象を指している

| つまらない側 | 面白い側 |
|---|---|
| 「そのまま勝ててしまう」 | 「思いついた手段で3ストライクできたところ」（最良の瞬間） |
| 「何しても勝てそう」 | 「ストライクが決まったところ」（最良の瞬間） |
| `no_pressure`：83%の戦闘を無傷で勝った | 「久々に明確な方針の存在するゲームをプレイできた」（面白さ5） |

**どちらも「一つの並びが何戦も通る」ことである。**
違うのは、それが**目標だったかどうか**だけ。
連勝機関はそれを偶然「目標」にしていて、**作者が5点を付けた唯一の版**になった。

### 2. 「正解を減らす」は、1戦の中ではもうできない

学び#30：**「暗算は面白さではない。答えを出して、正解を減らす」。**
ところが正解は減らせなかった。1戦あたりの無傷率を下げると詰みが出る（T1 と両立しない）。
**天井の条件は16組中13組で満たせていない**（`analysis/BUGS_2026-08-23.md` の付記）。
天井を通していた3組は全部「減衰」入りで、それは上がる側が1巡上限に食われた**罰だけの法則**だった。

**1戦の中で減らせないなら、戦をまたいで減らす。**
第3戦を抜ける並びは十分ある。第3戦と第4戦を**続けて**抜ける並びは少ない。
**どの1戦も易しいまま、答えの数だけが減る。**T1 を壊さずに天井を下げられる唯一の方向である。

### 3. 大きさを測ってから決めた（`analysis/streak-space.mjs`）

16組・6ラン分の到達しうる持ち物で、並びを全列挙して「何戦続けて勝てるか」を数えた：

| | 値 |
|---|---|
| その持ち物で届く**いちばん長い連勝**（平均） | **3.43 戦** |
| 勝てる並びのうち**2戦続く**割合 | **26.0%** |
| 最長（組による） | 6（＝一つの並びで6戦通す組が多い） |

**狙って取る大きさである。**全部が続くわけでも、一つも続かないわけでもない。
そして上限6は、等級（無傷で頭打ち）と違って**上が詰まっていない。**
第10回に継続が止まった理由——「もうハイスコアが二度と得られない」——を、この値は持たない。

### 4. 探索には値段をつけない

一度は「探索が無料だから総当たりで無傷が出る、だから探索を有限にする」と書いた。
**取り下げる。**作者は第6回に「暗算がストレス／探索は楽しい」と明示していて、
学び#30 はそれを受けて書かれている。**楽しい方に値段をつけることになる。**

連勝は探索を1回も削らない。好きなだけ並べ替えてよい。
**制約は「その答えが次の戦闘でも通ること」だけ**である。

## 変えたこと

- **連勝が得点。**帯に常時出る（`第4戦 / 全6戦 ・ 連勝 2（最高 2）`）。
  飛ばした直後の札にしか出ていなかったので、伸ばしている最中は見えなかった。**見えない得点は狙えない。**
- **自己最高は法則の組ごとに残る**（`skip:balance+fade:連勝`）。上限6。
- **ラン終わりに最長連勝を出す。**勝敗ではなくこちらがこの版の成績である。
- **取引を報酬画面に書いた。**「拾うだけなら連勝は切れない。切れるのは枠に入れて手で戦ったとき」。
  拾い物で**強くなる**か、連勝を**続ける**か。正面からぶつかる。
- **既定の版を連勝機関にした。**素の法則機関は比較の相手として一覧に残す。
