## 直したもの：**負けた瞬間、ログに何も書かれていなかった**

> 「え、なんか負けた？もしかして時間制限がある？知らないけど」（3ラン目）

制限巡数（8巡）は画面に3か所出ていた。見出しの「次 N/8巡」、
「残りN巡」、次の一手の説明文「1戦は8巡で停止する」。
それでも伝わっていない。理由は `graft/engine.mjs` の `finishBattle` にあった。

**突破したときだけ `log()` を呼んでいて、負けたときは何も書かずに画面が切り替わる。**
プレイヤーは1戦のあいだずっと機関ログを読んでいるので、
**最後の行が「敵の攻撃5：遮蔽5、HP 13→13」のまま止まる。**

負けにも一行出すようにした。`analysis/smoke-graft.mjs` が、
その行が無ければ落ちる（実際、直す前の状態で落ちることを確かめてある）。

**画面に出ていることと、その瞬間に言われることは別である。**

なお GRAFT には検査が既にあった（`analysis/graft-smoke.mjs`、Terra 作、通る）。
だが **`analysis/check-all.sh` はこれを引いていなかった。**
束ねる glob が `analysis/smoke-*.mjs` で、この一本だけ `graft-smoke.mjs` という
逆の並びだったからである。`#67` と同じ形が、**関門を足した当日にもう一度出た。**
glob を `analysis/*smoke*.mjs` に広げ、名前の向きで漏れないようにした。

## 測ったもの：**「反動打撃あれば何やっても勝てます」は本当だった**

主張は「強い」ではなく「**何をしても勝てる**」なので、
最善手の勝率ではなく**でたらめに押したときの勝率**を測った
（`node analysis/graft-dominance.mjs 300`、1戦あたり300試行 × 敵4体）。

| 接ぎ木 | でたらめな方針の勝率 | 接ぎ木なしとの差 |
|---|---|---|
| **反動 → 打撃** | **55.0%** | **+42.0pt** |
| 余波 → 打撃 | 44.5% | +31.5pt |
| 継ぎ火 → 充電 | 30.0% | +17.0pt |
| 反動 → 充電 | 24.5% | +11.5pt |
| 継ぎ火 → 遮蔽 | 22.4% | +9.4pt |
| 反動 → 遮蔽 | 17.8% | +4.8pt |
| 余波 → 充電 | 16.3% | +3.3pt |
| 継ぎ火 → 打撃 | 15.1% | +2.1pt |
| 余波 → 遮蔽 | 13.6% | +0.6pt |
| 接ぎ木なし | 13.0% | — |

敵ごとの内訳（反動→打撃）：巡回ドローン 72% / 圧縮獣 67% / 鋸歯炉 68% / **心臓炉 14%**。

**最初の3戦は、反動を打撃に載せれば、でたらめに押して3回に2回勝てる。**
作者の言葉どおりである。抵抗しているのは最終戦だけ。

なお「打撃に何か載せれば強い」ではない。継ぎ火→打撃は 15.1% で、
接ぎ木なし（13.0%）とほぼ変わらない。効いているのは**倍化と反復**であって、
載せる先ではない。

## 報告だけして、直していないもの：**継ぎ火 × 反動が、説明と合っていない**

> 「反動と継ぎ火は重複しないのか。5×2×1.5=15になると思ったが13。シナジーはないのか。無念」

作者の計算が説明どおりで、**実装がそうなっていない。**

- 継ぎ火の説明：「この行動の後、次に別の行動を選ぶと、**その効果が1.5倍になる**」
- `applyHandoff` は加算分を `baseEffect(actionId)`（**変異前の素の値**）から作る
- 打撃5・反動あり → 手動 10、継ぎ火の加算は `round(5/2)=3` → 合計 **13**
- 説明どおりなら、その行動の効果は 10 なので 1.5倍で **15**

**素の行動には差が出ない**（5 → 5+3=8、5×1.5=7.5→8）。
食い違うのは**別の変異と重なったときだけ**である。
つまりこれは、**噛み合わせを考えずに書かれた一箇所**であって、
噛み合わせを禁じる設計判断ではない。

直さなかった理由は2つ。

1. **これは仕様の変更になる。**`AGENTS.md` の分担では、閾値と仕様は独自に変えない
2. `analysis/experiments/exp-04/` が進行中で、`graft/` の意味論に触れると交絡しうる

ただし**この一箇所は、この企画が探しているものそのものである。**
`BOREDOM.md` が特定した最大の熱源は「機構が噛み合うと分かる瞬間」で、
その代表例として引かれているのが「一撃99の制限は2回攻撃なら198までいける」だった。
**作者は今日、同じ形の期待を自分で立てて、engine に断られている。**

直すなら1行で足りる（`applyHandoff` の加算分を、変異後の効果から取る）。
**判断は作者と Sol に任せる。**

### 直したらどうなるかは、もう測ってある

`node analysis/graft-handoff-whatif.mjs 250`。
engine の該当箇所だけを書き換えた一時モジュールを import して、
**同じ物差しで現状と並べる**（ルールは再実装していない）。

一発のダメージ：**いま 13 → 説明どおり 15**。作者の計算と一致する。

でたらめな方針の勝率（1戦あたり、250試行 × 敵4体）：

| 盤面 | いま | 説明どおり | 差 |
|---|---|---|---|
| **継ぎ火→遮蔽 ＋ 反動→打撃（作者の答え）** | 60.9% | 66.4% | **+5.5pt** |
| 継ぎ火→充電 ＋ 反動→打撃 | 60.3% | 67.3% | **+7.0pt** |
| 継ぎ火→遮蔽 ＋ 余波→打撃 | 50.1% | 50.1% | +0.0pt |
| 継ぎ火→打撃 ＋ 反動→遮蔽 | 20.2% | 20.2% | +0.0pt |
| 反動→打撃だけ | 54.7% | 54.7% | +0.0pt |
| 継ぎ火→遮蔽だけ | 22.0% | 22.0% | +0.0pt |
| 接ぎ木なし | 12.7% | 12.7% | +0.0pt |

**動くのは、継ぎ火が反動の載った行動へ渡るときだけ。**他は1つも動かない。
つまりこれは釣り合いの変更ではなく、**噛み合わせが一箇所だけ止まっていたのを外す**変更である。

ただし**代償はある。**いちばん支配的な盤面が 60.9% → 66.4% になる。
説明どおりに直すと、**支配はわずかに強くなる。**
だから直すなら、敵側（心臓炉のような「効かない敵」）とセットで考える方がよい。

### 測り方を2回間違えた（記録）

1. **最初、全部 +0.0pt と出た。**差が無いのではなく、
   `graft-dominance.mjs` が接ぎ木を**1つずつしか載せていなかった**。
   変異どうしの噛み合わせは、2つ載せた盤面でしか動かない。
   **測れない測り方で「差が無い」と言うところだった。**
2. **一発の確認が 12 → 12 と出た。**13ダメージが敵HP12で頭打ちになっていた。
   敵HPを999にしたら 13 → 15 になった。

どちらも「標本が端（全部同じ／ゼロ）を指したら、まず測り方を疑う」で拾えた
（`AGENTS.md` の5規則の2）。
