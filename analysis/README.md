# ゲームシステム機械評価

このディレクトリは、ゲームの面白さを数値で決めるためではなく、実装前に「ほぼ不可能」「自明」「総当たり」「支配戦略」「未来予知依存」といった構造を足切りするための実験基盤である。

## 比較候補

- A 多用途素材：同じ素材を砲塔・外殻・炉へ割り当てる現在型。
- B 固定機械＋性質変異：固定された機関・砲撃・装甲・修復へ、増幅・反復・連動・初動などの性質を付ける。
- C 循環駆動列：単独でも働く装置を最大5個並べ、生成したエネルギーを後続装置が利用する。

すべて、初期3要素、戦闘後の異なる2択、5稼働枠、6戦という共通骨格で比較する。

## 実行

```bash
node analysis/system-tournament.mjs --seeds=160
```

基準値に加え、敵数値を±10%変えた頑健性試験を実行する。

候補・敵倍率を絞る場合：

```bash
node analysis/system-tournament.mjs --seeds=40 \
  --models=cyclic_drive_line --scales=0.94,0.96,1
```

比較結果と採用判断は `SYSTEM_TOURNAMENT_REPORT.md` に記録する。

## 解釈上の注意

- 全知探索の勝率は面白さではなく、答えが存在する上限である。
- 一戦先読みは全配置を列挙するため、人間の能力を過大評価する。
- 構成数は同じ機能の置換を多く含むため、機能量でまとめた勝ち筋も併記する。
- 良い数値は必要条件であって十分条件ではない。足切り後は必ず人間がプレイする。
- 一つの合成スコアで順位を決めず、複数軸のパレート比較を行う。
