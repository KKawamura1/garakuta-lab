# 現在地 — 灰の遠征

更新日: 2026-08-31（UTC）

## 結論

EXP-18 R8 の Campaign Stage 0〜3 が本編です。R9（初期4Stageのチュートリアル化）と
R8 Phase C（手続き生成装備と Blueprint）を実装しました。実装と機械検査は進んでいますが、
作者は現行版をまだ評価していません。面白さと再プレイ欲は未判定です。

## 現行の遊び方

- Campaign Stage を選ぶ。Stage 0 が既定で、Stage 1〜3 は前段のクリアで順に開く。
- 初回の Stage は、同行する仲間が決まっている。Stage 0 は2人で、Stage を進むごとに1人加わり、Stage 3 で5人になる。
- Stage 0 の初回だけ、勝てない配置で始まる一戦がある。負けると時間が巻き戻り、戦闘予測を見ながら配置を変えて挑み直す。
- 一度クリアした Stage を遊び直すときは、8人から5人を自由に選べる。会話も出ない。
- 隊列は2×3。前列3・後列2、または前列2・後列3。人数が少ないぶんだけ空き枠が増える。
- 各人物に行動3、反応3、常設2を装着し、装備を2枠まで割り当てる。
- 次の戦闘の敵、狙い、法則、変異、脅威の概要を開始前に読む。
- 自動戦闘を決定的に再生し、盤面の動きとイベントログで因果を追う。
- 報酬、野営、補給、撤退を選びながら遠征を進め、終了時に記録する。

## Campaign Stage（R9）

| Stage | 人数 | 加入 | 新しい pack | 有効 pack | 問い |
|---|---:|---|---|---|---|
| 0 — 灰の入口 | 2 | — | pack_edge（入口） | E | 攻撃と防御と、ただ殴ることの違い |
| 1 — かばう手 | 3 | ナギ | pack_wall（入口） | E＋W | 誰を守り、守った結果をどう使うか |
| 2 — 間合いと順番 | 4 | トワ | pack_tempo（入口） | E＋W＋T | 誰がいつ動くと得か |
| 3 — 傷を抱えて進む | 5 | ミナ | pack_care（入口） | E＋W＋T＋C | 傷・資源・状態をどう管理するか |

pack は累積します。新しい pack はその Stage では入口（7〜10技能）だけが出て、
次の Stage から全体が出ます。**前に覚えた技能は消えません。**

1遠征は3幕12戦です。4、8、12戦目が act boss です。敵の数と threat budget は
遠征の人数に合わせて減ります。通常戦と精鋭戦の HP は持ち越し、4・8戦目のボス後に
全回復します。補給は再挑戦、報酬の引き直し、偵察、野営などで消費する有限資源です。

## 生成装備と Blueprint（Phase C）

- 報酬の装備2枠のうち一つは手続き生成装備。**rule は最初から全部読めます**（情報を隠して売らない）。
- 生成は決定的で、同じ seed / drop / 等級 / affix family からは同じ品が出ます。
- 完結しない rule（発火不能、無料無限循環、打ち消し合う代償）は生成しません。50 attempt で作れなければ診断を表示します。
- 遠征終了時に、等級の高い順で Blueprint として残ります（勝利2・安全撤退2・敗北1）。
- Blueprint archive に所持上限はありません。次の遠征へ持ち込める枠だけが 1〜5 です。
- 持ち込んだ品は、その遠征の affix family の外でもそのまま動きます。
- 目利き（5段）は等級の引きを良くします。読める情報は変わりません。

## 現行の技術境界

- ecology/ が UI、content、engine、進行、replay、local save の本体。
- Profile は遠征をまたぐ資金・解禁・人物状態・Blueprint archive・物語の既読印を持つ。
- Run は遠征内の資源と構成、そして**その遠征で拾った生成装備の定義そのもの**を持つ。
- Battle は一戦の再生状態を持つ。
- 同じ入力と seed は同じ戦闘イベント列を返す。
- exact preview は、開始前の見える情報と実際の battle input の一致を監視する。
- functions/api/runs.js と migrations/ が D1 の受け側です。

## 既知の未実装

- 横断pack `pack_relay`（余波と受け渡し）は試作。Campaign には入れていない。
- `pack_barrage` は Stage 3 が C になったため Campaign から外れ、Free / Endless に残っている。
- affix family の購入は未実装。
- Stage 4 以降と Endless は未実装。

- `analysis/ecology-decision-space-smoke.mjs`（Free mode の意思決定空間の診断）は
  「考えた編成が素朴な編成に大きく勝てていない」で非ゼロ終了します。R8 以前からの
  既知の診断で、check-all.sh の fast path には載せていません。

## 機械検査で分かっていること

- Stage 0〜3 のいずれにも、12戦を通せる build が少なくとも一つある
  （`analysis/ecology-campaign-smoke.mjs`）。素の初期構成では通せない。
- 少人数 Stage では、敵の数・threat budget・boss の体力・受けが人数の比で下がる。
  5人の遠征の出力は変わらない。数値は未調律。
- 本編の入口（会話・勝てない一戦・巻き戻し・2人編成・生成装備の報酬・
  設計図の持込）は `analysis/ecology-tutorial-trial.mjs` が画面で通す。
