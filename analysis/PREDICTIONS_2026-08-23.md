# 遊ぶ前に登録する予測（2026-08-23、作者が起きる前）

新しい3版は**まだ誰も遊んでいない。**測ったのは全部、盤面の性質である。
**遊んでもらう前に、何が起きるはずかを書いておく。**当たったか外れたかを後から言えるように。

## COST 0.1

| 予測 | 根拠 |
|---|---|
| **「無傷で行くか、速く行くか」で迷う場面が出る** | 速さ順位と安全さ順位の相関が **+0.30 → −0.26**。片方を取ると片方を失う |
| **暴走は、勝ち筋のほとんどで鳴る**（飾りではない） | 最小失点の手でも78%で鳴っている |
| 「敵が強い」ではなく**「出しすぎた」**という言い方が出る | 削られる原因が敵ではなく自分の並びになる |

**外れの形：**「ただ難しくなっただけ」「暴走を避けて薄く殴るのが正解で、選んでいる感じがしない」。
そのときは代償ではなく**ただの上限**を作ったことになる。

### 追記：**COST は損害を強制しない**（`analysis/run-viability.mjs`）

失点が最小になる並びを選び続けて6戦通すと、**COST 0.1 は 48回中46回完走し、
平均残HPは 30.0**——つまり**まったく削られずに終わる。**

これは版が壊れているのではなく、**代償の形がそうなっている**ということである。
安全だけを見るなら、遅く行けば無傷でいられる。**代償は、速さを欲しがったときにだけ請求される。**

だから予測を絞り直す：

> **速さを狙わない限り、COST は laws-0.3 とほぼ同じに感じられるはずである。**
> 差が出るのは、作者が**撃破巡回の記録を詰めにいったとき**だけ。
> （作者の感情マーカーは実際そこに集まっている：「巡数更新オウケーイ」「4T撃破」。）

**外れの形が一つ増える：**「言われてみれば暴走があったが、気にせず遅く行って無傷で終わった」。
そのときは、**等級が失点でしか決まっていないこと**が効いている可能性が高い
（画面は「無傷を狙え」と言い、心は速さを欲しがっている）。等級の基準は別の変数なので、
**この結果だけで等級をいじらない。**

なお完走率そのものは版の比較に使えない。**報酬は毎回1番目を取る雑な方針**で通しているので、
laws-0.3 側の「勝てる並びが無い」15回にはその雑さが混ざっている。

### 【取り下げ 2026-08-23 深夜】この予測は成り立たない

上の数字は観測を「勝敗・巡回・残HP」に絞って測っていた。**実際の画面はもっと出している。**
位相表の枠ごとの値まで入れて測り直すと、**1回並べれば候補は1.8**（倍率の札を伏せても同じ）。

**当てるのに数戦かかるという予測は取り下げる。**正しくは「**一瞬で決まる**」。
版そのものをどうするか（表を潰す／畳む／形を変える）は作者の判断なので、
公開したまま、遊び分けの一覧にその旨を書いた。詳細は `analysis/IDENT_0_1.md`。

## SQUEEZE 0.1（COST の抜け道を塞いだ版）

| 予測 | 根拠 |
|---|---|
| **無傷で終わるランがほぼ無くなる** | 無傷で抜けられる局面が0〜40%（多くの組で0%）。実測の平均残HPは 27.8 |
| **「遅く行く」を選べなくなったと気づく** | 敵が毎巡回復するので、削り切れずに12巡で打切りになる並びが出る |
| 完走率は laws-0.3 と変わらない | 35/48 対 33/48 |

**外れの形：**
- 「ただ難しいだけ」「回復のせいで勝ち筋が細って、選ぶ余地が減った」
  → 挟んだつもりが**通路を狭めただけ**だったことになる
- 「暴走も回復も気にせず、いつもどおり勝てた」
  → 両方とも知覚されていない。**0.9 の規則どおり、この線を畳む**

**COST と SQUEEZE の比較が本命である。**片方は代償を避けられ、もう片方は避けられない。
どちらも「代償がある」が、**請求されるかが違う。**
両方とも同じくらい面白い／つまらないなら、**代償の有無は面白さを動かしていない。**

## 書かない予測

**「無傷で勝てる並びが存在するか」は測ったが、載せない。**
測ったときの母集団が作者の選択と違っていた——
手持ち8個のうち**先頭5個の並べ替えだけ**を見ていて、
**どの5個を選ぶか**を作者は毎回決めている。数字は出たが（74% 対 57%）、
**比べてよい数字ではない。** 母集団が違う測定を予測に混ぜると、
当たっても外れても何も言えなくなる。

## 全部に共通して外れる形

**3つとも、押す前に結果が分かること自体は変えていない**（予告は実機を回している）。
Into the Breach の線——「不確実なのは結果ではなく、何を諦めるかの正解」——に賭けているが、
**もし3つとも空振りしたら、賭けた線が違っていた**ということになる。
そのときは 0.9 の規則どおり、**版を足すのではなく、この線を畳む。**
