# ゲームシステム足切り試験 2026-08-17

## 結論

人間テストへ進める候補は **C 循環駆動列** とする。これは面白さの証明ではない。候補A/Bと同程度の「全知ならクリア可能」な難度へ揃えた時、未来予知なしで残る勝ち筋と、最終構成の許容幅が最も広く、ルール数も最少だったためである。

候補Bは「選択肢は大量だが勝てる領域は細い」という明確な棄却条件に触れた。候補Aは引き続き価値があるが、整数境界による難度の崖と、勝てる最終構成の細さがある。

## 共通条件

- 6戦、最大耐久30、戦闘後に耐久2回復
- 初期要素3個、各勝利後に異なる2択から1個を取得
- 最大5個を稼働
- 各戦闘では全配置を列挙し、最良結果を選ぶ
- 全32通りの報酬選択経路を列挙
- 単純方針、ランダム方針、一戦先だけ最適化する方針を比較

難しさの差を構造差と誤認しないため、敵倍率を調整して全知勝率を約75%へ揃えた。A/Cは40シード、計算量の大きいBは24シードの暫定値である。

## 解釈

### A 多用途素材

通常難度では全知勝率97.5%だったが、敵倍率1.06で0%になった。1.04では77.5%であるため、わずかな変更が徐々に難しくするのでなく、全経路をまとめて消す。撃破巡回・有限装甲・持越し耐久の整数境界が連鎖している。

同難度のCと比べると、報酬の両側に勝ち筋が残る率は半分、最終構成の勝利領域は約1/4.5である。人間が全配置探索できないことを考えると、実感上はさらに細い可能性が高い。

### B 固定機械＋性質変異

固定行動へ変異を割り当てる上位仮説は棄却しない。しかし今回の「4系統へ最大2個ずつ自由割当」は、平均約5,800候補のうち勝てる領域が0.7%しかない。認知負荷と総当たりを増やしながら、許容幅を増やせていないため、この実装は人間テストへ進めない。

### C 循環駆動列

ルール数が最少で、両方の報酬に将来の勝ち筋が残る率と最終勝利領域が最大だった。各機構が単体でも最低限働き、順番変更が現在の戦闘へ即座に反映されるため、特定部品待ちと遠い将来の罠を弱められる可能性がある。

ただし全順列は依然として約1,090候補ある。UI上で一手ずつ隣へ動かした時に改善方向が読めるか、単に全順列を試したくなるかは機械評価できない。

## 人間テストで反証すること

1. 発電機を前へ、砲・盾を後ろへ置く固定手順だけで終わらないか。
2. 並べ替え一手の結果差から、次に試す方向が見えるか。
3. 報酬の両方を「使い道はある」と感じるか。特定機構待ちにならないか。
4. 合理的に選んだ報酬が数戦後にだけ罠だったと感じないか。
5. 約5個の順列が、少なすぎず総当たりにもならないか。
6. 反響・蓄電による2巡目の変化を理解できるか。

肯定条件は勝率ではなく、少なくとも一度「来た機構で以前の順番の評価が変わり、その理由を戦闘前後に説明できた」ことである。否定条件は、固定順、総当たり、欲しい機構待ち、または予測表示を見ても結果の因果が分からないことである。

## 限界

- 仮想プレイヤーは全配置を列挙できるため、人間より大幅に強い。
- シード数は設計探索用であり、統計的な製品評価ではない。
- 機能的構成の分類は粗い手製の特徴量である。
- 数値正規化は候補の相対比較用であり、最終バランスではない。
- 面白さ、驚き、操作感、説明可能性は人間テストでしか判定しない。
