# SCRAPLINE 0.6 — 敵・装備・配置の面白さ仮説を実装

更新日: 2026-08-27（UTC）  
ruleset: `scrapline-0.6`  
build: `scrapline-build-20260827-r6`

## 実装した中心体験

- 一つの鉄塊をID付きの弾として、車両ごとの前後状態を追跡する。
- 切断、圧縮、帯電、溶融、磁化、装甲形成、回収、逆走、ループ、傷跡を、
  専用の合成レシピではなく共通の弾の状態へ作用させる。
- 配置順で、弾数、重さ、速度、火花、溶融、帰還、炸裂が変わる。
- 群れ、装甲、速攻、拾い屋という四つの異なる敵の問いと、群れ＋帰還を要求する
  二段階ボスを実装する。
- 新しい残骸を仮組み表示し、連結・交換・見送り・解体・ドラッグ配置を一つの
  再構築ループへ入れる。
- 戦闘はイベント列から再生し、敵弾の標的、弾ID、分裂、着弾、帰還再加工、
  回収、窃取を同じ因果線で表示する。
- 終了時に最終車列、最も派手な一射、最大三つの因果、改造履歴、自動命名、
  次に試す問いを残す。

## 敵ごとの検証結果

`analysis/scrapline-balance-smoke.mjs` は通常車両11種の順序付き列を1〜5両まで
全列挙し、5つの代表的な問いへ322,355件の戦闘を判定した。

| 問い | 勝てる列の数 | 確認した解法の例 |
| --- | ---: | --- |
| 群れ | 52,787 | 切断、帯電→溶解、磁石＋帰還 |
| 装甲 | 36,915 | 圧縮、溶融、帰還の累積 |
| 拾い屋 | 33,416 | 回収車、早期撃破、尾部防衛 |
| 速攻砲台 | 694 | 短い列、加速、四両の加速溶融列 |
| ボス | 1,973 | 圧縮＋帰還、切断＋溶融＋帰還 |

全ての問いに異なる勝ち列が二つ以上あり、五つ全てへ勝つ万能列は0本だった。
速攻砲台では、四両以上の遅い列と五両列を迎撃し、短い列や前方の加速溶融弾に
別の答えを残している。

## seedと一ランの検証結果

`analysis/scrapline-seed-regression.mjs` を0〜255 seedで実行した。

- 256 / 256 seedで、決定的な方策が7区画を完走。
- 敵順は86通り、開始パターンは2通り。
- 開始時の残骸候補は94通り。
- 診断方策は安全な一列へ収束するが、これは固定方策の結果であり、実際の配置の
  選択肢を表すものではない。
- `analysis/scrapline-run-diversity-smoke.mjs` では、同じseed・同じ報酬でも
  最終配置の異なる二つの完走ルートを確認。

## 意図的に控えたもの

熱・電気などの抽象ゲージ、専用A+Bレシピ、レベル上げ、リロール店、隠し乱数、
長い物語、永続スコア、分岐マップ、恒久成長は入れていない。音・振動は補助とし、
ミュートや非対応端末でも弾の状態と因果が視覚で読めることを優先した。
