## 0. なぜ人物を差し替えるか

現行 `ecology/content/character-lore.mjs` の5人と、PR #80 の5人には、
**同じ構造的な問題**がある。

1. **全員が観察者である。**現行はシキ・ナズナ・レイ・スミの4人が「他人を静かに観察して
   正確に訂正する人」。PR #80 もハル・コヨリ・リツの3人が記録と観察の人。
   ボケが居ないので、ツッコミも笑いも驚きも成立しない。
2. **全員が感情を抑制する側。**誰も声を荒げず、泣かず、照れず、怒らない。
3. **望みが抽象的。**現行は5人とも「知りたい」としか言っていない。感情移入は
   具体的で外向きな望みにしか働かない。
4. **差異が静かな差異しかない。**体格も声量もテンションも揃っていて、立ち絵を並べても
   記憶に残らない。PR #80 も女性3人が全員小柄。
5. **可愛げ（愛せる欠点）が無い。**Will / Lie / Need は文学的な欠点であって、
   愛せる欠点ではない。

暗い世界に明るい人物を置くのは矛盾ではなく正攻法である。世界が暗いから人を暗くするのが
一番効かない選択で、明暗の対比があって初めて暗さが刺さる。

### 2.1 ゴウ — 主役1

**男・24歳・大柄。**ガサツ、声がでかい、口が上手い、調子がいい。
民間潜行班〈十三号室〉の責任者。軽薄に見えて、判断は全部自分で被る。

- **Will**：5年前に失踪した兄ユウを見つける（PR #80 のハルから継承）
- **Lie**：**「全部、俺が引き受ければいい」**
- **Need**：背負えないものがあると認め、人に預ける
- **ギャップ**：何でも茶化すのに、**兄の話だけは一度も茶化さない。**黙るので全員に伝わる
- **愛せる欠点**：字が壊滅的に汚い／暗いところが苦手／料理だけ異常に上手い／
  ツグミに論破されると素直に謝る
- **声**：短く、雑に、断定。困ると話を逸らす。「……はい」と素直に折れる

兄ユウは、ある潜行から「全員で帰った」と証言して帰還した。外部記録では6人で出発し、
5人しか帰っていない。三日後にユウは姿を消した。手帳の最後の一文は
「第七層より下。記録を信じるな」。

### 2.2 ツグミ — 主役2・ヒロイン

**女・15歳・小柄。**観測院の医療研究部から飛び級で出てきた天才。
丁寧語のまま容赦がない。早口。遮られると被せてくる。

- **Will**：灰庭性記憶障害の治療法を見つける
- **時限装置**：**彼女自身の記憶剥離の進行が、異常に速い。**隠している
- **Lie**：「記憶さえ戻れば、人は元に戻る」（PR #80 のコヨリから継承）
- **Need**：完全に復元できなくても、その後の人生は続けられる
- **ギャップ**：大人4人を論破するのに、**背が届かない・眠くなる・
  暗いところはゴウより怖い**
- **愛せる欠点**：謝れない／甘いものを断れない／眠いと急に無口になる／
  支給外套が大きすぎて袖を二回折る
- **声**：**丁寧語を崩さないまま、感情だけ振り切る。**言い過ぎて即座に後悔する
- **ゴウとの関係**：5人で唯一、ゴウだけが彼女を子供扱いしない。
  恋愛にはせず、対等な相棒として書く

**この時限装置が、これまで欠けていた「賭け金」になる。**しかも作品テーマ
（人は記憶と記録の総和なのか）そのものである。

### 2.3 ヒバナ

**女・11歳・最小。**小さい、速い、よく笑う、よく怒る。考えたことが全部顔に出る。

- **設定の核**：**5人で一番よく忘れる。**だから毎回が初めてで、いつも楽しそう
- **Will**：「みんなと一緒に行きたい」
- **Lie**：「役に立てば置いていかれない」（PR #80 から継承）
- **Need**：役に立てなくても仲間は残る
- **来歴**：灰庭の中で拾われた子。**記録が最初から無い**
- **愛せる欠点**：食べる速度が異常／すぐ寝落ちする／ナギの後ろをついて回る／
  ツグミを「ツグミお姉ちゃん」と呼んで本気で嫌がられる
- **声**：全部感嘆。相手の返事を待たない

### 2.4 ナギ

**女・22歳・中背。**優しい。断れない。愚痴が多い。そして手だけは絶対に止まらない。

- **ギャップ**：常に嘆いているのに、**一度も隊を抜けない。愚痴りながら誰より庇う**
- **Secret**（PR #80 のスミから継承）：**実は5人と会う前から、何年も灰庭へ潜っている。**
  その時期の公式記録が消されている。棚のガラクタは、過去の自分が毎回
  「絶対に捨てるな」と書き残したもの
- **不憫を悲哀へ反転させる仕掛け**：彼女は同じ愚痴を何度も言い、何度も忘れている。
  ガラクタの一つに、自分の筆跡で「もう一回だけ、がんばれ」と書いてある
- **Lie**：「昔の自分を知れば、今の自分が分かる」
- **Need**：今の自分が何を大切にするかは、今の自分が決めていい
- **ヒバナとの関係**：異常によく庇う。理由を聞かれても「危ないから」。
  二年前の映像で同じ班だったと判明する。二人とも覚えていない
- **愛せる欠点**：泣き言が多い／褒められると挙動不審／甘やかされ慣れていない
- **声**：語尾が下がる。訴えるが、手は止まらない

**記録の対称性**：ナギ＝記録を消された人／ヒバナ＝最初から記録が無い子。
「人は記憶と記録の総和なのか」という主題に、二つの極が立つ。

### 2.5 ソウジ

**男・58歳・中背。**中央観測院の記録主任。完璧な物腰。全員に敬称を付ける。

- **初登場は敵対者。**停止命令を持って現れ、ゴウに「お兄様は、ご存命ですよ」と
  告げるが所在は言わない（PR #80 のリツから継承）
- **Lie**：「記録は人間より正しい」
- **Need**：記録に無いものを、人との関係から信じる
- **Will**：戻らなかった潜行員の記録を、一人残らず正しい形で残す
- **背景**：三十年、遺族対応の場に記録係として立ち会ってきた。「一緒に潜ったでしょう！」と
  泣く家族と「知らない人です」と答える帰還者を、何百回も見ている
- **初老にしたことで設定が自然になる。**PR #80 のリツは24歳で「遺族対応を何百件」
  だったが、58歳ならそのまま成立する
- **ギャップ**：完璧な老紳士なのに、**元一級潜行員。**彼自身の潜行記録も消されている
- **愛せる欠点**：甘いものに目がない／若者言葉を覚えようとして必ず失敗する／
  実は院を辞めたくて仕方がなかった
- **声**：完全な敬語。間が長い。一度も語気を強めない
- Scenario 3 で記録改竄を発見し、消去命令を拒否して職を失い加入

## 3. 数値設計

### 3.1 職業ではなく「初期構成と数値の傾き」

`docs/DESIGN.md` §2 の不変条件は「通常行動には攻撃手段を保証する」と定めており、
**engine 上は誰でもどの技能も取れる。**以下は初期構成と数値の傾きであって、
クラス制限ではない。

現行 `roster.mjs:48` の「攻め手を一つも持たせない」と
`character-lore.mjs:109` の「攻撃の行動を持たない」は、この方針と矛盾するので**削除する。**

### 3.2 5人が持つ軸

| 人物 | 突出させる軸 | 代償 | 役割名 |
|---|---|---|---|
| **ゴウ** | **HP最大 ＋ 腕力最大** | 受け最低・低速・技ゼロ | 突撃 |
| **ツグミ** | **集中最大**（技火力） | **HP最低**・紙 | 術式 |
| **ナギ** | **受け最大 ＋ 治療** | 火力が出ない | 守護 |
| **ヒバナ** | **速度最大・AP2・手数最多** | **一撃が最弱** | 遊撃 |
| **ソウジ** | **反応点最大**（割り込み） | 突出した攻守が無い | 後詰 |

### 3.4 それぞれの設計意図

**ゴウ — HPも火力も最大。ただし極端に歪んでいる。**
受けは hit ごとの固定軽減なので、**受け1のゴウは多段攻撃が全部素通りする。**
HP300 は一撃では溶けないが、細かい攻撃を延々受けると誰より早く沈む。
さらに速度4・AP1・集中12。5軸のうち2つで最大、3つで最低クラスという極端なピーキー型。
「全部俺が引き受ければいい」という Lie が、そのまま
「**引き受けきれない相手が居る**」という穴になる。
`AGENTS.md`「完全上位互換を作らない。作る場合は明確な代償を付ける」は、
この歪みで満たす。

**ツグミ — 隊の主火力。そして前に出たがる。**
集中52 で位置に関係なく削れる。HP110 で隊最低。
ここで **「前に出ないといけない」というドラマが、性格の側へ移る。**

> プレイヤーは後ろに置きたい。本人は前に出たがる。

理由は子供扱いされたくないから。そして実際に前に出すと死ぬ。
**序章でゴウがまさにそれをやって、ツグミを死なせる。**
現行の `PROLOGUE`（後列へ下げると勝てる4通り）は、
ゴウ＝腕力なので前列必須、ツグミ＝集中なので後列でも落ちない、で**構造を変えずに動く。**

**ナギ — 受けて、庇って、自分で治す。**
受け24 で多段を殺し、集中34 で治療と防壁を出す。攻撃もできるが主火力にはならない。
「うう、なんで私ばっかり」の中身が**庇護と治療を両方やらされている**になる。
しかも自分で自分を治せてしまうので、周りが遠慮しない。
秘密（何年も潜っていた）は、**受け方だけが異常に上手い**という形で数値に現れる。

**ヒバナ — 一撃は隊で一番弱い。**
腕力14・集中14 で一撃は最弱。11歳として自然。稼ぐのは hitCount
（`skills-active.mjs` に3hit・2hit の語彙が既にある）。
**受けの高い敵には固定軽減で全部消される。**弱点が明快で、しかも可愛い。
速度13・AP2 で誰より速く二回動く。本人は理屈を分かっていない。

**ソウジ — 反応点4。先に動かない。**
58歳に「筋力最大」も「速度最大」も無理があるので、反応点（割り込み回数）を渡す。
自分からは動かず、相手が動いてから読んで割り込む。AP1 と両立する。
攻守が中庸なのも「歳だから」で説明が付く。

## 4. 加入順と学習順

- **Stage 0：ゴウ ＋ ツグミ** — 主役2人。チュートリアルは現行と同型のまま動く
- **Stage 1：ナギ** — ゴウの穴（多段に弱い）を埋める役が早く要る。秘密も長く効かせられる

- **Stage 3：ソウジ** — 観測院から敵対者として来て、最後に加入

pack の解禁順（`care → edge → wall → tempo`）は、この加入順だと
**wall を Stage 1 へ、多段系を Stage 2 へ**移す必要がある。`campaign-stages.mjs` の調整が要る。

## 8. 未決事項

### 8.1 「集中（focus）」の再定義 ★要判断

現行の集中は、**なぜ後列でも威力が落ちず、腕力と無関係で、しかも攻撃・治療・防壁が
すべて同じ数値で伸びるのか**を説明していない。「集中」という語は精神状態を指すだけで、
それがなぜ距離を無視して敵を削るのかが世界観の側に無い。

PR #80 の世界設定は、この穴をそのまま埋められる。灰庭では**固定因果**が働き、
先見機はそれを読み出す。**一部の人間は、読むだけでなくわずかに書き換えられる**とすれば、

- 攻撃 … 敵に起きる出来事を確定させる（**因果に距離は無いので後列でも落ちない**）
- 治療 … 味方に起きた出来事を巻き戻す（帰環杭の極小版）
- 防壁 … まだ起きていない出来事を先に固定する

の三つが同じ数値で伸びる理由も、腕力と無関係な理由も、灰庭の外では効かない理由も
同時に説明が付く。腕力は物理なので距離が要る、というのはむしろ当たり前になる。

名称案：**「観測」**（中央観測院の名の由来にもなる）／「干渉」／「読み」。

**さらに、これを採ればツグミの時限装置に代償の説明が付く。**
書き換えるほど自分の記憶が削れる。だから彼女は誰より速く忘れ、だから急いでいる。
数値上の代償ではなく物語上の代償になる。

採否は未決。採る場合は `values.mjs` / `effects.mjs` / UI 文言の用語変更を伴う。

### 8.2 その他

- **数値は未検証。**`node ecology/check.mjs`、`bash analysis/check-all.sh`、
