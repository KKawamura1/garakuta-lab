# 十二の明日をほどく — 世界・人物・数値のリブート案

> 仮題。現行 `ecology/` の戦闘・成長・12戦構造は残し、**タイトル、世界観、人物、関係、
> 数値設計、物語を全面的に組み替える案**。
>
> この文書は**実装仕様ではなく設計の候補**。現行コードはまだ変更していない。

---

## 0. 目標

このゲームの強みは、戦闘そのものより
**「結果を完全に先読みし、隊列・技能・装備を組み替えて勝てる未来へ寄せる」**ことにある。

物語側でも同じ主題を扱う。

- 未来は完全に読める。
- しかし過去は、灰庭から帰るたびに抜け落ちる。
- 数字は嘘をつかない。
- だが、人が何を思い、なぜ誰かを選んだかは数字だけでは残らない。

中心テーマは次の一問。

> **人は、記憶と記録の総和なのか。**

プレイヤーは戦闘では完全情報を得る一方、人物については不完全な記憶と不完全な記録を
頼りに関係を積み上げる。

キャッチコピー案：

> **負ける未来を見た。だから、勝てる形に並べ替える。**

「十二」は各遠征の12戦。「明日」は次戦予測。「ほどく」は、固定された因果を隊列・技能・
装備で組み替えることと、失われた過去を人間関係から読み解くことの両方を指す。

# 第一部 世界

## 1. 舞台〈灰庭〉

「迷宮」という語は使わない。旧市街の地下から広がる異常領域を、人々は**〈灰庭〉**と呼ぶ。

外から見れば地下遺構だが、内部では距離・物質・記憶の保存則が崩れている。深度ごとに景観も
法則も異なり、同じ経路を二度通っても同じ物が見つかるとは限らない。

人々は「迷宮へ入る」ではなく、**灰庭へ降りる／第二深度へ潜行する／層域を越える／
結節を断つ**と言う。

### 1.1 起源

約40年前、国家研究施設〈明日観測所〉が未来予測研究中に事故を起こした。施設は消滅せず、
周辺を巻き込んで現実から半ば切り離された。その跡にできたのが灰庭である。

事故以降、灰庭では「まだ起きていない出来事」が、条件さえ固定されれば一意に定まる。

---

## 2. 三つの法則

### 2.1 固定因果

灰庭では、戦闘条件が確定すると結果も確定する。敵、味方、現在HP、隊列、技能、装備が
同じなら、同じ戦闘は必ず同じ結果になる。

潜行員は携帯型の**〈先見機〉**で、その固定未来を戦闘前に読み出せる。表示されるのは
確率ではない。

```
  > 勝利 / 7巡
  > ゴウ   　128 → 43
  > ツグミ 　104 → 0
  > ヒバナ 　 96 → 17
```

という**確定結果**である。隊列や装備を変えれば初期条件が変わり、別の未来が表示される。

**ゲームとの対応**：Preview ＝ 先見機による固定未来の観測。本戦 ＝ 観測済みの未来を実行する。
同構成なら完全一致 ＝ 世界法則そのもの。

### 2.2 記憶剥離

灰庭の中で形成された**具体的なエピソード記憶**は、境界を越えて外へ出ると崩れる。

| 残るもの | 失うもの |
|---|---|
| 灰庭へ入る前までの人生 | 誰とどんな会話をしたか |
| 外で読んだ日記・映像・報告書の内容 | 第何戦で誰が倒れたか |
| 身体に残った傷や疲労 | どの瞬間に誰を好きだと思ったか |
| 人間関係についての知識 | 戦闘中に身につけた身体感覚 |
| 理屈として学び直した事実 | 深部で何を恐れ、何を決めたか |
| 理由を説明できない感情の残滓 | |

このため潜行員は年齢の割に独特の幼さを持つ。危険な経験を何年しても、その「経験した実感」が
十分には積み上がらない。妙に実務的なのに妙に無邪気、修羅場慣れしているのに感情処理だけ
未熟、というアンバランスさが灰庭潜行員の特徴になる。

ただし人格が毎回初期化されるわけではない。外で日記を読み、仲間と話し、自分なりに
意味づけたことは次の遠征へ持ち越される。

> 何があったかは覚えていない。
> でも、その人の隣にいると安心する。

という関係が成立する。

### 2.3 灰外崩壊

灰庭で生成された特殊物質**〈遺装〉**は、外へ持ち出すと急速に崩れる。ただし帰還時に一つだけ、
高価な**〈定着処理〉**を施せる。定着した遺装だけは次の潜行へ持ち込める。

この一品には性能だけでなく来歴を残す。

```
  白銀の留め針
  第六層域「雨のない街」で発見
  第7〜12戦：ツグミ使用
  第12戦後、本人の希望で定着
```

本人はその遠征を忘れている。だから装備は、**失われた冒険の物証**になる。

## 3. 観測 —— 非物理の攻め手

現行の「集中（focus）」は、**なぜ後列でも威力が落ちず、腕力と無関係で、しかも攻撃・治療・
防壁がすべて同じ数値で伸びるのか**を説明していない。`docs/HISTORY.md` §3.3 の通り、
R11 で技攻撃を focus へ移したのは「攻めの軸が1本だと編成が守りへ寄る」という
**ゲーム設計上の理由**であって、世界観から生まれた値ではない。

ここで固定因果を使って定義し直す。名称は**「観測」**とする。

### 3.1 定義

灰庭では因果が固く、結果は条件から一意に定まる。**ただし、まだ条件が揃っていない部分には
確定していない余地が残る。**

観測とは、**その未確定の余地を、どちらへ倒れるか先に決めてしまう行為**である。

**確定した因果を書き換えるのではない。**書き換えなら先見機の完全予測と矛盾するし、
「30 の damage を出す」という規模に対して大袈裟すぎる。観測が触れるのは
**まだ決まっていない部分だけ**であり、しかも「その人が何を確定させるか」自体も条件から
一意に決まるので、決定的 engine とも先見機の完全予測とも矛盾しない。

先見機は**もう確定した部分を読む機械**。人間の観測者は**まだ確定していない部分に触る**。
役割が分かれている。

### 3.2 三つの用途が同じ数値で伸びる理由

| いまの呼び名 | 観測として何をしているか | そこから出る仕様 |
|---|---|---|
| 技攻撃 | 敵に起こりうることのうち、悪いほうを先に確定させる | **確定は接触ではないので距離が要らない**＝後列でも落ちない |
| 治療 | 負った損傷のうち、まだ治るか残るか決まっていない部分を「治った」側へ倒す | **既に確定した傷（戦闘不能・死）は戻せない** |
| 防壁 | これから起きる被弾について「浅く済む」を先に確定させておく | **先に張らないと意味がない。**起きてからでは触れない |

三つとも「未確定の余地を確定させる」という**同じ一つの行為**なので、同じ数値で伸びる。
そして各用途のタイミング制限が、世界法則から自然に出てくる。

腕力は物理なので距離が要る——というのが、むしろ当たり前の側になる。

### 3.3 できないこと

- 確定済みのものには触れない（敵の存在そのもの、既に落ちた仲間）
- 灰庭の外では効かない（外では因果が固くなく、確定と未確定の境目がぼやけている）
- **観測は無料ではない。**下記 3.4

### 3.4 代償 —— 記憶剥離の正体

**観測して確定させるたび、観測者の側の「まだ確定していない部分」が持っていかれる。**

記憶は本来ゆらいでいるものなので、真っ先に削られる。つまり**記憶剥離は観測の代償**であり、
灰庭に入るだけでも微弱に起きるが、**濃く観測する者ほど速く進む。**

これは世界法則の例外を作らずに、ツグミ（観測値最大）が誰より速く忘れる理由になる。
彼女は法則の外にいるのではなく、**法則の中で一番濃く被っている。**

### 3.5 〈中央観測院〉の名の由来

観測できる者を登録し、管理し、記録する院。組織名がこの能力から生えている。

### 3.6 実装への影響

計算式は変えない。`values.mjs` / `effects.mjs` / UI 文言の**用語だけ**を
`focus / 集中` から `観測` へ改める。技能の分類名も `technique` から `観測` 系へ。

## 4. 先見と巻き戻しは別物

### 4.1 先見

- 常用・既知技術
- 未来を読むだけ。現実は変えない

### 4.2 〈帰環杭〉

潜行開始時に設置する緊急安全装置。

- 灰庭内でしか作動しない
- ごく狭い範囲・短時間だけ
- 致命的事故時に、直前の局所状態へ戻す
- 莫大な備蓄を消費するため通常運用では使えない
- **使用者の記憶も戻る**ため、便利な経験稼ぎにはならない

観測が「未確定の余地を確定させる」ものなら、帰環杭は**確定してしまったものを一度だけ
未確定へ戻す**装置である。人間にはできないことを、莫大な出力で無理やり行う。
だから高価で、だから一度きり。

Scenario 0 の最初の一戦だけ、先見機が故障した状態で**本当に敗北する。**帰環杭が一度だけ
作動し、同じ場所へ戻る。ツグミが先見機を応急修理し、今度は「負ける未来」を戦う前に見る。
ここでゲームの中心ルールをプレイヤー自身に体験させる。

## 5. システムの物語上の意味

| システム | 物語上の意味 |
|---|---|
| 戦闘予測 | 先見機が固定未来を読み出す |
| 隊列変更 | 未来の初期条件を変える |
| SP | 遠征中に得た実戦経験。帰還時に記憶剥離とともに失う |
| スキル解禁 | 「さっきので分かった」という、その遠征中だけの学習 |
| 装備 | 灰庭で生成された遺装 |
| 装備リセット | 灰外崩壊で失われる |
| 1つ持ち帰り | 一品だけ定着処理できる |
| 補給 | 灰庭内で使える医療・凝固・触媒資材 |
| SPを諦めて補給+1 | 戦闘後の短い安定時間を「復盤」に使うか「採取・調合」に使うかの二択 |
| 4,8戦目後の全快 | 結節を断つと安全域が生まれ、まとまった治療時間が取れる |
| 12戦 | 一層域を維持する三つの結節を順に断つ。4/8/12 が結節守護体 |

### 5.1 SPか補給か

戦闘後、次の灰流が来るまでの安定時間は短い。その時間でできることは一つだけ。

- **復盤する** … 直前の戦闘を振り返り、身体が覚えているうちに動きを詰める → Skill Point
- **採取・調合する** … 灰庭内でのみ効く薬材・凝固剤・触媒を集める → Supply +1

> **強くなるために今の戦いを学ぶか、次の傷に備えるか。**

## 6. 組織

### 6.1 中央観測院

灰庭の管理、救助、潜行許可、帰還者ケア、記録保管を担う公的機関。**悪の組織ではない。**
むしろ社会に不可欠。ただし深部記録の一部を封印している。

**院長：カナエ（42）**。元潜行員。かつて夫と灰庭へ潜り、自分だけ帰還した。本人に記憶はない。
映像には、自分が夫を見捨てて逃げる姿が残っている。

- Will：灰庭を段階的に完全封鎖する
- 信念：**記憶のない人間に、記録だけを根拠として過去の罪や愛情を背負わせるべきではない**

主人公たちの敵対者ではあるが、主張はかなり正しい。

### 6.2 白紙会

元潜行員と家族による運動体。

> **忘れた人には、忘れたままでいる権利がある。**

帰還者へ映像を突きつけ、「あなたはこの人を愛していた」「あなたはこの人を見捨てた」と
迫る行為を暴力だと考える。穏健派は帰還者の権利保護を行い、過激派は記録庫を破壊する。

ゴウとは根本的に対立するが、ナギにとっては救いになる思想でもある。

# 第二部 人物

## 7. なぜ人物を作り直すか

現行 `ecology/content/character-lore.mjs` の5人には、次の構造的な問題がある。

1. **全員が観察者である。**シキ・ナズナ・レイ・スミの4人が「他人を静かに観察して正確に
   訂正する人」。ボケが居ないので、ツッコミも笑いも驚きも成立しない。
2. **全員が感情を抑制する側。**誰も声を荒げず、泣かず、照れず、怒らない。
3. **望みが抽象的。**5人とも「知りたい」としか言っていない。感情移入は具体的で外向きな
   望みにしか働かない。
4. **差異が静かな差異しかない。**体格も声量もテンションも揃っていて、立ち絵を並べても
   記憶に残らない。
5. **可愛げ（愛せる欠点）が無い。**Will / Lie / Need は文学的な欠点であって、
   愛せる欠点ではない。

暗い世界に明るい人物を置くのは矛盾ではなく正攻法である。世界が暗いから人を暗くするのが
一番効かない選択で、明暗の対比があって初めて暗さが刺さる。

|---|---|---|---|---|
| **ゴウ** | 男 24 | 大柄 | ボケ（軽薄）・主役1 | 『勇者のクズ』ヤシロ |
| **ツグミ** | 女 15 | 小柄 | ツッコミ（毒舌）・主役2 | 『風花雪月』リシテア |
| **ヒバナ** | 女 11 | 最小 | ボケ（天真爛漫） | 『にじさんじ』雲母たまこ |
| **ナギ** | 女 22 | 中背 | 被害担当 | 『DQXI』セーニャ |

### 8.1 ゴウ — 主役1

**男・24歳・大柄。**ガサツ、声がでかい、口が上手い、調子がいい。民間潜行班〈十三号室〉の
責任者。軽薄に見えて、判断は全部自分で被る。

- **Will**：5年前に失踪した兄ユウを見つける
- **Lie**：**「全部、俺が引き受ければいい」**
- **Need**：背負えないものがあると認め、人に預ける
- **ギャップ**：何でも茶化すのに、**兄の話だけは一度も茶化さない。**黙るので全員に伝わる
- **愛せる欠点**：字が壊滅的に汚い／暗いところが苦手／料理だけ異常に上手い／
  ツグミに論破されると素直に謝る
- **声**：短く、雑に、断定。困ると話を逸らす。「……はい」と素直に折れる

兄ユウは、ある潜行から「全員で帰った」と証言して帰還した。外部記録では6人で出発し、
5人しか帰っていない。ユウ本人は六人目を覚えていない。三日後、ユウは姿を消した。
手帳の最後の一文は「**第七層より下。記録を信じるな**」。

### 8.2 ツグミ — 主役2・ヒロイン

**女・15歳・小柄。**観測院の医療研究部から飛び級で出てきた天才。丁寧語のまま容赦がない。
早口。遮られると被せてくる。

- **Will**：灰庭性記憶障害の治療法を見つける
- **時限装置**：**彼女自身の記憶剥離の進行が、異常に速い。**隠している（理由は §3.4）
- **Lie**：「記憶さえ戻れば、人は元に戻る」
- **Need**：完全に復元できなくても、その後の人生は続けられる
- **ギャップ**：大人4人を論破するのに、**背が届かない・眠くなる・暗いところはゴウより怖い**
- **愛せる欠点**：謝れない／甘いものを断れない／眠いと急に無口になる／
  支給外套が大きすぎて袖を二回折る
- **声**：**丁寧語を崩さないまま、感情だけ振り切る。**言い過ぎて即座に後悔する
- **ゴウとの関係**：5人で唯一、ゴウだけが彼女を子供扱いしない。恋愛にはせず、
  対等な相棒として書く

**この時限装置が賭け金になる。**しかも作品テーマそのものである。

### 8.3 ヒバナ

**女・11歳・最小。**小さい、速い、よく笑う、よく怒る。考えたことが全部顔に出る。

- **設定の核**：**5人で一番よく忘れる。**だから毎回が初めてで、いつも楽しそう
- **Will**：「みんなと一緒に行きたい」
- **Lie**：「役に立てば置いていかれない」／ **Need**：役に立てなくても仲間は残る
- **来歴**：灰庭の中で拾われた子。**記録が最初から無い**
- **愛せる欠点**：食べる速度が異常／すぐ寝落ちする／ナギの後ろをついて回る／
  ツグミを「ツグミお姉ちゃん」と呼んで本気で嫌がられる
- **声**：全部感嘆。相手の返事を待たない

### 8.4 ナギ

**女・22歳・中背。**優しい。断れない。愚痴が多い。そして手だけは絶対に止まらない。

- **ギャップ**：常に嘆いているのに、**一度も隊を抜けない。愚痴りながら誰より庇う**
- **Secret**：**実は5人と会う前から、何年も灰庭へ潜っている。**その時期の公式記録が
  消されている。棚のガラクタは、過去の自分が毎回「絶対に捨てるな」と書き残したもの
- **不憫を悲哀へ反転させる仕掛け**：彼女は同じ愚痴を何度も言い、何度も忘れている。
  ガラクタの一つに、自分の筆跡で「もう一回だけ、がんばれ」と書いてある
- **Lie**：「昔の自分を知れば、今の自分が分かる」
- **Need**：今の自分が何を大切にするかは、今の自分が決めていい
- **ヒバナとの関係**：異常によく庇う。理由を聞かれても「危ないから」。二年前の映像で
  同じ班だったと判明する。二人とも覚えていない
- **愛せる欠点**：泣き言が多い／褒められると挙動不審／甘やかされ慣れていない
- **声**：語尾が下がる。訴えるが、手は止まらない

**記録の対称性**：ナギ＝記録を消された人／ヒバナ＝最初から記録が無い子。
「人は記憶と記録の総和なのか」という主題に、二つの極が立つ。

### 8.5 ソウジ

**男・58歳・中背。**中央観測院の記録主任。完璧な物腰。全員に敬称を付ける。

- **初登場は敵対者。**停止命令を持って現れ、ゴウに「お兄様は、ご存命ですよ」と告げるが
  所在は言わない
- **Lie**：「記録は人間より正しい」／ **Need**：記録に無いものを、人との関係から信じる
- **Will**：戻らなかった潜行員の記録を、一人残らず正しい形で残す
- **背景**：三十年、遺族対応の場に記録係として立ち会ってきた。「一緒に潜ったでしょう！」と
  泣く家族と「知らない人です」と答える帰還者を、何百回も見ている
- **ギャップ**：完璧な老紳士なのに、**元一級潜行員。**彼自身の潜行記録も消されている
- **愛せる欠点**：甘いものに目がない／若者言葉を覚えようとして必ず失敗する／
  実は院を辞めたくて仕方がなかった
- **声**：完全な敬語。間が長い。一度も語気を強めない
- Scenario 3 で記録改竄を発見し、消去命令を拒否して職を失い加入

- **ヒバナ ⇄ 全員**：かき回す。誰も怒れない
- **ナギ ⇄ ヒバナ**：忘れた絆。テーマの中心線
- **ソウジ ⇄ ゴウ**：老紳士がガサツ男を丁寧に躾ける

### 11.2 それぞれの設計意図

**ゴウ — HPも火力も最大。ただし極端に歪んでいる。**
受けは hit ごとの固定軽減なので、**受け1のゴウは多段攻撃が全部素通りする。**HP300 は
一撃では溶けないが、細かい攻撃を延々受けると誰より早く沈む。さらに速さ2・AP1・観測12。
5軸のうち2つで最大、3つで最低クラスという極端なピーキー型。「全部俺が引き受ければいい」
という Lie が、そのまま「**引き受けきれない相手が居る**」という穴になる。
`AGENTS.md`「完全上位互換を作らない。作る場合は明確な代償を付ける」は、この歪みで満たす。

**ツグミ — 隊の主火力。そして前に出たがる。**
観測52 で位置に関係なく削れる。HP110 で隊最低。
ここで**「前に出ないといけない」というドラマが、性格の側へ移る。**

> プレイヤーは後ろに置きたい。本人は前に出たがる。

理由は子供扱いされたくないから。そして実際に前に出すと死ぬ。
**序章でゴウがまさにそれをやって、ツグミを死なせる。**
現行の `PROLOGUE`（後列へ下げると勝てる4通り）は、ゴウ＝腕力なので前列必須、
ツグミ＝観測なので後列でも落ちない、で**構造を変えずに動く。**

**ナギ — 受けて、庇って、自分で治す。**
受け24 で多段を殺し、観測34 で治療と防壁を出す。攻撃もできるが主火力にはならない。
「うう、なんで私ばっかり」の中身が**庇護と治療を両方やらされている**になる。しかも
自分で自分を治せてしまうので、周りが遠慮しない。秘密（何年も潜っていた）は、
**受け方だけが異常に上手い**という形で数値に現れる。

**ヒバナ — 一撃は隊で一番弱い。**
腕力14・観測14 で一撃は最弱。11歳として自然。稼ぐのは hitCount
（`skills-active.mjs` に3hit・2hit の語彙が既にある）。**受けの高い敵には固定軽減で
全部消される。**弱点が明快で、しかも可愛い。AP2 で一巡に二度動く。

**ソウジ — 先に動かない。読んでから動く。**
58歳に「筋力最大」は無理があるので、**手番の自由度**（§12）と反応点を渡す。
自分からは動かず、相手が動いてから読んで割り込む。AP1 と両立する。攻守が中庸なのも
「歳だから」で説明が付く。

## 12. 速さの再設計 ★要判断

### 12.1 いまの速さは閾値でしかない

`engine.mjs:547-551` の通り、**speed は round 内の並び替えキーとしてしか使われていない**
（降順ソート、同値は位置とインスタンスIDで解決）。AP は毎 round 基準値へリセットされる。

結果として、**相手より 1 でも速いかどうかが全てで、その先の差は一切効かない。**
格上には常に負け、格下には常に勝つ。連続量として設計されているのに、閾値としてしか
働かない値になっている。

### 12.2 行動ゲージ制にすると壊れる

「AP を廃止し、速さに応じてゲージが溜まったら行動」は自然な発想だが、**速さが行動回数に
直結すると線形に強くなりすぎる。**回数は攻撃・治療・防壁・資源獲得のすべてを同時に増やす
ので、他のどの軸とも釣り合わない。

### 12.3 原則

> **速さで「回数」を増やすと必ず壊れる。**
> **速さで「情報」か「選択肢」を増やすと壊れない。**

### 12.4 提案 —— 速さ＝手番をずらせる幅

- round の頭に、全員の基準手番が速さ順で並ぶ（**ここは現状のまま**）
- 各人物は**速さに応じた「間（ま）」を持つ**
- 自分の手番が来たとき、「間」を1つ払って**手番を1つ後ろへ送れる**
- 遅い人物は 0〜1、速い人物は 3〜4 持つ

**速い＝先に動ける、ではなく、速い＝いつ動くか選べる。**

これが効く理由は、この game に**条件付き技能（predicate）が大量にある**からである。
`docs/DESIGN.md` §3 の pack 設計（発生源 → 変換器 → 利得先）は、まさに
「誰かが動いた後に動くと得をする」構造になっている。手番を送れるということは、
**発生源が撃った後に利得先を撃てる**ということ。

- **待つだけでは何も起きない。**条件を組んでいないと「間」は無価値
- したがって**速さの価値がビルド依存になる**。数値の大小だけでは強さが決まらない
- **敵との比較ではなく自分の自由度**なので、格上／格下で無意味にならない
- 遅い人物（ゴウ・ナギ）は先に動くしかない＝**自然に発生源になる。**
  速い人物（ソウジ・ヒバナ）は待って利得を回収する
- **完全予測と相性が良い。**予測画面で「ソウジをここまで遅らせる」と結果がどう動くかを
  先に見られる。組み替えの対象が一つ増える
- **ソウジの造形と一致する。**58歳が「速い」のは不自然だが、
  「いつ動くか選べる幅が広い」なら老練さそのものになる

### 12.5 実装の見積り

- round 内の行動順を「基準順 ＋ 各人物の遅延指定」で決める
- 遅延の上限を速さから導く
- 決定的で、同じ入力から同じ順が出る（完全予測を壊さない）
- 新しい event（手番の送り）を schema・validator・表示・replay と同時に追加する
- UI：隊列画面に順番の帯を足す

`engine.mjs` の順序決定は 1 箇所に閉じているので、**中規模の変更で収まる見込み。**
ただし未検証。

### 12.6 採らない場合

速さを「同値時の並びを決めるだけの副次的な値」と割り切り、5人の軸から外す。
その場合ソウジの軸は反応点（RP4）だけになり、ヒバナと合わせて tempo 系が薄くなる。

# 第四部 物語

## 13. 12戦のドラマ構造

各 Scenario を三幕として使う。

- **1〜4戦：Want** … 今回の具体的な目的を置く。4戦目ボスで最初の障害を突破し、
  予想外の情報を得る
- **5〜8戦：Conflict** … 最初の目的だけでは解けない問題へ変わる。仲間内でも意見が割れる。
  8戦目で意味を反転させる情報を置く
- **9〜12戦：Choice** … 「強い敵」だけで終わらせない。その Scenario の中心人物が
  何かを選び、その選択を実行するための12戦目にする
- **帰還後：Aftermath** … 本当のエンディング。全員が遠征中の具体的記憶を失っている。
  記録、装備、傷、感情の残滓から、自分たちが何を選んだかを知る

## 14. 最初の4 Scenario

### Scenario 0「明日の死者」— ゴウ ＋ ツグミ

目的：兄ユウが使っていた識別符号を追う。

- **Act 1** … 先見機故障。最初の一戦で本当に敗北。帰環杭が作動。ツグミが応急修理。
  今度は同じ敗北を戦闘前に見る。隊列を変え、勝つ
- **Act 2** … 兄の識別符号が深部に残っていることが確定。ただし記録上、その時期のユウは
  別の場所にいたことになっている
- **Act 3** … 12戦目後、ユウの個人記録端末の破片を発見。一行だけ再生される。
  「記録を信じるな。……ゴウ、お前は特に」

### Scenario 1「（仮）庇う人」— ＋ ナギ

目的：新しい深度へ入るための戦力補充。

ゴウは HP と火力を両取りしている代わりに**受けが最低**で、多段攻撃に異常に弱い。
その穴を埋める人物としてナギが要る。ナギは断れない性格で、庇い続け、治療し続け、
そして愚痴り続ける。

終盤、ゴウは「もう庇うな」と言い、ナギは初めて折れない。

### Scenario 2「（仮）記録の無い子」— ＋ ヒバナ

深部で単独行動するヒバナと遭遇。**記録が一件も存在しない。**

ナギはなぜかヒバナへの攻撃だけ異常によく庇う。8戦目後、二年前の古い映像を発見。
そこには同じ隊にいるナギとヒバナ。二人とも覚えていない。

> ヒバナ「じゃあ、あたしたち友達だったの？」
> ナギ 「……知りません」
> ナギ 「……でも、また知ればいいと思います」

### Scenario 3「正しい記録」— ＋ ソウジ

観測院から潜行停止命令。ソウジが同行監視として付く。彼はゴウに兄の生存を告げる。

途中、ソウジ自身が書いたはずの私的記録と公式保存版が食い違う。8戦目で「記録改竄」が
事故ではなく制度的に行われている可能性が出る。12戦目、ソウジは院から命じられたデータ
消去を拒否し、職を失う。

帰還後：

> ソウジ「……求人は、まだございますか」
> ゴウ 「給料は安いぞ」
> ツグミ「先に言うんですね、そこ」

5人完成。ここを第一幕の終点とし、以降は新加入ではなく既存5人を掘る。

## 17. 終盤のフック — プレイヤーだけが覚えている

**プレイヤーはゴウの視点で進めるが、記憶剥離を受けない。**遠征中の全部を覚えている。
人物は忘れる。**このずれ自体を終盤の仕掛けにする。**

```

ツグミ「見れば分かります」
ゴウ 「全員生きてる」
ツグミ「それも見れば分かります」

  『——ですから、わたしが忘れても』
  『あなたは、覚えていてください』

（映像が切れる）
```

ツグミは記憶剥離が人より速く（§3.4）、それを隠している。彼女が最後に頼れる相手は、
忘れない誰か——つまり画面のこちら側である。視線の先が**空いた席**なので、
六番目の椅子もここで一本に繋がる。

## 18. 会話を書くときの原則

1. **属性を言わせない。**「私は元気です」「私は賢いです」を台詞で説明しない。
   ヒバナは話す速度と行動で、ツグミは観察の細かさで、ナギは手が止まらないことで、
   ソウジは説明の精度で見せる
2. **好意を説明しすぎない。**行動の累積で見せる
3. **キャラは主人公のためだけに存在しない。**ゴウ不在でも成立する関係と目的を持たせる
4. **記憶喪失を安い感動装置にしない。**毎回「忘れちゃった、悲しい」を繰り返さない。
   忘れることが社会制度、仕事、恋愛、責任、医療、記録文化へどう影響するかを日常側でも描く
5. **帰還後を必ず描く。**12戦目が終わりではない
