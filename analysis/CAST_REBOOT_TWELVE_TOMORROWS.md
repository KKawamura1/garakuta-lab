# One Battle Ahead — 世界・人物・数値のリブート案

> 仮題。現行 `ecology/` の戦闘・成長・12戦構造は残し、**タイトル、世界観、人物、関係、
> 数値設計、物語を全面的に組み替える案**。
>
> この文書は**実装仕様ではなく設計の候補**。現行コードはまだ変更していない。

---

## 0. 目標

このゲームの強みは、戦闘そのものより
**「結果を完全に先読みし、隊列・技能・装備を組み替えて勝てる未来へ寄せる」**ことにある。

物語側でも同じ主題を扱う。

- 未来は完全に読める。
- しかし過去は、坑から帰るたびに抜け落ちる。
- 数字は嘘をつかない。
- だが、人が何を思い、なぜ誰かを選んだかは数字だけでは残らない。

中心テーマは次の一問。

> **人は、記憶と記録の総和なのか。**

> **未決（R13）** — この主題は**尺度が実装と合っていない。**「記憶」「過去」は一生分を
> 含意するが、記憶剥離が実際に消すのは §2.2 のとおり**一回の遠征のエピソード記憶だけ**
> であり、1ランはプレイヤー体感で数十分である。主題の候補（記憶と記録／経験が積み
> 上がらない／残るのは物証だけ／覚えているのはプレイヤーだけ）は
> `analysis/TITLE_STUDY.md` §6 に整理してある。**作者はまだ選んでいない。**
> なお §14 の Scenario 題は R13 で直した。Scenario 1 は「明日の死者」だったが、
> **先見機が見せるのは一戦先であって明日ではない**ので「一戦先の死者」にした
> （題 `One Battle Ahead` と同じ語で揃う）。Scenario 2・3 の（仮）も外した。
> **主題そのものは、まだ未決である。**

プレイヤーは戦闘では完全情報を得る一方、人物については不完全な記憶と不完全な記録を
頼りに関係を積み上げる。

キャッチコピー案：

> **負ける未来を見た。だから、勝てる形に並べ替える。**

## 0.1 タイトル

**`One Battle Ahead`**（決定・R13）。日本語の副題は付けない。

決め手は**尺度**である。戦闘予測が見せるのは「明日」でも「未来」でもなく、
**ちょうど一戦先の確定結果**であり、しかも "one" が「**二戦先は見えない**」という
上限まで同時に言っている。先見機の設定（§2.1）そのままで、誇張がゼロになる。

検討の全文——却下した候補と、それぞれが想起させるゲーム、RPG題の型、日本語と英語の
長さの違い、俳句の取り合わせ——は `analysis/TITLE_STUDY.md` にある。

**「忘却坑」は場所の名前として §1 に残す。**ゲームの題としては座らない（作者判断）。
加えて『忘却前夜』（2026年3月 Steam、記憶喪失テーマのカードRPG）と語頭が衝突し、
検索性でも不利だった。

> **注意** — §1 の舞台〈忘却坑〉は**まだ実装に入っていない。**現行 `ecology/` の世界は
> 灰系（灰の辺境・灰の門・灰殻）のままで、この節は世界観の提案に留まる。R13 で実装へ
> 入れたのは人物・数値・会話と題だけである。

# 第一部 世界

## 1. 舞台〈忘却坑〉

旧市街の地下に、四十年前の事故で生まれた異常領域がある。公式には**〈忘却坑〉**。
外から見れば地下遺構だが、内部では距離・物質・記憶の保存則が崩れている。

### 1.1 呼び名は、短くする

**世界観語彙を増やすほど、プレイヤーに読ませる文章が増える。**用語は必要な数だけにし、
しかも**公式名と現場の呼び名を分ける。**現実にそうなっているからである。

| | 公式 | 現場 |
|---|---|---|
| 場所 | 忘却坑 | **「坑（あな）」** |
| 行く | 潜行する | **潜る／降りる／帰る** |
| 深さ | 第二深度 | **「二つ目」** |
| 各層のボス | — | **「門番」** |

「層域を越える」「結節を断つ」のような造語は使わない。**現場が短い言葉で呼ぶこと自体が、
それが彼らの日常である証拠**になる。

### 1.2 起源

約四十年前、**第七研究所**が事故を起こした。施設は消滅せず、周辺を巻き込んで現実から
半ば切り離された。研究内容は特筆すべきものではない。**未来が読めるようになったのは
事故の結果であって、目的ではない。**

## 2. 三つの法則

### 2.1 固定因果

坑では、戦闘条件が確定すると結果も確定する。敵、味方、現在HP、隊列、技能、装備が
同じなら、同じ戦闘は必ず同じ結果になる。

潜行員は携帯型の**〈先見機〉**で、その固定未来を戦闘前に読み出せる。表示されるのは
確率ではない。

```
  > 勝利 / 7巡
  > ゴウ   　128 → 43
  > ツグミ 　104 → 0
  > ヒバナ 　 96 → 17
```

という**確定結果**である。隊列や装備を変えれば初期条件が変わり、別の未来が表示される。

**ゲームとの対応**：Preview ＝ 先見機による固定未来の観測。本戦 ＝ 観測済みの未来を実行する。
同構成なら完全一致 ＝ 世界法則そのもの。

### 2.2 記憶剥離

坑の中で形成された**具体的なエピソード記憶**は、境界を越えて外へ出ると崩れる。

| 残るもの | 失うもの |
|---|---|
| 坑へ入る前までの人生 | 誰とどんな会話をしたか |
| 外で読んだ日記・映像・報告書の内容 | 第何戦で誰が倒れたか |
| 身体に残った傷や疲労 | どの瞬間に誰を好きだと思ったか |
| 人間関係についての知識 | 戦闘中に身につけた身体感覚 |
| 理屈として学び直した事実 | 深部で何を恐れ、何を決めたか |
| 理由を説明できない感情の残滓 | |

このため潜行員は年齢の割に独特の幼さを持つ。危険な経験を何年しても、その「経験した実感」が
十分には積み上がらない。妙に実務的なのに妙に無邪気、修羅場慣れしているのに感情処理だけ
未熟、というアンバランスさが潜行員の特徴になる。

ただし人格が毎回初期化されるわけではない。外で日記を読み、仲間と話し、自分なりに
意味づけたことは次の遠征へ持ち越される。

> 何があったかは覚えていない。
> でも、その人の隣にいると安心する。

という関係が成立する。

### 2.3 坑外崩壊

坑で生成された特殊物質**〈遺装〉**は、外へ持ち出すと急速に崩れる。ただし帰還時に一つだけ、
高価な**〈定着処理〉**を施せる。定着した遺装だけは次の潜行へ持ち込める。

この一品には性能だけでなく来歴を残す。

```
  白銀の留め針
  第六層「雨のない街」で発見
  第7〜12戦：ツグミ使用
  第12戦後、本人の希望で定着
```

本人はその遠征を忘れている。だから装備は、**失われた冒険の物証**になる。

## 3. 技術 —— 非物理の攻め手

現行の「技術（focus）」は、**なぜ後列でも威力が落ちず、腕力と無関係で、しかも攻撃・治療・
防壁がすべて同じ数値で伸びるのか**を説明していない。`docs/HISTORY.md` §3.3 の通り、
R11 で技攻撃を focus へ移したのは「攻めの軸が1本だと編成が守りへ寄る」という
**ゲーム設計上の理由**であって、世界観から生まれた値ではない。

### 3.1 能力値の条件

作り直すにあたり、二つの規則を先に立てる。どちらも、これを破った案が実際に破綻して分かった。

> **規則1：世界法則を能力値にしない。**法則は全員に等しく働くので、
> 「その法則が上手い人」という概念自体がおかしくなる。
>
> **規則2：能力値になれるのは、その人がやっている最中にしか存在しないものだけ。**
> 物として切り離せるものは、渡せてしまうので装備になる（不変条件「人物は永続、
> 偶然性は装備」に抵触する）。

腕力が能力値として成立するのは、腕力を人に渡せないからである。

### 3.2 定義

第二の攻め手は **「技術」** とする。**腕力 ⇄ 技術**で対になり、どちらも普通の文に入る
（「腕力はあるが技術が無い」「技術が高いので治療も上手い」）。

能力値の名前は**文に入る言葉でなければ失格である。**「精度が高い」「見立てが高い」とは
言わないので、どちらも落とした。

共通項は物質ではなく、**同じ問い**に置く。

> **どこに、どれだけ。**

| | 技術が答えている問い |
|---|---|
| 攻撃 | 急所がどこか |
| 治療 | 患部がどこか、どれだけ塞ぐか |

三つ目（防壁）はここから外す（§3.4）。

一行の説明：

> **当てる場所を知っている人間は、殺すのも治すのも速い。**

### 3.3 条件の確認

| 要件 | 成立するか |
|---|---|
| 腕力と無関係 | 力ではなく知識 |
| 後列で落ちない | 射出器を使う。**引き金を引く力は誰でも同じ** |
| 渡せない | 狙う場所の知識は本人にしか無い |
| 一行で説明できる | 上の一行だけ |
| 個人差が桁で付く | 当たり前 |
| それで倒れる | 急所 |
| **新しい世界法則を足すか** | **ゼロ** |

**ツグミが医者であることと完全に一致する。**15歳の天才医療研究者が隊の主火力で、
その理由が「人体を一番よく知っているから」。医者が一番人を殺すのが上手い、というのは
古典的に強い形であり、彼女の Will（記憶障害の治療法）とも同じ知識体系の上に乗る。

ゴウは技術が最低（大雑把）。ナギはそこそこ持つ（だから治療できる）。

「医療技術」という語がそのまま存在するのも、この名前を選ぶ理由になる。

### 3.4 防壁は能力値から外す

防壁の量は**技能と装備の固定値**とし、誰が張っても同じにする。理由は二つ。

1. **治療と防壁が同じ数値で伸びると、役割がほぼ完全に被る。**
2. 技術で防壁を説明しようとすると「次にどこへ来るかを読んで先に当て物を置く」と
   一段ひねる必要があり、§3.2 の一行から外れる。

ただし**外すだけでは足りない。**誰が張っても同じ量なら、
**行動権（AP）が余っている人物が張るのが常に最適**になり、ヒバナが本人の性格に合わない
支援役へ引っ張られる（§11.2）。

そこで**置き場所も変える。防壁を行動（AP）ではなく反応（RP）にする。**

> 被弾しそうな瞬間に割り込んで、当て物を置く。

これでゲンゾウの領分になる。「先に動かない。読んでから動く」がそのまま防壁の張り方になり、
量が固定なので彼の低い攻守と無関係でも成立する。RP4 を持っている理由にもなる。

結果、三つが三人に割れる。

| | 誰が主に担うか | 何で決まるか |
|---|---|---|
| 治療 | ツグミ・ナギ | **技術** |
| 防壁 | ゲンゾウ | **反応点**（量は固定） |
| 受け | ナギ | **受け** |

### 3.5 実装への影響

計算式は変えない。`values.mjs` / `effects.mjs` / UI 文言の**用語**を `focus` から
`技術` へ改める。状態 `focused` の表示「集中」は変えない。防壁付与の技能を active から reactive へ移し、付与量を能力値非依存にする。

## 4. 先見と巻き戻しは別物

### 4.1 先見

- 常用・既知技術
- 未来を読むだけ。現実は変えない

### 4.2 〈帰環杭〉

潜行開始時に設置する緊急安全装置。

- 坑の中でしか作動しない
- ごく狭い範囲・短時間だけ
- 致命的事故時に、直前の局所状態へ戻す
- 莫大な備蓄を消費するため通常運用では使えない
- **使用者の記憶も戻る**ため、便利な経験稼ぎにはならない

坑では条件が確定すれば結果も確定する。帰環杭は、**その確定を一度だけ剥がす**装置である。
莫大な出力で無理やり行うので高価で、だから一度きり。

Scenario 1 の最初の一戦だけ、先見機が故障した状態で**本当に敗北する。**帰環杭が一度だけ
作動し、同じ場所へ戻る。ツグミが先見機を応急修理し、今度は「負ける未来」を戦う前に見る。
ここでゲームの中心ルールをプレイヤー自身に体験させる。

## 5. システムの物語上の意味

| システム | 物語上の意味 |
|---|---|
| 戦闘予測 | 先見機が固定未来を読み出す |
| 隊列変更 | 未来の初期条件を変える |
| SP | 遠征中に得た実戦経験。帰還時に記憶剥離とともに失う |
| スキル解禁 | 「さっきので分かった」という、その遠征中だけの学習 |
| 装備 | 坑で生成された遺装 |
| 装備リセット | 坑外崩壊で失われる |
| 1つ持ち帰り | 一品だけ定着処理できる |
| 補給 | 坑の中で使える医療・凝固・触媒資材 |
| SPを諦めて補給+1 | 戦闘後の短い安定時間を「復盤」に使うか「採取・調合」に使うかの二択 |
| 4,8戦目後の全快 | 門番を抜けると安全域が生まれ、まとまった治療時間が取れる |
| 12戦 | 各層の門番を順に抜ける。4/8/12 が門番 |

### 5.1 SPか補給か

戦闘後、次の流れが来るまでの安定時間は短い。その時間でできることは一つだけ。

- **復盤する** … 直前の戦闘を振り返り、身体が覚えているうちに動きを詰める → Skill Point
- **採取・調合する** … 坑の中でのみ効く薬材・凝固剤・触媒を集める → Supply +1

> **強くなるために今の戦いを学ぶか、次の傷に備えるか。**

## 6. 組織

### 6.1 中央観測院

坑の管理、救助、潜行許可、帰還者ケア、記録保管を担う公的機関。**悪の組織ではない。**
むしろ社会に不可欠。ただし深部記録の一部を封印している。

**院長：カナエ（42）**。元潜行員。かつて夫と坑へ潜り、自分だけ帰還した。本人に記憶はない。
映像には、自分が夫を見捨てて逃げる姿が残っている。

- Will：坑を段階的に完全封鎖する
- 信念：**記憶のない人間に、記録だけを根拠として過去の罪や愛情を背負わせるべきではない**

主人公たちの敵対者ではあるが、主張はかなり正しい。

### 6.2 白紙会

元潜行員と家族による運動体。

> **忘れた人には、忘れたままでいる権利がある。**

帰還者へ映像を突きつけ、「あなたはこの人を愛していた」「あなたはこの人を見捨てた」と
迫る行為を暴力だと考える。穏健派は帰還者の権利保護を行い、過激派は記録庫を破壊する。

ゴウとは根本的に対立するが、ナギにとっては救いになる思想でもある。

# 第二部 人物

## 7. なぜ人物を作り直すか

現行 `ecology/content/character-lore.mjs` の5人には、次の構造的な問題がある。

1. **全員が観察者である。**シキ・ナズナ・レイ・スミの4人が「他人を静かに観察して正確に
   訂正する人」。ボケが居ないので、ツッコミも笑いも驚きも成立しない。
2. **全員が感情を抑制する側。**誰も声を荒げず、泣かず、照れず、怒らない。
3. **望みが抽象的。**5人とも「知りたい」としか言っていない。感情移入は具体的で外向きな
   望みにしか働かない。
4. **差異が静かな差異しかない。**体格も声量もテンションも揃っていて、立ち絵を並べても
   記憶に残らない。
5. **可愛げ（愛せる欠点）が無い。**Will / Lie / Need は文学的な欠点であって、
   愛せる欠点ではない。

暗い世界に明るい人物を置くのは矛盾ではなく正攻法である。世界が暗いから人を暗くするのが
一番効かない選択で、明暗の対比があって初めて暗さが刺さる。

## 8. 主役5人

**男2・女3。**年齢と体格を意図的に散らし、立ち絵のシルエットと声量が全員違うようにしてある。

| 名前 | 性別・年齢 | 体格 | 喜劇の役 | 着想元 |
|---|---|---|---|---|
| **ゴウ** | 男 24 | 大柄 | ボケ（軽薄）・主役1 | 『勇者のクズ』ヤシロ |
| **ツグミ** | 女 15 | 小柄 | ツッコミ（毒舌）・主役2 | 『風花雪月』リシテア |
| **ヒバナ** | 女 11 | 最小 | ボケ（天真爛漫） | 『にじさんじ』雲母たまこ |
| **ナギ** | 女 22 | 中背 | 被害担当 | 『DQXI』セーニャ |
| **ゲンゾウ** | 男 71 | 中背 | 余裕の大人 | 『ユニコーンオーバーロード』ジョセフ |

ボケ2／ツッコミ1／被害担当1／余裕の大人1。**被害担当（＝事が起きる対象）が要である。**
これが無いと喜劇は成立しない。

### 8.1 ゴウ — 主役1

**男・24歳・大柄。**ガサツ、声がでかい、口が上手い、調子がいい。民間潜行班〈十三号室〉の
責任者。軽薄に見えて、判断は全部自分で被る。

- **Will**：5年前に失踪した兄ユウを見つける
- **Lie**：**「全部、俺が引き受ければいい」**
- **Need**：背負えないものがあると認め、人に預ける
- **ギャップ**：何でも茶化すのに、**兄の話だけは一度も茶化さない。**黙るので全員に伝わる
- **愛せる欠点**：字が壊滅的に汚い／暗いところが苦手／料理だけ異常に上手い／
  ツグミに論破されると素直に謝る
- **声**：短く、雑に、断定。困ると話を逸らす。「……はい」と素直に折れる

兄ユウは、ある潜行から「全員で帰った」と証言して帰還した。外部記録では6人で出発し、
5人しか帰っていない。ユウ本人は六人目を覚えていない。三日後、ユウは姿を消した。
手帳の最後の一文は「**第七層より下。記録を信じるな**」。

### 8.2 ツグミ — 主役2・ヒロイン

**女・15歳・小柄。**観測院の医療研究部から飛び級で出てきた天才。丁寧語のまま容赦がない。
早口。遮られると被せてくる。

- **Will**：坑性記憶障害の治療法を見つける
- **時限装置**：**彼女自身の記憶剥離の進行が、異常に速い。**理由は**自分に試しているから。**
  記憶剥離の治療法を探すために、自分を被験者にしている。隠している（止められるから）。
  世界法則の例外ではなく**本人の選択**なので、欠点として書ける
- **Lie**：「記憶さえ戻れば、人は元に戻る」
- **Need**：完全に復元できなくても、その後の人生は続けられる
- **ギャップ**：大人4人を論破するのに、**背が届かない・眠くなる・暗いところはゴウより怖い**
- **愛せる欠点**：謝れない／甘いものを断れない／眠いと急に無口になる／
  支給外套が大きすぎて袖を二回折る
- **声**：**丁寧語を崩さないまま、感情だけ振り切る。**言い過ぎて即座に後悔する
- **ゴウとの関係**：5人で唯一、ゴウだけが彼女を子供扱いしない。恋愛にはせず、
  対等な相棒として書く

**この時限装置が賭け金になる。**しかも作品テーマそのものである。

### 8.3 ヒバナ

**女・11歳・最小。**小さい、速い、よく笑う、よく怒る。考えたことが全部顔に出る。

- **設定の核**：**5人で一番よく忘れる。**だから毎回が初めてで、いつも楽しそう
- **戦い方**：殴らない。**走る・拾う・引っ張る。**隊で唯一、戦闘中に隊列を動かせる（§12）
- **Will**：「みんなと一緒に行きたい」
- **Lie**：「役に立てば置いていかれない」／ **Need**：役に立てなくても仲間は残る
- **来歴**：坑の中で拾われた子。**記録が最初から無い**
- **愛せる欠点**：食べる速度が異常／すぐ寝落ちする／ナギの後ろをついて回る／
  ツグミを「ツグミお姉ちゃん」と呼んで本気で嫌がられる
- **声**：全部感嘆。相手の返事を待たない

### 8.4 ナギ

**女・22歳・中背。**優しい。断れない。愚痴が多い。そして手だけは絶対に止まらない。

- **ギャップ**：常に嘆いているのに、**一度も隊を抜けない。愚痴りながら誰より庇う**
- **Secret**：**実は5人と会う前から、何年も坑へ潜っている。**その時期の公式記録が
  消されている。棚のガラクタは、過去の自分が毎回「絶対に捨てるな」と書き残したもの
- **不憫を悲哀へ反転させる仕掛け**：彼女は同じ愚痴を何度も言い、何度も忘れている。
  ガラクタの一つに、自分の筆跡で「もう一回だけ、がんばれ」と書いてある
- **Lie**：「昔の自分を知れば、今の自分が分かる」
- **Need**：今の自分が何を大切にするかは、今の自分が決めていい
- **ヒバナとの関係**：異常によく庇う。理由を聞かれても「危ないから」。二年前の映像で
  同じ班だったと判明する。二人とも覚えていない
- **愛せる欠点**：泣き言が多い／褒められると挙動不審／甘やかされ慣れていない
- **声**：語尾が下がる。訴えるが、手は止まらない

**記録の対称性**：ナギ＝記録を消された人／ヒバナ＝最初から記録が無い子。
「人は記憶と記録の総和なのか」という主題に、二つの極が立つ。

### 8.5 ゲンゾウ

**男・71歳・中背。**中央観測院の記録主任。完璧な物腰。全員に敬称を付ける。

**年齢が世界法則から出てくる。**潜行員は記憶剥離のせいで経験が積み上がらず、年齢の割に
幼い（§2.2）。ということは、**本当に老成している人間は、潜るのをやめた人間しかいない。**
ゲンゾウは三十代で潜行をやめ、四十年間、地上で記録を書き続けた。
**この隊で唯一、本当に歳を取った人間である。**

- **初登場は敵対者。**停止命令を持って現れ、ゴウに「お兄様は、ご存命ですよ」と告げるが
  所在は言わない
- **Lie**：「記録は人間より正しい」／ **Need**：記録に無いものを、人との関係から信じる
- **Will**：戻らなかった潜行員の記録を、一人残らず正しい形で残す
- **背景**：四十年、遺族対応の場に記録係として立ち会ってきた。「一緒に潜ったでしょう！」と
  泣く家族と「知らない人です」と答える帰還者を、何百回も見ている
- **ギャップ**：完璧な老紳士なのに、**元一級潜行員。**彼自身の潜行記録も消されている
- **愛せる欠点**：甘いものに目がない／若者言葉を覚えようとして必ず失敗する／
  実は院を辞めたくて仕方がなかった
- **声**：完全な敬語。間が長い。一度も語気を強めない
- **戦い方**：自分の手番では動かない。**他人の手番に割り込んで、当て物を置く**（防壁・§3.4）
- Scenario 4 で記録改竄を発見し、消去命令を拒否して職を失い加入

## 9. 関係

5人を「男主人公＋女性のハーレム」にしない。ゴウ⇄ツグミ以外にも同程度に太い線を作る。

- **ゴウ ⇄ ツグミ**（主役コンビ）：無茶を言う／即座に潰す。
  ただし**互いだけが相手を対等に扱う**
- **ゴウ ⇄ ナギ**：ゴウが無茶する → ナギが庇う → 「なんで私ばっかり」
- **ヒバナ ⇄ 全員**：かき回す。誰も怒れない
- **ナギ ⇄ ヒバナ**：忘れた絆。テーマの中心線
- **ゲンゾウ ⇄ ゴウ**：老紳士がガサツ男を丁寧に躾ける
- **ツグミ ⇄ ゲンゾウ**：知性の衝突。「記録が正しい」対「記録では足りない」。
  ツグミには時間が無いので、この対立は彼女にとって切実

### 11.2 それぞれの設計意図

**ゴウ — HPも火力も最大。ただし極端に歪んでいる。**
受けは hit ごとの固定軽減なので、**受け1のゴウは多段攻撃が全部素通りする。**HP300 は
一撃では溶けないが、細かい攻撃を延々受けると誰より早く沈む。さらに技術6・AP1。
5軸のうち2つで最大、3つで最低クラスという極端なピーキー型。「全部俺が引き受ければいい」
という Lie が、そのまま「**引き受けきれない相手が居る**」という穴になる。
`AGENTS.md`「完全上位互換を作らない。作る場合は明確な代償を付ける」は、この歪みで満たす。

**ツグミ — 隊の主火力。そして前に出たがる。**
技術52 で位置に関係なく削れる。HP110 で隊最低。
ここで**「前に出ないといけない」というドラマが、性格の側へ移る。**

> プレイヤーは後ろに置きたい。本人は前に出たがる。

理由は子供扱いされたくないから。そして実際に前に出すと死ぬ。
**序章でゴウがまさにそれをやって、ツグミを死なせる。**
現行の `PROLOGUE`（後列へ下げると勝てる4通り）は、ゴウ＝腕力なので前列必須、
ツグミ＝技術なので後列でも落ちない、で**構造を変えずに動く。**

**ナギ — 受けて、庇って、自分で治す。**
受け24 で多段を殺し、技術30 で治療を出す。攻撃もできるが主火力にはならない。
「うう、なんで私ばっかり」の中身が**庇護と治療を両方やらされている**になる。しかも
自分で自分を治せてしまうので、周りが遠慮しない。秘密（何年も潜っていた）は、
**受け方だけが異常に上手い**という形で数値に現れる。

**ヒバナ — 殴らない。動かす。**
腕力14・技術14 で一撃は最弱。11歳として自然。彼女の価値は damage ではなく **AP2**、
すなわち**一巡に二度動けること**にある。詳細は §12。

**ゲンゾウ — 先に動かない。読んでから動く。**
71歳に突出した攻守を持たせるのは無理があるので、**反応点**を渡す。自分の手番では
ほとんど動かず、他人の手番に割り込んで防壁を置き、条件が揃えば反撃する。AP1 と両立する。

## 12. 速度能力値を削除し、位置を設計軸にする

### 12.1 廃止前の問題

廃止前の実装では、速度は round 内の並び替えキーとしてしか使われていなかった
（降順ソート、同値は位置とインスタンスIDで解決）。AP は毎 round 基準値へリセットされる。

結果として、相手より 1 でも速いかどうかが全てで、その先の差は一切効かなかった。
格上には常に負け、格下には常に勝つ。連続量として設計されているのに、閾値としてしか
働かない値だった。

### 12.2 行動ゲージ制も、手番をずらす自由度も採らない

「AP を廃止し、速さに応じてゲージが溜まったら行動」は自然な発想だが、**速さが行動回数に
直結すると線形に強くなりすぎる。**回数は攻撃・治療・防壁・資源獲得のすべてを同時に増やす。

「速さに応じて自分の手番を後ろへ送れる」という案も**採らない。**連続値の自由度を増やすと、
`docs/DESIGN.md` §5 が失敗条件として挙げている

> 終了 HP が増えるまで技能・装備を一個ずつ交換し、event 接続を説明しない

がそのまま起きる。とくに条件行動の発火順は事前に読みづらいので、
**結果だけ見て組み替える**動きを誘発する。

### 12.3 実装済みの変更

**能力値を足すのではなく、一つ減らす。**

- 行動順は**前列 → 後列**、同列は左 → 中 → 右（敵味方とも）
- 速度能力値を content、engine、結果、装備、パッシブ、UI から削除
- 先手・後手は戦闘単位で決まる（奇襲かどうか）

こうすると、**プレイヤーが既に持っている「隊列」という一つの決定が、三つの結果を
同時に決める。**

| 前に置く | 後ろに置く |
|---|---|
| 武器の威力が出る | 武器が40%に落ちる |
| **先に動く**＝条件を作る側 | **後に動く**＝条件を回収する側 |
| 先に狙われる（`sort: position_asc`） | 守られる |

**ノブは増えていない。**隊列は離散的な数択で、しかも今も毎回いじる場所である。
そこに意味が一つ増えるだけなので、連続値のダイヤルは生まれない。

ゲンゾウの「先に動かない。読んでから動く」は、能力値ではなく**置き場所**になる。

行動順と隊列を使う対象選択へ整理し、速度能力値を持たない実装にした。

### 12.4 ヒバナの AP2 は「位置と物」に使う

追加行動は、**自分の低い能力値に依存しない行動**に使うのが常に最適である。だから AP2 は
放っておくと必ずテクニカル支援（バフ・デバフ・防壁付与）へ引っ張られる。
それは11歳の天真爛漫な子供にまるで合わない。

しかし**「能力値に依存しない」＝「テクニカル」ではない。**もう一つ、まったくテクニカルで
ない stat 非依存の行動がある。

> **動く。拾う。引っ張る。**

位置と物である。どちらも誰がやっても同じで、しかも**子供そのもの**である。

そしてこのゲームでは位置が全てを決める（§12.3）。**戦闘中に隊列を動かせる唯一の人物**は、
それだけで大きな役割になる。

**AP2 の本当の意味は「往復できること」である。**AP1 の人物は片道しか行けない。
前へ出たら出たまま、下がったら下がったまま。ヒバナだけが**入って、戻れる。**
だから彼女だけが位置役をやれる。

「拾う」は坑の物を戦闘中に拾う役。補給や遺装に繋がるので、遠征の資源に触れる。
「わーい、大成功！」が**拾い物が当たったとき**の台詞になり、Lie（役に立てば置いて
いかれない）にも直結する。誰かを殺すことではなく、**役に立つこと**で存在を証明しようとする子。

### 12.5 位置移動を使わせるための設計 ★最重要

**位置移動は、それ自体では割に合わない。**移動は `swap_positions`（`effects.mjs:578`）
なので必ず誰かと入れ替わり、ヒバナは HP120・受け3 の紙で、しかも前列は
`sort: position_asc` により先に狙われる。**明確な見返りが無ければ誰も使わない。**

したがって、**移動を発生源とする分かりやすい利得先を先に用意する。**
`docs/DESIGN.md` §3 の pack 設計（発生源 → 変換器 → 利得先 → 制動）に沿う。

既存語彙は揃っている。

| 既にあるもの | 場所 |
|---|---|
| `swap_positions` 効果（原子的な入れ替え） | `effects.mjs:578` |
| `actor_moved` イベント | `effects.mjs:593` |
| `times_moved` 履歴 | `effects.mjs:589` |
| 行・列を単位とする対象指定 | `effects.mjs:222` |
| `reach: melee / ranged` | `skills-active.mjs:360` |
| `actor_moved` を読む reactive の実例（`stride_into_reach`） | `skills-reactive.mjs:430` |
| `reposition`（utility 技能） | `skills-active.mjs:16` |

#### コンボ1：撃ったら前に出る（本命・ツグミと組む）

**ツグミの最大火力技に「撃つと前へ出る」という代償を付ける。**

- 撃たない → 安全だが火力が出ない
- 撃つ → 前に晒され、次の巡で狙われる（HP110）
- **撃つ＋ヒバナが引き戻す → 両立する**

これで「ヒバナが居ると初めて成立する構築」ができる。しかも**二人の性格が
そのままメカニクスになる**（前に出たがるツグミ、引っ張り戻すヒバナ）。
分かりやすさの点でも、予測画面に「ツグミ 110 → 0」が「110 → 78」へ変わる形で出る。

#### コンボ2：敵を寄せて薙ぐ（攻めの本命）

敵を動かして同じ行・列へ揃え、行/列単位の攻撃で複数体に当てる
（`effects.mjs:222` の対象指定がそのまま使える）。

**利得が数字で一目に出る。**予測画面で「1体ヒット」が「3体ヒット」に変わる。
ヒバナが前に出る危険と、火力が3倍になる利得を、同じ画面で比較できる。

#### コンボ3：動いたこと自体を読む（つなぎ）

`actor_moved` を listen する reactive を各人に配る。ヒバナが動くたびに誰かが得をする。
`stride_into_reach` という実例が既にあるので、語彙の追加は要らない。

- ゴウ … 誰かが動いたら踏み込んで追撃する
- ゲンゾウ … 誰かが動いたら当て物を置く（防壁・§3.4）

これで**移動が「一手を捨てる行為」ではなく「一手で二人を動かす行為」**になる。

#### 制動

- 移動は必ず swap なので、**得をする代わりに誰かが不利な位置へ行く**
- ヒバナ自身が紙なので、前へ出た巡は必ずリスクを負う
- `times_moved` を条件に使う技能を置けば、動きすぎに代償を付けられる

#### ガチャガチャを誘発しないか

しない。**移動は実行時の自由選択ではなく、事前に選ぶ技能である。**組み替えの粒度は
他の技能と同じ離散的な数択であって、連続値のダイヤルではない。§12.2 で退けたのは
「実行中に手番を任意にずらせる」案であって、これとは別物である。

# 第四部 物語

## 13. 12戦のドラマ構造

各 Scenario を三幕として使う。Scenario は 1 から数える。

- **1〜4戦：Want** … 今回の具体的な目的を置く。4戦目ボスで最初の障害を突破し、
  予想外の情報を得る
- **5〜8戦：Conflict** … 最初の目的だけでは解けない問題へ変わる。仲間内でも意見が割れる。
  8戦目で意味を反転させる情報を置く
- **9〜12戦：Choice** … 「強い敵」だけで終わらせない。その Scenario の中心人物が
  何かを選び、その選択を実行するための12戦目にする
- **帰還後：Aftermath** … 本当のエンディング。全員が遠征中の具体的記憶を失っている。
  記録、装備、傷、感情の残滓から、自分たちが何を選んだかを知る

## 14. 最初の4 Scenario（1〜4）

### Scenario 1「一戦先の死者」— ゴウ ＋ ツグミ

目的：兄ユウが使っていた識別符号を追う。

- **Act 1** … 先見機故障。最初の一戦で本当に敗北。帰環杭が作動。ツグミが応急修理。
  今度は同じ敗北を戦闘前に見る。隊列を変え、勝つ
- **Act 2** … 兄の識別符号が深部に残っていることが確定。ただし記録上、その時期のユウは
  別の場所にいたことになっている
- **Act 3** … 12戦目後、ユウの個人記録端末の破片を発見。一行だけ再生される。
  「記録を信じるな。……ゴウ、お前は特に」

### Scenario 2「庇う人」— ＋ ナギ

目的：新しい深度へ入るための戦力補充。

ゴウは HP と火力を両取りしている代わりに**受けが最低**で、多段攻撃に異常に弱い。
その穴を埋める人物としてナギが要る。ナギは断れない性格で、庇い続け、治療し続け、
そして愚痴り続ける。

終盤、ゴウは「もう庇うな」と言い、ナギは初めて折れない。

## 16. 会話サンプル

**声を見るための試作。**実装用の最終稿ではない。

### 16.0 長さの方針

**台詞は長く、会話は短く。**往復を増やさず、一人の台詞へ情報を二つ三つ積む。
短い応酬だけで組むと、読み味は軽いが**何も伝わらない会話**になる。

**行数のハードリミットは置かない（R13・作者判断）。**`story.test.mjs` にあった
2〜6行・2〜4行・12行以下の縛りは外した。数で縛ると、一行に情報を詰められない場面まで
一律に切り詰めることになり、「短いが伝わっていない」が通ってしまう。

代わりに**厚みの勾配**を置く。**プレイヤーは物語を読みに来たのではなく、
ゲームをしに来ている。**

- **Stage 0** … 一番薄い。まだ何も分かっていない人を待たせない
- **Stage 1〜3** … 人が増えるぶん厚くする。ここで初めて関係が動く
- **根城** … 一番厚い。**読みに行った人だけが開く場面**なので、長くてよい

「もう終わり？ もっと読みたいのに」で切り上げるのが正しいのは、序盤の話である。

## 17. プレイヤーは登場しない

**プレイヤーは物語世界に居ない。**ゴウたちが自分で隊列・技能・装備を決めており、
プレイヤーはその判断を追体験している。

一度は「プレイヤー＝先見機」「プレイヤー＝地上に残る六人目」を検討したが、どちらも
成立しなかった。理由を残しておく。

> **装備や技能を組み替えているのがプレイヤーである以上、選べるのは二つしかない。**
> ① 人物は組み替えられず、プレイヤーが組み替える（＝プレイヤーは世界に登場する）
> ② 人物が自分で組み替え、プレイヤーは追体験する（＝プレイヤーは登場しない）
>
> 先見機は装備に手を出せないので、①として成立しない。

六人目のオペレーターとして①を成立させることはできるが、**この5人のやかましい会話に、
喋らない一人が入る余地が無い。**厚く描写するか、露骨にハブるかの二択になる。
仕掛けのために会話を壊すのは順序が逆なので、②を採る。

### 17.1 したがって、こうしない

- **六番目の椅子を伏線にしない。**隊列の6枠目という意味だけにする
- ツグミが画面の外を見る、といった思わせぶりな描写を置かない

プレイヤーだけが遠征を覚えていて人物は忘れている、というずれ自体は**放っておいても
起きる。**それをプレイヤーが感じ取る分には何の設計も要らない。**仕掛けとして書かない。**

### 17.2 最終盤の一戦だけ、勝敗が読めない

このゲームの弱点は、**強大な敵でも勝敗が戦う前に分かってしまう**ことである。
完全予測は中心の魅力なので捨てられないが、**一度だけ例外を作れば緊張が戻る。**

「門番がこちらを読んで並べ替えてくる」を**定常のシステムにはしない。**読み合いを常設すると
何を選んでも噛み合った結果へ落ち着き、しかもルールが複雑になる。一発ネタとして使う。

### 王道のイベント戦闘にする

```
1. いつも通り予測を見て、勝てる形にして戦闘へ入る
   → 先見機が「先見不能」を出す。このゲームで唯一、結果が分からない一戦
2. 負ける（敗北確定の一戦）
   → あとで理由が分かる。相手がこちらの先見機を読んでいた
3. 物語上の出来事が起きる
4. 先見が戻り、しかも今度は相手が読めない。勝つ
```

**契約を破らない。**予測と本戦が食い違うのではなく、**予測を出さないだけ**である
（`docs/DESIGN.md` の「同じ入力から同じイベント列」は無傷）。しかも
**Scenario 1 の第一戦と対になる。**あちらは機械の故障で先見不能、こちらは読まれて先見不能。
最初と最後だけ、プレイヤーは何も見えないまま戦う。

こちらが読めなくなると同時に相手も読めなくなる、という混ぜ方もできる。
いずれにせよ**最終盤の一発限り**とする。

## 18. 会話を書くときの原則

1. **属性を言わせない。**「私は元気です」「私は賢いです」を台詞で説明しない。
   ヒバナは話す速度と行動で、ツグミは観察の細かさで、ナギは手が止まらないことで、
   ゲンゾウは説明の精度で見せる
2. **好意を説明しすぎない。**行動の累積で見せる
3. **キャラは主人公のためだけに存在しない。**ゴウ不在でも成立する関係と目的を持たせる
4. **記憶喪失を安い感動装置にしない。**毎回「忘れちゃった、悲しい」を繰り返さない。
   忘れることが社会制度、仕事、恋愛、責任、医療、記録文化へどう影響するかを日常側でも描く
5. **帰還後を必ず描く。**12戦目が終わりではない
