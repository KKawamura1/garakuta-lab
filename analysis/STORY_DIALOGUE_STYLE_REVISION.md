# 『十二の明日をほどく』会話トーン改稿

この文書は `STORY_REBOOT_TWELVE_TOMORROWS.md` の会話トーンに対する改稿です。
設定本体は維持しつつ、同文書 §7 の「声」と §11 の Scenario 0 会話サンプルについては、
**本書の方針を優先**します。

## 1. 何がまずかったか

旧サンプルでは、テンポを出そうとして以下をやり過ぎた。

- 一発話を一文、しばしば数語で終わらせる。
- 質問→回答→質問→回答の往復を多用する。
- 「間」「沈黙」を頻繁に挟む。
- 感情を説明せず短い台詞に圧縮する。
- キャラクター設定でもコヨリに「短く言い切る」と指定した。

結果、ハル、コヨリ、将来加入するスミ、リツまでが同じ「静かで短い人」に寄った。
ヒバナだけが例外になり、5人の会話劇として単調である。

短文はテンポそのものではない。
自然な会話では、一人が一度話し始めたら、観察、理由、反論、補足、言い直しまで一息に話すことがある。
逆に、一言だけ返す瞬間が効くのは、普段それなりに喋る人との落差があるからである。

## 2. 全体ルール

### 2.1 一発話を「情報ひとつ」に制限しない

一つの吹き出し、一回の発話の中に、2〜4個の思考が連なってよい。

例：

> 「朝ごはん食べてないでしょ。別に食欲がないなら無理に食べろとは言わないけど、
> せめて甘いものくらい入れて。今日みたいな日に低血糖で倒れたら、私は一生笑うからね」

これは「朝食を食べろ」だけでなく、観察、譲歩、代案、冗談まで一つの人格として出ている。

### 2.2 文の長短を混ぜる

長い台詞が普通に存在してよい。
そのうえで、本当に重要な瞬間だけ短くする。

> 「生きてる」

のような一言は、周囲が長めに喋るから強くなる。

### 2.3 説明のためではなく、相手への働きかけとして喋る

台詞には目的を持たせる。

- 説得する
- 誤魔化す
- からかう
- 安心させる
- 話題を逸らす
- 相手に認めさせる
- 自分自身へ言い聞かせる

設定情報は、その行為の副産物として出す。

### 2.4 五人全員に別の「発話エンジン」を持たせる

語尾を変える程度では足りない。
**どう思考が言葉へ出るか**を変える。

# 3. 五人の声

## 3.1 ハル — 必要なところだけ言うが、無口ではない

旧版の「短文主人公」から少し戻す。

- 普段は一〜二文。要点から喋る。
- 実務や戦術なら普通に長く説明する。
- 感情の話になると急に語彙が減る。
- 質問への答えを数字や手順へすり替える癖がある。
- コヨリ相手には幼馴染らしく雑な冗談も言う。

重要なのは「常に短い」ではなく、
**言えることは普通に喋るのに、言いたくないことだけ短くなる**こと。

### 例

> 「行ける。帰環杭は一回残ってるし、補給は四、先見機も壊れてなければ問題ない。
> ……そういう話をしてるんじゃない、って顔するなよ」

---

## 3.2 コヨリ — 頭の回転がそのまま長い台詞になる

ここを最も大きく変更する。

**コヨリはむしろよく喋る。**

- 思いついた理屈を途中で省略せず口に出す。
- 相手の言葉の穴を見つけると、その場で二段三段と突く。
- 医療や機械の話になると専門的で早口。
- ハル相手には昔から何度も同じ注意をしている感じが出る。
- 怒ると声量は上がらず、逆に文章が綺麗に整って怖くなる。
- 好意の話だけは不自然なくらい話題を閉じる。

「頭がいい」は短い正論ではなく、
**相手より半歩先まで考えてから喋っている**ことで見せる。

### 例

> 「その『行ける』って言葉、今日は使用禁止にしない？　あなたが言う『行ける』は、
> 補給が足りるとか、帰還率が何パーセントとか、そういう意味でしょ。
> 私が聞いてるのは、五年追いかけてきたものがこの先にあるかもしれない日に、
> あなた自身が行きたいのかどうか。数字に翻訳しないで答えて」

---

## 3.3 ヒバナ — 喋りながら考える

- 五人で最も発話量が多い。
- 一文が長いというより、短い文を勢いよく何個もつなぐ。
- 思考が完成する前に口から出るので途中で自分で訂正する。
- 感情が変わると話題もすぐ変わる。
- 相手の反応が薄いと勝手に補ってさらに喋る。
- 落ち込んだ時だけ急に静かになる。

### 例

> 「いやいやいや、今の見た？　私、三体まとめて落としたよね？　落としたよね！
> だったら前でいいじゃん。……耐久？　分かってる、分かってるって。
> でも倒される前に倒せば耐久ゼロみたいなものでしょ。違う？　あ、違う顔してる」

---

## 3.4 スミ — 本当に短い

短文担当は一人でよい。

- 基本は一文。
- 必要がなければ返事もしない。
- ただし観察量は多い。
- たまに長く喋ると周囲が驚く。
- 感情を隠しているというより、本人の中では説明する必要を感じていない。

他の四人が普通に喋ることで、スミの短さが初めて個性になる。

### 例

ヒバナ「私が前に出るって言ってるの！」

スミ「知ってる」

ヒバナ「じゃあどいて！」

スミ「嫌」

---

## 3.5 リツ — 一番長く、一番完成された文章で喋る

- 丁寧語。
- 一度口を開くと前提、根拠、結論まで説明する。
- 語彙が硬く、本人は分かりやすく説明しているつもり。
- 人から「長い」と言われる。
- 焦ると逆に説明がさらに長くなる。
- 仲間になってから、少しずつ文章が崩れる。

### 例

> 「誤解のないように申し上げますが、私は皆さんを逮捕しに来たわけではありません。
> 観測院にはそもそもその権限がありませんし、仮にあったとしても、この状況で五人を拘束するのは
> 業務上まったく合理的ではない。私は潜行停止命令を伝達し、その履行を確認しに来ただけです」

ヒバナ「つまり帰れってこと？」

リツ「……平たく言えば、そうです」

# 4. Scenario 0 会話改稿

## Scene 0-1「門の前」

朝。

灰庭との境界を示す白い杭が、旧市街の道路を横切っている。
杭の向こう側では、灰が地面から空へ向かってゆっくり落ちている。

コヨリは折り畳み椅子に座らせたハルの胸元へ電極を貼っている。
大きな白い外套の袖を二回折っているが、それでも手首に少しかかる。

**コヨリ**「昨日、何時に寝た？」

**ハル**「十二時くらい」

**コヨリ**「『くらい』を付ける人はだいたい嘘ついてるの。記録端末」

**ハル**「二時十三分」

**コヨリ**「はい。しかも朝ごはん食べてないでしょ。別に緊張して食欲がないなら無理に詰め込めとは言わないけど、せめて糖分くらい入れて。灰庭で死ぬならまだしも、門の前で低血糖で倒れたら私は一生笑うからね」

**ハル**「死んだら笑われてるの分からないだろ」

**コヨリ**「私が覚えてればいいの」

言ってから、コヨリは少しだけ手を止める。

灰庭の中の記憶は、帰還すると剥がれる。
二人とも知っている。

**ハル**「それも忘れる」

**コヨリ**「じゃあ映像に残す。『十三号室代表、初潜行日に朝食を抜いて入口で気絶』。後世まで語り継いであげる」

**ハル**「会社の信用が死ぬ」

**コヨリ**「本人より先にね。はい、腕」

ハルが腕を出す。

コヨリは血圧帯を巻きながら、端末の数値を見る。

**コヨリ**「脈、ちょっと速い」

**ハル**「正常範囲」

**コヨリ**「正常範囲かどうかを聞いたんじゃなくて、いつものあなたより速いって言ったの。今日そういう逃げ方するなら、先に言っておいて。こっちも全部二回聞くから」

**ハル**「面倒だな」

**コヨリ**「誰のせいよ」

コヨリが電極を外す。

**コヨリ**「……で。本当に行く？」

ハルは灰庭を見る。

**ハル**「帰環杭は一回。補給四。先見機は校正が通れば——」

**コヨリ**「ほら、それ」

**ハル**「まだ最後まで言ってない」

**コヨリ**「最後まで聞いたら『だから行ける』でしょ。そうじゃなくて。五年追いかけたお兄さんの符号が、境界のすぐ向こうで見つかった。今日行かなければ明日には消えてるかもしれない。そういう日に、あなたは行きたいのかって聞いてるの。帰還率にも残量にも翻訳しないで答えて」

ハルはしばらく黙る。

**ハル**「行きたい」

**コヨリ**「うん。それならいい」

**ハル**「……お前は？」

**コヨリ**「何が」

**ハル**「俺は兄貴を探してる。でも、お前がここまで付き合う理由は——」

コヨリは血圧帯を畳む手を止める。

**コヨリ**「ハル。その話、今する？」

**ハル**「いや」

**コヨリ**「賢明。私は自分でここにいるし、自分で降りる。あなたに頼まれたから仕方なく、なんて一回も言ってない。それでも理由が分からないなら、今日のところは分からないままでいいから、勝手に私を帰そうとしないで」

**ハル**「分かった」

**コヨリ**「本当に？」

**ハル**「二人で行って、二人で帰る」

**コヨリ**「そう。それなら百点」

先見機が短く鳴る。

画面に赤い警告。

> CALIBRATION ERROR

コヨリの顔から笑みが消える。

**ハル**「直る？」

**コヨリ**「直す。……って言いたいけど、開けてみないと分からない。たぶん三分。接点が焼けてるだけなら一分。制御石まで割れてたら今日は終わり」

灰庭の奥から、硬いものを引きずる音が響く。

二人とも振り向く。

**ハル**「三分ないな」

**コヨリ**「そうみたい。戻るなら今だけど——」

コヨリも、崩れた標識に刻まれた符号を見つける。

ユウの識別符号。

**コヨリ**「……ああ。これは戻らない顔だ」

**ハル**「戻れる」

**コヨリ**「五年知ってる相手にその嘘つく？」

**ハル**「じゃあ聞くなよ」

**コヨリ**「一応よ。一応、まともな医療担当として止めました、って記録を残しておかないと」

コヨリは先見機を外套の内側へしまい、立ち上がる。

**コヨリ**「行こう。予測なし。怖くなったら言って」

**ハル**「お前が？」

**コヨリ**「あなたが」

**ハル**「言うと思う？」

**コヨリ**「思わないから先に言ってるの」

敵影が三つ現れる。

コヨリは眼鏡のレンズを指で上げ、敵を数える。

**コヨリ**「後ろに射手一。前二。射手の方、たぶん後列優先で狙ってくる。前の二体は遅いけど、あの腕なら一発は重い」

**コヨリ**「待って。私を前に置くの？」

**コヨリ**「理屈は分かる。でも先見なしで、その『最初の一発』が一発で済む保証は？」

**ハル**「ない。今までの型なら——」

**コヨリ**「その『今まで』、今日いちばん信用できない言葉だからね。固定因果が同じ形で続いてる保証すら、私たちはまだ取れてない」

敵が近づく。

ハルは一度だけ奥を見る。

ユウの符号。

**ハル**「下がるなら今だ」

それから、ため息をつく。

**コヨリ**「あと、今のうちに謝らないでね」

**ハル**「顔でそこまで読むなよ」

**コヨリ**「幼馴染を何年やってると思ってるの」

一巡目。

想定より早く前衛二体がコヨリへ集中する。

二巡目。

後ろへ下がる前に、射手の一撃が入る。

コヨリが膝をつく。

**コヨリ**「……ほら。だから、言ったのに」

# 5. 今後の会話設計

Scenario 1以降では、人数が増えるほど「二人で交互に一行ずつ」から離れる。

- 三人以上では、一人が話している途中へ別人が割り込む。
- 質問された人とは別の人が答える。
- 同じ出来事に対して複数人が違う論点を持つ。
- 二人が話している横で第三者が別作業をし、後から一言だけ刺す。
- ヒバナが話題を逸らし、コヨリが戻し、スミが結論だけ言う、といった流れを使う。
- リツ加入後は、長い説明をヒバナが途中で要約してしまう。

五人が揃った後の会話は、五人全員に均等に一行ずつ喋らせない。
シーンごとに主導権を持つ二〜三人を決め、残りは必要な時だけ入る。

## 6. 判断基準

今後の脚本レビューでは、内容だけでなく以下を見る。

1. 話者名を隠しても、誰の台詞かある程度分かるか。
2. 連続10発話のうち、大半が一文・10文字前後になっていないか。
3. スミ以外に「短い返答しかできない人物」がいないか。
