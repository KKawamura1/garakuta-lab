## 事前登録の判定

### P1 勝敗と面白さの分離 — 合格

200ランの局所探索標本で、勝利と認識指標の相関はすべて0近傍または負だった。

| 指標 | 勝利との相関 |
|---|---:|
| 問題の連鎖 | −0.144 |
| 既存部品の再解釈 | −0.142 |
| 方針転換 | −0.164 |
| 苦戦予期 | −0.656 |
| 死に時間 | +0.221 |

指標は勝ったランを高く評価していない。死に時間だけが勝利と正に相関するが、これは「楽に勝つほど死に時間が増える」という意図どおりの向きである。人間ログの「勝利は再プレイ度 −0.75」と符号が一致する。

### P2 死に時間の検出 — **不合格**

`dead_time` 警告はエージェント4ラン中0件。しかし**4体全員が、勝敗が実質決まった時点を具体的に名指ししている。**

| ラン | 本人が申告した決着点 | その後の記述 |
|---|---|---|
| seed 202 | 第1戦直後の報酬 | 「以後5戦は余った1〜2枠に何を挿すかしか動いていない」 |
| seed 404 | 第3戦後の報酬 | 「以後は何巡かかるかを数えるだけ、負ける絵が見えなくなった」 |
| seed 101 | 第5戦の報酬 | 「第6戦の報酬画面は結果が出た後の儀式」 |
| seed 303 | 第5戦のログ時点 | 「build画面に入った時点でどう組んでも届かないのが見えた」 |

現在の定義（末尾から連続する「圧勝予測 かつ 無傷 かつ 予想どおり」の戦闘）が狭すぎた。実際の決着感は次の二つで起きており、どちらも捕まえられていない。

1. **勝ち確定：** 予測は「勝てそう」「ギリギリ」のまま、判断だけが結果に効かなくなる。予測語ではなく、報酬・配置の変更が結果を変えないことが本体だった。
2. **負け確定：** seed 101 と 303 の第6戦。学習ログ#16の「不可視の将来罠」そのもの。現在の定義は敗北側を一切数えない。

対照的に、局所探索は死に時間1.75と高く出る。つまりこの警告は現状**「圧勝と言い切る予測スタイル」を測っているだけ**で、ゲームの性質を測っていない。

### P3 単一ゲートの検出 — **不合格**

基準は「過半のランで警告が立ち、出力集中の首位が防御系へ偏る」。実際は警告25%、首位は違法砲身2・電磁ラム2で**防御部品はゼロ**。

原因は指標ではなく、エージェントと人間・機械最適化の戦略的不一致だった。4体全員が第1戦を無傷または軽傷で抜けた結果から「反撃は巡回末に1回」と推論し、**全員が防御を捨てて火力に寄せた**。seed 303 は防御部品3種が一度も最終構成に残らなかったと報告している。

一方、局所探索200ランでは出力集中の首位が即席装甲機75回・違法砲身66回・吸着ドリル35回で、**装甲が最大勢力**である。人間のARC 3ランも感情が装甲へ集中していた。

つまり **同じルールについて、エージェントは人間および機械最適化と反対の結論に達した。** 代理として使う前に、この不一致の原因を切り分ける必要がある。第1候補は情報条件の欠落（下記）。

### P4 代理としての下限 — 合格

問題の連鎖 0.75、既存部品の再解釈 0.90 で、素朴方針（ともに0）を明確に上回る。局所探索と比べても問題の連鎖は0.75対0.30、苦戦予期は0.50対0.04で上回った。

ただし留保がある。問題の連鎖は「申告された不安の分類が前戦から変わった回数」であり、語彙の多様性を測っている可能性を排除できていない。局所探索の不安は固定関数から出るため変化しにくい。次回は不安の変化が実際の構成変更を伴ったかを併記する。

## 指標側で見つかった欠陥

### 予想外れの測定が機能していない

24戦すべてで `worse`（予想より悪い）が0件だった。内訳は better 16 / expected 8 / worse 0。

原因は `app.js` から継承した `outcomeLevel` がHPの帯だけを見ていることである。たとえば seed 101 の第5戦は HP29→13 と16も失いながら、HP13が「勝てそう」帯に入るため「予想より良い」と判定された。これは期待の裏切りではなく帯の跨ぎを測っている。

**この関数は人間のARCデータにも同じく使われている。** 「予測18件中14件は期待どおり」という記述も、同じ理由で信頼できない可能性がある。

### 方針転換の閾値が体感とずれている

`pivotRate` はCYCLE比較から引き継いだ「稼働列距離40%以上」を使っている。5枠では2枠の入れ替えが必要になる。

seed 404 は最終戦前に装甲プリズム→違法砲身の1枠入替を行い、これを「このランの唯一のピボット、自分の型を捨てる判断で本当に手が止まった」と報告したが、距離0.2のため `no_pivot` 警告が立った。アンケートで「方針転換あった」と答えた2ランのうち、機械判定が同意したのは0件だった。

**閾値は今回動かしていない。** 事前登録の後に基準を動かすのは、まさに避けたい手続きだからである。第2回の事前登録として、5枠系では距離0.2以上を方針転換候補とし、体感との一致率を再測する。

## ハーネス側で見つかった欠陥（修正済み）

1. **情報条件がプロトコル違反だった。** 巡回ログを生成しながらCLIが表示しておらず、エージェントは人間より少ない情報で遊んでいた。seed 202 が「暴走炉は熱4でも熱9でも4ダメージ、熱ルートは死んでいる」と誤推論した原因はこれである（実際は熱に応じて2→6まで伸びる。表示していたのは戦闘終了時の余剰熱で、部品が読む作動時点の熱ではなかった）。**P3の不一致もこの欠落が原因である可能性がある。**
2. **`finish` が指標をプレイヤーへ出力していた。** seed 202 が最終報告で `no_pivot` を引用しており、定性報告が指標に引きずられた。表示を `--showMetrics` の時だけに変更。
3. **行動の引数スキーマを表示していなかった。** 4体中3体が `partId` の名前が分からず弾かれた。型名だけでなく引数名と語彙を表示するよう変更。
4. **アンケートの欠測が黙って通っていた。** seed 303 と 404 は replay=0 として記録され、本人の報告（両方3点）と食い違った。replay と settledAt を必須にし、読めなければ拒否するよう変更。

なお seed 404 が報告した「`swap` が黙って無視された」は再現しなかった。実際は「slots must be 1..5」と拒否し終了コード1を返す。

## この4ランがゲームについて言っていること

指標の検証とは別に、被験者としての観察が一致した。

- **収束：** 4体とも同じ戦略（防御を捨てて一撃の大きい部品を並べる）へ到達した。局所探索200ランの方が最終構成は多様である。
- **中盤の消失：** 4体とも中盤を「平均ダメージの大きい方を取るだけの足し算」と評した。
- **死に資源：** seed 101 は熱18を余らせて終了、seed 404 は「説明文にペナルティなしと自白している」と指摘。3資源のうち熱が空回りしている。学習ログ#12の再検出。
- **一度だけ起きた正の構造：** seed 303 で違法砲身が候補に出た瞬間、死に札だった熱2枚の価値が反転した。憲章§3.2そのものだが、本人は「このランで唯一」と書いている。

## 第2回の事前登録

情報条件の欠落を直したうえで再走する。今回の結果で基準を都合よく変えないため、次を先に固定する。

- **P2′：** 決着点の検出を、予測語ではなく反実仮想で定義する。各戦闘の開始状態から報酬経路をK通り標本化し、局所探索で最善を打たせて全経路が同じ結末になる最初の戦闘を決着点とする。エージェントの自己申告 `settledAt` との一致率を測る。合格条件は一致率が偶然（±1戦の許容で約40%）を明確に上回ること。
- **P3′：** 巡回ログを見せた条件で、出力集中の首位分布が局所探索200ランの分布へ近づくか。近づけば不一致の原因は情報欠落、近づかなければエージェント固有の推論の癖である。
- **P5：** 方針転換の閾値を5枠系で0.2とし、アンケートの自己申告との一致率を測る。今回は0/2だった。
