# 感情の落差仮説：第一検証

## 問い

このゲームの面白さは、理不尽さの少なさや勝ち筋の適量よりも、**期待・不足・発見・方針転換・急成長が作る感情の落差**によって強く説明されるか。

機械評価は面白さを直接採点しない。次の二つを分離する。

1. 人間ログ上で、感情の山と方針転換が再プレイ意欲に併存していたか。
2. ゲーム構造に、当たり・既存部品の再評価・構成変化・反復回避を生みうる余地があるか。

## 人間ログの探索的結果

D1から、回答がある22ランを個人識別情報なしで固定した。OBSは13ラン、うち初期OBS 0.1は5ランである。

| 対象 | 比較 | 再プレイ度の平均差 |
|---|---|---:|
| 全22ラン | 最高瞬間あり − なし | +0.85 |
| 全22ラン | 方針転換あり − なし | +1.24 |
| 全22ラン | 勝利 − 敗北 | -0.75 |
| OBS 13ラン | 最高瞬間あり − なし | +0.86 |
| OBS 13ラン | 方針転換あり − なし | +1.17 |
| OBS 0.1 | 最高瞬間あり − なし | +1.33 |
| OBS 0.1 | 方針転換あり − なし | +1.17 |
| OBS 0.1 | 勝利 − 敗北 | -1.17 |

初期OBSで再プレイ4/5だった2ランは、どちらも敗北し、「欲しい部品待ちあり」「方針転換あり」だった。最高瞬間はそれぞれ「違法砲身を引いた」「火花ノズルの有効性に気づいた」であり、幸運と洞察という異なるピークが観測された。

一方、OBS内ではプレイ順と再プレイ度の相関が -0.752 だった。面白さが構造だけでなく、未理解だったことによる新鮮さを含む可能性が高い。少標本かつ版変更とプレイ順が交絡しているため、これは因果推論ではなく次の実験を正当化する兆候に留める。

再現：

```bash
node analysis/emotional-arc-observed.mjs
```

## 構造代理指標

OBS 0.1、CYCLE 0.1、CYCLE 0.2について、60ラン、各状態250構成を標本化した。各報酬の前後で次を測る。

- **当たりの裾:** 最善報酬による戦闘評価改善の90パーセンタイルと中央値の差
- **既存部品の再評価:** 新部品だけでなく、控えだった既存部品の採用や既存順序の大変更が起きた率
- **意味のある方針転換:** 報酬前後の稼働列距離が40%以上になった率
- **平坦さ:** 標本構成のうち最良から3点以内に収まる割合
- **安全構成の氾濫:** 無傷勝利する構成の割合
- **反復リスク:** 最終構成の最多パターンへの集中率

| 指標 | OBS 0.1 | CYCLE 0.1 | CYCLE 0.2 |
|---|---:|---:|---:|
| 当たりの裾 | 7 | 16 | 5 |
| 既存部品の再評価率 | **11.0%** | 5.7% | 4.7% |
| 大きな方針転換率 | 8.0% | 12.0% | 15.3% |
| ほぼ最良の構成割合 | **36.8%** | 46.1% | **63.4%** |
| 無傷勝利構成割合 | 22.9% | 21.3% | **48.3%** |
| 最多最終構成への集中 | 20.0% | **51.7%** | 21.7% |
| 最終構成パターン数 / 60 | **32** | 16 | 16 |

大きな方針転換率だけではCYCLE 0.2を誤って高く評価した。これは、部品の追加により並びが変わることと、既存部品の意味が変わることが別だからである。OBSは既存部品の再評価と最終構成の多様さが高い。CYCLE 0.1は報酬効果の振幅が最大だが、最終構成の半数以上が一パターンへ収束し、短期の刺激と長期の反復性が両立していない。CYCLE 0.2は安全構成とほぼ最良構成が多く、実プレイの「何をしても勝てる」を機械側でも再現した。

再現：

```bash
node analysis/emotional-arc-probe.mjs
```

## 現時点の判断

仮説は**部分的に支持**される。

- 勝利や高HPは再プレイ度を説明せず、感情の山と方針転換は高い再プレイ度と併存した。
- OBSには、CYCLEより既存部品を再評価させる構造と、異なる最終機械を作る余地が多かった。
- ただしOBSの再プレイ低下は速く、新鮮さを使い切った後にも再評価が続くかは未検証である。
- 当たり、方針転換、構成多様性のいずれも単独では十分条件ではない。合成得点は作らない。

## 次の人間実験

初期OBS 0.1のルールと数値を復元し、ルールを改善せずに再試験する。これは懐古的な巻き戻しではなく、次を分離する対照実験である。

1. 中身を既に知った現在でも、期待・発見・方針転換が再発するか。
2. 面白かったのが初見の新鮮さだけなら、再プレイ度と認識更新は再現しない。
3. 構造に持続性があるなら、別の部品の再評価、別のラン物語、または新しい当たりへの期待が再発する。

戦闘前に任意の勝敗予測を一タップで残し、実際の結果との差を自動記録する。ラン終了時には「このランを一言で」と「次に見たいもの」を追加し、勝率ではなく、良い意味の予想外・固有の物語・再試行の動機を観測する。
