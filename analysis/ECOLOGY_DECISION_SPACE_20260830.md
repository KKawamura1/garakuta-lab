# 灰の遠征の選択空間 — 測定と関門（2026-08-30）

対象: main `3106f84`（EXP-18 Phase B、7区画の遠征）
検査: [`analysis/ecology-decision-space-smoke.mjs`](ecology-decision-space-smoke.mjs)（SLOW_CHECKS、約2分半）

## 1. なぜ測ったか

作者の判断は「ゲームがあまり面白くない。構成自体は既知の手法なので、
もっと細かいところ（スキルのぶっ飛び度の不足、戦略のわかりやすさの不足）に
原因がある気がする」。SCRAPLINE 0.7 の「始終なにもわからん」と同じ症状が
灰の遠征でも出ていないかを、散文ではなく数で見た。

## 2. 最初に見た数字

技能・反応・常設・装備を**でたらめに埋めた編成**で、7区画をHP持ち越しで通した。

| 到達 | 300編成中 |
|---|---|
| 4区画 | 12 (4%) |
| 5区画 | 5 (2%) |
| 6区画 | 81 (27%) |
| **7区画（完走）** | **202 (67%)** |

無作為に枠を埋めるだけで3回に2回完走する。技能ごとの寄与（その技能を持つ編成と
持たない編成の平均到達区画の差）も、**全20種が ±0.2 区画（7区画中）に収まった**。
どれを選んでも結果が変わらない。

思いつきやすい対策は2つとも潰れた。

- **通常攻撃100%が犯人ではない。** 45%へ下げても完走率は 67%→59% にしか動かない。
  枠が埋まっていれば通常攻撃はほとんど発火しない。
- **係数の広がり不足でもない。** 技能係数の差を5乗して誇張したら、完走率は
  **上がって** 74% になった。火力は勝敗の律速ではない。

## 3. 関門をどう設計したか

「無作為編成の完走率」だけを関門にすると、**難度を上げるだけで通ってしまう**
（敵×4で完走率3%。しかし選択は何も生まれていない）。「敵を強くしただけ」を
成功と誤認しない測り方が要る。

そこで**難度に依存しない量**にした。編成ごとに **耐久倍率**（敵を一律何倍まで
強くしても完走できるか）を二分探索で出し、比を取る。

```
知識の利得 = 探索で見つけた最良編成の耐久倍率 ÷ 無作為編成の中央値
運の幅     = 無作為編成の最良の耐久倍率       ÷ 無作為編成の中央値
```

敵を一律に強くすると分子も分母も同じだけ下がるので、この比は動かない。
**この関門は、敵がどう作られるべきかについて何も仮定しない。**
特定の対策を強いる敵を正解として埋め込んでいない。

閾値 `知識の利得 ≥ 2.0` は**数字を見る前に**決めた。破綻の足切りであって
面白さの水準ではないので、意図して控えめにしてある。

### 関門自身の参照点

参照点の無い関門は、自分が壊れていることを教えてくれない（AGENTS.md）。
本番より先に、答えの分かっている content 2つへ同じ物差しをかける。

| 参照 | 中身 | 出るべき値 | 実測 |
|---|---|---|---|
| 陰性 | 12技能すべて同一のクローン | ちょうど 1.00 | **1.00** |
| 陽性 | 11種は弱く、1種だけ明確に強い | 閾値 2.0 以上 | **4.04** |

物差しは信号を捏造せず、実在する差を見つけられている。どちらかが落ちたときに
壊れているのは game ではなくこの検査であり、検査の出力もそう言う。

## 4. 本番の結果

```
現行: 中央値 1.26倍 [95% 1.13〜1.35] / 運の最良 1.98倍 / 探索の最良 2.56倍
      → 知識の利得 2.03 倍（運の幅 1.57 倍、探索 1064 回）
```

**知識の利得 2.03 は閾値 2.0 を通った。** これは §2 の読み（「選択が何も効いていない」）と
食い違う。両方を突き合わせると、より正確な診断になる。

**無作為編成の耐久倍率の中央値が 1.26 倍ある。出荷している難度は 1.0 倍。**
つまり2倍ぶんの選択の幅は実在するのに、**プレイヤーが立っている場所がその幅の外**にある。
編成系は壊れていない。**難度設定によって無効化されている。**

「知識の利得」だけを関門にしていたら、この状態を見逃していた。

## 5. 関門は3本

別々の条件なので、別々に落ちる。

| # | 条件 | 何を防ぐか | 2026-08-30 の main |
|---|---|---|---|
| 1 | 探索の最良編成は難度1.0を完走できる | 「勝てなくすれば通る」関門になること | 通る（2.56倍） |
| 2 | 無作為編成の耐久倍率の中央値 < 1.0 | 幅は在るのにプレイヤーがその外に立っていること | **落ちる（1.26倍）** |
| 3 | 知識の利得 ≥ 2.0 | 考える幅そのものが無いこと | 通る（2.03倍） |

関門2は中央値の95%区間が 1.0 をまたいでいたら判定せず、
「標本 48 件では判定できない」と言って落ちる（AGENTS.md 検証5規則の3）。

## 6. いまの判定

**この検査は意図して赤い。** 未修正の欠陥を記録している赤であって、検査の不具合ではない。
直すまでは `RUN_EXHAUSTIVE=1` がこの1本で落ちる。**閾値を動かして緑にしない。**

関門2だけが落ちているという形は、次に何をすべきかをかなり絞る。
**まず難度が編成系の効く帯に入っていない**（無作為編成が半分以上完走する）。
一方、関門3が通っている以上、技能・装備の設計をやり直さなくても幅そのものは在る。

ただし関門3は 2.03 と閾値ぎりぎりで、**運の幅 1.57 に対する余裕も小さい**。
考えて組んで得られるもの（2.03倍）と、48回さいころを振って一番良かったもの（1.57倍）が
近い。難度を上げれば関門2は通るが、それだけでは「考えるより引き直すほうが早い」状態は残る。
関門3の余裕を広げる作業は別に要る。

## 7. この検査が言っていないこと

- 面白いかどうか。これは破綻の足切りであって、fun 判定ではない。
- 敵をどう作るべきか。物差しは敵の作り方について中立で、
  特定の戦略以外を拒否する敵を正解として持っていない。
- 3本すべて通れば良い game になる、ということ。**必要条件であって十分条件ではない。**
