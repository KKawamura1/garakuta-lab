# 灰の遠征の選択空間 — 測定と関門（2026-08-30）

対象: main `3106f84`（EXP-18 Phase B、7区画の遠征）
検査: [`analysis/ecology-decision-space-smoke.mjs`](ecology-decision-space-smoke.mjs)（SLOW_CHECKS、約2分半）

## 1. なぜ測ったか

作者の判断は「ゲームがあまり面白くない。構成自体は既知の手法なので、
もっと細かいところ（スキルのぶっ飛び度の不足、戦略のわかりやすさの不足）に
原因がある気がする」。SCRAPLINE 0.7 の「始終なにもわからん」と同じ症状が
灰の遠征でも出ていないかを、散文ではなく数で見た。

## 2. 最初に見た数字

技能・反応・常設・装備を**でたらめに埋めた編成**で、7区画をHP持ち越しで通した。

| 到達 | 300編成中 |
|---|---|
| 4区画 | 12 (4%) |
| 5区画 | 5 (2%) |
| 6区画 | 81 (27%) |
| **7区画（完走）** | **202 (67%)** |

無作為に枠を埋めるだけで3回に2回完走する。技能ごとの寄与（その技能を持つ編成と
持たない編成の平均到達区画の差）も、**全20種が ±0.2 区画（7区画中）に収まった**。
どれを選んでも結果が変わらない。

思いつきやすい対策は2つとも潰れた。

- **通常攻撃100%が犯人ではない。** 45%へ下げても完走率は 67%→59% にしか動かない。
  枠が埋まっていれば通常攻撃はほとんど発火しない。
- **係数の広がり不足でもない。** 技能係数の差を5乗して誇張したら、完走率は
  **上がって** 74% になった。火力は勝敗の律速ではない。

## 3. 関門をどう設計したか

「無作為編成の完走率」だけを関門にすると、**難度を上げるだけで通ってしまう**
（敵×4で完走率3%。しかし選択は何も生まれていない）。「敵を強くしただけ」を
成功と誤認しない測り方が要る。

そこで**難度に依存しない量**にした。編成ごとに **耐久倍率**（敵を一律何倍まで
強くしても完走できるか）を二分探索で出す。

倍にするのは**連続量の4つ**（`maxHp` `might` `focus` `guard`）。R6 §4.4 が
連続量と呼んでいるものと同じ。`speed` `AP` `RP` は小整数のままにする。
ここを倍にすると敵の手数そのものが増えて、「同じ敵が強い」ではなく
「敵が増えた」に化ける。**測りたいのは強さであって数ではない。**

**この関門は、敵がどう作られるべきかについて何も仮定しない。**
特定の対策を強いる敵を正解として埋め込んでいない。

### 関門自身の参照点

参照点の無い関門は、自分が壊れていることを教えてくれない（AGENTS.md）。
本番より先に、答えの分かっている content 2つへ同じ物差しをかける。

| 参照 | 中身 | 出るべき値 | 実測 |
|---|---|---|---|
| 陰性 | 12技能すべて同一のクローン | ちょうど 1.00 | **1.00** |
| 陽性 | 11種は弱く、1種だけ明確に強い | 閾値 2.0 以上 | **4.04** |

物差しは信号を捏造せず、実在する差を見つけられている。どちらかが落ちたときに
壊れているのは game ではなくこの検査であり、検査の出力もそう言う。

## 4. 関門は2本 — 帯の床と天井

| | 条件 | 何を防ぐか |
|---|---|---|
| **床** | 無作為編成の耐久倍率の**中央値 < 1.0** | 考えずに枠を埋めた編成が出荷難度を通ること |
| **天井** | 探索で見つけた最良編成の耐久倍率 **≥ 2.0** | 上振れる編成が存在しないこと |

天井は作者の指定（2026-08-30）。**「いい戦略には、いい意味でゲームを壊してほしい」。**
強い編成の到達点を、比ではなく絶対値で留める。難度を上げるだけでは通らない
（敵を強くすると探索の最良も同じだけ下がる）ので、天井を上げるには
編成側の上振れを作るしかない。

床が無いと天井は「簡単にすれば通る」関門になり、天井が無いと床は
「難しくすれば通る」関門になる。**両側から挟む。**

知識の利得（＝ 天井 ÷ 床）はこの2つから導かれるので関門にしない。
床 < 1.0 かつ 天井 ≥ 2.0 なら利得は必ず 2.0 を超える。診断として印字だけする。

1.0 は「出荷している難度そのもの」であって選んだ値ではない。2.0 は作者が決めた。

床は中央値の95%区間が 1.0 をまたいでいたら判定せず、
「標本 48 件では判定できない」と言って落ちる（AGENTS.md 検証5規則の3）。

## 5. 本番の結果

```
現行: 中央値 1.17倍 [95% 1.06〜1.28] / 運の最良 2.07倍 / 探索の最良 2.47倍
      → 知識の利得 2.11 倍（運の幅 1.77 倍、探索 1061 回）
```

| 関門 | 実測 | 判定 |
|---|---|---|
| 床（中央値 < 1.0） | 1.17 倍 [1.06, 1.28] | **落ちる** |
| 天井（最良 ≥ 2.0） | 2.47 倍 | 通る |

**天井は既に足りている。落ちているのは床だけ。**
連続量を全部2倍にしても完走できる編成は、いまの content で既に存在する（2.47倍）。
問題は、出荷している難度 1.0 倍がその帯のはるか下にあること。
**編成系は壊れていない。プレイヤーが、それが効く場所に立っていない。**

これは §2 の読み（「選択が何も効いていない」）と食い違う。両方を突き合わせた
この形が正しい診断で、§2 だけ、あるいは天井だけを見ていたら見逃していた。

### 出荷難度をどこへ置くか（関門ではなく判断材料）

```
    敵 1.0 倍: 無作為編成の完走率  77%（37/48）  ← いまここ
    敵 1.2 倍: 無作為編成の完走率  46%（22/48）
    敵 1.4 倍: 無作為編成の完走率  25%（12/48）
    敵 1.6 倍: 無作為編成の完走率  13%（6/48）
    敵 1.8 倍: 無作為編成の完走率   2%（1/48）
    敵 2.0 倍: 無作為編成の完走率   2%（1/48）
```

天井が 2.47 倍なので、1.8 倍あたりへ置くと「雑な編成はまず通らないが、
考え抜いた編成には 37% の余裕が残る」形になる。

### 残る問題 — 上振れが、考えた結果になっていない

天井 2.47 倍に対し、**48回引き直したときの当たりが 2.07 倍**ある。
知識の利得 2.11 に対して運の幅 1.77。**天井の85%まで、引き直すだけで届く。**

難度を上げれば床は通るが、それだけでは「考えるより引き直すほうが早い」状態は残る。
**床は難度で通せる。天井を「考えた結果」にするのは別の作業**であり、
技能・装備の側に掛け算になる軸が要る。

## 6. 作者の「今の最強編成」を測った（2026-08-30）

作者の申告：カイ・レオン・スイを**大溜め（準備3段、might 2.25倍）のみ**にし、
反応に**急かす＋準備の螺旋**。ナギは防壁形成のみ＋身代わり、ミナは手当てのみ＋余剰治療。
全員 出足＋備え。装備は行動追加をアタッカー、耐久をナギへ。
体感は「2倍と言わず結構出そう」。

**実測 1.27 倍。** 無作為編成の中央値 1.17 倍の 1.08 倍でしかなく、
48回引き直したときの当たり（2.07倍）にも、探索の天井（2.47倍）にも届かない。

### コンボは設計どおり動いている

急かすが味方3人ぶん発火して3段の準備が**その場で完了**し、
スイは行動権4（基礎1＋出足1＋軽い締め具1＋予備のばね1）で
第1ラウンドに大溜めを3発撃つ。狙いは完全に実現している。

### それでも弱い理由 — 反応権が「余っているのに使えない」

**反応権は行動権と同じく毎ラウンド頭に全回復する**（`ecology/engine.mjs:530`、
`actor.reactionPoints = actor.baseReactionPoints`）。枯れっぱなしではない。
問題は回復しないことではなく、**回復した反応権の行き先が無いこと**。

第5区画（敵1.27倍）の実測：

| ラウンド | 準備開始 | 準備完了 | 急かす発火 | 螺旋発火 | アタッカーのRP |
|---|---|---|---|---|---|
| 1 | 6 | **3** | 9（3人×3） | 0 | 3 → 0 |
| 2 | 0 | 0 | **0** | 3 | 2 → **2（丸ごと余る）** |
| 3 | 0 | 3 | **0** | 0 | 2 → **2（丸ごと余る）** |
| 4 | 5 | 2 | 6（3人×2） | 0 | 2 → 0 |
| 5 | 0 | 0 | **0** | 3 | 2 → **2（丸ごと余る）** |
| 6 | 0 | 3 | **0** | 0 | 2 → **2（丸ごと余る）** |

三つの事実が重なっている。

1. **急かすは `preparation_started` にしか反応しない。** 準備が始まる瞬間しか窓が無く、
   **一度詰まった準備は、あとから何RP積んでも救えない。**
2. **準備中は新しい準備を宣言できない**ので、ラウンド2・3には `preparation_started` が
   一件も出ない。**反応権は満タンのまま、使い道が無い。**
3. **備え（foundation_rp）と出足（foundation_ap）は戦闘中1回だけ**（R6 §6.8、
   `limit: {scope:"battle", count:1}`）。ラウンド2以降の補充は素の 2 に戻るので、
   **長い戦いではこの常設2枠がほぼ死ぬ。**

結果、コンボは**第1ラウンドに反応権を使い切って3発撃ち、そのあと2ラウンド、
満タンの反応権を抱えたまま何もしない。** 6ラウンドで11発、
アタッカー1人あたり 0.6発/ラウンド × 2.25倍 ＝ 実効 1.35倍。
斬撃（1.20倍）を毎AP撃つほうが多い。

**しかもアタッカーに積んでいるのは行動追加の装備。** 詰まっているのは行動権ではないので、
ほとんど効いていない。**盤面には「RPが余っている」とも「準備が詰まった」とも出ない。**

### 切り分け

| 編成 | 耐久倍率 |
|---|---|
| A 作者の指定どおり（枠を絞る・大溜めコンボ） | **1.27** |
| B 枠を絞る・コンボ無し（ただ斬撃を押すだけ） | 2.01 |
| C 枠を全部埋める・コンボあり | 2.06 |
| D 枠を全部埋める・コンボ無し | **2.11** |
| E 大溜めを一人に絞り、残り4人が急かすを供給 | **2.24** |

**コンボは、あってもマイナス。** A→B（コンボを外して斬撃にするだけ）で 1.27 → 2.01。
C→D（枠を埋めた状態でも）2.06 → 2.11。

RPを集中させれば構想は生きる（E＝2.24）。**配分が逆だっただけで、読みは正しかった。**
ただしそれでも探索の天井 2.47 には届かない。

### ここから出る設計上の問題

1. **枠を絞ること自体が罰になっている。** 行動3・反応3・常設2の枠は埋めるコストがゼロなので、
   「絞る」設計は必ず「同じ構成＋余りを埋めた版」に負ける。
   A→D の差（1.27→2.11）の大半は、空き枠へ**地力（+50 maxHp）を詰めた**ぶんである。
   作者の「メインは○○のみ」という美学が、ルール上は純粋な損になっている。

2. **山登りの最適解は、専門化とコンボを外す方向へ進む。** 作者の編成を種に登らせると、
   ナギの防壁形成→貫き突き、カイの大溜め→斬撃、常設は全員 地力 へ置き換わる。
   **game は「専門化とコンボ」より「全員に+HPを積んで殴る」を高く買っている。**

3. **急かすは時間を早めるだけで、威力を増やさない。** 3RPを注いで得るのは
   「2.25倍が早く出る」であって「2.25倍が大きくなる」ではない。
   1AP＋3RP で 2.25倍、1AP だけで 1.20倍。**3RP の対価が 1.05倍。**
   仕込みに人数を注いでも、出力は線形にしか増えない。
   **コンボが掛け算になっていないので、注ぎ込んでも壊れない。**

4. **仕込みの窓が一瞬しかない。** 急かすが `preparation_started` にしか反応しないので、
   反応権は「その瞬間に在るぶん」しか意味を持たない。溜め続ける、次のラウンドに
   まとめて注ぐ、といった**貯めて放つ遊び方が構造上できない。**
   準備中に注げるようにするか、注いだ段数ぶん威力が乗るようにすれば、
   ラウンド2・3に丸ごと余っている反応権が仕事を持つ。

5. **常設の 備え・出足 は戦闘中1回だけなので、長い戦いほど価値が落ちる。**
   R6 §6.8 は「毎ラウンド手数が増える passive を作らない」ためにこうしたが、
   結果として**この2種は短期戦専用**になっている。作者の編成は全員がこの2枠を
   使っており、7区画の後半ほど無駄が大きい。

この検査は作者の編成を参照点として毎回測る。content を触ったとき、
作者の考えた戦略が強くなったか弱くなったかが数字で出る。

## 7. 途中で直した測り方の欠陥（記録）

**山登りを「無作為編成の中央値の難度」で回していた。** その難度でだけ強い編成が
見つかるので、天井（もっと高い倍率で勝てるか）とずれる。実測で
`探索の最良 2.02 < 運の最良 2.07` という逆転が出て気づいた。
いまは**その時点で一番強い編成がちょうど限界を迎える倍率**で登る。

あわせて、報告する天井を `max(探索の結果, 種にした編成)` にした。山登りは固定難度の
点数を上げるので、耐久倍率で見ると種より下がることがある（別の量だから）。
下がったときに種を捨てると、**探索の弱さを game の平坦さとして報告してしまう。**

## 8. いまの判定

**この検査は意図して赤い。** 未修正の欠陥を記録している赤であって、検査の不具合ではない。
直すまでは `RUN_EXHAUSTIVE=1` がこの1本で落ちる。**閾値を動かして緑にしない。**

## 9. この検査が言っていないこと

- 面白いかどうか。これは破綻の足切りであって、fun 判定ではない。
- 敵をどう作るべきか。物差しは敵の作り方について中立で、
  特定の戦略以外を拒否する敵を正解として持っていない。
- 両方通れば良い game になる、ということ。**必要条件であって十分条件ではない。**

## 10. 常設技能の効き（2026-08-30、作者の懸念への回答）

「地力(+50 maxHp)が強すぎて膂力+2などが空気になっていないか」を測った。
土台を全員同じにし、**常設1枠だけ**を差し替えて耐久倍率を比べる。

| 常設 | 耐久倍率 | 差 |
|---|---|---|
| なし | 1.35 | — |
| **地力**（maxHp +50） | **1.51** | **+11.9%** |
| **出足**（AP +1、戦闘中1回） | **1.51** | **+11.9%** |
| 速さ（+1） | 1.44 | +6.8% |
| 膂力（might +2） | 1.42 | +5.1% |
| 集中力（focus +2） | 1.35 | ±0 |
| 受け（guard +1） | 1.35 | ±0 |
| 備え（RP +1、戦闘中1回） | 1.35 | ±0 |

**地力は強いが突出はしていない。出足がちょうど同着。** 膂力は地力の4割強あり、
空気にはなっていない。**死んでいるのは集中力・受け・備えの3種**（測定分解能以下）。

- 受け: +1 に対して被弾が10〜40、しかも最低保証（raw の10%）に吸われる
- 集中力: 回復・防壁の量しか動かさないので、回復役以外では効き所が無い
- 備え: 反応1回ぶん、しかも戦闘中1回

短期決戦（出足・備え）と長期対応（地力）のトレードオフは成立している。
**直すなら地力を下げる方向ではなく、下の3種を効かせる方向。**

## 11. 準備機構の試作（2026-08-30、作者提案）

作者の提案は二つ。

1. 準備中のキャラクターは、行動権を得たら必ず「準備を進める」という AP-1 の行動を行う
2. 急かすは、準備を要求する技能の開始にも、「準備を進める」にも反応する

現行は `engine.mjs:601` で、**準備中の起動は行動権を払わずに1段進めて終わる**。
さらに `requeueOnResourceGain` が準備中は早期 return するので、
**準備中は行動権を何点持っていても無意味**だった。

| | 現行 | 工程1のみ | 工程1＋2 |
|---|---|---|---|
| 床（無作為の中央値） | 1.17 | 1.17 | 1.17 |
| 天井（探索の最良） | 2.47 | **2.47** | **2.02** |
| 知識の利得 | 2.11 | **2.11** | **1.73** |
| 作者の編成 | 1.26 | **1.53** | 1.33 |
| C コンボ | 2.06 | 2.13 | 2.20 |
| D 殴るだけ | 2.11 | 2.11 | 2.11 |

**工程1だけが正味の得。** 作者の編成が 1.26 → 1.53（+21%）へ上がり、
「考えたビルド C」が初めて「殴るだけ D」を上回る（2.06<2.11 → 2.13>2.11）。
床・天井・知識の利得はどれも動かない。**副作用が無い。**
天井が動かないのは、山登りの最適解が準備系技能を使っていないため。

**工程2は構造を下げる。** 急かすが「進める」にも反応すると、
コンボ編成は伸びる（2.13→2.20）が、**天井が 2.47 → 2.02、知識の利得が 2.11 → 1.73**。
急かすは反応技能の候補として無作為編成にも入るので、**準備している味方が
いるだけで反応権を吸い、他の反応技能（反撃・身代わり・受け流し）を殺す。**
コンボを組んでいない編成にとって、急かすが純粋な負債になる。

工程2の考え自体が悪いのではなく、**発火条件が無差別なのが悪い。**
狙った味方だけ、あるいは代償を上げる形なら成立しうる。
