# 締付機関 SQUEEZE 0.1（2026-08-23 深夜）

**COST 0.1 で足りなかったところを塞ぐ版。**

## なぜ作ったか：**COST は代償を請求していなかった**

`analysis/run-viability.mjs` で1ラン通して測った結果：

| | 完走 | 平均残HP |
|---|---|---|
| laws-0.3 | 33/48 | 29.3 |
| **COST 0.1** | **46/48** | **30.0** |

**失点が最小になる並びを選び続けると、まったく削られずに終わる。**
速さと安全さの相関は確かに負（−0.26）だが、**安全だけを見るなら遅く行けばいい。**
代償は、速さを欲しがったときにしか請求されなかった。

Into the Breach の形は「全部は守れない」である。**遅い方も塞がないと、その形にならない。**

## 何を足したか

暴走に加えて、**敵が毎巡、最大HPの1.5〜4%を回復する**（組ごとに違う）。

> 速く出せば**暴走**で自分が削れ、遅く行けば**敵が回復**して削り切れない。

## 効いたか

| | 完走 | 平均残HP | 無傷で抜けられる局面 |
|---|---|---|---|
| COST 0.1 | 46/48 | **30.0** | 多い |
| **SQUEEZE 0.1** | **35/48** | **27.8** | **0〜40%（多くの組で0%）** |
| （参考）laws-0.3 | 33/48 | 29.3 | — |

**平均残HPが下がった＝代償が実際に請求されている。**
完走率は laws-0.3 と同程度（35/48 対 33/48）なので、**理不尽になったわけではない。**

13組すべてで相関が負（−0.08〜−0.48）、詰みなしは12組が100%・1組が97%。

## 表は直に測って作った。**近道が使えなかった**

`tune-laws.mjs` は巨大HPの身代わりに1回だけ戦わせ、累計ダメージから
あらゆる敵HPの結果を読み出す（速い）。**毎巡回復とは両立しない**——
回復は「その敵の最大HP」で頭打ちになるので、身代わりの敵では頭打ちが起きず、
本物の敵の結果とずれる。

**ずれた表は、静かに間違った実験を作る。**この企画は一度それをやっている
（とどめの巡回の敵の攻撃を数えていた誤り）。
`analysis/tune-squeeze.mjs` は候補ごとに本物の敵で測る。遅いが数分で終わる。

生成条件に**「無傷で抜けられる局面が40%以下」**を入れてある。
これが COST 0.1 に無かったもので、**代償が「ある」ことと「請求される」ことは別**である。

## 検査

`analysis/smoke-squeeze.mjs`：詰みなし90%以上／選択に勝目20%以上／相関が負／
**無傷で抜けられる局面が50%以下**／毎巡回復が0に丸められていない／規則が文面に出ている。

## 遊び方

「ゲーム」から **締付機関 / SQUEEZE 0.1**。直接なら `?ruleset=squeeze`。

**比べる相手は COST 0.1 である。**片方は代償があるが避けられ、
もう片方は避けられない。**避けられない代償が面白いのか**を見たい。
