# ECHO 0.1：残響工房

## 状態

**事前登録。人間プレイ待ち。** GRAFTの改修案ではなく、再プレイ動機の別仮説を短時間で検証する独立試作。

## 問い

作者がもう一度遊びたくなるのは、未発見のランダム内容を求めるからか。それとも、直前の自分の具体的な判断を見て「ここを変えたらどうなるか」を試したくなるからか。

直近のGRAFTでは、反動打撃を発見して勝つ初回の理解・発見は面白かった。一方、勝ち筋を知った後は、最高点や勝利そのものが再プレイを強く生まなかった。そこで、GRAFTのバランスを再調整せず、前回の行動列をゲーム内の足跡として次の走行へ渡す。

## 変更

- 6区画、3行動（刈り取る／整える／賭ける）、熱10超過で崩壊。
- 初回は前回の足跡なし。走行後、次回へ6手のアイコンと前回スコアを残す。
- 前回と同じ手なら熱−1、違う手なら部品+2。変更点の効果をその場で返し、「書き換え」を操作上の目的にする。
- URLの `?seed=12` で同じ問題を再現する。ランダム性の寄与を混ぜず、まず反実仮想の効果を測る。
- 結果画面で面白さ、再プレイ度、良かった瞬間、引っかかった点、次に試す手を記録する。

## 維持するもの

- 1走行を数分で終える。
- 途中の感情マーカーを残す。
- 選択・結果・アンケートをD1へ送る。
- 人間テストは作者自身が行い、エージェントはUIと決着の検査に限定する。

## 事前の成功信号

次のうち複数が観測されること。

1. 初回終了後、促されなくても「もう一度」を押す。
2. 2走目で、前回の特定区画・特定行動を変える意図を言える。
3. 「面白さ」だけでなく「今すぐもう一度やりたい度」が4以上になる。
4. 良かった瞬間がスコア更新ではなく、残響を利用／書き換えた局面として記述される。

## 失敗信号

- 前回手順がただの履歴表示に見える。
- 変更しても勝敗・判断がほぼ変わらず、違いを試す理由にならない。
- 再プレイ度が2以下、または「もう一度」はあっても次に試す手が具体化しない。
- 3行動のうち一つが常に優位で、GRAFTと同じ支配戦略へ戻る。

## プレイ手順

1. `https://garakuta-lab.pages.dev/echo/?seed=12` を初回として遊ぶ。
2. 結果画面で回答し、画面に出た前回の6手を確認する。
3. 同じURLのまま「この残響を書き換える」を押し、少なくとも1手を意図的に変える。
4. 2走目の結果で、再プレイ度と「次に変えたい手」を記録する。

seedは検証上固定する。実際のゲームとしてランダム性を入れるかは、この仮説の判定後に別要因として試す。

## 判定後の分岐

- 成功：残響の仕組みだけを抽出し、より豊かな行動差（分岐、前回の失敗の利用、ゴーストとの競争）を一つずつ追加する。
- 失敗：ECHOを延命せず、次は「見えているリスクをどこまで押すか」を主役にする別試作へ移る。
- 判定保留：面白さは低くないが再プレイ理由が言語化されない場合、UIの問題か構造の問題かを分ける短い対照版を作る。
