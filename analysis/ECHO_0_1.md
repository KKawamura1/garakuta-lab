# ECHO 0.1：残響工房

## 状態

**事前登録。人間プレイ待ち。** GRAFTの改修案ではなく、再プレイ動機の別仮説を短時間で検証する独立試作。

## 問い

作者がもう一度遊びたくなるのは、未発見のランダム内容を求めるからか。それとも、直前の自分の具体的な判断を見て「ここを変えたらどうなるか」を試したくなるからか。

直近のGRAFTでは、反動打撃を発見して勝つ初回の理解・発見は面白かった。一方、勝ち筋を知った後は、最高点や勝利そのものが再プレイを強く生まなかった。そこで、GRAFTのバランスを再調整せず、前回の行動列をゲーム内の足跡として次の走行へ渡す。

## 変更

- 6区画、3行動（刈り取る／整える／賭ける）、熱10超過で崩壊。
- 初回は前回の足跡なし。走行後、次回へ6手のアイコンと前回スコアを残す。
- 前回と同じ手なら熱−1、違う手なら部品+2。変更点の効果をその場で返し、「書き換え」を操作上の目的にする。
- URLの `?seed=12` で同じ問題を再現する。ランダム性の寄与を混ぜず、まず反実仮想の効果を測る。
- 結果画面で面白さ、再プレイ度、良かった瞬間、引っかかった点、次に試す手を記録する。

## 維持するもの

- 1走行を数分で終える。
- 途中の感情マーカーを残す。
- 選択・結果・アンケートをD1へ送る。
- 人間テストは作者自身が行い、エージェントはUIと決着の検査に限定する。

## 事前の成功信号

次のうち複数が観測されること。

1. 初回終了後、促されなくても「もう一度」を押す。
2. 2走目で、前回の特定区画・特定行動を変える意図を言える。
3. 「面白さ」だけでなく「今すぐもう一度やりたい度」が4以上になる。
4. 良かった瞬間がスコア更新ではなく、残響を利用／書き換えた局面として記述される。

## 失敗信号

- 前回手順がただの履歴表示に見える。
- 変更しても勝敗・判断がほぼ変わらず、違いを試す理由にならない。
- 再プレイ度が2以下、または「もう一度」はあっても次に試す手が具体化しない。
- 3行動のうち一つが常に優位で、GRAFTと同じ支配戦略へ戻る。

## プレイ手順

1. `https://garakuta-lab.pages.dev/echo/?seed=12` を初回として遊ぶ。
2. 結果画面で回答し、画面に出た前回の6手を確認する。
3. 同じURLのまま「この残響を書き換える」を押し、少なくとも1手を意図的に変える。
4. 2走目の結果で、再プレイ度と「次に変えたい手」を記録する。

seedは検証上固定する。実際のゲームとしてランダム性を入れるかは、この仮説の判定後に別要因として試す。

## 判定後の分岐

- 成功：残響の仕組みだけを抽出し、より豊かな行動差（分岐、前回の失敗の利用、ゴーストとの競争）を一つずつ追加する。
- 失敗：ECHOを延命せず、次は「見えているリスクをどこまで押すか」を主役にする別試作へ移る。
- 判定保留：面白さは低くないが再プレイ理由が言語化されない場合、UIの問題か構造の問題かを分ける短い対照版を作る。

### 1ラン目の感情マーカー

初回は前回の足跡がなく、`previousScore=null` の基準ランだった。

- stage-1で「勢い」2回、「迷い」1回。
- 「これはどうやって感想を送ればいいんだろう。「閃き」などと自由入力はどちらかしか送れない？」というメモ。
- 「『賭ける』は熱<圧なら常に成功？それともランダム？」というメモ。
- アンケートは面白さ1、再プレイ2。「全部刈り取り戦略」を次の案として残した。

このため、初回の低評価にはゲーム構造だけでなく、(a) 感情マーカーUIの送り方が分かりにくい、(b) 「賭ける」の結果規則が分かりにくい、という計測・理解上の摩擦も含まれる。「勢い」2回は記録された事実として扱うが、これだけで強い快感とは解釈しない。

### 4ランを通した読み直し

- 1ラン目は、残響を使う前の基準ランとして、具体的な次案（全刈り取り）を生んだ。ただし面白さは1で、まずルールとUIの理解に注意が向いていた。
- 2ラン目で「前回と違うとボーナスがつく」ことを発見し、「なるほど新しい」という感情マーカーが出た。差分表示は発見を生む弱い信号になった。
- 3ラン目では「次で最高得点を目指す」という具体的な再試行が起きたが、面白さは1だった。これは反実仮想というより、スコア最適化の捨てランに近い。
- 4ラン目でスコアは36まで伸びたが、部品数の意味が分からず、再プレイ1・「もういいや」で終了した。

### 何が当たったか

- 前回と違う手に反応があること自体は発見になった。
- 低評価の初回でも、次に試す行動案（全刈り取り）は具体化した。
- ただし、これは「この区画の結果を変えたい」という反実仮想の持続ではなく、ルール理解後の差分ボーナス探索と最高点探索だった。

### 何が外れたか

- `違う手なら部品+2` は、前回を理解して比較する仕組みではなく、違う手を選べば必ず得をするボーナスになった。そのため「前回の自分を超えるのは当たり前では？」という指摘が出た。
- 部品の数に意味のある到達目標がなく、24・34・28・36が良いのか判断できなかった。
- 最高点を追う一時的な再試行は起きたが、面白さとは一致しなかった。
- 3ラン目以降、スコアが上がっても再プレイ理由が強くならず、4ラン目で「もういいや」となった。

### 判定

**ECHO 0.1は中心仮説を不採択。初回ランと感情マーカーを含めても、残響は発見と短期的な試行案を生むが、持続する再プレイ動機にはならなかった。**

今回の初回データから追加で残す学びは、「初回の低評価をそのままゲーム構造の失敗と解釈せず、ルール理解と感情記録UIの摩擦を分離する」こと。ただしECHO自体は延命しない。

残す学びは「前回との差分を表示すると、最初の発見と次の試行案は生まれうる」。捨てる学びは「差分へ固定ボーナスを付ければ、前回の自分との対戦になる」。

次はスコアではなく、帰還・救出・到達など意味のある目標と、見えているリスクをどこまで押すかを主役にした独立試作へ移る。ECHOへ戻る場合も、差分ボーナスではなく前回走行の実際の状態・失敗地点・目標達成状況を比較対象にする。
