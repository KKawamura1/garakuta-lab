# 同定機関 IDENT 0.1（2026-08-22 深夜）

## 【休止 2026-08-23】1ラン遊ばれて、面白さ1・また遊びたい1

> 「ただ最初にルール当てゲーム（それもめちゃ簡単）を当てるだけで、
> 　当てた後は普通の法則機関。めちゃつまらない。もうやりたくない」
> 「謎のルール当てゲームが挟まれるだけの法則機関」
> 当てた回数：**2回**（測り直した予測「1回並べれば候補1.8」と一致）

**当てやすさより、当てたあとに何も残らないことの方が本体である。**
作者は**当てる前に**こう書いていた：「ルールがわかった後もゲーム続くの？もう消化試合じゃん」。

知識アンロック系が成立している作品では、**得た知識が次の局面の手になる**
（`analysis/KNOWLEDGE_SURVEY.md`）。ここでは手にならない。法則は最初から効いていて、
当てても盤面は1も変わらないからである。**伏せることは、知識を報酬にしない。**

判定は `analysis/PREDICTIONS_2026-08-23.md`。交絡（同じランで無理ゲーを引いている）も書いた。

---

**主張：毎ラン引き直される未知なら、知識は尽きない。**

サーベイの型2（NetHack / DCSS の同定ゲーム）。
「赤い薬が何か」は毎回違うので、**覚えるのは事実ではなく確かめ方**になる。
知識ゲート型（Outer Wilds）が二度目を持てないのと、ここが決定的に違う。

## 何を変えたか

盤面は laws-0.3 とまったく同じ。**法則の名前と説明だけを伏せた。**

- 法則は「？？？」と出る
- 「法則を当てる」で13件から選ぶ。当たれば以後は名前も説明も出る
- **外しても罰は無い。何度でも言える**（等級と同じで、罰ではなく志）
- 位相表も予告も伏せていない。**手がかりは全部出ている**

## 当てられるのか（`analysis/identify.mjs`）

並びをK通り試したとき、**観測（勝敗・撃破巡回・残りHP）と矛盾しない法則の組が
91通りのうち何通り残るか。**

| 試した並び | 残る候補（平均） |
|---|---|
| 1通り | **24.8** |
| 3通り | 16.5 |
| 6通り | 2.9 |
| 12通り | **1.8** |

**12通り試すと、16組中9組は1つに絞れる。**残りも2〜4通りまで落ちる。
1通りでは24.8通り残るので、**最初から分かるわけでもない。**確かめる過程がある。

### ただし、これは上限である

91通りを**完全な記憶と完全な再現**で突き合わせた数字である。人はそうしない。
言えているのは「**情報が盤面に載っている**」ことまでで、
「人が当てられる」ことではない。載っていなければ当てさせるのは不当だが、
載っていても難しすぎることはあり得る。

そこは遊んでもらって測る。**何回言ったか（`answers.guesses`）と、
何を当てたか（`answers.identified`）が記録に残る。**

## 出す前に、**答えが画面に書いてあった**

伏せたつもりで公開したあと、画面の側から見直したら2か所から漏れていた。

1. **見出しが `ident-0.1:reflect+monotony` と出ていた。**版の名前に法則の id が入っている。
   この企画を触っている人なら reflect＋monotony が反射＋単調だと読める。**答えが常時表示されていた**
2. **遊び方の文面に「【このランの法則】」として名前と説明が並んでいた**

どちらも「伏せる」実装を法則の札にしか入れていなかったせいである
（学び#58：データに在ることと、画面に出ることは別）。
見出しは `publicId`（法則を含まない名前）を出すようにし、遊び方の文面からも外した。
記録と通報には法則入りの id を使い続ける——あとで突き合わせるのに要るし、そこは遊ぶ側が見ない。

`analysis/smoke-ident.mjs` が、画面に出す名前と遊び方の文面に法則が入っていたら落とす。
`analysis/browser-check.mjs` は、**実際の画面のどこにも法則の id と名前が出ていないこと**を見る。

## **測り直したら、当てるのは一瞬だった**（2026-08-23 深夜）

上の表（1通りで24.8、12通りで1.8）は、**観測を「勝敗・撃破巡回・残りHP」だけに絞って**測っていた。
**それは実際の画面より狭い。**

位相表は実機のログから描いていて、**枠ごと・巡回ごとの実際の値**を出す。
さらに法則が掛けた倍率を `×2` のように札で出している。

観測をそこまで広げて測り直した結果：

| 見えているもの | 1通り試す | 3通り | 12通り |
|---|---|---|---|
| 勝敗・巡回・残HP だけ | 24.8 | 16.5 | 1.8 |
| ＋位相表の倍率（`×2` の札） | **1.8** | **1.0** | 1.0 |
| ＋位相表の値のみ（札は伏せる） | **1.8** | **1.0** | 1.0 |

**1回並べれば決まる。**しかも倍率の札を伏せても変わらない——
**枠ごとの値だけで足りてしまう。**

### だからこの版は、いまの形では成立しない

位相表は、この企画で**遊べるようにした当の仕掛け**である（PHASE 0.1 で入れた）。
実機の値をそのまま描くからこそ、遊ぶ側は並べ替えの意味を読める。

**その表がある限り、法則は伏せられない。**表を潰せば同定は成り立つが、
それは「同定が面白いか」ではなく「表を潰すと何が起きるか」を試すことになる。
**一度に二つ変えたら、どちらのせいか言えない。**

### 作者の判断を仰ぐところ

- **このまま出しておく**（当てるのは一瞬だと分かった上で、それでも遊んで感触を見る）
- **畳む**（型2はこの interface とは相性が悪かった、として記録に残す）
- **形を変える**（位相表が映さないもの——たとえば敵側の性質——を伏せる。
  ただしそれはサーベイの型3で、繰り返しに弱いと分かっている）

**勝手に決めない。**版を消すのも、作者の時間の使い道を私が決めることになるので。
