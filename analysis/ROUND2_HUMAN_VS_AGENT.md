## P3′ 装甲をめぐる不一致は、情報欠落ではなかった — 判定：エージェント固有の癖

第1回で、エージェント4体全員が「装甲は罠」と結論し、局所探索200ランおよび人間の観測と食い違った。
仮説は「巡回ログを見せていなかったせい」だった。**巡回ログを見せた条件でも、食い違いは消えなかった。**

| 最終構成の防御部品 | 勝 | 敗 |
|---|---:|---:|
| あり | **3** | 0 |
| なし | 0 | **3** |

6ランで完全に分離した。人間は2ランとも即席装甲機を入れて2勝。エージェントは4体中1体だけが入れ、その1体だけが勝った。
`analysis/armor-probe.mjs` の「防御禁止で200シード0勝」とも整合する。

したがってP3′は「近づかなかった」側で決着する。エージェントは第1戦の余剰装甲という局所的な証拠から
「装甲は無駄」へ一般化し、敵の攻撃力が伸びる終盤までその一般化を保持する。人間はしなかった。
代理として使う際は、この癖を既知のバイアスとして扱う必要がある。

## P2′ 決着点の検出 — 判定：合格、ただし片側だけ

報酬経路の全探索が示す客観的な決着点は、自己申告と±1戦で一致した。

- agent s14-b：申告 第5戦 / 客観 第4報酬の後に消滅
- agent s89-b：申告 第4戦 / 客観 第3報酬の後に消滅
- agent s89-a：申告 第6戦 / 客観 最後まで勝ち筋あり（本人も「装甲を1枚残していれば勝てた」と報告しており、実際に勝ち筋は残っていた）
- 人間 seed89：申告 なし / 客観 最後まで勝ち筋あり

一方、人間 seed14 の申告「第3戦で決まった」は、この探索では検出できない。**探索が測るのは「負けが確定した時点」だけ**で、

**決着点は片側では足りない。** 負け確定は反実仮想探索、勝ち確定は死に時間で、両方を並べて初めて全6ランを覆えた。

## 最大の発見：作者が支配戦略を知っているほど、この核はつまらなくなる

**人間は2ランとも勝ち、再プレイ度は seed14 が1、seed89 が3。エージェントは3敗1勝で、再プレイ度3〜4。**

同一盤面での比較が要点である。**seed14 では、本人が1、同じ盤面のエージェント2体がともに3を付けた。**
seed89 では本人3・エージェント4/4で、差はほとんどない。したがって「知っているほどつまらない」は、
支配戦略を綺麗に実行できた seed14 で起きた現象であり、2ラン全体の傾向としては主張できない。

seed14 の本人の記録は決定的である。

- runStory：「いつものパターンに持ち込めた回」
- friction：「勝ち確定してつまらない」
- 決着点：「3かな？　装甲2個目を引いたとき」
- 結果：全6戦を通じてHP損失2、最終HP 30/30

不安の申告も6戦中5戦が「なし」で、感情マーカーは2件だった。第4戦だけ「負けそう」と予測して外している（実損2）。

seed89 は辛勝で、「最後ギリギリで勝てたところ。装甲6だとやや不足するのがこのゲームの良いところだと思った」という
肯定的な最高瞬間が記録され、再プレイ度は3だった。**無傷勝利より辛勝のほうが高い**という並びは、
#21の「未解決の不安を伴う理解更新」が良いという結論と同じ向きである。

学習ログ#2・#3・#8が記録した装甲支配は、解決していない。そして**作者本人はその支配戦略を既に知っている**。
初見のエージェントは同じ盤面で苦戦し、より高い再プレイ度を付けた。

これは「エージェントが人間より下手」という話ではない。**同じ盤面の面白さが、支配戦略を知っているかどうかで反転する**という観測である。
企画の目的は「中身を知った後もiPhoneで繰り返し楽しめるゲーム」なので、この核はその目的を満たしていない。

## 示唆

1. **数値調整では戻らない。** 学習ログ#6・#8が既に結論している。装甲を弱くすると「引けなければ負け」になるだけである。
2. **生成契約（勝ち筋1本以上）はこの問題を解かない。** 契約は死んだ盤面を落とすだけで、支配戦略の存在には触れない。
   seed14 は勝ち筋が最後まであり、契約を通る。それでも再プレイ度1だった。
3. **次の候補は、支配戦略が固定されない構造を持つべきである。** 第1回・第2回を通じて、6ラン中6ランの最終構成で
   出力首位が違法砲身だった。部品の引きが違っても収束先が同じという事実のほうが、勝率より重い。
4. **エージェントの装甲バイアスは、そのまま「初見プレイヤーの誤学習」の測定器として使える。**
   序盤の証拠が終盤に嘘になる設計を検出したいなら、初見エージェントを走らせて、その一般化が破綻するかを見ればよい。

## 訂正と、その原因になった計測欠陥（2026-08-19）

初回の集計では「人間は2ランとも再プレイ度1」と書いた。**これは誤りだった。**

同一視点モードのアンケートで、選択式の項目が既定値を持っていた。`replay` は触らなければ 1、`pivot` は「あった」、
`settledAt` は空欄なら「なし」に置換されて記録される作りで、**未回答と回答を区別していなかった**。
本人の事後申告は seed14 が1、seed89 が3である。

無効化した回答：

| ラン | replay | pivot | settledAt |
|---|---|---|---|
| seed14 | 記録1・申告1で一致、採用 | 無効 | 自由記述あり、採用 |
| seed89 | 記録1は無効、申告3を採用 | 無効 | 無効 |
| seed29254（第1回） | 無効 | 無効 | 無効 |

影響を受けない結論：

- **P3′（装甲の採用と勝敗、3勝0敗／0勝3敗）** は勝敗と最終構成から出しており、アンケートを使っていない。
- **P2′の客観側**（報酬経路の全探索）と `deadTime`（予測とHP損失から計算）も同様。
  seed14 の `deadTime=2` と「勝ち確定してつまらない」という自由記述は、どちらも既定値の影響を受けない。
- **ARC 0.1 の勝ち筋ゼロ率24%** と生成契約の比較も、アンケートを使っていない。

seed29254 のランについては、再プレイ度1という数値は無効になるが、
「全1024経路が敗北」「開始時点で勝ち筋ゼロ」という客観と、自由記述「装甲引けなかった回」は有効である。

**手続き上の示唆:** 選択式の計測項目に既定値を置かない。未回答は未回答として残す。
本編（`index.html`）はラジオボタンで未選択のまま送るため同じ欠陥はなく、
これは同一視点モードを急いで作ったときに持ち込んだ退行だった。
