# 別ルールセットの試作：BUS「帯域機関」

実施日：2026-08-19 / 目的：ARC 0.1 で測定された支配戦略の固定（学習ログ#23）を、構造で崩せるか

人間の初見は一度も使っていない。すべて `analysis/ruleset-compare.mjs` による機械評価である。

## 出発点

ARC 0.1 の問題は、勝率でも公平さでもなく **収束** だった。第1回・第2回の人間＋エージェント6ランすべてで
最終構成の出力首位が違法砲身であり、局所探索60ランでも首位部品の最頻シェアは0.417だった。
そして防御部品を最終構成に残したランが3勝0敗、残さなかったランが0勝3敗だった。

## 0.1：防御を有料にする → 失敗

**仮説：** 防御が無料の乗数だから支配する。すべての部品が「帯域」という共通資源を消費し、
遮蔽が巡回をまたいで残らなければ、「守る＝撃つ回数が減る」となって一択が消える。

**結果：悪化した。**

| | ARC 0.1 | BUS 0.1 |
|---|---:|---:|
| 首位部品の最頻シェア | 0.417 | **0.75**（遮蔽板 45/60） |
| 死に時間 | 0.083 | 0.400 |
| 問題の連鎖 | 0.511 | 0.187 |

**学び：** 防御が無料だったことが問題ではなかった。**生存そのものが乗数**だったことが問題だった。
HPが尽きたら終わる以上、1巡生き延びれば列1本分の出力が丸ごと増える。帯域を払ってでも遮蔽を買うほうが得になる。
値段を付けても交換レートが有利なら支配は消えない。

## 0.2：制限巡回を入れる → 支配が移っただけ

**仮説：** 各戦闘を敵ごとの制限巡回で打ち切れば、生き延びても巡回は増えない。防御は乗数から線形の資源へ落ちる。

**結果：機構は効いたが、支配の位置が動いただけだった。**

遮蔽板の首位は 45/60 → 6/60 へ落ちた。代わりに双撃腕29＋重鎚21で、火力が支配した。勝率は0.05まで落ちた（調整不足）。

**学び：** **勝利条件がひとつしかない限り、支配軸もひとつになる。** 撃破しか勝ち方が無いなら火力が正解になり、
生存しか負け方が無いなら防御が正解になる。軸を潰しても、別の軸が正解になるだけである。

## 0.3：敵ごとに問いを変える → 部分的に成功

**仮説：** 敵ごとに勝利条件を変える。「撃破型」は制限巡回のうちに削り切る、「耐久型」は制限巡回を生き延びれば勝ち。
一つの構成で両方は満たせないので、どちらへ寄せるかと、報酬で何を補うかが判断になる。

**結果：狙った軸では成功、他は悪化。**

| | ARC 0.1 | BUS 0.3 |
|---|---:|---:|
| 勝率（局所探索） | 0.450 | 0.567 |
| **首位部品の最頻シェア** | 0.417 | **0.383** |
| 首位部品の内訳 | 即席装甲機25 / 違法砲身24 | **重鎚23 / 遮蔽板21** |
| 死に時間 | **0.083** | 0.700 |
| 苦戦予期率 | **0.152** | 0.028 |
| 問題の連鎖 | **0.511** | 0.133 |
| 最終構成の種類（1シードあたり） | **0.600** | 0.317 |
| 採用率5%未満の部品 | **1** | 3 |

首位部品が攻撃と防御へ割れたのは設計意図どおりである。ARCでも上位2つは装甲機と砲身に割れているので、
最頻シェアの差（0.417→0.383）は小さい。**明確に良くなったとは言えない。**

一方、死に時間0.7・問題の連鎖0.133・構成の種類0.317は、いずれもARCより明確に悪い。
帯域の経済に関わる部品（分配器・逆流弁・過負荷炉・拡張架）は採用率がほぼ0で、死に部品になっている。

なお死に時間と苦戦予期率は、局所探索プレイヤーの**予測関数**から計算される。制限巡回と耐久型が入ったことで
その予測が「圧勝」に寄っている可能性があり、ゲームの性質ではなく評価器の癖を見ている恐れがある。切り分けが要る。

## 現時点の判定

**BUS 0.3 は人間テストに出す段階にない。** 収束は少し良くなったが、死に部品が3つあり、問題の連鎖が
ARCの4分の1で、死に時間が8倍である。この状態で作者の初見を1回使うのは割に合わない。

得られたものは、ゲームそのものより **設計上の因果** である。

1. 支配は「その要素が無料だから」ではなく「その要素が乗数だから」生まれる。
2. 乗数を潰しても、勝利条件がひとつなら別の軸が乗数になる。
3. 支配を割るには、**勝利条件そのものを複数持つ**必要がある。0.3でそれは実際に起きた。
4. ただし勝利条件を割ると、判断の連鎖と構成の多様性が犠牲になった。ここはまだ解けていない。

3回の試作を、人間の初見をゼロ消費で回せた。この点だけは、エージェント評価の基盤が機能した証拠である。

# 第2の別ルールセット：PHASE「位相機関」

実施日：2026-08-19 / BUSで三つ同時に変えて切り分けに困った反省から、**変更を一点に絞った**。

## 変更点

各部品は作動周期を持ち、**置いたスロットで作動する巡回がずれる**。
周期Pの部品を枠iに置くと `(巡回-1) % P === i % P` の巡回にだけ動く。
敵にも攻撃周期があり、間隔が空く敵ほど一撃が重い。遮蔽は巡回をまたいで残らない。

狙いは、防御を「常に正しい」から「**攻撃と位相が合った時だけ正しい**」へ落とすこと。
BUS 0.1で「有料にする」だけでは崩れず（乗数のままだった）、0.2で乗数を消すと支配が火力へ移った。
ここでは乗数を残したまま、発動条件を配置に依存させる。

副次的に、同じ部品を複数持っても、同位相に置けば単発の山、ずらせば毎巡の安定になる。
どちらが正しいかは敵で変わる（命中上限のある敵は山を無駄にし、命中下限のある敵は小突きを潰す）。

## 結果（局所探索60シード）

| 指標 | ARC 0.1 | BUS 0.3 | **PHASE 0.1** |
|---|---:|---:|---:|
| 勝率 | 0.450 | 0.567 | 0.533 |
| 素朴方針の勝率 | 0 | 0.067 | **0** |
| **首位部品の最頻シェア** | 0.417 | 0.383 | **0.317** |
| **首位部品の種類** | 6 | 6 | **8** |
| **最終構成の種類** | 0.600 | 0.317 | **0.700** |
| **最多構成への集中** | 0.117 | 0.317 | **0.083** |
| **採用率5%未満の部品** | 1 | 3 | **0** |
| **無傷勝利率** | 0.525 | 0.544 | **0.411** |
| 死に時間 | **0.083** | 0.783 | 0.683 |
| 苦戦予期率 | **0.152** | 0.028 | 0.014 |
| 問題の連鎖 | **0.511** | 0.133 | 0.335 |

**収束と多様性は全項目でARCを上回った。** 死に部品がゼロなのは3案で初めてである。
圧力（無傷勝利率0.411）もARCの0.525より良い。

**悪いのは死に時間・苦戦予期率・問題の連鎖の3つ。** ただしこの3つは、いずれも
局所探索プレイヤーの**予測関数**を経由して計算される。ルールが変わると予測の当たり方も変わるため、
ゲームの性質ではなく評価器の癖を見ている可能性がある。切り分けが必要。

## 調整で分かったこと

- 難易度は崖だった。敵1.4倍で勝率0.5、1.7倍で0。位相が合うか合わないかで戦闘が二値になるため。
- **無傷勝利率が難易度にほとんど反応しなかった。** 位相が合えば全遮断、合わなければ全通過だったため。
  遮蔽量を敵攻撃より小さくして部分遮断にしたところ、初めて反応するようになった（0.7→0.41）。
- 最終値は 敵HP×1.2・敵攻撃×1.2・遮蔽×0.65。

## 手続き上の事故

遮蔽量を振る調整を一度、**無効なまま完走させた。** `simulateBattle` がモジュール直下の `PARTS` を
直接参照していたため、ルールセット側で差し替えた部品が反映されず、遮蔽倍を変えても結果が1文字も動かなかった。
2つの設定で結果が完全一致したことで気付いた。`parts` を引数化して修正済み。

**調整実験は「効かないのに完走する」形で失敗しうる。** 同じ入力で違う設定が同じ結果を出したら疑う。
